# 2. The Overlap Finder

Spots the tools that secretly do the same job so you stop paying twice.

Act as a software efficiency consultant who audits the tool stacks of solo business owners and small teams. Here is the full list of subscriptions I pay for and what I use each one for: [PASTE THE LIST FROM THE PREVIOUS PROMPT AND ADD A FEW WORDS ON WHAT EACH TOOL DOES FOR YOU]. Group them by the job they actually do, like design, writing, scheduling, storage, email, and payments. Show me every place where two or more tools overlap and do the same job, and tell me which one in each group is the strongest and which are redundant. Then estimate how much I could save each year if I kept only the best tool in each group.
