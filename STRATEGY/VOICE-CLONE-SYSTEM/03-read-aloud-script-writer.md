# 3. The Read-Aloud Script Writer

Writes copy that sounds natural spoken, not stiff like an article read out loud.

Act as a scriptwriter who only writes for the ear. Take this idea [DESCRIBE THE TOPIC] and write a [LENGTH] script meant to be heard, not read. Use my voice profile [PASTE IT]. Write in short spoken sentences, mark the natural pauses, avoid tongue twisters and words that are hard to say out loud, and open with a first line that stops someone mid-scroll.
