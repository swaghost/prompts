# Single-File Website Builder

## Prompt

```
Build a complete website for [BUSINESS TYPE] as a single self-contained HTML file I can open in a browser. Write all the copy yourself, make every button and link work, and make it mobile-first. Use one accent colour: [ACCENT COLOUR]. Use no stock photos; use original CSS visuals, supplied assets, or clearly marked placeholders. Include a hero, services, testimonials only if provided, FAQ, and contact form. Then tell me how to put it live free in 5 minutes.
```

## Output Requirements

- Keep CSS and JavaScript self-contained unless a dependency is explicitly requested.
- Use one coherent accent colour with accessible contrast.
- Make every navigation link, button, form state, and interactive control work or clearly explain its integration requirement.
- Use honest placeholders instead of fabricated testimonials or business claims.
- Provide concise free deployment steps for a static host and explain any form limitations.
