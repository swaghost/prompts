# Website Booking Page Builder

## Prompt

```
Build me a booking page as one HTML file where someone picks a service, picks a time, and submits their details. Send the submissions to my email: [EMAIL]. Use my business details: [BUSINESS, SERVICES, AVAILABILITY, BRAND STYLE]. Make it clean, mobile-first, accessible, and easy to use. Add validation, clear availability states, a success confirmation message after booking, and a useful fallback if direct email submission cannot work without a backend.
```

## Output Requirements

- Include service selection, date/time selection, contact details, validation, and confirmation state.
- Make the page usable on mobile and keyboard accessible.
- Explain the email-delivery limitation of a static HTML file and provide the simplest secure integration option.
- Do not expose API keys, passwords, or private credentials in client-side code.
