# Free Website Deployment Walkthrough

## Prompt

```
Walk me through putting this website live for free, step by step, as if I've never done it before. Tell me exactly what to click and what to type. If I need an account somewhere, say which one and why. Explain where to upload the HTML file, how to set the correct entry file, how to preview the result, and how to get the public URL. Stop after each step until I say done. Do not ask me to share passwords, API keys, or private tokens.
```

## Output Requirements

- Choose one free static-hosting path appropriate for a single HTML file.
- Provide one action per step with exact labels where known.
- Stop after each step and wait for confirmation.
- Include preview, troubleshooting, update, and rollback guidance.
- Explain that server-side forms, payments, databases, and email delivery require separate secure services.
