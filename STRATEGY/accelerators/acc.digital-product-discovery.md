# Digital Product Discovery Prompts

## Purpose

A practical prompt set for turning an existing skill or body of knowledge into sellable digital products. Use the prompts independently for focused exploration or run them in sequence from idea discovery through product validation.

## Recommended Discovery Flow

```text
1. Find ideas -> 2. Simplify products -> 3. Build the ladder -> 4. Choose a fast launch -> 5. Design the mini-course -> 6. Validate demand -> 7. Mine existing knowledge
```

## Prompt 1: Find Profitable Passive-Income Ideas From a Skill

### Prompt

```
Act as a digital product strategist. My skill is [SKILL]. My experience level is [BEGINNER / INTERMEDIATE / EXPERT]. My target audience is [AUDIENCE]. Give me 15 passive-income product ideas that I can create from this skill.

For each idea, include:

- What the product is
- Who buys it
- What problem it solves
- How difficult it is to create
- How quickly I can launch it
- The best platform to sell it on

Rank the ideas from most promising to least promising based on buyer demand, ease of creation, speed to launch, and realistic income potential. Explain the assumptions behind the ranking.
```

## Prompt 2: Turn a Skill Into Beginner-Friendly Digital Products

### Prompt

```
Help me turn my skill [SKILL] into simple digital products I can sell online. My audience is [AUDIENCE]. Suggest 10 products that do not require advanced technical skills. Focus on products I can create using simple tools like Google Docs, Canva, Notion, or spreadsheets.

For each one, give me:

- Product name
- Format
- Price range
- Creation steps
- Why people would buy it
- The beginner result or quick win it should deliver
- The simplest tool stack needed to create and deliver it
```

## Prompt 3: Create a Product Ladder From Low-Ticket to Premium

### Prompt

```
Act as a product ecosystem expert. My skill is [SKILL] and my audience is [AUDIENCE]. Build me a 4-tier product ladder:

1. Low-ticket offer
2. Mid-ticket offer
3. Digital premium offer
4. Recurring offer

Each offer should naturally connect to the next. For each tier, explain:

- What to sell
- Price range
- Delivery format
- Buyer type
- Core outcome
- How it leads to the next product
- The proof or milestone that shows the buyer is ready to advance
```

## Prompt 4: Find the Fastest Passive-Income Product to Launch in 7 Days

### Prompt

```
I want a passive-income product I can create in 7 days using my skill in [SKILL]. I can dedicate [X] hours per day. My audience is [AUDIENCE]. Give me 7 product ideas I can finish quickly.

For each, include:

- Product concept and target buyer
- Day-by-day creation plan
- Necessary tools
- Estimated selling price
- Expected difficulty
- Fastest path to a first sale
- The main risk or bottleneck

Highlight the best option for speed, simplicity, and first sales. Explain why it is preferable to the other options and state the cheapest way to test it before fully building it.
```

## Prompt 5: Turn Knowledge Into a Sellable Mini-Course

### Prompt

```
Act like an instructional designer skilled in turning knowledge into products. My area of expertise is [TOPIC]. My target audience is [PROFILE]. Create the complete structure of a 5-module mini-course that I can sell for $47-$97.

Include:

- Course title and hook
- The main promise
- The transformation and measurable completion outcome
- The content of each module
- Practical deliverables, exercises, or templates
- The recommended lesson order
- Common beginner mistakes to address
- 3 ways to get the first 10 buyers without paid advertising
```

## Prompt 6: Validate What People Will Actually Pay For

### Prompt

```
Act as a market validation researcher. I want to sell a passive-income product based on [SKILL] to [AUDIENCE]. Give me 10 product ideas, then rate each idea from 1 to 10 on:

- Demand
- Urgency
- Ease of creation
- Uniqueness
- Likelihood of purchase

After that, tell me which are the top 3 ideas most likely to generate income the fastest and explain why. For each top idea, give me the cheapest ethical validation test, the evidence to collect, the strongest objection, and the signal that would justify building the product.

Do not treat guesses as market evidence. Clearly separate assumptions, observed demand, and evidence that still needs to be gathered.
```

## Prompt 7: Build a Product From Existing Knowledge

### Prompt

```
I do not want to start from scratch. Help me turn what I already know about [SKILL] into digital products.

First ask me about:

- What tasks I often repeat
- What I often explain
- What shortcuts I use
- What mistakes I help people avoid
- What frameworks I already follow
- What questions people repeatedly ask me
- What results I have already helped create

Then turn that knowledge into 10 passive-income product ideas with:

- Product title
- Ideal client or buyer
- Problem solved
- Clear outcome
- Best format
- What existing knowledge or asset it uses
- Fastest credible way to create it
- Why the buyer would pay for it

Rank the ideas by evidence of demand, speed to create, usefulness, and potential to become part of a larger product ecosystem.
```

## Shared Output Standards

Apply these rules when using any prompt in this collection:

- Focus on a specific buyer, urgent problem, and measurable outcome.
- Prefer products that can be created with simple tools and delivered digitally.
- Distinguish passive delivery from passive demand generation; every product still needs distribution and support.
- Avoid promising guaranteed income or calling an unvalidated idea profitable.
- Rank opportunities using explicit assumptions and evidence rather than novelty alone.
- Keep the first product narrow enough to create and test quickly.
- Identify what the product does not solve so the promise stays credible.
- Respect copyright, licensing, privacy, consumer-protection, and platform rules.

## Prompt Combination Examples

### Skill to First Product

Run Prompt 1, then Prompt 2, then Prompt 6. Use the top validated idea in Prompt 4.

### Product Ecosystem

Run Prompt 7, then Prompt 3, then Prompt 5 for the premium educational tier.

### Fastest Test

Run Prompt 4, validate the winner with Prompt 6, then create only the minimum deliverable needed for a pre-sale or small buyer test.
