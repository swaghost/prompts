# Reference Website Layout Extractor

## Prompt

```
Here's a screenshot of a site I like: [UPLOAD SCREENSHOT]. Rebuild this as a working HTML page using my content instead: [DESCRIBE YOUR BUSINESS]. Match the layout, hierarchy, spacing, and interaction intent, but use my own colours, copy, imagery, and branding. Do not copy their branding, logo, proprietary text, or distinctive assets. Create an original implementation inspired by the reference structure.
```

## Output Requirements

- Extract layout principles, section order, spacing rhythm, responsive behaviour, and interaction patterns before building.
- Replace all brand identity, copy, imagery, and proprietary assets with original alternatives.
- Deliver a working, responsive page rather than a static screenshot imitation.
- Explain which elements were structurally inspired by the reference and which were redesigned for the user's business.
