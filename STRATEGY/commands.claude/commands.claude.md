# Claude Command Library

Quick reference for the available Claude slash commands, grouped by the job they help complete.

## Content Creation

| Command     | Use it for                                              |
| ----------- | ------------------------------------------------------- |
| `/HOOK`     | Write better content openings and attention hooks       |
| `/CAROUSEL` | Turn ideas into structured carousel posts               |
| `/THREAD`   | Create viral thread-style content                       |
| `/CAPTION`  | Improve captions for clarity, retention, and engagement |
| `/REWRITE`  | Rewrite weak content into a stronger version            |

## Learning and Understanding

| Command            | Use it for                                          |
| ------------------ | --------------------------------------------------- |
| `/EL10`            | Learn faster with focused explanation and practice  |
| `/PRIMER`          | Master a topic from the fundamentals upward         |
| `/QUIZ`            | Test understanding and reveal knowledge gaps        |
| `/ANALOGY`         | Simplify complexity through useful comparisons      |
| `/FIRSTPRINCIPLES` | Break a concept down to its underlying fundamentals |

## Analysis and Decisions

| Command    | Use it for                                          |
| ---------- | --------------------------------------------------- |
| `/COMPARE` | Compare options using clear criteria and trade-offs |
| `/DECIDE`  | Make a decision with structured reasoning           |
| `/AUDIT`   | Audit a business, offer, process, or strategy       |

## Systems and Operations

| Command       | Use it for                                       |
| ------------- | ------------------------------------------------ |
| `/SYSTEM`     | Build repeatable systems and operating processes |
| `/AUTOMATION` | Automate repetitive workflows and handoffs       |

## Growth and Revenue

| Command  | Use it for                                               |
| -------- | -------------------------------------------------------- |
| `/CTA`   | Increase conversions with stronger calls to action       |
| `/GTM`   | Create go-to-market plans for products or offers         |
| `/SCALE` | Scale revenue, distribution, or a working business model |

## Recommended Command Flow

### From Idea to Published Content

`/PRIMER` -> `/ANALOGY` -> `/HOOK` -> `/CAROUSEL` or `/THREAD` -> `/CAPTION` -> `/CTA`

### From Question to Confident Decision

`/EL10` -> `/FIRSTPRINCIPLES` -> `/COMPARE` -> `/QUIZ` -> `/DECIDE`

### From Business Diagnosis to Growth

`/AUDIT` -> `/SYSTEM` -> `/AUTOMATION` -> `/GTM` -> `/SCALE`

### Command Selection Notes

- Use `/PRIMER` when the subject is unfamiliar; use `/EL10` when speed and retention matter most.
- Use `/ANALOGY` when the subject is technically complex or difficult to explain plainly.
- Use `/QUIZ` after learning to verify actual understanding instead of relying on recognition.
- Use `/COMPARE` when multiple options remain; use `/DECIDE` when a final choice is required.
- Use `/AUDIT` before changing a business or workflow so the intervention targets a real constraint.
- Use `/SYSTEM` for repeatability and `/AUTOMATION` for removing manual execution.
- Use `/CTA` at the conversion point, `/GTM` for launch strategy, and `/SCALE` after a working motion exists.
