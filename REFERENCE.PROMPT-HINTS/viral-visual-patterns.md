# Viral Visual Patterns

Visual techniques that drive engagement and shareability.

## Pattern 1: Seamless Loop

Loopable motion, seamless start and end, continuous visual flow

## Pattern 2: Unexpected Transition

Unexpected transition between scenes, snap or match cut effect

## Pattern 3: Contrast Dynamics

Contrast-based visuals (light vs dark, fast vs slow, calm vs chaotic)

## Pattern 4: Rhythmic Repetition

Repetitive pattern that builds rhythm and keeps attention

## Pattern 5: Visual Escalation

Visual escalation each frame more intense than the last
