# How to Use These Prompt Hints

## Best Practices

**Don't use all 20.**  
**Pick 2-3 per reel:**

- **One hook** - Choose an attention-grabbing opening
- **One motion style** - Select a camera movement approach
- **One structure** - Pick a narrative framework

## That's enough to:

- Hold attention
- Increase retention
- Improve performance

---

## Strategy

Less is more. Combining too many techniques can feel overwhelming or disjointed. Focus on executing a few elements well rather than attempting everything at once.
