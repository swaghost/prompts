🎭 A. Human Motion (Actors)
Macro‑Movement
walks / runs / charges / retreats

crosses frame (L→R or R→L)

approaches camera / backs away

circles / sidesteps / paces

Micro‑Movement
glances / looks over / scans

fidgets / shifts weight / taps

inhales sharply / exhales slowly

tightens jaw / softens gaze

Gesture
reaches / grasps / clutches / releases

points / waves / signals

covers face / wipes brow

Posture
stands tall / slumps / hunches

leans in / leans back / recoils

opens posture / closes off

🎨 B. Spatial Behavior
foreground / midground / background

center‑framed / edge‑weighted

profile / three‑quarter / over‑the‑shoulder

isolated in negative space / crowded by environment

🌫️ C. Visibility & Focus
emerges into focus / falls out of focus

silhouetted / backlit / partially obscured

revealed / concealed / masked by shadow

⚙️ D. Object Motion
slides / rolls / swings / drops

clatters / shatters / skids / veers

drifts / floats / sways / ripples

billows / flickers / vibrates
