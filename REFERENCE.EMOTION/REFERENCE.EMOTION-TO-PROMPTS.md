# Emotion To Prompts Reference

Use this table to create a character emotion board for image or video generation. Each row is a concise facial-performance direction derived from [Emotion-To-FACS Cross-Reference](REFERENCE.EMOTION-to-FACS.md) and [FACS Cheat Sheet](../REFERENCE.EMOTION.FACS/FACS-cheat-sheet.md).

## Operating Rules

- Use the same character reference, identity lock, camera, lens, lighting, wardrobe, and framing for every board row. Change the facial performance only.
- Treat the linked FACS combinations as observable starting directions, not proof of an internal emotional state. Use the plain-language instructions in this table inside generation prompts.
- `Low`, `moderate`, and `high` intensity describe amplitude. Add onset, hold, and release when animating the expression.
- For complex states with no fixed facial code, use the named contextual cues rather than forcing a complete basic-emotion pattern.
- Every reproduction prompt assumes: `same character identity, same pose and composition, face unobstructed, natural skin texture, no text, no logos, no extra objects`.

## Prompt Assembly Pattern

For a new board row, preserve this order:

`same character identity and reference lock` + `same framing, lighting, wardrobe, and background` + `observable brow/eye/cheek/lip/jaw movements` + `gaze/head behavior` + `intensity, onset, hold, and release` + `natural anatomy and hard negatives`.

## Validation Note

These prompts are validated for consistency with the AU directions and interpretation boundaries in the linked FACS references. They are creative generation prompts, not clinical emotion classifiers or a substitute for formal FACS coding. Test the selected prompt with the target image or video model and adjust intensity wording for that model's response.
