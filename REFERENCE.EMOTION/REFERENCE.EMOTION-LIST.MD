## Usage Notes

**For Creative Work:**

- Layer emotions for depth (e.g., "nostalgic yet hopeful")
- Consider intensity levels
- Mix compatible emotions for nuance
- Use atmospheric emotions for setting

**For Character Development:**

- Choose emotions that reveal character
- Show emotional contradictions
- Track emotional arcs
- Use subtle emotions for sophistication

**For Prompts:**

- Be specific rather than generic
- Combine emotions for uniqueness
- Consider cultural context
- Match emotion to visual/narrative tone

**For AI Image Generation:**

- Primary emotions read clearly
- Subtle emotions need context
- Combine with facial expressions
- Use atmospheric emotions for mood

## Emotion Intensity Scale

**1-2: Mild**
Slight, faint, barely noticeable

**3-4: Moderate**
Noticeable, present, felt

**5-6: Strong**
Pronounced, clear, affecting behavior

**7-8: Intense**
Powerful, consuming, hard to hide

**9-10: Overwhelming**
All-consuming, overpowering, extreme
