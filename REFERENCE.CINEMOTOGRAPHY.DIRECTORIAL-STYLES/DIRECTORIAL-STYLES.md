# Directorial Styles Reference

This reference describes recognizable craft tendencies associated with 100 influential directors. Use these as analytical starting points for image and video prompts, not as instructions to copy a living artist's exact work. Combine a director's craft cues with an original subject, setting, story, and visual intention.

## Directorial Style Prompt Formula

`directorial grammar` + `camera and lens behavior` + `composition and blocking` + `lighting and color` + `production design` + `editing rhythm` + `sound strategy` + `performance direction` + `theme or emotional effect` + `original scene action`.
