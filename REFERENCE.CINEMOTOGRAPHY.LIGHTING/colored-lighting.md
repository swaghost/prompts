# Colored Lighting

## Description

Colored lighting uses gels, filters, or colored light sources to introduce specific hues into the illumination, creating stylized, artistic, or emotionally coded atmosphere. Multiple colored lights can create complex, vibrant aesthetics or subtle mood enhancement through color psychology.

## Usage

**Emotional Purpose:** Conveys specific emotions through color psychology (blue=cold/sad, red=passion/danger, purple=mystery, etc.). Creates stylized, artistic atmosphere.

**Psychological Purpose:** Uses color to code emotional states, environmental conditions, or narrative themes. Associated with music videos, science fiction, cyberpunk aesthetics, and contemporary commercial work. Makes visual storytelling more expressive.

**Physical Purpose:** Creates artistic separation, establishes mood quickly, adds production value and style. Ideal for music videos, fashion editorial, sci-fi content, contemporary portraiture, and creating bold visual identity. Enables creative color grading in-camera.
