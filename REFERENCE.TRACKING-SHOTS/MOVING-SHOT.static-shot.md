# Static Shot

## Shot Group

Specials (not any of the others)

## Description of Resulting Shot

A locked-off static shot holding one fixed camera position for the full clip with no movement, maintaining the same angle, height, lens distance and composition throughout.

## Usage

Used for establishing stability, creating tension through stillness, allowing subject movement to dominate the frame, or providing clean plates for VFX work. Essential for documentary interviews, formal compositions, and moments requiring audience focus without camera distraction.

## Video Prompt

**Camera:** locked-off static shot.

**Movement:** hold one fixed camera position for the full clip.

**Speed:** still and steady.

**Framing:** keep the same angle, height, lens distance and composition.

**End:** finish with the same framing and camera position.
