# Waviboy Effect Pack: Material Transformation Workflow

**Source:** waviboy.com/effect-pack  
**Model:** Nano Banana Pro (Gemini 3 Pro Image)  
**Primary Mode:** Image Edit (not text-to-image)

---

## Overview

This guide explains how to run the Waviboy material-style transformations while preserving the original photo composition. The core technique is to convert the subject into a new material or medium (chrome, mosaic, engraving, glass, thermal, etc.) while locking pose, framing, and composition.

---

## Non-Negotiable Rules

1. **Use image edit, not text-to-image.**
2. **Always keep the final lock line:**
   - _“Keep the pose, silhouette, framing and composition exactly as they are.”_
3. If output is too conservative, append:
   - _“abandon the original rendering entirely”_
4. Choose effect based on source image structure:
   - Faces: engraving/stained glass
   - Hard silhouettes: neon/topographic
   - Organic shapes: ink in water/blown glass

---

## How to Run (Recommended)

1. Upload your original image to Nano Banana Pro.
2. Paste one effect prompt.
3. Ensure lock line remains at the end.
4. Generate v1.
5. If too weak, regenerate with:
   - _“abandon the original rendering entirely”_
6. Export best version and repeat for other effects.

---

## Quality Checklist

- Subject remains in same pose/framing/composition
- Material behavior is physically believable
- Effect-specific details are visible (lead came, hatching, caustics, stitches, etc.)
- Background treatment matches effect instructions
- No identity drift (unless intentionally abstracted)

---

## Common Mistakes

- Removing the composition-lock line
- Running in text-to-image mode
- Picking effects that clash with photo geometry
- Accepting first timid output without regeneration
