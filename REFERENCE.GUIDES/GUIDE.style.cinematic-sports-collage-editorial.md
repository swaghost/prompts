# Cinematic Sports Collage: Universal Editorial Poster Guide

**Source:** biblioteca-esportes-pro.marquin017.chatgpt.site (#cinematic-sports-collage)  
**Prompt Type:** Universal sports campaign collage (automatic team/sport adaptation)

---

## Overview

This guide recreates the “Cinematic Sports Collage” workflow: one athlete photo becomes a premium campaign poster with strict identity lock, automatic sport/team recognition, official-kit reconstruction, and fixed editorial layout hierarchy.

---

## Inputs

- Athlete identity photo (required)
- Optional higher-detail jersey reference for logo/sponsor fidelity

---

## Core Prompt Logic

The source prompt is built around four locks:

1. **Identity Lock** (face/body fidelity, no beautify/no blend)
2. **Automatic Sports Analysis** (sport/team/league/stadium/crest/colors/kit details)
3. **Layout Lock** (exact strip hierarchy and spacing preserved)
4. **Official History Block** (major verified titles only)

---

## Composition System (from source)

1. **Top strip:** official home stadium, full crowd, dramatic floodlight color  
2. **Second strip:** intense close-up athlete emotion  
3. **Third strip:** oversized official crest integrated into texture  
4. **Fourth strip:** cinematic jersey detail crop (crest/sponsor/fabric/stitching)  
5. **Fifth strip:** dynamic diagonal paint streak in team colors  
6. **Bottom section:** athlete full-body overlap over clean white base  
7. **Footer info:** crest + team name + official major titles + trophy icons

---

## Output Requirements

- Ultra photoreal sports editorial
- Premium commercial campaign finish
- HDR, sharp skin/fabric detail, realistic anatomy
- No random promo text, no fake branding, no invented titles

---

## Best Practices

- Use the cleanest reference with visible facial detail
- Add jersey close-up if sponsor/crest precision matters
- Keep action pose sport-specific
- Verify titles before final export

---

## Common Mistakes

- Mixing club and national-team visual elements
- Inventing trophies or wrong title counts
- Incorrect equipment for detected sport
- Breaking layout proportions while adapting colors
