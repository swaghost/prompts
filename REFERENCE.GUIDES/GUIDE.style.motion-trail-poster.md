# Motion Trail Poster Creation

## Description

A complete workflow for creating premium 4:5 editorial posters with motion echo/afterimage effects using AI. Transform portrait photos into stylish fashion-editorial posters with repeated exposure motion trails, monochrome subjects with colored accent layers, and bold modern typography. Perfect for sports campaigns, artist showcases, fashion editorials, and luxury branding.

## Tools Required

- **Higgsfield.ai** — Using Nano Banana 2 tool for poster generation
- **Character Reference Image** — Portrait photo of your subject
- **Master Reference Image** — Template/style reference for the poster effect

## What You'll Learn

- Creating premium editorial posters with motion trail effects
- Using character reference and master reference images together
- Writing detailed prompts with echo/repeated exposure effects
- Adding bold editorial typography to AI-generated posters
- Working with monochrome subjects and colored accent layers
- Professional poster composition with clean luxury aesthetic

## Workflow Overview

### Step 1: Upload Reference Images

**Required Uploads:**

1. **Character Reference Image** — Portrait photo of the subject whose identity you want to preserve
2. **Master Reference Image** — The motion trail poster style reference (provided in original guide)

Upload both images before generating your poster.

### Step 2: Fill the Template

Replace the placeholders with your specific information:

- **[BIG NAME]** — Surname or short name for large text (e.g., "ROWE")
- **[FULL NAME]** — Complete name (e.g., "ELIAS ROWE")
- **[NUMBER]** — Number like 01, 07, 11, 23, etc.
- **[CITY]** — City name (e.g., "ROME")
- **[ACCENT COLOUR]** — Color for echo trails and text: teal / red / orange / green / purple / pink / blue / yellow

### Step 3: Generate with Main Prompt

Use the filled prompt template in Higgsfield.ai with Nano Banana 2 tool.

## Main Prompt Template

Transform the uploaded portrait into a premium 4:5 editorial poster with the same visual DNA as a modern echo portrait / repeated exposure identity poster.

Preserve the subject's exact facial identity, hairstyle, age, skin tone, expression, and overall likeness while turning the image into a clean, stylish, high-end fashion poster.

### Composition

- Use a close-up portrait framing
- Keep the subject as the main focus
- Place the portrait against a clean light beige / off-white background
- Make the main portrait mostly monochrome / desaturated
- Add multiple faded duplicate echo layers of the subject trailing behind them horizontally, creating a motion-trail / repeated exposure effect
- The echo layers must use the chosen accent colour
- Keep the layout very clean, premium, minimal, and editorial

### Typography

Add bold poster typography in a clean, modern, condensed editorial style.

Use these exact text elements:

- Large main text: "[BIG NAME]"
- Small name text: "[FULL NAME]"
- Small number text: "[NUMBER]"
- Small city text: "[CITY]"

### Text Placement

- Put "[BIG NAME]" in very large bold type across the lower half of the poster
- Put "[FULL NAME]", "[NUMBER]", and "[CITY]" in smaller clean text, similar to a premium magazine poster layout
- Keep the typography sharp, readable, stylish, and aligned neatly
- The large main text and graphic accents should use [ACCENT COLOUR]
- Make sure the text is properly spelled and rendered clearly

### Style

- Premium fashion editorial
- Modern poster design
- Monochrome portrait with colour accent
- Motion echo / afterimage effect
- Clean luxury graphic design
- High contrast
- Realistic skin texture
- Sharp facial detail
- Polished studio-poster finish

### Colour Instruction

Use [ACCENT COLOUR] for:

- The repeated echo duplicates

Keep the overall look realistic, sharp, luxurious, and high-end, with clean typography and strong poster composition.

## Tips for Best Results

1. **Character Reference Quality**
   - Use high-resolution portrait photos
   - Clear facial features work best
   - Good lighting on the subject
   - Neutral expression provides most versatility

2. **Accent Color Selection**
   - Choose colors that complement the subject's skin tone
   - Bold, saturated colors work best for the echo effect
   - Consider brand colors if creating for a client
   - Popular choices: teal, red, orange, purple

3. **Typography Customization**
   - Keep names short for maximum impact
   - Numbers can be jersey numbers, dates, or symbolic figures
   - City names add location context
   - Maintain visual hierarchy with size contrast

4. **Composition Balance**
   - The main portrait should be centered or slightly off-center
   - Echo trails typically move horizontally to the right
   - Leave adequate space for typography at the bottom
   - Keep background clean and uncluttered
