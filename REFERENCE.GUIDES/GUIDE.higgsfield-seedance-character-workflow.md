**Founder Reel · Prompt Deck**

## Overview

This workflow creates photorealistic character videos with perfect identity consistency across frames. The two-step process:

1. **Character Sheet Creation** (Nano Banana 2 Pro) — Generate a consistent character reference
2. **Video Animation** (Seedance 2.5) — Animate the character with precise keyframe control

---

## Workflow Steps

### Step 1: Character Sheet Generation (Nano Banana 2 Pro)

Use Nano Banana 2 Pro to create a professional character reference sheet that locks facial identity, bone structure, skin texture, and hair across every subsequent generation.

**Purpose**:

- Maintain EXACT facial identity
- Establish character appearance baseline
- Create reusable reference for video generation

**Key Requirement**: CHARACTER LOCK — The character's face, bone structure, skin, and features must remain identical across all outputs.

---

### Step 2: Video Generation (Seedance 2.5)

Use Seedance 2.5 with keyframe-based prompting to animate your character reference. The system uses:

- **Keyframe prompting** (not timeline)
- **Real-time rendering** (no SLO-MO)
- **30-second exact duration** with precise beat breakdowns
- **Scene-to-scene transitions** without cuts

**Critical Rules**:

- Keyframe prompts replace traditional timeline prompts
- 30 seconds = real-time speed (no slow-motion)
- All content must appear naturally within the 30-second window
- Beats define where visual changes occur

## Technical Specifications

### Rendering Style

- **Aesthetic**: Photorealistic, Kodak Portra 400 colour science
- **Grain**: Fine analog grain, matte finish
- **Sharpness**: Not beauty filter, no smoothing, no airbrushing
- **Skin**: Visible pores, natural skin texture
- **Hair**: Natural hair movement, linen shirt texture

### Camera Behavior

- **Format**: 16:9 horizontal, high resolution
- **Movement**: Starts wide, stays light on face, slow gentle push towards face
- **Composition**: Right third negative space initially
- **Lens**: Shallow depth of field, armchair soft background dissolved

### Environment

- **Setting**: Editorial apartment living room, early evening
- **Lighting**: Soft lamp behind left shoulder, cooler window light from right
- **Props**: Deep low armchair, dark upholstery, minimal expensive interior
- **Mood**: Warm-cool contrast, soft halo on hair, slight warm shadows

## Best Practices

✅ **Character Lock**: Use the exact character reference from Nano Banana — no variations  
✅ **Keyframe Precision**: Define exact beats for visual changes  
✅ **Natural Timing**: All actions must fit naturally within 30-second real-time window  
✅ **Lighting Consistency**: Maintain warm lamp + cool window light throughout  
✅ **Expression Control**: Map facial expressions to specific beats  
✅ **Camera Discipline**: Smooth, slow movements only — no jarring transitions

⚠️ **Avoid**:

- Slow-motion effects (renders at real-time only)
- Multiple cuts or scene changes
- Overly fast movements that can't complete in 30 seconds
- Inconsistent lighting across keyframes
- Character appearance drift
