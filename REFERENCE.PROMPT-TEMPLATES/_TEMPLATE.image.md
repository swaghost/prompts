## Template Usage Notes:

1. **Naming Convention:** Use descriptive filenames with category prefixes (e.g., `influencer.woman.beachwear.md`, `portrait.man.cinematic.md`, `product.luxury-watch.md`)

2. **Description:** Focus on the visual end result - what will the generated image look like?

3. **Prerequisites:** Be specific about what reference images or inputs are needed

4. **Included Effects:** This helps users understand what visual treatments are baked into the prompt so they know what to expect

5. **Included Camera Frames:** Technical photography details help users understand the professional setup and composition approach

6. **Image Prompt:** This is the actual generation prompt - be extremely detailed and specific with every visual element

7. **Usage Section:** Help users understand when this prompt is appropriate and what contexts it works best in

8. **Organization:** Consider organizing image prompts into subfolders by category (portraits/, products/, influencers/, editorial/, etc.)
