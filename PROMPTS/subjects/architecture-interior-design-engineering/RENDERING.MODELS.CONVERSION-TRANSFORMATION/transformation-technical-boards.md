# Technical Detail Boards - Architectural Image Transformations

## Overview

Transform architectural facades into comprehensive technical detail boards with elevations, sections, callouts, specifications, dimensions, and annotations - ready for construction documentation, permit submissions, and technical communication.

**Part of:** [Architectural Transformations Collection](architectural-transformations-image.md)

---

## Use Cases

- **Construction Documents** - Complete technical detail sheets for construction
- **Permit Submissions** - Code-compliant documentation for building permits
- **Contractor Bid Packages** - Clear scope definition for bidding
- **Technical Specifications** - Visual support for written specifications
- **Client Review Documents** - Technical review and approval
- **Coordination Documents** - Multi-discipline design coordination
- **Shop Drawings** - Fabrication and installation guidance
- **Quality Control** - Installation verification and inspection standards
- **As-Built Documentation** - Record drawings and facility documentation
- **Submittal Packages** - Product and system submittals
- **Value Engineering** - Alternative system evaluation and comparison

## Base Prompt Template

```
Transform this architectural façade into a professional technical detail board while preserving the original design. Add elevations, construction sections, enlarged detail callouts, material specifications, dimensions, and technical annotations with a professional architectural presentation.
```

**When to Use:**

- Quick technical board generation
- Standard detail documentation
- General construction documents
- Time-constrained projects

**Customization:**

- Specify drawing types needed (elevation, section, plan)
- Add annotation density level

## Enhanced Prompt Variations

### Complete CD Board

**Prompt:**

```
Create comprehensive technical detail board from this façade. Preserve original design completely. Include: main elevation drawing (scaled), horizontal section through typical wall, vertical section at window head/sill/jamb, enlarged detail callouts (1:5 or 1:2 scale), material schedule with specifications, dimension strings (overall and component), technical notes and annotations, title block with project info, scale bars and north arrow. Professional architectural construction document style, CAD-quality line work, clear hierarchy of information, black line drawings with subtle grey tones for depth.
```

**Best For:**

- Complete construction document sets
- Contractor-ready documentation
- Permit submission packages
- Comprehensive technical communication
- Standard of care documentation

**Key Features:**

- Multiple drawing types coordinated
- Multiple scales shown
- Complete dimensional information
- Material specifications included
- Professional CD standard presentation

**Board Components:**

**1. Main Elevation (Primary Drawing):**

- Scale: 1/4" = 1'-0" or 1:50 typical
- Overall dimensions shown
- Opening locations and sizes
- Material indications
- Grid lines or reference marks
- Detail reference bubbles

**2. Horizontal Section (Plan Cut):**

- Scale: 1/4" = 1'-0" or 1:50 typical
- Cut through typical wall assembly
- Shows depth and reveals
- Material hatching/patterns
- Dimension to faces and reveals
- Connection to structure indicated

**3. Vertical Sections:**

- Scale: 3/4" = 1'-0" or 1:20 typical
- Window head, sill, and jamb details
- Flashing and waterproofing shown
- Material layers visible
- Fastening and connections
- Structural support indicated

**4. Enlarged Details:**

- Scale: 1-1/2" = 1'-0" or 1:10, larger as needed
- Critical connections and assemblies
- Fastener types and spacing
- Sealant and gasket details
- Very specific material callouts
- Installation sequence notes

**5. Material Schedule/Legend:**

- Material key with numbers or letters
- Full material specifications
- Manufacturer information
- Color/finish specifications
- Reference standards (ASTM, etc.)

**6. Dimensions:**

- Overall building or façade dimensions
- Floor-to-floor heights
- Opening dimensions (width x height)
- Component dimensions
- Critical clearances and tolerances
- Cumulative and individual dimensions

**7. Technical Notes:**

- Installation requirements
- Performance specifications
- Code compliance notes
- Coordination requirements
- Quality standards
- Testing and inspection requirements

**8. Title Block:**

- Project name and address
- Sheet title and number
- Scale(s) used on sheet
- Drawing date and revisions
- Professional seal space
- Consultant information
- Sheet index reference

**Line Weight Hierarchy:**

- Extra Heavy: Building outline, primary cut lines
- Heavy: Major elements, floor lines
- Medium: Secondary elements, details
- Light: Hatching, fill, texture
- Extra Light: Background elements, references

## Technical Specifications

### Drawing Scale Standards

**Small Scale (Overview):**

- 1/8" = 1'-0" (1:100 metric)
- 1/4" = 1'-0" (1:50 metric)
- Building elevations, site plans
- Context and overall composition

**Medium Scale (General Detail):**

- 3/4" = 1'-0" (1:20 metric)
- 1" = 1'-0" (1:10 metric)
- Wall sections, typical details
- Standard construction details

**Large Scale (Specific Detail):**

- 1-1/2" = 1'-0" (1:5 metric)
- 3" = 1'-0" (1:2 metric)
- Critical connections and assemblies
- Fabrication details

**Full Size:**

- 1:1
- Templates and special conditions
- Shop drawings and fabrication
- Complex connections

**Recommendation:** Use multiple scales on one board with appropriate detail density for each

---

### Line Weight Standards

**CAD/BIM Line Weights:**

- 0.13 mm (Extra Light): Hatching, backgrounds, reference
- 0.18 mm (Light): Minor elements, dimensions, text
- 0.25 mm (Medium): Standard elements, typical lines
- 0.35 mm (Heavy): Major elements, emphasis, section cuts
- 0.50 mm (Extra Heavy): Building outline, primary features
- 0.70 mm (Bold): Titles, sheet borders, special emphasis

**Traditional Pen Weights:**

- 0.1, 0.2, 0.3, 0.5, 0.7, 1.0 mm
- Maintain clear hierarchy
- Heavier weight = more importance

**Recommendation:** Maintain consistent line weight standards across all sheets

---

### Annotation Density

**Minimal:**

- Basic dimensions only
- Major material callouts
- Essential notes
- Schematic level

**Standard:**

- Complete dimensions
- Material specifications
- Installation notes
- Construction document level

**Comprehensive:**

- Very detailed dimensions
- Full specifications
- Extensive notes and references
- Shop drawing level
- All tolerances specified

**Recommendation:** Match annotation density to document purpose and audience

---

### Material Representation

**Line Work (Elevation/Section):**

- Solid poche for cut elements (walls, structure)
- Hatching for material indication
- Standard architectural hatch patterns
- Consistent pattern use across documents

**Common Hatch Patterns:**

- Concrete: Stipple or dots
- Masonry: Running bond pattern
- Wood: Grain lines or diagonal
- Insulation: Batting or R-value text
- Metal: Diagonal lines
- Earth: Random irregular pattern
- Glazing: Typically left blank or single diagonal

**Color Use (Optional):**

- Generally black and white line work standard
- Subtle grey tones for depth and hierarchy
- Color for coordination or emphasis only
- Must print clearly in black and white

**Recommendation:** Standard architectural conventions, black and white with grey tones

## Common Issues and Solutions

### Issue: Original Design Not Preserved

**Problem:** Technical board doesn't reflect actual façade design  
**Solution:** Emphasize "preserving the original design" and "maintain exact proportions and character" multiple times.

---

### Issue: Wrong Drawing Types

**Problem:** Doesn't include needed elevations, sections, or details  
**Solution:** Explicitly list drawing types: "include elevation, horizontal section, vertical section, enlarged details."

---

### Issue: Missing Dimensions

**Problem:** No dimensions or incomplete dimensional information  
**Solution:** Request "complete dimension strings," "overall and component dimensions," "dimensioned for construction."

---

### Issue: Insufficient Detail

**Problem:** Details not large enough scale or missing information  
**Solution:** Specify scales: "enlarged details at 1:5 or 1:2 scale" and "show all materials, connections, and fasteners."

---

### Issue: Poor Line Weight Hierarchy

**Problem:** All lines same weight, no visual hierarchy  
**Solution:** Request "varied line weights," "clear hierarchy of information," "CAD-quality line work with proper line weights."

---

### Issue: Missing Annotations

**Problem:** No material callouts, notes, or specifications  
**Solution:** Add "complete annotations," "material specifications," "technical notes," "installation requirements."

---

### Issue: Too Artistic, Not Technical

**Problem:** Looks like presentation drawing, not construction document  
**Solution:** Emphasize "construction document style," "technical drawing," "CAD-quality," "contractor-ready documentation."
