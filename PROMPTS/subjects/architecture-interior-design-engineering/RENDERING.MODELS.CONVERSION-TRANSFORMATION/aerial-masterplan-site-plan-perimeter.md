## Platform-Specific Notes

**ChatGPT/DALL-E:**

- Upload site plan as reference image
- Emphasize "preserve exact perimeter building layout"
- Specify "soft daylight, no dramatic light beams"
- Request "4K photorealistic aerial view"

**MidJourney:**

- Use uploaded site plan as image reference
- Add `--style raw` for photorealistic output
- Specify `--ar 16:9` or `--ar 3:2` for aerial views
- Emphasize "exact building footprints preserved"

**Adobe Firefly:**

- Select "Photo" style preset
- Upload site plan as structure reference
- Emphasize "architectural visualization quality"
- Specify "soft natural daylight"

**Stable Diffusion:**

- Use ControlNet with site plan input
- Apply architectural photography model
- Emphasize preservation of exact layout
- Soft lighting settings

## Best Practices

**Layout Preservation:**

- Always prioritize exact building perimeter accuracy
- Maintain precise footprint dimensions
- Preserve site boundaries and setbacks
- Keep building-to-building relationships accurate

**Aesthetic Guidelines:**

- Use curved, elegant roads (avoid harsh straight lines)
- Apply lush, well-maintained landscaping
- Ensure soft, natural daylight (no dramatic effects)
- Select premium, clean materials throughout
- Include mature trees (clean and healthy appearance)

**Common Mistakes to Avoid:**

- Adding dramatic sun rays or light beams
- Using weathered or distressed materials
- Creating overly straight or harsh road layouts
- Distorting building proportions or footprints
- Over-saturating colors or lighting
- Including construction equipment or temporary elements

## Output Specifications

**Resolution:** Minimum 4K (3840 x 2160 pixels)  
**Format:** High-quality JPEG or PNG  
**Color Space:** sRGB for digital presentation  
**Aspect Ratio:** 16:9 or as appropriate for site proportions
