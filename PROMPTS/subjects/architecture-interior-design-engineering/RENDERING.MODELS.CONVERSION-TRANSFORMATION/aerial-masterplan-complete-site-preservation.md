# Aerial Masterplan Render - Complete Site Preservation

## Prompt Type

Architectural Visualization - Comprehensive Aerial Masterplan

## Primary Platform

ChatGPT/DALL-E, MidJourney, Adobe Firefly, Stable Diffusion

## Core Concept

Create a photorealistic aerial masterplan render preserving the exact building footprints, internal roads, parking, pathways, and tree placement. Generate a refined high-end masterplan with premium materials, elegant landscaping, soft natural daylight, and clean architectural finishes.

## Detailed Prompt

```
Create a photorealistic aerial masterplan render preserving the exact building footprints, internal roads, parking, pathways, and tree placement.

Generate a refined high-end masterplan with premium materials, elegant point parking, curved roads, lush landscaping, soft daylight, clean mature trees, and sophisticated architectural finishes. Maintain precise accuracy of all site elements while creating a photorealistic visualization suitable for high-level presentations.

Preserve every element with survey-level accuracy while applying premium materials, refined aesthetics, and professional natural lighting. No dramatic light beams or exaggerated effects.
```

## Input Requirements

**Required Input:**

- Site plan or survey with comprehensive site information
- Building footprints with exact dimensions
- Internal road layouts and specifications
- Parking area configurations and layouts
- Pathway networks and pedestrian routes

- Site boundaries and property lines

**Preservation Priority (All Must Be Exact):**

- Building footprints (positions, dimensions, orientations)
- Internal roads (routes, widths, curves, intersections)
- Parking areas (layouts, space configurations, access)
- Pathways (pedestrian routes, connections, widths)
- Tree placement (exact positions, mature tree locations)
- Site boundaries and setbacks
- Access points and circulation hierarchy
