# Exploded Construction Details - Architectural Image Transformations

## Overview

Transform architectural facades into 3D exploded construction details showing building systems, material layers, assembly sequences, and connection details with technical precision. Perfect for construction documentation, technical presentations, contractor communication, and educational materials.

**Part of:** [Architectural Transformations Collection](architectural-transformations-image.md)

---

## Use Cases

- **Construction Documentation** - Technical construction details and assembly
- **Technical Presentations** - Client and stakeholder technical education
- **Contractor Communication** - Clear assembly sequence and methodology
- **Building Science Analysis** - Wall assembly and system performance study
- **Educational Materials** - Teaching construction techniques and details
- **Specification Development** - Visual support for written specifications
- **Value Engineering** - Alternative assembly exploration
- **Submittal Drawings** - Detailed product and assembly submittals
- **Quality Control** - Installation verification and inspection guidance
- **Marketing Materials** - Technical capability demonstration for manufacturers
- **Bid Documents** - Contractor scope clarity

### Wall Assembly Exploded

**Prompt:**

```
Create 3D exploded view of façade showing complete wall assembly. Preserve original design and materials. Separate and offset layers to reveal: exterior cladding/finish, air/moisture barrier, insulation layer, structural substrate, interior finish. Show connection details, fasteners, and assembly sequence. Realistic material textures, technical accuracy, professional construction detail visualization. Include dimensional callouts and material labels. Clean technical illustration style with photorealistic materials.
```

**Best For:**

- Standard wall assembly documentation
- Building envelope studies
- Technical specifications support
- Educational construction materials
- Contractor training and communication

**Key Features:**

- Complete wall assembly shown
- All layers separated and visible
- Connection details included
- Material specifications clear
- Assembly sequence indicated

**Typical Wall Assembly Layers (Outside to Inside):**

1. **Exterior Cladding/Finish:**
   - Brick veneer
   - Metal panel system
   - Fiber cement siding
   - Stucco/EIFS
   - Natural stone
   - Wood siding

2. **Air/Drainage Cavity:**
   - Cavity space (typically 1"-2")
   - Drainage plane
   - Ventilation path

3. **Weather Resistive Barrier (WRB):**
   - Building wrap/housewrap
   - Fluid-applied membrane
   - Self-adhered membrane
   - Overlap and sealing details

4. **Sheathing/Substrate:**
   - Plywood or OSB
   - Gypsum sheathing
   - Cement board
   - Structural sheathing

5. **Insulation:**
   - Continuous exterior insulation (rigid foam, mineral wool)
   - Cavity insulation (fiberglass, spray foam, cellulose)
   - Thermal break considerations

6. **Structure:**
   - Wood framing (2x4, 2x6, etc.)
   - Steel stud framing
   - CMU or concrete wall
   - Load-bearing considerations

7. **Interior Air/Vapor Barrier:**
   - Polyethylene sheet
   - Smart vapor retarder
   - Vapor-permeable membrane (climate-dependent)

8. **Interior Finish:**
   - Gypsum board (drywall)
   - Plaster
   - Wood paneling
   - Other finish materials

**Connection Details to Show:**

- Cladding attachment (clips, fasteners, ties)
- Flashing at openings and transitions
- Foundation connection
- Roof/wall intersection
- Window/door integration
- Control joints and expansion joints

**Customization Tips:**

- Specify exact materials: "brick veneer over CMU backup wall"
- Define climate zone requirements
- Add energy code compliance elements
- Show specific fastener types and spacing
- Include dimensional tolerances

### Sequence Assembly

**Prompt:**

```
Transform to exploded view showing construction sequence. Preserve façade design. Display layers in installation order with sequential numbering: (1) structure, (2) sheathing, (3) weather barrier, (4) framing/substrate, (5) insulation, (6) finish cladding, (7) glazing, (8) trim and details. Realistic materials, construction-accurate details, contractor-friendly visualization. Technical presentation quality.
```

**Best For:**

- Contractor instruction
- Installation sequence documentation
- Quality control procedures
- Training materials
- Phasing and scheduling

**Key Features:**

- Clear sequential order
- Installation logic
- Numbered steps
- Contractor-oriented
- Realistic methodology

**Assembly Sequence Development:**

**Typical Exterior Wall Sequence:**

1. **Structure Installation:**
   - Install structural frame (columns, beams)
   - Install floor deck/structure
   - Verify structural alignment and plumb

2. **Sheathing:**
   - Install structural sheathing
   - Seal sheathing joints (if required)
   - Verify plane and alignment

3. **Weather Resistive Barrier:**
   - Install WRB starting from bottom
   - Lap horizontally (upper over lower)
   - Seal penetrations and transitions
   - Flash rough openings

4. **Window/Door Installation:**
   - Install flashing pan at sill
   - Set window/door unit
   - Install head and jamb flashing
   - Seal perimeter

5. **Continuous Insulation (if applicable):**
   - Install exterior rigid insulation
   - Stagger joints
   - Fasten or adhere per manufacturer
   - Seal joints if required

6. **Drainage Cavity & Furring:**
   - Install drainage mat or furring strips
   - Maintain continuous cavity
   - Verify ventilation path

7. **Finish Cladding:**
   - Install cladding from bottom up
   - Follow manufacturer specifications
   - Maintain proper lap and clearances
   - Install flashings and trim

8. **Sealants & Final Details:**
   - Install perimeter sealants
   - Install trim and accessories
   - Final waterproofing verification
   - Quality control inspection

**Visual Presentation:**

- Number each component or layer (1, 2, 3...)
- Use arrows to show installation direction (bottom-up, etc.)
- Color-code by trade if multi-discipline
- Include brief notes for critical steps
- Show proper overlaps and transitions

**Customization:**

```
Show construction sequence for [building system type]. Number each step and indicate installation order. Include critical installation notes.
```

## Technical Specifications

### Separation Distance

**Close (6"-12"):**

- Tight detail presentation
- Component relationships clear
- Connections visible
- Limited space requirements

**Standard (12"-24"):**

- Good balance of clarity and context
- All layers clearly separated
- Professional standard
- Versatile for most uses

**Wide (24"+):**

- Maximum component clarity
- Educational emphasis
- Large-format presentation
- Detailed annotation space

**Recommendation:** 12"-18" for most construction details

## Common Issues and Solutions

### Issue: Original Design Lost

**Problem:** Exploded detail doesn't reflect original façade appearance  
**Solution:** Emphasize "preserving the original materials and composition" and "maintain façade design intent."

---

### Issue: Missing Layers

**Problem:** Not all assembly layers shown  
**Solution:** List all layers explicitly in prompt: "show exterior cladding, air cavity, WRB, sheathing, insulation, studs, interior finish."

---

### Issue: Incorrect Assembly Sequence

**Problem:** Layers in wrong order or assembly doesn't make construction sense  
**Solution:** Specify "installation order" or "typical construction sequence" and number layers if needed.

---

### Issue: Unrealistic Materials

**Problem:** Materials look wrong or not construction-accurate  
**Solution:** Add "realistic material textures," "construction-accurate materials," and specify exact materials.

---

### Issue: Separation Too Tight or Too Wide

**Problem:** Can't see details or components lose relationship  
**Solution:** Specify separation distance: "separate layers 12" apart" or "maintain clear but connected presentation."

---

### Issue: Missing Connection Details

**Problem:** Don't see how components connect or attach  
**Solution:** Add "show fasteners, connectors, and attachment methods" and "include connection details."
