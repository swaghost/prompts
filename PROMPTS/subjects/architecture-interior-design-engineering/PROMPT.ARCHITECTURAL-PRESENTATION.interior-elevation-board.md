# Architectural Presentation Board - Interior Elevation

## Category
Architectural Visualization / Technical Presentation

## Style
Professional Technical Drawing / Architectural Elevation

## Purpose
Transform provided interior image into a premium architectural presentation board while preserving 100% of the original design.

## Prompt

Transform the provided interior image into a premium architectural presentation board while preserving 100% of the original design, furniture layout, materials, lighting, and camera perspective.

**Top Section:** A professional architectural elevation/technical drawing version of the scene with precise dimension lines in millimeters, spacing measurements between walls and elements, minimal technical annotations, thin linework, arrows, and subtle red connection dots. Add material and lighting callouts like "Walnut veneer," "Wood flooring surface," and "Marble Slab."

Use a monochrome beige/grey architectural style with modern typography on a soft off-white paper texture background.

**Bottom Section:** The original interior image reproduced in full color and detail exactly as provided - same camera angle, same layout, same lighting, same materials, same furniture placement. Label it discreetly with "HD Stg.: Lounge" and "Maple Surface" in small, minimal sans-serif text.

## Format Specifications

**Layout:** Two-section vertical composition  
**Background:** Soft off-white paper texture  
**Style:** Professional architectural presentation  
**Typography:** Modern, minimal sans-serif  

## Top Section: Technical Elevation

### Requirements
- Professional architectural elevation/technical drawing
- Preserve exact scene from provided image
- Same camera perspective
- Monochrome beige/grey color scheme
- Modern architectural typography

### Technical Elements
- Precise dimension lines (millimeters)
- Spacing measurements between walls and elements
- Minimal technical annotations
- Thin linework
- Arrows showing relationships
- Subtle red connection dots

### Callouts and Labels
- Material callouts (e.g., "Walnut veneer")
- Surface specifications (e.g., "Wood flooring surface")
- Finish details (e.g., "Marble Slab")
- Lighting notes
- Clear, professional labeling

## Bottom Section: Color Reference Image

### Requirements
- Original interior image reproduced exactly
- Full color and detail preserved
- Same camera angle as original
- Same layout as original
- Same lighting as original
- Same materials as original
- Same furniture placement as original

### Labeling
- Discreet labels in small minimal sans-serif text
- Example labels: "HD Stg.: Lounge", "Maple Surface"
- Non-intrusive placement

## Core Principles

### Preservation
- 100% original design preserved
- Furniture layout unchanged
- Materials exactly as provided
- Lighting maintained
- Camera perspective identical

### Professional Quality
- Premium architectural presentation standard
- Clean, modern aesthetic
- Technical precision
- Sophisticated typography
- Proper spacing and hierarchy

### Technical Accuracy
- Dimension lines must be precise
- Measurements in millimeters
- Connection dots and arrows used appropriately
- Material callouts accurate and clear

## Critical Avoidances

**DO NOT:**
- Change the original design
- Alter furniture placement
- Modify materials or finishes
- Change lighting setup
- Use different camera angle
- Add decorative elements not in original
- Over-annotate or clutter
- Use bold or heavy typography
- Apply filters that alter colors (in bottom section)
