# Architecture: Construction Animation - Reference-Based Reveal

**Style**: Photorealistic architectural construction animation sequence

---

## PROMPT

```
Use the provided reference image as the exact and exclusive reference for the house. Preserve every architectural detail exactly as shown in the reference image, including the building's shape, proportions, dimensions, structure, façade, natural stone-clad columns, windows, black window frames, wooden front door, second floor, cantilevered balcony, glass railing, potted plants, flat dark roof, warm wooden soffit, recessed ceiling lights, materials, textures, colors, and overall design. Do not redesign, reinterpret, add, remove, replace, or modify any element of the house. The final completed house must look exactly like the reference image.

Starting from an empty scene, base and walls rise out of the ground, then the natural stone-clad columns, the large floor-to-ceiling black-framed windows and the wooden front door form, then the second floor rises into place with its windows and the cantilevered balcony with glass railing and potted plants, and finally the flat dark roof overhangs with the warm wood soffit and recessed ceiling lights slide into position at the very top until the complete house stands fully built. Smooth seamless clean architectural reveal, materials growing upward layer by layer, bright natural daylight, blue sky with soft moving clouds, photorealistic, ultra detailed.

The reference image must remain completely consistent throughout the entire sequence. No changes to the architecture, camera perspective, composition, proportions, materials, colors, lighting style, landscaping, or surroundings. No morphing, warping, melting, flickering, duplication, disappearing elements, or invented architectural details. The construction animation should only reveal/build the exact house shown in the reference image.
```

## USAGE NOTES

This prompt is designed for architectural visualization animations that show construction/assembly sequences while maintaining absolute fidelity to a reference image.

**Critical Success Factors**:

1. Reference image must be provided as source
2. No creative interpretation allowed - exact replication only
3. Construction sequence reveals existing design, doesn't create new design
4. All phases must match reference image exactly
5. Camera and environment remain static throughout

**Ideal Use Cases**:

- Architectural presentation animations
- Real estate development visualizations
- Construction process demonstrations
- Design reveal sequences
- Portfolio architectural animations

**Quality Control Checklist**:

- ✓ Final frame matches reference image exactly
- ✓ No architectural elements added or removed
- ✓ Proportions and scale consistent throughout
- ✓ Materials and colors match reference
- ✓ Camera position unchanged
- ✓ Smooth progressive reveal
- ✓ No visual artifacts (morphing, flickering, etc.)
