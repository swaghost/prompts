# Architectural Presentation Board - Premium Technical Documentation

## Description

Transform an interior render into a premium architectural presentation board that preserves the original design, furniture layout, materials, lighting, proportions, composition, and camera angle while adding professional architectural documentation. Creates a complete technical package with furniture specification sheet, curated material palette, floor plan, exploded millwork diagrams, interior elevations, FF&E callouts, and clean annotation lines using a refined Swiss grid, off-white/warm neutral background, and sharp, client-ready presentation quality.

## Usage

Use this when you need to convert a design visualization into an architectural-level presentation board with technical documentation. Perfect for client deliverables, construction documentation, RFP submissions, and portfolio work that demonstrates both design vision and technical expertise.

## What This Preserves

- **Original design**: All aesthetic decisions intact
- **Furniture layout**: Every piece in exact placement
- **Materials**: All finishes and surfaces as shown
- **Lighting**: Fixtures and ambient quality
- **Proportions**: Accurate scale and relationships
- **Composition**: Framing and visual balance
- **Camera angle**: Perspective and viewpoint

## Board Components

**1. Hero Render**

- Main visual (largest element)
- Your original design preserved exactly
- Central focal point of the board

**2. Furniture Specification Sheet**

- Item list with dimensions (W × D × H)
- Material and finish for each piece
- Manufacturer or style reference
- Custom fabrication notes
- Model numbers if standard items

**3. Curated Material Palette**

- Flooring swatch with specification
- Wall finish sample
- Countertop/surface material
- Cabinetry finish and wood species
- Hardware finish (brass, chrome, matte black)
- Fabric/upholstery samples
- Tile or stone accents
- Each labeled with name, finish, supplier

**4. Floor Plan Excerpt**

- Annotated layout showing furniture placement
- Room dimensions
- Door swings
- Circulation paths
- Key measurements
- North arrow or orientation

**5. Exploded Millwork Diagrams**

- Cabinetry broken down into components
- Drawer/door configuration
- Shelf spacing and adjustability
- Hardware placement
- Construction details
- Joinery callouts

**6. Interior Elevations**

- Flat wall views showing vertical design
- Cabinet heights
- Artwork placement and size
- Shelving dimensions
- Window/door locations
- Material transitions

**7. FF&E Callouts**

- Leader lines from furniture to specifications
- Fixture identification numbers
- Material notes
- Finish callouts
- Dimension arrows

**8. Clean Annotation System**

- Thin, precise lines
- Neat arrowheads
- Consistent line weights
- Professional lettering
- Clear, uncluttered callouts

## Swiss Grid Layout Principles

**Hierarchy**:

- Largest: Hero render (main visual focus)
- Medium: Floor plan, elevations, exploded views
- Small: Material swatches, detail callouts, notes

**Alignment**:

- Everything snaps to invisible grid columns
- Consistent gutters between elements
- Margins respected throughout
- Horizontal and vertical alignment

**White Space**:

- Generous margins
- Breathing room around each element
- Never cramped or cluttered
- Negative space as design element

## Typography System

**Headings**: Large, bold, all caps (project name, room name)
**Subheads**: Medium weight, title case (section labels)
**Body Text**: Regular weight, sentence case (specifications, notes)
**Callouts**: Small, all caps, tight kerning (dimensions, labels)

**Font Choices**: Helvetica, Futura, Univers, or similar clean sans-serif

## Colour Palette

**Background**:

- Off-white warm neutral (#F5F3EE, #E8E6E0, #F2EFE9)
- NOT stark white (too harsh)

**Accents**:

- Soft beige/taupe (#D4CFC4, #C9C4BA)
- Warm grey (#8A8780, #6B6760)

**Text**:

- Charcoal (#3D3D3D, #4A4A4A) for body
- Black (#000000) for emphasis only

**Lines**:

- Medium grey (#A9A9A9) for diagrams
- Dark grey (#5A5A5A) for annotations
