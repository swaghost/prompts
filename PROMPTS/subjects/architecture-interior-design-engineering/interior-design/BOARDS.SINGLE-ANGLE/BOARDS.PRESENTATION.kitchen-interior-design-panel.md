# Kitchen Interior Design Presentation Panel

## Description

Transform an uploaded kitchen image or floor plan into a single premium vertical architectural presentation board. Preserve the source design exactly while presenting it through an isometric hero view, floor plan, wall elevations, detail perspectives, schedules, lighting plan, material palette, design highlights, and project information.

## Usage

Use this prompt for client presentations, interior-design portfolios, kitchen renovation proposals, design reviews, and social-ready architectural boards. The uploaded kitchen image or floor plan is the only source of truth; the board documents the existing design without redesigning it or inventing unsupported specifications.

## Prerequisites / Dependencies

- Dependency #1 - One uploaded kitchen image or floor plan.
- Dependency #2 - Replace `[PROJECT NAME]` and `[DESIGN STYLE]` only when those details are known or visually supported.
- Dependency #3 - Optional verified project metadata for the project-information table. Never infer measurements or specifications from appearance alone.

## What This Preserves

- Exact floor-plan proportions and spatial arrangement
- Existing walls, doors, windows, and circulation
- Cabinet, countertop, island, and bar geometry
- Appliance, sink, fixture, and furniture placement
- Visible materials, colors, lighting, and architectural elements
- One consistent kitchen across every view, elevation, diagram, and callout

## Board Structure

- Top header with project title, concept subtitle, material preview, and client need
- Central photorealistic 3D isometric hero view with callouts
- Left column with floor plan, numbered legend, and wall elevations
- Right column with design highlights and project information
- Four-view photorealistic detail strip beneath the isometric view
- Bottom panels for furniture schedule, ceiling lighting plan, and material palette

## Quality-Control Checklist

- Confirm the output is one vertical 4:5 board.
- Compare every wall, opening, cabinet, counter, island, appliance, sink, fixture, and furniture item against the uploaded source.
- Confirm the isometric view, plan, elevations, detail views, schedules, and palettes all describe the same kitchen.
- Remove unsupported measurements, materials, project facts, or architectural elements.
- Check that labels are readable, callouts point to real elements, and the grid remains balanced.
- Confirm that no decorative object or lighting fixture has been added unless supported by the source.
