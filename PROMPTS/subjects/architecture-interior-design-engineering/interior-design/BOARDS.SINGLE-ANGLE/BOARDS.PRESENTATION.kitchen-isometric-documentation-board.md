# Kitchen Isometric Documentation Presentation Board

## Description

Create a premium vertical architectural presentation board from an uploaded kitchen image or floor plan. The board preserves the source design exactly while presenting it through a central photorealistic isometric view, floor plan, wall elevations, detail views, schedules, lighting plan, and material palette.

## Usage

Use this style for kitchen design portfolios, client presentations, design reviews, and social media boards that require one coordinated 4:5 sheet. It is especially useful when every generated view must represent the same kitchen without redesigning or inventing unsupported details.

## Prerequisites

- Uploaded kitchen image or floor plan
- Project name
- Design style

## Board Structure

- **Header:** Project title, concept subtitle, material preview, and client need
- **Center:** Large photorealistic 3D isometric kitchen view with callouts
- **Left column:** Exact floor plan and wall elevations
- **Right column:** Design highlights and project information
- **Detail strip:** Four coordinated photorealistic views of the same kitchen
- **Bottom panels:** Furniture schedule, ceiling lighting plan, and material palette

## Negative Constraints

- No redesign, reinterpretation, relocation, resizing, additions, or removals
- No altered walls, cabinetry, countertops, islands, openings, appliances, furniture, or fixtures
- No invented measurements, specifications, architectural elements, materials, or project facts
- No inconsistent geometry or styling between the isometric, plan, elevations, and detail views
- No unnecessary decorative objects, illegible labels, cluttered hierarchy, or inconsistent graphic language
