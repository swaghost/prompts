# Architectural Model Mockup - Scale Model Photography

## Description

Create a close-up photograph of an architectural mockup model in axonometry view with depth of field, closeup framing, and bokeh effect. The highly detailed scale model features depth of field in its space, clean materials like white foam board, wood, and acrylic, precise miniature windows and structures, placed on a presentation table with soft studio lighting. This prompt delivers professional architectural model photography with miniature craftsmanship quality—ideal for design presentations, architectural portfolio, concept communication, and professional marketing.

## Photography Overview

**Subject:** Architectural scale model (physical mockup)  
**View:** Axonometry/isometric perspective  
**Shot Type:** Close-up with shallow depth of field  
**Model Materials:** White foam board, wood, acrylic  
**Setting:** Presentation table, studio lighting  
**Purpose:** Professional model photography, design presentation
