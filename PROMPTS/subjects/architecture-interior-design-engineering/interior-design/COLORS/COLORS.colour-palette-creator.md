# Colour Palette Creator

## Description

A professional colour palette generator that creates 5 cohesive colour schemes for any room type and interior style. Each palette includes wall colours, furniture tones, accent shades, décor suggestions, and exact hex codes for precise colour matching. Perfect for creating harmonious colour stories that bring interior design concepts to life.

## Usage

Specify your room type and design style to receive 5 distinct colour palettes, each with a unique mood and character. Use this for client presentations, mood board development, paint selection, or exploring different colour directions for the same space.

## Palette Themes

Each palette has a distinct character:

- **Warm Neutrals**: Creamy, beige, taupe, warm whites
- **Modern Minimal**: Greys, whites, blacks, subtle tones
- **Sage Earth**: Greens, browns, terracotta, natural tones
- **Modern Luxe**: Deep tones, rich accents, sophisticated darks
- **Coastal Calm**: Blues, whites, sandy neutrals, seafoam

_(Themes vary based on room type and style specified)_

## Colour Components

Each palette includes:

- **Wall Colours**: Primary wall paint (2-3 options)
- **Furniture Tones**: Sofa, tables, cabinetry colours
- **Accent Shades**: Pillows, throws, decorative pieces
- **Décor Suggestions**: Artwork, plants, accessories
- **Hex Codes**: Exact colour values for digital/print matching

## Output Format

The AI will provide:

**For Each of 5 Palettes:**

1. **Palette Name**: Descriptive title (e.g., "Warm Neutrals", "Sage Earth")
2. **Mood Description**: The feeling this palette creates
3. **Wall Colours**: 1-2 primary wall colours with hex codes
4. **Furniture Tones**: Wood finish or upholstery colours with hex codes
5. **Accent Shades**: 2-4 accent colours with hex codes
6. **Décor Suggestions**: Specific items that work with this palette
7. **Hex Code Summary**: All colours listed with codes

## Colour Theory Principles

- **60-30-10 Rule**: 60% dominant, 30% secondary, 10% accent
- **Analogous Schemes**: Colours next to each other on the colour wheel
- **Complementary Schemes**: Opposite colours for contrast
- **Monochromatic Schemes**: Variations of a single hue
- **Neutral Foundations**: Grounded palettes with colourful accents

## Hex Code Usage

Hex codes enable:

- Precise paint colour matching
- Digital design mockups
- Fabric and material sourcing
- Print materials (brochures, mood boards)
- Online shopping and colour coordination
- Client presentations with exact colours

## Best Practices

- Request palettes for the specific room to get appropriate suggestions
- Mention existing elements you want to keep (e.g., "oak floors", "grey sofa")
- Specify if you prefer warm or cool tones
- Ask for bolder or more subdued options based on your comfort level
- Request paint brand equivalents (e.g., "Suggest Sherwin-Williams equivalents")
- Save hex codes for easy reference during shopping
