# Optimized Furniture Layout

## Description

Create optimized furniture layouts for any space using dimensions while maintaining circulation, functionality and visual balance. This prompt generates floor plan views and 3D visualizations that maximize space efficiency while ensuring proper traffic flow and aesthetic appeal.

## Usage

Perfect for interior designers, space planners, architects, and anyone arranging furniture in residential or commercial spaces. Ideal for small space optimization, open floor plan arrangements, multi-functional rooms, and ensuring proper ergonomics and flow.

## Prerequisites

- Room dimensions (length × width × height)
- Existing architectural features (windows, doors, built-ins)
- Room function and activities
- Number of occupants
- Existing furniture to incorporate (optional)
- Style preferences

## Image Prompt

Create an optimized furniture layout for a [ROOM TYPE] measuring [LENGTH] × [WIDTH] feet/meters.

**Room Function:** [PRIMARY USE - e.g., family living room, home office, bedroom]

**Architectural Features:**

- Windows: [LOCATION AND SIZE]
- Doors: [LOCATION AND SWING DIRECTION]
- Built-ins: [EXISTING FEATURES]
- Focal points: [FIREPLACE, VIEW, TV WALL]

**Furniture Requirements:**
[LIST ESSENTIAL FURNITURE PIECES WITH APPROXIMATE DIMENSIONS]

**Circulation Needs:** Maintain [MINIMUM CLEARANCE - typically 30-36 inches] for main walkways, ensure clear paths to all doors and windows, create conversation zones with [SEATING ARRANGEMENT DISTANCE]

**Design Priorities:** [FUNCTIONALITY, FLOW, VISUAL BALANCE, FLEXIBILITY]

Generate a floor plan view showing furniture placement with dimensions and clearances marked. Include a 3D perspective view showing the spatial relationships and visual balance. Ensure proper scale, ergonomic spacing, and functional zones clearly defined.

## Negative Prompt

Blocked pathways, furniture too large for space, poor traffic flow, cramped arrangement, unrealistic scale, furniture blocking doors or windows, no clearance between pieces, awkward angles, impractical layout, poor focal point arrangement

## Output Specifications

- **View 1:** Top-down floor plan with dimensions
- **View 2:** 3D perspective showing spatial relationships
- **Scale:** Accurate furniture and room proportions
- **Annotations:** Key measurements and clearances
- **Style:** Clean, professional architectural drawing

## Layout Principles

**Circulation Guidelines:**

- Main walkways: 36-48 inches clear
- Secondary paths: 24-30 inches minimum
- Door clearance: Full swing radius unobstructed
- Window access: Allow for opening and cleaning

**Functional Zones:**

- Conversation areas: 8-10 feet maximum across
- TV viewing distance: 1.5-2.5× screen diagonal
- Workspace clearance: 36-42 inches behind chairs
- Bed access: 24-30 inches minimum on entry side

**Visual Balance:**

- Anchor large pieces on solid walls
- Create symmetry or intentional asymmetry
- Balance visual weight across the room
- Leave breathing room, avoid wall-hugging
- Create focal points with furniture arrangement

## Room-Specific Considerations

**Living Rooms:**

- Conversation groupings within 8-10 feet
- Coffee table 14-18 inches from seating
- TV at eye level when seated
- Multiple seating zones for large spaces

**Bedrooms:**

- Bed as focal point, typically centered on wall
- Nightstands within arm's reach
- Dresser with 36-42 inch clearance in front
- Clear path to closet and bathroom

**Home Offices:**

- Desk positioned for natural light (side window)
- Chair clearance: 36-42 inches from wall
- Storage within arm's reach
- Meeting zone separate from work zone

**Dining Rooms:**

- 36 inches per person at table minimum
- 42-48 inches clearance around table for chairs
- Buffet/credenza 36-42 inches clearance
- Chandelier centered over table, 30-36 inches above
