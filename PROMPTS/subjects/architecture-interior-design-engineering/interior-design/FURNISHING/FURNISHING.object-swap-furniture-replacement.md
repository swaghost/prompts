# Interior Object Swap — Furniture & Element Replacement

## Overview

Swap specific furniture items or elements from one interior image into another scene while maintaining natural integration. Precisely matches the object's design, material, and proportions from the source image while ensuring seamless integration with consistent lighting, shadows, and photorealistic editing in the target scene. Perfect for furniture placement testing, design element exploration, and creating cohesive interior compositions from multiple references.

---

## Master Prompt

```
Swap the [specific furniture/object] in [image 2] for the [same furniture
type] shown in [image 1], precisely matching the design, material, and
proportions from [image 1], ensuring both replacements are naturally
integrated into the existing scene in [image 2] with consistent lighting
and shadows. High-resolution, photorealistic editing.
```

- Appliances
- Tiles and backsplashes

---

### Integration Requirements

**For Natural Seamless Integration:**

**Lighting Match:**

- Object receives same light direction as scene
- Shadows cast appropriately on floor/surfaces
- Highlights and reflections consistent with environment
- Color temperature matches scene lighting

**Perspective & Scale:**

- Object maintains proper perspective with room
- Scale appropriate to surrounding furniture
- Placement feels natural, not floating
- Proportions realistic for space

**Material Rendering:**

- Object textures match scene quality
- Reflections show environment
- Surface properties consistent (glossy vs matte)
- Detail level matches scene fidelity

**Environmental Integration:**

- Ambient occlusion where object meets surfaces
- Contact shadows under furniture
- Light bounce between object and surroundings
- Visual connection to space

## Technical Specifications

### Input Image Requirements

**Image 1 (Object Source):**

- High resolution: 2000px+ shortest side
- Clear, well-lit view of object
- Object fully visible (not cropped)
- Neutral or simple background preferred
- Sharp focus on object details

**Image 2 (Target Scene):**

- High resolution: 2000px+ shortest side
- Clear view of area where object will be placed
- Good lighting (for matching)
- Similar perspective/angle to Image 1 object
- Photographic quality

---

### Output Specifications

**Resolution:**
| Use Case | Minimum | Recommended |
|----------|---------|-------------|
| **Social Media** | 2000px shortest side | 3000px |
| **Portfolio** | 3000px shortest side | 4500px |
| **Print** | 3600px shortest side @ 300 DPI | 5400px |

**File Format:**

- PNG (preserves quality, no compression artifacts)
- JPEG (web use, smaller files)
- TIFF (print, highest quality)

**Aspect Ratio:** Match Image 2 (target scene) aspect ratio

## Best Practices

### ✅ Do:

1. **Use high-quality images** — Both source object and target scene should be clear
2. **Match lighting conditions** — Similar light quality helps integration
3. **Specify materials precisely** — "Brass, leather, bouclé" not just "nice looking"
4. **Request consistent shadows** — Essential for realistic integration
5. **Mention perspective** — "Proper perspective with surrounding furniture"
6. **State proportions** — "Match exact proportions" or "scale to 80%"
7. **Emphasize photorealism** — "Photorealistic editing, seamless integration"
8. **Check scale relationships** — Object size should make sense in space

---

### ❌ Don't:

1. **Use blurry object photos** — Won't integrate cleanly
2. **Mix incompatible perspectives** — Frontal object photo into angled room view problematic
3. **Forget about shadows** — Objects without shadows float unnaturally
4. **Ignore lighting direction** — Object lit from right in left-lit room looks wrong
5. **Skip material specifics** — Vague requests yield generic results
6. **Overlook scale** — Oversized furniture looks comical
7. **Expect perfection first try** — May need multiple attempts for seamless result
8. **Use low-resolution sources** — Can't upscale poor quality

## Troubleshooting

### Issue: Object looks pasted on, not integrated

**Solution:**

- Emphasize "natural integration with consistent lighting and shadows"
- Specify "shadows cast on floor/surfaces"
- Add "ambient occlusion where object meets ground"
- Request "matches scene lighting direction and quality"
- Mention "reflections showing environment"

---

### Issue: Object scale looks wrong

**Solution:**

- Specify exact proportions: "match size from [image 1]"
- Add scale reference: "coffee table 48 inches long"
- Mention "appropriate scale for room"
- Compare to existing furniture: "same height as existing chairs"
- Request "proper perspective and proportion"

---

### Issue: Object style doesn't match scene

**Solution:**

- Ensure object and scene are compatible aesthetically
- Request adjustments: "adapt finish to match warmer tones in [image 2]"
- Consider style transfer first, then swap
- Choose objects that naturally fit scene aesthetic

---

### Issue: Lighting doesn't match

**Solution:**

- Specify light direction: "lit from left side like scene"
- Mention color temperature: "warm afternoon light matching scene"
- Request "consistent lighting with existing environment"
- Add "highlights and shadows matching scene's light source"

---

### Issue: Multiple swaps conflict

**Solution:**

- Do swaps sequentially if needed (one at a time)
- Clearly specify each object and its replacement
- Mention relationships: "both chairs flanking fireplace"
- Request "cohesive integration of all swapped elements"

## Final Tips

**Secrets to seamless object swaps:**

1. **Lighting match is critical** — Object must receive scene's light direction/quality
2. **Shadows sell the reality** — Cast shadows on floor/surfaces essential
3. **Scale must be appropriate** — Reference existing furniture for proportion
4. **Material details matter** — Specify texture, finish, color precisely
5. **Perspective consistency** — Object and scene should have compatible angles
6. **Ambient occlusion** — Where object touches surfaces needs subtle shadow
7. **Reflection awareness** — Glossy floors/surfaces should reflect new object
8. **High-res inputs** — Can't make clean swaps from poor quality images
9. **Environmental integration** — Object should interact with light, space
10. **Multiple attempts okay** — First swap may need refinement

**Pro tip:** For furniture shopping, this technique is invaluable. Take photos of your rooms with phone, save product images of furniture you're considering, generate swaps to see each piece in your actual space with your actual lighting. Eliminates guesswork and expensive returns. Many interior designers now use this workflow for client presentations before purchasing anything.
