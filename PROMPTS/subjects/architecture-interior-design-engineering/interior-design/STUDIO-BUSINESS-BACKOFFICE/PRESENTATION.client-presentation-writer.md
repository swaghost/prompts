# Client Presentation Writer

## Description

A premium client presentation generator for interior design projects. This prompt creates polished, persuasive presentations that include the concept story, design inspiration, layout decisions, material selections, mood board explanation, and a compelling design narrative. Perfect for winning clients and communicating design vision professionally.

## Usage

Use this when you need to present a design concept to clients in a structured, professional format. The output provides a complete presentation script or document that explains your design decisions, builds excitement, and demonstrates expertise.

## Project Types

- Residential (homes, apartments, condos)
- Commercial (offices, retail, hospitality)
- Renovation projects
- New construction
- Staging for sale
- Model homes

## Presentation Components

- **Concept Story**: The "why" behind the design
- **Design Inspiration**: Mood, references, aesthetic direction
- **Layout Decisions**: Space planning rationale
- **Material Selections**: Finishes, colours, textures with reasoning
- **Mood Board Explanation**: How visual elements work together
- **Design Narrative**: Compelling story that sells the vision

## ChatGPT Prompt

```
Write a premium client presentation for an interior design project. Include the concept story, design inspiration, layout decisions, material selections, mood board explanation, and a persuasive design narrative.

PROJECT DETAILS:
• Room type: [Specify room]
• Style: [Specify aesthetic]
• Client needs: [Functional requirements]
• Budget level: [Luxury/mid-range/budget]

INCLUDE:
• Opening concept story that captures the design vision
• Design inspiration (references, mood, influences)
• Layout decisions with space planning rationale
• Material selections with reasoning for each choice
• Mood board walkthrough explaining visual elements
• Persuasive narrative that makes clients excited about the design
• Implementation timeline and next steps

Make it professional, inspiring, and client-ready.
```

## Example Usage

**Luxury Living Room Renovation:**

```
Write a premium client presentation for a luxury living room renovation. The style is Modern Organic with warm neutrals, natural materials, and clean lines. The clients want comfortable seating for 6, built-in storage, and a sophisticated aesthetic for entertaining. Include the concept story, design inspiration, layout decisions, material selections, mood board explanation, and a persuasive design narrative.
```

**Boutique Hotel Lobby:**

```
Write a premium client presentation for a boutique hotel lobby design. The style is Art Deco Luxe with rich jewel tones, brass accents, and vintage-inspired furniture. The space needs check-in area, lounge seating, and dramatic lighting. Include the concept story, design inspiration, layout decisions, material selections, mood board explanation, and a persuasive design narrative.
```

## Output Format

The AI will provide:

**1. Opening/Concept Story** (1-2 paragraphs)

- The vision statement
- What makes this design unique
- How it meets client needs

**2. Design Inspiration** (1 paragraph + references)

- Aesthetic influences
- Mood and feeling
- Style references

**3. Layout Decisions** (detailed section)

- Space planning rationale
- Circulation and flow
- Functional zones
- Furniture placement reasoning

**4. Material Selections** (by category)

- Flooring with rationale
- Wall finishes with reasoning
- Furniture materials
- Fabric selections
- Hardware and fixtures
- Why each choice supports the design

**5. Mood Board Explanation** (walkthrough)

- How colours work together
- Texture balance
- Visual harmony
- Key elements highlighted

**6. Design Narrative** (compelling close)

- Experiential description (how it will feel to use the space)
- Lifestyle benefits
- Value proposition
- Call to action

**7. Next Steps**

- Timeline
- Budget
- Approvals needed
- Implementation phases

## Presentation Tone

- **Professional**: Demonstrates expertise and attention to detail
- **Inspiring**: Creates excitement about the transformation
- **Clear**: Explains decisions without jargon
- **Confident**: Shows conviction in recommendations
- **Client-Focused**: Emphasizes benefits and how needs are met

## Best Practices

- Provide complete project details for tailored presentation
- Mention client lifestyle, preferences, and pain points
- Include budget parameters for appropriate recommendations
- Specify any must-have elements or constraints
- Request editable format for customization
- Ask for talking points if presenting verbally
