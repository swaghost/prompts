# Space Planning Expert

## Description

A professional space planning tool that creates the most efficient furniture layout for any room based on dimensions and functional needs. This prompt optimizes circulation paths, zoning, seating arrangements, storage placement, and natural light utilization while keeping the space balanced and practical. Perfect for maximizing functionality in any size space.

## Usage

Provide your room type and dimensions, then receive a detailed furniture layout plan that addresses traffic flow, functional zones, seating capacity, storage needs, and natural light placement. Use this when you need to solve spatial challenges or create an optimal room arrangement.

## Room Measurements

Specify dimensions in:

- Feet (e.g., "15 x 12 feet")
- Meters (e.g., "4.5 x 3.6 meters")
- Include ceiling height if relevant
- Note any architectural features (windows, doors, columns, alcoves)

## Planning Elements

- **Layout**: Furniture placement and scale
- **Circulation**: Clear pathways and movement flow
- **Zoning**: Functional areas within the space
- **Seating**: Optimal arrangement for conversation or activity
- **Storage**: Strategic placement for accessibility
- **Natural Light**: Furniture positioned to maximize daylight

## ChatGPT Prompt

```
Create the most efficient furniture layout for a [Room Type] measuring [Dimensions]. Improve circulation, zoning, seating, storage, and natural light while keeping the space balanced and practical.

INCLUDE:
• Detailed furniture layout with measurements
• Circulation paths and traffic flow
• Functional zoning (e.g., seating area, work zone, dining zone)
• Seating arrangement optimized for use
• Storage placement for accessibility
• Natural light considerations

The layout should feel spacious, functional, and easy to navigate.
```

## Example Usage

**Living Room Layout:**

```
Create the most efficient furniture layout for a living room measuring 18 x 14 feet with a window on the north wall and entry on the east wall. Improve circulation, zoning, seating, storage, and natural light while keeping the space balanced and practical.
```

**Open-Plan Kitchen/Dining:**

```
Create the most efficient furniture layout for an open-plan kitchen and dining area measuring 8 x 4 meters. Include a 6-person dining table, kitchen island, and storage. Improve circulation, zoning, seating, storage, and natural light while keeping the space balanced and practical.
```

## Output Format

The AI will provide:

1. **Floor Plan Description**: Overall layout strategy
2. **Furniture Placement**: Each piece with specific positioning
3. **Circulation Analysis**: Clear pathways and movement zones
4. **Functional Zoning**: How different areas work together
5. **Seating Configuration**: Arrangement that supports activity and conversation
6. **Storage Strategy**: Placement for optimal access and aesthetics
7. **Natural Light Plan**: Positioning to maximize daylight without glare

## Space Planning Principles

- **3-Foot Rule**: Maintain minimum 3-foot clearance for circulation
- **Focal Point**: Arrange furniture to highlight the room's best feature
- **Conversation Distance**: 4-8 feet between seating for comfortable talking
- **Traffic Flow**: Straight paths without obstacles
- **Balance**: Visual weight distributed evenly
- **Scale**: Furniture sized appropriately for the room

## Best Practices

- Provide exact room dimensions for accurate planning
- Mention all doors, windows, and architectural features
- Specify functional requirements (TV viewing, work area, dining for X people)
- Note any existing furniture you must work around
- Include ceiling height if you're planning tall storage or lighting
- Mention which direction windows face for natural light planning

## Use Cases

- New home furniture planning before purchasing
- Rearranging existing furniture for better flow
- Small space optimization
- Multi-functional room design (living/dining, bedroom/office)
- Open-plan space zoning
- Awkward or irregularly shaped rooms
- Pre-renovation space analysis
