# 2D Layout to 3D Isometric Interior Model

## Description

Convert an attached 2D interior layout or floor plan into a realistic 3D isometric model. The generated space must follow the source plan precisely while adding complete walls, furniture, finishes, and interior elements that make the spatial design easy to evaluate.

## Usage

Use this prompt for interior-design concept development, client presentations, space-planning reviews, architectural visualization, furniture-layout studies, and converting technical layouts into an understandable three-dimensional view.

## Prerequisites

- **Required reference:** Attach a clear 2D layout or floor plan.
- **Optional references:** Add furniture, material, lighting, or style references when the plan does not define them.
- Keep the source image's room boundaries, openings, circulation, and spatial relationships authoritative.

## Image Prompt

```
Analyze the attached 2D layout carefully. Generate a realistic 3D isometric model that strictly follows this floor plan. Erect the walls and populate the space with complete, fully detailed furniture and interior elements that match the layout. Apply highly realistic textures, materials, and a balanced color scheme that complements the design. Ensure professional studio lighting to clearly showcase the entire 3D space.
```

## Layout Fidelity Rules

- Preserve the exact room arrangement, wall positions, openings, circulation routes, and proportions from the 2D layout.
- Convert the plan into a coherent three-dimensional space rather than redesigning or reinterpreting it.
- Place furniture and fixtures according to the locations, orientation, and scale indicated in the source plan.
- Show walls, floors, ceilings, doors, windows, built-ins, furniture, and key interior elements as complete objects.
- Where the plan is ambiguous, make restrained, functional assumptions that do not change the underlying layout.

## Isometric View and Composition

- Use a clean 3D isometric or axonometric camera with the floor plan clearly readable from above and at an angle.
- Keep the entire layout visible in one balanced composition, with no important room cropped out.
- Use a professional architectural visualization presentation with clear spatial hierarchy and realistic scale.
- Avoid a flat top-down plan, distorted perspective, dollhouse clutter, or a camera angle that hides room relationships.

## Materials and Lighting

- Apply physically realistic materials to flooring, walls, ceilings, cabinetry, furniture, textiles, glass, stone, wood, and metal.
- Use a balanced, design-complementary colour scheme rather than arbitrary colours.
- Use professional soft studio lighting with realistic shadows, ambient occlusion, contact shadows, and gentle material highlights.
- Ensure the lighting reveals the complete 3D space, circulation, furniture placement, and material differences without crushing shadows or blowing out highlights.

## Technical Specifications

Realistic 3D isometric architectural visualization, high-resolution output, accurate floor-plan conversion, complete furniture and interior elements, physically based materials, realistic scale, professional studio lighting, balanced composition, clean presentation, no text or labels unless visible in the source plan.

## Negative Prompt

```
Do not change the floor-plan layout, room proportions, wall positions, openings, circulation, furniture placement, or spatial relationships. No missing rooms, missing walls, invented extensions, collapsed geometry, impossible furniture scale, floating objects, duplicate furniture, distorted perspective, flat top-down view, extreme fisheye distortion, cluttered styling, random decor, inconsistent materials, unrealistic textures, harsh overexposure, crushed shadows, poor studio lighting, low resolution, blurry details, text, labels, logos, watermark, cartoon, illustration, or unfinished 3D model.
```
