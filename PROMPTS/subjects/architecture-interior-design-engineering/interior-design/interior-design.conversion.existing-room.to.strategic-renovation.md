# Existing Room to Strategic Renovation

## Conversion

- **Source type:** Existing room image or documented current condition
- **Target type:** Buildable strategic renovation and before/after transformation

## Description

Redesign an existing room to improve function, storage, lighting, and visual cohesion while preserving structural walls, openings, and essential utilities.

## Usage

Use for renovation proposals, client presentations, feasibility studies, property upgrades, storage planning, before-and-after campaigns, and design-development reviews.

## Prerequisites

- One existing-room reference, ideally with documented current condition
- Selected `(ROOM)` and target `(STYLE)`
- Known structural walls, openings, utilities, plumbing, and electrical constraints
- Optional budget tier and accessibility requirements

## Preservation Rules

- Preserve structural walls, windows, doors, ceiling height, and essential utilities unless a verified feasible relocation is specified.
- Keep before and after views at the same camera angle for direct comparison.
- Use realistic dimensions, standard materials, code-aware circulation, and buildable assemblies.

## Complete Prompt

```text
Redesign this existing (ROOM) to improve functionality, storage, lighting and visual cohesion. Preserve structural walls, openings and essential utilities. Propose a realistic (STYLE) renovation with buildable solutions, accurate scale and a clear before-and-after transformation.
```

## Renovation Priorities

- Improve traffic flow, ergonomic use, accessibility, and functional zoning.
- Add practical built-in, vertical, hidden, and point-of-use storage.
- Layer ambient, task, and accent lighting while maximizing plausible natural light.
- Unify palette, materials, focal points, and visual proportions.
- Respect structural integrity, utilities, standard dimensions, code constraints, and stated budget.

## Example

```text
Redesign this existing home office to improve functionality, storage, lighting and visual cohesion. Preserve structural walls, openings and essential utilities. Propose a realistic Scandinavian minimalist renovation with buildable solutions, accurate scale and a clear before-and-after transformation.
```

## Negative Prompt

```text
moved load-bearing wall, invented opening, moved window, impossible plumbing relocation, impossible electrical layout, changed ceiling height, changed camera between before and after, unrealistic scale, blocked circulation, insufficient clearance, floating furniture, unbuildable cabinetry, unsupported structure, generic makeover, no storage improvement, flat lighting, oversaturation, watermark, logo
```

## Quality Checklist

- [ ] Room and style variables are replaced.
- [ ] Structural walls, openings, and essential utilities remain preserved.
- [ ] Before and after use the same camera and architectural bones.
- [ ] Function, circulation, storage, lighting, and cohesion clearly improve.
- [ ] Furniture and construction scale are realistic.
- [ ] Proposed work is practical, buildable, and constraint-aware.
