# Interior Design Quick Reference Prompts

A collection of concise, action-oriented prompts for rapid interior design transformations using image references.

---

## 1. AD Magazine Photography Version

**Prompt:**

```
Show me the AD magazine photography version of this image.
```

**Use Case:**

- Transform any interior photo into Architectural Digest-style editorial photography
- Premium luxury magazine aesthetic
- High-end professional styling and lighting
- Award-winning interior photography look

**Best For:**

- Client presentations
- Portfolio pieces
- Marketing materials
- Premium real estate listings

---

## 2. Mediterranean Style Transformation

**Prompt:**

```
Restyle this interior in a Mediterranean style with warm natural materials and linen textures.
```

**Use Case:**

- Complete style transformation to Mediterranean aesthetic
- Warm, natural, organic material palette
- Linen, wood, terracotta, stone textures
- Coastal European design sensibility

**Best For:**

- Style exploration
- Client mood boards
- Regional design adaptations
- Vacation property styling

---

## 3. Furniture Replacement

**Prompt:**

```
In image 1 replace all the furniture with the furniture shown on image 2.
```

**Use Case:**

- Direct furniture substitution between two images
- Maintain room layout and architecture
- Replace entire furniture set with specific reference pieces
- Preserve spatial relationships

**Best For:**

- Furniture shopping visualization
- Product placement testing
- Client furniture selection process
- Before/after comparisons with specific products

**Required:**

- Image 1: Base interior scene
- Image 2: Reference furniture to be transplanted

---

## 4. Soft Morning Light

**Prompt:**

```
Change the lighting in this photo to soft morning light.
```

**Use Case:**

- Transform lighting atmosphere to gentle morning ambiance
- Soft, warm, natural daylight
- Golden hour quality
- Peaceful, serene mood

**Best For:**

- Time-of-day variations
- Mood adjustments
- Natural lighting studies
- Atmospheric realism

**Variations:**

## 5. Add People on Sofa

## Usage Guidelines

### How to Use These Prompts

1. **With AI Image Tools:**
   - Upload your base interior image
   - Copy the exact prompt
   - Let the AI transform based on the instruction

2. **With Image Reference:**
   - Some prompts require uploading 2 images (like #3)
   - Always specify "Image 1" and "Image 2" clearly
   - The AI will use Image 2 as reference for transformation

3. **Customization:**
   - These prompts are templates
   - Adjust style descriptors to your needs
   - Add specific details as needed

### Best Practices

**Keep It Simple:**

- Short, direct commands work best
- One transformation per prompt
- Clear action verbs (show, restyle, replace, change, add)

**Be Specific When Needed:**

- Specify materials, styles, or moods
- Reference image numbers clearly
- Define lighting conditions precisely

**Iterative Refinement:**

- Start with base prompt
- Review result
- Add specific refinements if needed

- "Restyle this interior in [STYLE] with [KEY MATERIALS]"

- "Show me the [MAGAZINE/BRAND] version of this image"

- "Change the lighting to [TIME OF DAY/MOOD]"

## Advanced Combinations

### Multi-Step Transformations

**Step 1:** Base transformation

```
Restyle this interior in modern minimalist style
```

**Step 2:** Lighting adjustment

```
Change the lighting to soft morning light
```

**Step 3:** Add lifestyle

```
Add a person having coffee by the window
```

### Precision Replacement

**For exact furniture matching:**

```
In image 1, replace the sofa with the exact sofa shown in image 2, maintaining the same position, angle, and lighting.
```

**For material changes:**

```
In this image, change the wall color to warm beige and replace the flooring with light oak hardwood.
```

## Tips for Best Results

1. **Use High-Quality Reference Images:**
   - Clear, well-lit photos work best
   - Higher resolution = better results
   - Straight-on architectural shots preferred

2. **Be Consistent with Terminology:**
   - Use the same style descriptors
   - Maintain consistent tone in prompts
   - Reference the same image numbers throughout

3. **Start Broad, Refine Narrow:**
   - Begin with general transformation
   - Add specific details in follow-up prompts
   - Build complexity gradually

4. **Maintain Architectural Integrity:**
   - Prompts should respect room proportions
   - Keep structural elements consistent
   - Preserve spatial relationships

5. **Test and Iterate:**
   - Try variations of phrasing
   - Compare different approaches
   - Build your own prompt library
