# Room Makeover Ideas

## Description

A comprehensive room transformation analyzer that takes an existing space and provides a complete makeover plan. This prompt evaluates your current room and recommends furniture placement, wall colour options, lighting upgrades, storage solutions, and styling changes that improve both function and appearance. Perfect for breathing new life into tired spaces.

## Usage

Upload a photo of your existing room or describe its current state, then receive professional makeover recommendations that address layout inefficiencies, aesthetic shortcomings, and functional improvements. Use this when you want to transform a space without starting from scratch.

## What It Analyzes

- Current furniture arrangement and flow
- Wall colours and their impact on the space
- Lighting quality and placement
- Storage adequacy and organization
- Overall styling and décor cohesion
- Functional challenges and opportunities

## Included Recommendations

- **Layout Improvements**: Better furniture placement and circulation
- **Wall Colours**: Paint options that enhance the space
- **Lighting Upgrades**: Fixtures and placement for better illumination
- **Storage Ideas**: Solutions for clutter and organization
- **Styling Changes**: Décor updates that modernize the look
- **Implementation Tips**: Practical advice for executing changes

## ChatGPT Prompt

```
Analyze this room and suggest a full makeover. Recommend furniture placement, wall colour options, lighting upgrades, storage ideas, and styling changes that improve both function and appearance.

INCLUDE:
• Layout recommendations with furniture placement
• Wall colour options with specific paint suggestions
• Lighting upgrades (fixtures and placement)
• Storage solutions for organization
• Styling changes (décor, textiles, accessories)
• Practical implementation tips

Focus on improvements that make the biggest impact while respecting the existing space constraints.
```

## Example Usage

**Before & After Analysis:**

```
[Upload photo of existing room]

Analyze this room and suggest a full makeover. Recommend furniture placement, wall colour options, lighting upgrades, storage ideas, and styling changes that improve both function and appearance.
```

**Text Description:**

```
Analyze this living room makeover: Currently has a brown leather sofa against the main wall, dated ceiling fan, beige walls, dark wood coffee table, limited natural light from one window, and no overhead lighting except the fan. The room feels dark and cramped. Suggest a full makeover with furniture placement, wall colours, lighting, storage, and styling changes.
```

## Output Format

The AI will provide:

1. **Current State Assessment**: What's working and what's not
2. **Layout Plan**: Recommended furniture placement with circulation flow
3. **Colour Recommendations**: 2-3 wall colour options with rationale
4. **Lighting Strategy**: Specific fixture suggestions and placement
5. **Storage Solutions**: Built-in, furniture, or organizational ideas
6. **Styling Updates**: Textiles, artwork, accessories, and finishing touches
7. **Priority Order**: Which changes to tackle first for maximum impact

## Before & After Focus

- **Before**: Analyze existing problems (dark, cramped, cluttered, dated)
- **After**: Show how changes create a transformed space (bright, open, organized, modern)

## Best Practices

- Provide clear photos from multiple angles if possible
- Mention budget constraints or must-keep items
- Specify any functional requirements (more seating, work area, etc.)
- Note architectural features that can't be changed (windows, doors, built-ins)
- Include room dimensions for accurate furniture scaling

## Use Cases

- Pre-renovation planning and visualization
- Budget-friendly room refreshes without major construction
- Selling a home (staging improvements)
- Renter-friendly updates that don't require permanent changes
- DIY makeover projects
- Design consultations and mood board creation
