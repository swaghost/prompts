# Interior Design Concept Generator

## Description

A comprehensive professional interior design concept generator that creates complete design packages for any room type and style. This prompt acts as a full-service interior designer, delivering colour palettes, furniture direction, lighting concepts, material suggestions, décor styling, and budget-friendly alternatives all in one cohesive design concept.

## Usage

Perfect for creating initial design concepts, client presentations, or exploring multiple design directions for any space. Use this when you need a complete design vision that covers all essential elements from colours to furniture placement to lighting strategy.

## Room Types

- Living rooms, bedrooms, kitchens, bathrooms
- Home offices, dining rooms, entryways
- Commercial spaces (offices, retail, hospitality)
- Multi-functional spaces

## Style Options

Replace `[Style]` with any design aesthetic:

- Modern Minimalist, Industrial Loft, Scandinavian
- Mid-Century Modern, Art Deco, Bohemian
- Japandi, Coastal, Transitional, Contemporary
- English Country, Farmhouse, Maximalist, etc.

## Included Components

- **Colour Palette**: Wall colours, accent shades, coordinating tones
- **Furniture Direction**: Key pieces, placement strategy, scale guidance
- **Lighting Ideas**: Ambient, task, accent, and decorative lighting
- **Material Suggestions**: Flooring, wall finishes, textiles, surfaces
- **Décor Styling**: Artwork, accessories, plants, decorative elements
- **Budget Alternative**: Affordable options that maintain the design vision

## ChatGPT Prompt

```
Act as a professional interior designer. Create a complete design concept for a [Room Type] in [Style]. Include a colour palette, furniture direction, lighting ideas, material suggestions, décor styling, and a simple budget-friendly alternative.

INCLUDE:
• Colour palette with specific paint suggestions
• Furniture recommendations with placement ideas
• Lighting plan (ambient, task, accent, decorative)
• Material selections for all surfaces
• Décor styling with specific examples
• Budget-friendly alternative approach

Keep the concept cohesive, practical, and inspiring. Make it feel professional and ready to implement.
```

## Output Format

The AI will provide:

1. **Design Overview**: Brief concept description
2. **Colour Palette**: Primary, secondary, and accent colours
3. **Furniture Plan**: Key pieces with rationale
4. **Lighting Strategy**: Layered lighting approach
5. **Materials & Finishes**: Surface selections with reasoning
6. **Styling Details**: Décor elements that complete the look
7. **Budget Alternative**: Cost-effective version maintaining the aesthetic

## Best Practices

- Be specific about room type and style for targeted results
- Mention any existing elements to preserve or work around
- Include room dimensions if space planning is critical
- Specify any functional requirements (storage, seating capacity, etc.)
- Request hex codes if you need exact colour specifications

## Use Cases

- Initial client consultations and concept presentations
- Exploring multiple design directions before committing
- Creating mood boards and design proposals
- DIY home renovation planning
- Content creation for interior design portfolios
- Teaching interior design principles
