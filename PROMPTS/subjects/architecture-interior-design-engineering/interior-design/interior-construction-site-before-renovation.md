## Tips for Architectural Consistency

### Critical Elements to Preserve

**From Completed Interior:**

- Exact camera angle and height
- Same floor-to-ceiling corner window size and position
- Identical room dimensions (width, length, ceiling height)
- Same panoramic ocean view outside
- Same spatial proportions
- Same architectural layout

### Implementation Strategies

**Strategy 1: Image-to-Image Reference**
Upload the completed interior as reference when generating the construction site version. Explicitly state: "Same architecture, same camera angle, only the interior finishing state changes."

**Strategy 2: Architecture Locks**
Add to prompt: "Same exact floor-to-ceiling corner windows as reference image, same room dimensions, same camera position, same ocean view. Preserve all architectural elements perfectly."

**Strategy 3: Multiple Generations**
Generate 3-4 versions and select the one with best architectural match to the completed interior. Minor differences acceptable but window placement and proportions must match.

**Strategy 4: Manual Verification**
Overlay the before and after images at 50% opacity to check alignment of:

- Window frames and corners
- Room corners and edges
- Ceiling lines
- Floor perspective lines

## Creative Variations

### Different Construction Phases

**Early Demolition Phase:**
More debris, broken drywall chunks, exposed brick, electrical wiring pulled out, plumbing visible, rougher condition.

**Nearly Complete Phase:**
Drywall installed but unpainted, floors laid but unfinished, electrical roughed in but no fixtures, cleaner appearance.

**Foundation Phase:**
Even more raw—exposed rebar, unfinished concrete, formwork still visible, structural elements more prominent.

### Different Building Types

**Residential Home:**
Wood framing instead of concrete, wood studs, insulation visible, residential construction materials.

**Commercial Office:**
Larger open space, commercial HVAC visible, more industrial infrastructure, office building proportions.

**Loft Conversion:**
Exposed brick walls, original industrial elements, warehouse bones visible, urban loft characteristics.
