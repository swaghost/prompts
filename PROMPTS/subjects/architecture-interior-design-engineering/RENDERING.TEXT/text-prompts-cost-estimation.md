# Cost Estimation & Feasibility - Architectural Text Prompts

## Overview

AI text prompts for generating preliminary cost estimates, analyzing construction feasibility, and evaluating project viability. Use ChatGPT or other AI text tools to quickly assess project costs, analyze site constraints, evaluate program requirements, and support investment decisions.

**Part of:** [Architectural Professional Text Tools Collection](architectural-professional-text.md)

---

## Use Cases

- **Early Project Budgeting** - Quick cost estimates for client discussions
- **Feasibility Studies** - Determine if program fits site and budget
- **Site Analysis** - Evaluate site constraints and opportunities
- **Program Viability** - Assess if requirements are realistic
- **Investment Decisions** - Support go/no-go decision making
- **Value Engineering** - Identify cost reduction strategies
- **Scenario Comparison** - Compare multiple design approaches
- **Budget Gap Analysis** - Find solutions when costs exceed budget

## Basic Prompt Templates

### Simple Cost Estimate

**Prompt:**

```
I have an 860 m² lot in a residential zone. The client wants a 2,500 m² building with a swimming pool. Provide a preliminary cost estimate and analyze the project's construction feasibility.
```

**When to Use:**

- Initial client conversations
- Quick feasibility check
- Order of magnitude budgeting
- First meeting preparation

**Customization:**

- Replace lot size with your site area
- Specify desired building size
- Add special features (pool, garage, etc.)
- Mention location for regional accuracy

---

### Quick Feasibility Check

**Prompt:**

```
Analyze feasibility for a [size] m² [building type] on a [lot size] m² [zone type] lot in [city]. Budget is approximately [amount]. Is this realistic?
```

**Example:**

```
Analyze feasibility for a 350 m² single-family home on a 600 m² residential lot in Austin, Texas. Budget is approximately $450,000. Is this realistic?
```

**When to Use:**

- Client brings unrealistic expectations
- Quick reality check needed
- Early planning phase
- Budget vs. program validation

## Detailed Analysis Prompts

### Comprehensive Feasibility Analysis

**Prompt:**

```
Analyze construction feasibility for the following project:
- Site: [size] m² in [zone type: residential/commercial/mixed-use]
- Program: [size] m² building with [specific features]
- Location: [city/region]
- Client budget: [amount if known]

Provide:
1. Zoning compliance analysis (typical FAR, height limits, setbacks)
2. Preliminary cost estimate ($/m² and total)
3. Construction timeline estimate
4. Key feasibility concerns
5. Recommendations for program adjustments if needed
```

**Example Application:**

```
Analyze construction feasibility for the following project:
- Site: 1,200 m² in urban residential zone
- Program: 800 m² three-story mixed-use building (retail ground floor, 2 residential units above)
- Location: Portland, Oregon
- Client budget: $1.2 million

Provide:
1. Zoning compliance analysis (typical FAR, height limits, setbacks)
2. Preliminary cost estimate ($/m² and total)
3. Construction timeline estimate
4. Key feasibility concerns
5. Recommendations for program adjustments if needed
```

**When to Use:**

- Formal feasibility study
- Project go/no-go decision
- Detailed client presentation
- Investment committee review
- Grant or funding applications

**Tips for Better Results:**

- Be as specific as possible about location
- Include all program requirements
- Mention any site constraints known
- State budget if available
- Request assumptions to be clearly stated

---

### Comparative Scenario Analysis

**Prompt:**

```
Compare construction feasibility and costs for [number] different scenarios:

Scenario A: [description]
Scenario B: [description]
Scenario C: [description]

For each provide:
- Estimated cost ($/m² and total)
- Construction timeline
- Zoning/regulatory considerations
- Pros and cons
- Recommendation with justification
```

**Example Application:**

```
Compare construction feasibility and costs for 3 different scenarios for a community center in suburban Denver:

Scenario A: New 2,500 m² single-story building on vacant lot
Scenario B: Renovation + 1,000 m² addition to existing 1,500 m² warehouse
Scenario C: New 2,000 m² two-story building with basement parking

For each provide:
- Estimated cost ($/m² and total)
- Construction timeline
- Zoning/regulatory considerations
- Pros and cons
- Recommendation with justification
```

**When to Use:**

- Multiple site options available
- Different building approaches possible
- Build vs. renovate decisions
- Phasing strategy evaluation
- Client needs decision support

**Enhancement Requests:**

- "Include lifecycle cost comparison"
- "Add sustainability impact analysis"
- "Compare long-term operational costs"
- "Analyze community impact for each"

## Cost Breakdown Prompts

### Detailed Cost Estimate by System

**Prompt:**

```
Provide detailed cost estimate for [project description] in [location].

Break down costs by major systems:
- Site work and preparation
- Foundation and structure
- Building envelope (exterior walls, roof, windows)
- Interior finishes
- Mechanical systems (HVAC)
- Electrical systems
- Plumbing and fire protection
- Special systems or features
- Site improvements and landscaping
- Soft costs (design, permits, contingency)

Include $/m² and total for each, plus assumptions.
```

**When to Use:**

- Detailed budget planning
- Design development phase
- Value engineering preparation
- Client budget discussions
- Funding application detail

## Value Engineering Prompts

### Budget Gap Solutions

**Prompt:**

```
I have a [project description] with current budget of [amount] and estimated cost of [amount], creating a [X]% budget gap.

Provide value engineering recommendations:
1. Cost reduction strategies that maintain design intent
2. Material substitutions with cost impact
3. Scope modifications to consider
4. Phasing opportunities
5. Alternative systems/methods
6. Prioritized list of reductions to meet budget
```

**Example:**

```
I have a 400 m² luxury residence with current budget of $800,000 and estimated cost of $1,050,000, creating a 31% budget gap.

Provide value engineering recommendations:
1. Cost reduction strategies that maintain design intent
2. Material substitutions with cost impact
3. Scope modifications to consider
4. Phasing opportunities
5. Alternative systems/methods
6. Prioritized list of reductions to meet budget
```

**When to Use:**

- Bids exceed budget
- Client budget reduced
- Cost escalation issues
- Design aspirations exceed budget
- Need to find savings quickly

### Material Substitution Analysis

**Prompt:**

```

- Similar aesthetic quality
- Comparable performance
- Acceptable durability
- Design intent

For each alternative provide:
- Material description
- Cost comparison ($/m² or $/unit)
- Total savings potential
- Performance trade-offs
- Aesthetic differences
- Recommendation
```

**Example:**

```
Current design uses European porcelain tile flooring throughout (2,500 m²). Analyze cost-effective alternatives that maintain:
- Similar aesthetic quality
- Comparable performance
- Acceptable durability
- Design intent

For each alternative provide:
- Material description
- Cost comparison ($/m² or $/unit)
- Total savings potential
- Performance trade-offs
- Aesthetic differences
- Recommendation
```

---

### System Alternative Analysis

**Prompt:**

```
Compare cost and performance of these systems for [project]:

Option A: [current design system]
Option B: [alternative 1]
Option C: [alternative 2]

For each analyze:
- Initial construction cost
- Installation complexity and timeline
- Energy/operating costs (annual)
- Maintenance requirements
- Expected lifespan
- Performance characteristics
- Total cost of ownership (10 years)
- Recommendation with justification
```

**Example:**

```
Compare cost and performance of these HVAC systems for 300 m² office building in Chicago:

Option A: Traditional split-system with gas furnace and A/C
Option B: High-efficiency heat pump system
Option C: VRF (Variable Refrigerant Flow) system

For each analyze:
- Initial construction cost
- Installation complexity and timeline
- Energy/operating costs (annual)
- Maintenance requirements
- Expected lifespan
- Performance characteristics
- Total cost of ownership (10 years)
- Recommendation with justification
```

## Phasing & Schedule Analysis

### Construction Phasing Strategy

**Prompt:**

```
Develop construction phasing strategy for [project description] with [constraint: limited budget/occupied building/seasonal restrictions/etc.].

Provide:
- Recommended number of phases
- Scope of each phase
- Cost breakdown by phase
- Timeline for each phase
- Critical dependencies between phases
- Temporary conditions needed
- Advantages of phased approach
- Risks and mitigation strategies
```

**When to Use:**

- Limited initial funding
- Occupied building renovation
- Large projects with flexible timeline
- Minimizing disruption
- Cash flow management

## Regional & Market Analysis

### Location-Specific Estimate

**Prompt:**

```
Provide cost estimate for [project description] specifically for [city/region] market.

Account for:
- Regional cost factors (labor, materials, market conditions)
- Local code requirements impacting cost
- Climate considerations affecting systems
- Regional construction practices
- Current market conditions (hot/normal/slow)
- Availability of contractors and trades
- Typical construction timeline for this region

Clearly state all regional assumptions.
```

**Example:**

```
Provide cost estimate for 250 m² single-family residence, contemporary design, mid-range finishes, specifically for Vancouver, BC market.

Account for:
- Regional cost factors (labor, materials, market conditions)
- Local code requirements impacting cost (BC Building Code, energy requirements)
- Climate considerations affecting systems (heating, envelope)
- Regional construction practices (wood frame typical)
- Current market conditions
- Availability of contractors and trades
- Typical construction timeline for this region

Clearly state all regional assumptions.
```

**Tips:**

- Name specific city/region for accuracy
- Mention if market is particularly hot or slow
- Note if remote or urban area (affects logistics)
- Indicate if labor shortages exist

---

### Market Timing Analysis

**Prompt:**

```
Analyze optimal construction timing for [project] in [location].
```

## Specialized Project Types

### Renovation Cost Analysis

**Prompt:**

```
Estimate costs for renovation of existing [building type] built in [decade]:
- Current size: [area]
- Renovation scope: [description]
- Work type: [cosmetic/moderate/extensive/gut renovation]
- Building condition: [good/fair/poor]
- Known issues: [structural, systems, code compliance]
- Special requirements: [historic preservation, occupied, hazmat]

Provide:
- Demolition and abatement costs
- Building upgrades and new construction costs
- Code compliance upgrade costs
- Contingency recommendations (renovation unknowns)
- Total estimated cost
- Risk factors and unknowns
```

**When to Use:**

- Adaptive reuse projects
- Historic renovation
- Building repositioning
- Tenant improvement
- Existing building upgrades

## Output Format Specifications

### Request Specific Format

**Add to any prompt:**

"Format the cost estimate as follows:

- Executive summary (total cost, $/m², timeline)
- Detailed cost breakdown by [system/phase/CSI division]
- Key assumptions clearly stated
- Risk factors and contingencies
- Comparison to similar projects if possible
- Recommendations for next steps"

---

### Table Format Request

**Add to any prompt:**

"Present cost breakdown in table format:

| Item | Quantity | Unit | Unit Cost | Total Cost | % of Total |
| ---- | -------- | ---- | --------- | ---------- | ---------- |
| ...  | ...      | ...  | ...       | ...        | ...        |

Include subtotals and grand total."

## Enhancement Techniques

### Increase Accuracy

**Add these details:**

- Specific location (city, state/province)
- Building type and use
- Quality/finish level (economy/standard/high-end/luxury)
- Special features or systems
- Site conditions and challenges
- Timeline requirements
- Known constraints

---

### Request Assumptions

**Always add:**
"Clearly state all assumptions made in this estimate, including:

- Cost basis ($/m² factors used)
- Regional multipliers applied
- Contingency percentages
- Market conditions assumed
- Escalation factors if applicable
- What is included vs. excluded"

---

### Range Instead of Single Number

**Add:**
"Provide cost estimate as range (low/medium/high scenarios) with explanation of what drives differences."

---

### Comparison Context

**Add:**
"Compare this estimate to typical costs for similar [building type] projects in this market."

## Follow-Up Prompts


### Validating Estimates

```
"What are the biggest cost uncertainties in this estimate? What could cause significant cost increases?"
```

---

### Alternative Exploration

```
"If budget is limited to [amount], what scope adjustments would you recommend to meet that target?"

```

## Quality Control Checklist

Before using AI cost estimate:

- [ ] Verified location specificity
- [ ] Included all program requirements
- [ ] Specified quality/finish level
- [ ] Mentioned special features or systems
- [ ] Noted site constraints
- [ ] Requested assumptions to be stated
- [ ] Asked for appropriate detail level
- [ ] Specified output format needed
- [ ] Included timeline parameters
- [ ] Noted any special requirements

After receiving estimate:

- [ ] Review assumptions for reasonableness
- [ ] Verify calculations if provided
- [ ] Check against known local costs
- [ ] Assess completeness (nothing major missing)
- [ ] Note what is included vs. excluded
- [ ] Understand contingency and soft costs
- [ ] Validate with professional estimator if critical
- [ ] Clearly label as "preliminary AI-generated estimate"
- [ ] Use as discussion tool, not final budget

## Professional Use Guidelines

### Appropriate Applications

✅ **Good for:**

- Initial client discussions
- Early feasibility studies
- Order of magnitude budgeting
- Scenario comparisons
- Value engineering ideation
- Internal planning
- Educational estimates

✅ **With Verification:**

- Project budgeting (verify with professional estimator)
- Funding applications (validate before submission)
- Client proposals (cross-check key numbers)

---

### Limitations & Disclaimers

❗ **Important:**

- AI estimates are preliminary and approximate
- Regional cost data may not be current
- Unique site conditions not fully accounted for
- Market conditions change rapidly
- Professional cost estimating still required for accuracy
- Not a substitute for quantity surveyor or professional estimator
- Actual bids may vary significantly

❗ **Always:**

- Label estimates as "AI-generated preliminary"
- Verify with current market data
- Engage professional estimator for critical decisions
- Include appropriate contingencies
- Update as design develops
- Get competitive bids for actual costs

---

### Risk Management

**Protect yourself and clients:**

1. **Disclose AI use** - Be transparent about AI-generated estimates
2. **Add contingency** - Higher for preliminary AI estimates
3. **Professional review** - Have estimates verified
4. **Document assumptions** - Keep track of what was included
5. **Use ranges** - Not single precise numbers
6. **Update regularly** - Market conditions change
7. **Competitive bidding** - Always get actual contractor bids
