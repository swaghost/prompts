## Prompt Description

A professional architectural concept sheet designed for portfolio presentations and jury reviews. Creates comprehensive presentation boards featuring uploaded 3D render/model with material callouts, form-development diagrams, material palettes, geometric analysis, human-scale diagrams, day/night lighting views, and key architectural details. Uses clean premium architecture-portfolio aesthetic with off-white background, subtle grid, black typography, thin annotation lines, and balanced editorial layout.

---

## Complete Prompt

Create a professional architectural concept sheet based on the uploaded render/model, in a 1:1 square format with a clean premium architecture-portfolio aesthetic. Use an off-white background, subtle grey grid, black typography, thin annotation lines, and a balanced editorial layout.

Include:

- Project title + concept summary
- Large hero render with architectural/material callouts
- Concept & form-development diagrams
- Material palette with labeled swatches
- Geometric rhythm + massing analysis
- Human-scale / user-experience diagram
- Day & night lighting/atmosphere views
- 3-4 key architectural detail images

Keep the architectural design, proportions, materials, and overall character of the uploaded project intact. Use realistic textures, clean structural diagrams, muted neutral colors, precise grid alignment, professional labels, and clear hierarchy, making it look like a polished architecture jury/presentation board.

## Structured Breakdown

### Board Layout & Format

**Format Specifications:**

- Professional architecture portfolio aesthetic

**Background Treatment:**

**Typography System:**

- Black professional architectural fonts
- Sans-serif clean typefaces (Helvetica, Futura, DIN)
- Clear hierarchy (titles, labels, annotations)
- Thin annotation lines connecting callouts
- Professional label formatting

### Project Title + Concept Summary

**Location:** Top section of board
**Contains:**

- **Project Title:** Clear prominent name
- **Project Type:** Building category (residential, commercial, cultural, etc.)
- **Concept Summary:** 2-4 sentence description of design intent
- **Key Stats:** Square footage, floors, location (if applicable)

**Typography:**

- Large bold title (24-36pt equivalent)
- Medium subtitle for project type
- Body text for concept summary (10-12pt)
- Black on off-white for maximum readability

**Example Layout:**

```
[PROJECT NAME]
Mixed-Use Cultural Center

A contemporary cultural hub integrating performance spaces,
gallery exhibitions, and community programs through a dynamic
folded-plate roof structure that creates varied ceiling heights
and natural daylighting strategies.
```

### Large Hero Render with Callouts

**Primary Visual Element:**

- **Size:** Occupies 40-50% of board space
- **Position:** Central or upper-center prominence
- **Source:** Uploaded 3D render/model as base
- **Treatment:** Clean professional architectural rendering

**Architectural/Material Callouts:**

- Thin black annotation lines pointing to features
- Labels for key materials (glass curtain wall, concrete, timber, metal cladding)
- Structural elements identified (columns, beams, cantilevers)
- Architectural features highlighted (entrance, roof overhang, facade system)
- Clean arrow/line leaders to text labels

**Callout Examples:**

- "Perforated metal screen facade"
- "Cantilevered concrete roof plate"
- "Floor-to-ceiling glazing system"
- "Exposed structural timber columns"
- "Green roof terrace"

### Concept & Form-Development Diagrams

**Purpose:** Show design evolution and spatial concepts
**Contains:**

- **Conceptual diagrams:** Abstract representations of core ideas
- **Form evolution:** 3-5 massing studies showing development
- **Spatial organization:** Diagrams showing program relationships
- **Circulation concepts:** Flow patterns and movement

**Diagram Style:**

- Simple axonometric or isometric views
- Minimal color (black, grey, one accent color)
- Clean line work
- Labeled with brief descriptive text
- Sequential left-to-right progression

**Example Diagrams:**

1. Initial massing concept (simple volume)
2. Subtracted/carved spaces (void creation)
3. Layered program zones (stacked functions)
4. Final integrated form (complete design)

### Material Palette with Labeled Swatches

**Layout:**

- Horizontal row or grid of material samples
- Each swatch 50-100px with label below
- Real material textures/photos
- Color-accurate representation

**Materials to Include:**

- Primary facade material (glass, metal, concrete, brick)
- Secondary facade material
- Structural material (steel, concrete, timber)
- Interior finish materials (flooring, wall, ceiling)
- Accent materials (wood, metal, stone)

**Swatch Format:**

```
[Material Image/Texture]
MATERIAL NAME
Technical spec (if relevant)
```

**Example:**

```
[Concrete texture]        [Glass texture]         [Timber texture]
Board-Formed Concrete    Low-Iron Glazing        White Oak Cladding
Exposed aggregate        Clear vision glass      Vertical grain
```

### Geometric Rhythm + Massing Analysis

**Purpose:** Demonstrate design logic and proportional systems
**Contains:**

- **Geometric overlay:** Grid systems, golden ratio, proportions
- **Rhythm diagrams:** Repetition patterns in facade or structure
- **Massing breakdown:** Volumetric composition analysis
- **Axonometric massing:** 3D view showing form relationships

**Analysis Style:**

- Overlay diagrams on plan/elevation/axon
- Colored or numbered zones showing relationships
- Dimension lines showing key proportions
- Abstract geometric breakdown

**Example Annotations:**

- "3:2 proportional system"
- "6m structural bay rhythm"
- "Primary volume + secondary canopy"
- "Rotated grid creates dynamic entry"

### Human-Scale / User-Experience Diagram

**Purpose:** Show how people interact with and move through space
**Contains:**

- **Human figures:** Silhouettes at correct scale
- **Circulation paths:** Arrows showing movement flows
- **Activity zones:** Areas labeled with program uses
- **Sight lines:** Visual connections and view corridors
- **Scale comparison:** Building elements related to human dimensions

**Diagram Types:**

- Section with human figures showing scale
- Plan with circulation arrows
- Perspective sketch with people
- Experience sequence diagram

**Example Labels:**

- "Main entrance at street level"
- "Vertical circulation core"
- "Public gathering space"
- "Views to exterior plaza"

### Day & Night Lighting/Atmosphere Views

**Purpose:** Show how building performs in different lighting conditions
**Contains:**

- **Daytime view:** Natural sunlight, shadows, material appearance
- **Nighttime view:** Artificial lighting, interior glow, exterior illumination
- **Same camera angle/viewpoint:** Direct comparison
- **Atmospheric rendering:** Mood and ambiance

**Rendering Style:**

- Photorealistic architectural rendering
- Accurate material response to light
- Realistic shadows and reflections
- Atmospheric depth

**Side-by-side Layout:**

```
[Day View]                    [Night View]
Natural daylighting          Interior lighting glows
Material textures visible    Facade illumination
Sun angles and shadows       Ambient exterior lighting
```

### 3-4 Key Architectural Detail Images

**Purpose:** Highlight significant design elements and construction details
**Contains:**

- **Detail 1:** Facade system closeup (cladding, glazing, joints)
- **Detail 2:** Structural connection or cantilever detail
- **Detail 3:** Material transition or corner condition
- **Detail 4:** Interior architectural feature (stair, ceiling, wall)

**Detail Style:**

- Closeup renders or technical drawings
- Material textures visible
- Construction logic clear
- Scale reference if needed

**Layout:**

- Grid of 3-4 images (equal size or varied)
- Brief labels beneath each
- Located in lower section or side panel

**Example Details:**

- "Perforated screen facade assembly"
- "Cantilevered roof edge detail"
- "Glass-to-concrete junction"
- "Timber ceiling panel system"

## Typography & Grid System

### Typography Hierarchy

**Level 1 - Project Title:**

- Large bold sans-serif
- 24-36pt equivalent
- Black color
- Prominent placement

**Level 2 - Section Headers:**

- Medium weight sans-serif
- 14-18pt equivalent
- Black or dark grey
- Clear section breaks

**Level 3 - Body Text:**

- Regular weight sans-serif
- 10-12pt equivalent
- Black or dark grey
- Concept descriptions

**Level 4 - Annotations/Labels:**

- Light or regular weight
- 8-10pt equivalent
- Thin leader lines
- Material and feature callouts

### Grid System Principles

**Base Grid:**

- Subtle grey grid overlay (10-20% opacity)
- 12-column or 16-column system
- Consistent margins (5-10% of board width)
- Gutter spacing between elements

**Alignment Rules:**

- All elements snap to grid
- Consistent spacing between sections
- Balanced visual weight distribution
- Clear hierarchy through size and position

**White Space:**

- Generous breathing room
- Not overcrowded
- Strategic emptiness for focus
- Premium editorial aesthetic

## Workflow Summary

### Step-by-Step Process

**Step 1: Prepare Your Render**

- Create or select primary 3D architectural render
- Ensure high-resolution quality
- Clean professional rendering
- Context included if relevant

**Step 2: Identify Key Elements**

- List materials used in project
- Identify key architectural features
- Select important details to highlight
- Determine diagram needs

**Step 3: Open AI Platform**

- ChatGPT/DALL-E or MidJourney
- Start new conversation

**Step 4: Upload Render**

- Upload primary 3D render/model image
- Ensure upload confirmation

**Step 5: Paste Prompt**

- Copy complete architectural concept sheet prompt
- Customize for your project type if needed
- Submit for generation

**Step 6: Review Generated Board**

- Check all required elements included
- Verify architectural design maintained
- Assess layout and hierarchy
- Confirm professional quality

**Step 7: Refine if Needed**

- Regenerate for different layout
- Adjust specific sections emphasis
- Try variations with different diagram focus

**Step 8: Export & Use**

- Download high-resolution board
- Use for presentations, portfolio, submissions
- Print or display digitally

## Common Issues & Solutions

### Issue: Board looks cluttered or overcrowded

**Solutions:**

- Regenerate emphasizing "clean layout with white space"
- Remove less critical elements from prompt
- Request "balanced editorial layout with breathing room"

### Issue: Diagrams don't relate to uploaded render

**Solutions:**

- Be more specific about building features in prompt
- Mention key design concepts to emphasize
- Regenerate with architectural feature callouts

### Issue: Typography too small or hard to read

**Solutions:**

- Emphasize "readable typography, clear hierarchy"
- Request "professional labels, large enough to read"
- Regenerate for better text sizing

### Issue: Materials don't match actual project

**Solutions:**

- Specify exact materials in prompt: "concrete, glass, timber"
- Upload closer detail shots of materials
- Regenerate with material emphasis

### Issue: Layout doesn't follow grid

**Solutions:**

- Emphasize "precise grid alignment, organized layout"
- Request "professional architecture portfolio aesthetic"
- Regenerate for cleaner grid adherence
