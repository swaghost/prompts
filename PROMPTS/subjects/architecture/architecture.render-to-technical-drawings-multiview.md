A complete set of professional architectural technical drawings generated from a 3D render, including Front, Back, Left, Right elevations, Plan View, and Sections A-A / B-B, with accurate dimensions, furniture details, wall systems, lighting, and CAD-style annotations in a clean professional architectural layout—all as accurate projections of the same scene.

Perfect for construction documentation, permit applications, design development presentations, and technical construction communication. Ideal for converting 3D visualizations into working drawings, creating construction documents from design renders, generating multi-view technical documentation, and providing contractors with complete dimensional information. This prompt excels at reverse-engineering renders into comprehensive technical drawing sets.

## Image Prompt

**CRITICAL:**
Generate full architectural elevations, plan, and sectional drawings directly from the original render while preserving all design details exactly. All views must be accurate projections of the same scene with no redesign, simplification, or missing elements.

**Subject:**
Complete architectural drawing set showing:

- **Front Elevation:** Full exterior or primary view with all windows, doors, materials, heights
- **Back Elevation:** Rear view with complete architectural features
- **Left Elevation:** Side view showing full height and depth
- **Right Elevation:** Opposite side view with all details
- **Plan View:** Top-down floor plan showing walls, doors, furniture placement, room dimensions
- **Section A-A:** Primary vertical cut-through showing interior heights, floor-to-ceiling dimensions, structural elements
- **Section B-B:** Secondary section (perpendicular to A-A) showing alternate spatial relationships

**Setting/Environment:**
Professional architectural drawing sheet with clean white background. Multi-panel layout with all seven views arranged in logical hierarchy following architectural drawing conventions. Primary elevations and plan positioned prominently, sections supporting.

**Visual Characteristics:**

- **Line Work:** Clean black lines on white background, varied line weights (thick for profiles, medium for objects, thin for details, dashed for hidden elements)
- **Dimensions:** Complete dimensional annotations with extension lines, dimension strings, arrows, and numerical callouts showing all critical measurements
- **Furniture Details:** All furniture from render shown in plan and relevant elevations with accurate scale and position
- **Wall Systems:** Wall thicknesses clearly defined, door swings indicated, window openings dimensioned
- **Lighting:** Light fixtures shown in plan view with symbols, ceiling fixtures indicated, switch locations marked
- **CAD-Style Annotations:** Room labels, material call-outs, numbered keys, north arrow, scale notation, section cut lines with reference bubbles
- **Accurate Projections:** Every view must be true orthographic projection of the same space—no inconsistencies between views

**Technical Drawing Elements:**

- Title block with project information, scale, date, drawing numbers
- Scale bar for each view
- Section cut lines shown on plan view indicating where A-A and B-B sections are taken
- Elevation markers showing viewing directions
- Grid lines or reference system (optional)
- Material hatching or patterns in sections (concrete, wood, insulation)
- Door and window schedules (optional reference)
- General notes and specifications

**Layout Structure:**
Professional architectural sheet layout with:

- Plan View (upper center or center)
- Front Elevation (primary position)
- Back Elevation (secondary position)
- Left and Right Elevations (supporting positions)
- Section A-A and Section B-B (lower or side positions)
- Title block (lower right corner)
- All views aligned and coordinated on grid
- Consistent scale across related views

**Typography Treatment:**
Professional architectural font (typically sans-serif like Arial, Helvetica, or technical drawing font). Varied text sizes: large for titles, medium for room labels, small for dimensions and notes. All text horizontal for readability.

**Composition:**
Balanced multi-panel layout with clear visual hierarchy. Primary views larger, supporting views appropriately sized. Generous white space between views. Professional margins. All elements aligned on underlying grid system.

**Style & Aesthetic:**
Contemporary architectural construction documentation aesthetic. Professional CAD-style line drawings. Clean minimal presentation focused on technical accuracy and clarity. Similar to professional architecture firm construction document sets.

**Technical Specifications:**
High-resolution technical drawing, precise dimensional accuracy, consistent scale notation, professional line work, orthographic projection standards, architectural drawing conventions compliance, construction document quality.

**Color Palette:**
Primarily monochrome: black lines on white background. Optional subtle gray for secondary elements, light colors for material differentiation in sections (concrete gray, wood tan, insulation pink—all muted and minimal).

**Mood & Atmosphere:**
Professional, precise, technical, comprehensive, construction-ready, documentation quality, architecturally accurate, contractor-friendly, permit-ready.

**Quality Keywords:**
Architectural drawings, multi-view projections, CAD-style documentation, construction drawings, dimensioned elevations, sectional drawings, plan view, technical precision, professional presentation, complete documentation set, orthographic projection.

**Negative Prompt (What to Avoid):**
Photorealistic rendering, perspective distortion, artistic interpretation, missing dimensions, incomplete views, inconsistent projections, decorative elements, 3D appearance, shadows or shading (except section cut poché), simplified details, missing furniture, inaccurate scale, hand-drawn sketch style, colorful presentation, missing annotations.
