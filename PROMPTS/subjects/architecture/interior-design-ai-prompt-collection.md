# Interior Design AI Prompt Collection – Professional Architectural Visualization

## Description

A comprehensive collection of 8 specialized AI prompts for interior design, architectural visualization, and space planning. Each prompt is designed for professional-grade results including complete design concepts, furniture layouts, material palette replacements, custom furniture design, color palette generation, moodboard creation, photorealistic rendering, and strategic renovations. All prompts emphasize photorealism, natural lighting, accurate scale, functional circulation, and preservation of architectural integrity. Variables allow customization for different room types, design styles, user counts, and material preferences.

## Usage

Perfect for interior designers, architects, real estate staging, renovation planning, client presentations, design portfolios, architectural visualization services, furniture design, color consulting, moodboard creation, before-and-after transformations, space optimization, and AI-powered design workflows for residential and commercial projects.

## Prompt 02: Furniture Layout Optimization

### Purpose

Analyze floor plans or existing rooms and propose optimized furniture layouts for specified number of users, ensuring comfortable circulation, functional zones, ergonomic distances, and visual balance.

### Complete Prompt

```
Analyze this floor plan or room and propose an optimized furniture layout for (NUMBER) users. Preserve doors, windows, plumbing points and structural walls. Ensure comfortable circulation, functional zones, ergonomic distances and visual balance. Show the result as a clean top-down layout with clear furniture placement and approximate measurements.
```

### Variable Definitions

**(NUMBER)** - Replace with user count:

- 1 user (individual space)
- 2 users (couple, shared space)
- 3 users (small family)
- 4 users (standard family)
- 5-6 users (large family)
- 8-10 users (dining/gathering spaces)
- 12+ users (commercial/office spaces)

### Layout Principles

- **Circulation Paths**: Minimum 90cm (36") walkways between furniture
- **Functional Zones**: Define areas for different activities (conversation, dining, work, relaxation)
- **Ergonomic Distances**: TV viewing distance 2-3x screen diagonal, dining table 60cm per person
- **Visual Balance**: Distribute visual weight evenly, avoid all furniture on one side
- **Traffic Flow**: Keep paths clear to doors, windows, and between zones

### Example Usage

```
Analyze this floor plan or room and propose an optimized furniture layout for 4 users. Preserve doors, windows, plumbing points and structural walls. Ensure comfortable circulation, functional zones, ergonomic distances and visual balance. Show the result as a clean top-down layout with clear furniture placement and approximate measurements.
```

## Prompt 06: Professional Moodboard Creation

### Purpose

Create professional editorial-quality moodboards for any room in any style, including cohesive color palette, material samples, textures, furniture silhouettes, lighting references, and décor details. Organized with clear hierarchy, generous spacing, and neutral background.

### Complete Prompt

```
Create a professional moodboard for a (ROOM) in (STYLE). Include a cohesive color palette, material samples, textures, furniture silhouettes, lighting references and décor details. Organize it with clear hierarchy, generous spacing and editorial composition. Neutral background, realistic samples, premium presentation.
```

### Variable Definitions

**(ROOM)** - Room type (same as previous prompts)

**(STYLE)** - Design aesthetic (same as previous prompts)

### Moodboard Components to Include

1. **Color Palette**: 5-7 color swatches with HEX codes
2. **Material Samples**: Wood swatches, stone samples, fabric swatches, metal finishes
3. **Textures**: Close-up texture photography showing materiality
4. **Furniture Silhouettes**: Key pieces (sofa, bed, dining table, chairs, storage)
5. **Lighting References**: Pendant lights, floor lamps, sconces, natural light examples
6. **Décor Details**: Artwork examples, plants, textiles, accessories
7. **Typography**: Room name and style in elegant font
8. **Layout**: Grid-based or free-flowing with balance and white space

### Presentation Guidelines

- **Background**: Off-white, cream, or soft grey - never pure white
- **Spacing**: Generous margins between elements (minimum 5-10% of board width)
- **Hierarchy**: Larger hero images (30-40% of board), supporting images (15-20%), detail images (10-15%)
- **Alignment**: Use grid system for clean organization
- **Quality**: High-resolution images, realistic material samples
- **Cohesion**: All elements should feel like they belong to the same design story

### Example Usage

```
Create a professional moodboard for a master bedroom in mid-century modern. Include a cohesive color palette, material samples, textures, furniture silhouettes, lighting references and décor details. Organize it with clear hierarchy, generous spacing and editorial composition. Neutral background, realistic samples, premium presentation.
```

## Prompt 07: Photorealistic Render (Render Realista)

### Purpose

Convert SketchUp models, sketches, or basic 3D renders into photorealistic interior renders with natural daylight, warm indirect lighting, refined architectural details, and high realism.

### Complete Prompt

```
Convert this SketchUp model or sketch into a photorealistic interior render. Preserve geometry, proportions, furniture positions and camera angle. Apply realistic materials, natural daylight, warm indirect lighting and refined details. Architectural photography, high realism.
```

### Rendering Enhancements

- **Materials**: Replace basic SketchUp materials with photorealistic PBR textures (wood grain, stone veining, fabric weave, metal reflections)
- **Lighting**: Add natural window light with realistic falloff, warm indirect bounce light, soft shadows
- **Details**: Include crown molding, baseboards, door frames, switch plates, realistic joints
- **Depth of Field**: Slight blur on distant elements for photographic realism
- **Color Grading**: Natural, slightly warm color temperature (3000-4000K)
- **Atmosphere**: Subtle dust particles in light rays, slight lens vignette
- **Scale**: Ensure all furniture and architectural elements are realistically sized
- **Textures**: High-resolution, properly scaled textures with normal maps

### Input Requirements

- SketchUp (.skp) file or exported image
- Clear camera angle and composition
- Defined furniture layout and spatial planning
- Specified or existing material indications

### Example Usage

```
Convert this SketchUp model or sketch into a photorealistic interior render. Preserve geometry, proportions, furniture positions and camera angle. Apply realistic materials, natural daylight, warm indirect lighting and refined details. Architectural photography, high realism.
```

## Prompt 08: Strategic Renovation (Reforma Estratégica)

### Purpose

Redesign existing rooms to improve functionality, storage, lighting, and visual cohesion. Preserve structural walls, openings, and essential utilities. Propose realistic renovation with buildable solutions, accurate scale, and clear before-and-after transformation.

### Complete Prompt

```
Redesign this existing (ROOM) to improve functionality, storage, lighting and visual cohesion. Preserve structural walls, openings and essential utilities. Propose a realistic (STYLE) renovation with buildable solutions, accurate scale and a clear before-and-after transformation.
```

### Variable Definitions

**(ROOM)** - Room type to renovate

**(STYLE)** - Target design aesthetic for renovation

### Renovation Focus Areas

**Functionality Improvements**:

- Better traffic flow and circulation patterns
- Optimized furniture placement for intended use
- Multi-functional spaces (home office + guest room, laundry + mudroom)
- Improved ergonomics and accessibility

**Storage Solutions**:

- Built-in cabinetry and shelving
- Under-stair storage
- Vertical storage maximization
- Hidden storage (under beds, in ottomans)
- Closet organization systems

**Lighting Enhancements**:

- Layered lighting (ambient, task, accent)
- Natural light maximization (larger windows, skylights if possible)
- LED recessed lighting
- Pendant and decorative fixtures
- Under-cabinet and toe-kick lighting

**Visual Cohesion**:

- Unified color palette
- Consistent material language
- Balanced proportions
- Focal point creation
- Style consistency throughout

**Buildable Solutions**:

- Maintain structural integrity
- Respect plumbing and electrical locations (or show realistic relocation)
- Standard material sizes and dimensions
- Code-compliant solutions
- Realistic budget considerations

### Before-and-After Requirements

- Same camera angle for both views
- Clear visual comparison showing improvements
- Maintain architectural bones (windows, doors, ceiling height)
- Show realistic wear/condition in "before"
- Show polished, cohesive design in "after"

### Example Usage

```
Redesign this existing home office to improve functionality, storage, lighting and visual cohesion. Preserve structural walls, openings and essential utilities. Propose a realistic Scandinavian minimalist renovation with buildable solutions, accurate scale and a clear before-and-after transformation.
```

## Pro Tips

### Maximum Impact

- **Start with Style Reference**: Always provide or specify a clear design style. "Contemporary" is too vague - use "Contemporary Scandinavian with warm oak and soft neutrals" for better results.
- **Be Specific with Materials**: Don't just say "wood" - specify "white oak with natural oil finish" or "reclaimed walnut with visible grain." Material specificity dramatically improves realism.
- **Lighting is Everything**: Natural daylight + warm indirect lighting creates the most realistic and inviting renders. Specify time of day and light quality.
- **Preserve Architecture**: Always emphasize preserving original architecture, proportions, and structural elements. AI tends to hallucinate new windows or doorways if not instructed otherwise.

### Professional Quality

- **Real-World Scale**: Specify realistic dimensions. A sofa should be 200-240cm wide, dining tables 90-100cm wide, walkways minimum 90cm. Including measurements improves accuracy.
- **Layer Your Lighting**: Request ambient (overall) + task (reading, cooking) + accent (artwork, architectural features) lighting. Single overhead lights look flat and unrealistic.
- **Material Transitions**: Where different materials meet (wood to stone, wall to floor), AI should show realistic transitions - not floating materials or abrupt changes.
- **Camera Height Matters**: Eye-level (150cm height) for living spaces, slightly lower (120cm) for dining rooms, higher (180cm) for large spaces to show layout.

### Technical Execution

- **Iteration Strategy**: Generate 4-5 variations of each design, then select the best and refine further. First generation rarely perfect.
- **Reference Images**: When possible, upload reference images for style, materials, or furniture types. This dramatically improves consistency and accuracy.
- **Negative Prompts**: Include "unrealistic proportions, floating furniture, oversaturated colors, fake plants, stock photos" to avoid common AI pitfalls.
- **Aspect Ratios**: Use 3:2 or 4:3 for most interior views, 16:9 for wide living spaces, 9:16 for tall spaces (entryways, staircases).

### Platform-Specific Tips

- **For Midjourney**: Use "--ar 3:2 --style raw --v 6.1" for most architectural renders. Add "--chaos 10" for variation, "--stylize 200" for more artistic interpretation.
- **For DALL-E 3**: Be extremely specific in prompts - DALL-E follows instructions literally. Include "photorealistic architectural photography" at the end of every prompt.
- **For Stable Diffusion**: Use ArchitectureXL or RealisticVision checkpoints. Include "architectural digest, interior design magazine, professional photography" in positive prompt.
- **For SketchUp to Render**: Export at high resolution (min 4K), use proper SketchUp materials as guides, ensure clean geometry before converting.

### Customization Strategies

- **Regional Styles**: Adapt materials and colors for regional aesthetics - Nordic (light woods, whites, greys), Mediterranean (terracotta, stone, warm whites), Asian (dark woods, paper, minimalism).
- **Budget Tiers**: Luxury (marble, brass, custom furniture), Mid-range (engineered quartz, quality laminate, mix of custom and standard), Budget (laminate, painted finishes, standard furniture).
- **Room Size Adaptation**: Small rooms (built-in storage, light colors, minimal furniture), Large rooms (zone definition, larger furniture, bold colors possible).
- **Client Preferences**: Always ask about client's lifestyle, preferred colors, storage needs, and must-have features before generating designs.

### Color Theory Applications

- **60/30/10 Rule**: 60% dominant (walls, large surfaces), 30% secondary (furniture, larger décor), 10% accent (pillows, art, accessories). This creates visual balance.
- **Complementary Contrast**: Use colors opposite on color wheel for drama (blue + orange, purple + yellow). Use analogous colors (next to each other) for harmony.
- **Neutral Foundation**: Start with neutral dominant colors (whites, greys, beiges) then layer in bolder secondary and accent colors. Easier to live with long-term.
- **Natural Light Consideration**: Cool-toned rooms (north-facing) benefit from warm colors (terracotta, warm greys, wood). Warm-toned rooms (south-facing) can handle cooler colors (blues, greens).

### Material Selection Guidelines

- **Wood**: Light woods (oak, ash, maple) feel modern and spacious. Dark woods (walnut, ebony) feel sophisticated and cozy. Match with room size and light levels.
- **Stone**: Marble for luxury (bathrooms, kitchens), limestone/travertine for warmth (living spaces), slate for texture (feature walls). Consider maintenance needs.
- **Fabric**: Linen for casual elegance, velvet for luxury, leather for durability, wool for texture. Layer different textures for depth.
- **Metal**: Brass for warmth (traditional, mid-century), black steel for modern edge (industrial, contemporary), chrome for clean minimalism (modern, bathrooms).

### Furniture Layout Principles

- **Conversation Distance**: Seating should be 180-270cm apart for comfortable conversation. Coffee table 45cm from sofa edge.
- **TV Viewing**: Distance should be 2-3x the screen diagonal. For 55" TV, sit 280-420cm away. TV center at eye level when seated.
- **Dining**: Allow 60cm width per person at table, 90-120cm pullout space for chairs behind diners.
- **Traffic Paths**: Main circulation 120cm wide, secondary paths 90cm minimum. Don't force people to walk around furniture to reach destinations.
- **Focal Points**: Arrange furniture toward focal point (fireplace, view, TV, artwork). Floating furniture away from walls often improves flow in large rooms.

### Storage Design Best Practices

- **Vertical Maximization**: Use full ceiling height for storage, especially in small spaces. Upper cabinets for seasonal items, lower for daily use.
- **Hidden Storage**: Under stairs, under beds, in ottomans, behind mirrors, toe-kick drawers. Every unused space is an opportunity.
- **Display vs. Closed**: 80% closed storage (cluttered items), 20% open display (curated beautiful items). Adjust ratio based on tidiness habits.
- **Zone Storage**: Store items near point of use. Dishes near dishwasher, clothing near dressing area, cleaning supplies near use locations.

### Lighting Design Layers

- **Ambient Lighting**: Overall illumination - recessed ceiling lights, cove lighting, central fixtures. Should provide 150-200 lux for living spaces.
- **Task Lighting**: Specific activities - desk lamps, under-cabinet kitchen lights, bedside reading lights. Should provide 300-500 lux at task surface.
- **Accent Lighting**: Highlight features - picture lights, uplighting for plants, strip lighting in niches. Creates drama and depth. 50-100 lux focused beams.
- **Dimming**: All lighting should be dimmable to adjust mood. Use warm white (2700-3000K) for living spaces, neutral white (3500-4000K) for task areas.

### Before-and-After Renovation Tips

- **Document Current State**: Accurate "before" images show clutter, wear, poor lighting, awkward furniture placement, dated finishes.
- **Address Core Issues**: Identify main problems (poor layout, insufficient storage, bad lighting, outdated style) and show clear solutions in "after."
- **Realistic Improvements**: Don't show impossible changes (moving load-bearing walls, relocating plumbing 10 feet) unless you specify it's feasible.
- **Cost Communication**: If presenting to clients, indicate budget tier (cosmetic refresh, moderate renovation, full gut renovation) to set expectations.

### Moodboard Creation Strategies

- **Hero Image**: Start with one large inspiring image (30-40% of board) that captures overall aesthetic. Build other elements around it.
- **Material Samples**: Include actual material swatches if possible - wood grain, stone chips, fabric swatches. More tangible than just photos.
- **Typography Matters**: Use elegant, readable fonts for room labels. Serif fonts (Playfair, Cormorant) for traditional, sans-serif (Helvetica, Montserrat) for modern.
- **White Space**: Don't fill every inch. Generous spacing (minimum 5-10% margins) creates a premium, sophisticated presentation.
- **Digital Delivery**: Export at high resolution (min 300 DPI) for print presentations, or create interactive digital moodboards with clickable links to products.

### Common AI Generation Pitfalls to Avoid

- **Floating Furniture**: AI often generates furniture that doesn't touch the floor. Always check and regenerate if physics are violated.
- **Wrong Scale**: AI may create oversized chairs or tiny tables. Compare furniture to architectural elements (doors are 200cm tall) to verify scale.
- **Impossible Reflections**: Glass and mirrors may show impossible reflections. Check that reflections match the room geometry.
- **Morphed Objects**: AI may blend two concepts into weird hybrid objects (chair-table fusion). Regenerate if objects are unclear or distorted.
- **Hallucinated Windows**: AI loves adding windows where none exist. Emphasize "preserve original windows and openings" to prevent this.
- **Over-Saturation**: AI tends toward unrealistic color saturation. Request "natural color palette, slightly desaturated" for realism.
