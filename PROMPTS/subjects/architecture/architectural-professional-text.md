## 1. COST ESTIMATION & FEASIBILITY

### Description

Generate preliminary cost estimates, analyze construction feasibility, and evaluate project viability based on site constraints and program requirements.

### Use Cases

- Early project budgeting
- Client feasibility discussions
- Site analysis and constraints
- Program viability assessment
- Investment decision support

### Prompt Templates

**Basic Cost Estimate:**

```
I have an 860 m² lot in a residential zone. The client wants a 2,500 m² building with a swimming pool. Provide a preliminary cost estimate and analyze the project's construction feasibility.
```

**Detailed Feasibility Analysis:**

```
Analyze construction feasibility for the following project:
- Site: [size] m² in [zone type: residential/commercial/mixed-use]
- Program: [size] m² building with [specific features]
- Location: [city/region]
- Client budget: [amount if known]

Provide:
1. Zoning compliance analysis (typical FAR, height limits, setbacks)
2. Preliminary cost estimate ($/m² and total)
3. Construction timeline estimate
4. Key feasibility concerns
5. Recommendations for program adjustments if needed
```

**Comparative Analysis:**

```
Compare construction feasibility and costs for [number] different scenarios:

Scenario A: [description]
Scenario B: [description]
Scenario C: [description]

For each provide:
- Estimated cost ($/m² and total)
- Construction timeline
- Zoning/regulatory considerations
- Pros and cons
- Recommendation with justification
```

**Value Engineering:**

```
I have a [project description] with current budget of [amount] and estimated cost of [amount], creating a [X]% budget gap.

Provide value engineering recommendations:
1. Cost reduction strategies that maintain design intent
2. Material substitutions with cost impact
3. Scope modifications to consider
4. Phasing opportunities
5. Alternative systems/methods
6. Prioritized list of reductions to meet budget
```

### Output Enhancement Tips

- Specify location for regional cost accuracy
- Include building type (residential, commercial, etc.)
- Mention any special requirements (sustainability, luxury finishes)
- Request breakdown by CSI divisions if needed
- Ask for assumptions to be stated clearly

## 2. TECHNICAL SPECIFICATIONS

### Description

Generate comprehensive technical specifications following professional standards (AIA, CSI MasterFormat, ABNT, local codes).

### Use Cases

- Construction documents
- Permit applications
- Contractor bid packages
- Quality control standards
- Compliance documentation

### Prompt Templates

**Complete Technical Specification:**

```
Create a technical architectural specification for a 180 m² single-family residence with 3 suites, contemporary style, and a concrete structure, located in São Paulo, Brazil. Follow all applicable ABNT standards.

Include:
- General project information
- Site and foundation specifications
- Structural system specifications
- Architectural finishes by room
- Window and door schedule
- Electrical system requirements
- Plumbing and mechanical systems
- Exterior finishes and landscaping
- Applicable ABNT standard references
- Quality control requirements
```

**System-Specific Specification:**

```
Generate detailed specifications for [specific system: exterior cladding/curtain wall/roofing/foundation/etc.] for [project type].

Include:
- Material specifications (type, grade, finish)
- Performance requirements
- Installation methods and sequence
- Quality standards and testing
- Applicable codes and standards
- Warranty requirements
- Submittal requirements
- Contractor qualifications
```

**Sustainable Building Specification:**

```
Create green building specifications for [project description] targeting [LEED/BREEAM/local certification] certification at [certification level].

Address:
- Sustainable site development
- Energy efficiency requirements
- Water conservation systems
- Materials and resources (recycled content, regional materials)
- Indoor environmental quality
- Innovation opportunities
- Documentation and commissioning requirements
- Referenced standards (ASHRAE, etc.)
```

**Historic Renovation Specification:**

```
Develop technical specifications for sensitive renovation of [historic building description] built in [year].

Cover:
- Historic preservation standards compliance
- Existing conditions assessment requirements
- Intervention philosophy and approach
- Material matching specifications
- Modern code compliance strategies
- Building system integration (minimal impact)
- Craftsmanship and trade qualification requirements
- Documentation and review process
```

### Specification Enhancement

**Request specific formats:**

- "Organize by CSI MasterFormat divisions"
- "Follow AIA specification format"
- "Include ABNT standard references"
- "Provide 3-part specifications (General, Products, Execution)"

**Add detail requests:**

- "Include manufacturer requirements"
- "Specify testing and quality control"
- "Add submittal requirements"
- "Include warranty specifications"

## 3. PROJECT BRIEFS & PROGRAMMING

### Description

Transform client meeting notes, requirements lists, or rough ideas into comprehensive technical project briefs with clear program of requirements, priorities, and constraints.

### Use Cases

- Project initiation documents
- Client requirement capture
- Design phase kickoff
- Stakeholder alignment
- Scope definition

### Prompt Templates

**Meeting Notes to Brief:**

```
I have these notes from a meeting with my client: [paste notes here].

Turn them into a complete technical project brief, including:
- Project overview and objectives
- Program of requirements (spaces, sizes, relationships)
- Priorities and must-haves vs. nice-to-haves
- Key constraints (budget, timeline, site, regulatory)
- Important project considerations (sustainability, style preferences, special needs)
- Success criteria
- Next steps and deliverables
```

**Requirements Organization:**

```
Organize these client requirements into a structured architectural program:

[List or paste requirements]

Deliver:
1. Space program (room list with sizes and requirements)
2. Functional relationships diagram (which spaces need adjacency)
3. Technical requirements by space
4. Special equipment or system needs
5. Accessibility requirements
6. Sustainability goals
7. Budget and schedule parameters
8. Regulatory/code considerations
```

**Stakeholder Requirement Synthesis:**

```
I have requirements from multiple stakeholders for [project type]:

Stakeholder A (Owner): [requirements]
Stakeholder B (Users): [requirements]
Stakeholder C (Facility Manager): [requirements]
Stakeholder D (Developer): [requirements]

Synthesize into unified project brief:
- Reconcile conflicting requirements with recommendations
- Prioritize requirements by stakeholder impact
- Identify gaps or unclear requirements
- Create comprehensive program addressing all needs
- Suggest design strategies that satisfy multiple stakeholders
```

**Concept to Brief:**

```
Expand this project concept into a detailed architectural brief:

Concept: [brief description]

Develop:
- Detailed program of requirements
- Site analysis requirements
- Design aspirations and principles
- Material and sustainability direction
- Budget and timeline framework
- Regulatory research needed
- Precedent studies to review
- Design phase scope and deliverables
```

### Brief Enhancement Tips

- Include all relevant meeting notes/emails
- Specify project type clearly
- Mention any special circumstances
- Request specific format if needed
- Ask for priority/phasing if complex
- Include budget and timeline if known

## 4. DESIGN CONCEPT GENERATION

### Description

Generate multiple architectural design concepts exploring different approaches, styles, or solutions to project requirements.

### Use Cases

- Early design exploration
- Client presentations
- Design competitions
- Alternative analysis
- Conceptual development

### Prompt Templates

**Multiple Concept Development:**

```
Create 3 distinct architectural concepts for a beachfront house for a family with two children. The site faces the ocean.

Explore three approaches:
1. Minimalist contemporary
2. Organic biophilic design
3. Regional vernacular contemporary

For each concept describe:
- Design philosophy and approach
- Form and massing strategy
- Material palette
- Spatial organization
- Relationship to site and ocean views
- Indoor-outdoor connections
- Sustainability strategy
- Unique features and character
- Pros and cons
- Estimated cost implications
```

**Site-Responsive Concepts:**

```
Generate [number] design concepts for [program] on a site with following characteristics:
- Size: [dimensions]
- Topography: [flat/sloped/challenging]
- Context: [urban/suburban/rural]
- Orientation: [sun path and views]
- Constraints: [setbacks, easements, etc.]

Each concept should address:
- Site placement and building orientation
- Topography response strategy
- View and daylighting optimization
- Privacy and context relationship
- Access and parking solution
- Landscape integration
- Climate response
- Unique site opportunities leveraged
```

**Style Exploration:**

```
Develop design concepts for [project type] in the following architectural styles:
- [Style 1: e.g., Modern minimalist]
- [Style 2: e.g., Industrial loft]
- [Style 3: e.g., Scandinavian contemporary]

For each style provide:
- Key design characteristics
- Material palette typical to style
- Spatial qualities and layout principles
- Exterior character
- Interior atmosphere
- Furniture and fixture direction
- Color palette
- Lighting approach
- Best suited for [client type/lifestyle]
```

**Problem-Solving Concepts:**

```
The project has the following challenges: [describe constraints, conflicts, or problems].

Generate [number] creative design concepts that solve these challenges. For each:
- Problem analysis and understanding
- Design strategy to address issues
- Innovative solutions employed
- Trade-offs and compromises
- Benefits of this approach
- Potential concerns
- Why this solution fits the project
```

### Concept Development Tips

- Be specific about site and context
- Define program clearly
- Mention client preferences or requirements
- Specify number of concepts wanted
- Request level of detail needed
- Ask for precedent references if helpful
- Include budget tier if relevant

## 5. CHECKLISTS & QUALITY CONTROL

### Description

Generate comprehensive pre-delivery checklists, quality control protocols, and review procedures ensuring project completeness and compliance.

### Use Cases

- Pre-delivery review
- Quality assurance
- Code compliance verification
- Accessibility review
- Construction milestone checks

### Prompt Templates

**Pre-Delivery Checklist:**

```
My project is a residential building with a leisure area on the ground floor and an apartment on the first floor.

Create a comprehensive pre-delivery checklist covering:
- Accessibility compliance (ramps, door widths, bathroom clearances)
- Safety requirements (railings, fire safety, emergency egress)
- Applicable NBR standards compliance
- Architectural quality and finish verification
- MEP systems completion and testing
- Landscape and site work completion
- Documentation and as-built drawing requirements
- Warranty and maintenance manual requirements
- Final cleaning and touch-up items
- Client orientation and handover process
```

**Construction Phase Checklist:**

```
Create inspection checklists for [project type] at following construction milestones:

1. Foundation completion
2. Structural frame completion
3. Building envelope closure
4. MEP rough-in
5. Interior finish start
6. Substantial completion
7. Final completion

For each milestone list:
- Items to verify/inspect
- Quality standards to check
- Code compliance points
- Common defects to look for
- Documentation required
- Sign-offs needed
- Issues that must be resolved before next phase
```

**Code Compliance Checklist:**

```
Generate a code compliance review checklist for [project type] in [jurisdiction].

Cover:
- Zoning compliance (setbacks, FAR, height, parking)
- Building code compliance (egress, fire safety, structural)
- Accessibility requirements (ADA/local standards)
- Energy code compliance
- Plumbing code
- Electrical code
- Life safety systems
- Special occupancy requirements
- Permit and inspection requirements
```

**Drawing Set QC Checklist:**

```
Create a quality control checklist for construction drawing set review for [project type].

Include verification of:
- Drawing set completeness (all disciplines)
- Coordination between disciplines
- Dimensions and scale accuracy
- Note and specification clarity
- Detail and section references
- Material and finish schedules
- Door and window schedules
- Structural, MEP coordination
- Code compliance documentation
- Title block and sheet numbering
- Revision tracking
- Seal and signature requirements
```

**Sustainability Checklist:**

```
Develop a green building compliance checklist for [certification: LEED/BREEAM/etc.] at [level] for [project type].

Organize by categories:
- Sustainable sites
- Water efficiency
- Energy and atmosphere
- Materials and resources
- Indoor environmental quality
- Innovation and design process

For each category:
- Required documentation
- Design strategies implemented
- Performance targets to verify
- Submittals needed
- Testing/commissioning requirements
- Points targeted vs. required
```

### Checklist Enhancement

**Increase specificity:**

- Name exact jurisdiction for codes
- Specify project type and use
- Mention certification targets
- Include special requirements
- Reference applicable standards

**Format requests:**

- "Organize by CSI divisions"
- "Priority order: critical first"
- "Include responsible party column"
- "Add checkbox format for printing"
- "Include acceptance criteria"

## Advanced Prompt Techniques

### Multi-Step Prompts

For complex deliverables, break into steps:

**Step 1:** "Analyze this project and identify key requirements"  
**Step 2:** "Based on that analysis, develop three concept approaches"  
**Step 3:** "For the preferred concept, create detailed specifications"

### Iterative Refinement

Start broad, then refine:

**Initial:** "Create a cost estimate for this project"  
**Follow-up:** "Break down the structural costs by system"  
**Follow-up:** "Compare concrete vs. steel structure costs"

### Context Building

Provide progressive context:

```
Context: I'm an architect in [location] working on [project type].
Client: [description and priorities]
Site: [characteristics and constraints]
Budget: [range]
Timeline: [schedule]

Task: [specific request]
```

### Output Format Specification

Control how information is presented:

```
Format the output as:
- Executive summary (2 paragraphs)
- Detailed requirements (bulleted list)
- Recommendations (numbered priority order)
- Next steps (action items with responsible parties)
```

## Best Practices

### For Better Results

✓ **Be Specific** - More detail yields better output  
✓ **Provide Context** - Background helps relevant answers  
✓ **State Format Needs** - Request structure you need  
✓ **Include Standards** - Reference codes/standards applicable  
✓ **Iterate** - Refine through follow-up prompts  
✓ **Verify** - Always review AI output for accuracy  
✓ **Customize** - Adapt output to your specific needs

### Common Issues to Avoid

✗ **Too Vague** - "Design a house" → Add program, site, budget, style  
✗ **Missing Location** - Codes and costs are regional  
✗ **No Constraints** - Include budget, timeline, regulations  
✗ **Unclear Output** - Specify what format/detail level you need  
✗ **Single Shot** - Use follow-up prompts to refine
