# Axonometric Cross-Section - 3D Technical Illustration

## Description

Create a 3D cross-section in axonometric orthographic projection, visible from top 3/4 view. This prompt produces technical architectural illustrations showing interior spaces revealed through sectional cuts while maintaining the three-dimensional axonometric perspective—ideal for design communication, spatial understanding, technical presentations, architectural documentation, and creating compelling visual explanations of building layouts, construction assemblies, and spatial relationships.

## Drawing Overview

**Projection Type:** Axonometric orthographic  
**View Angle:** Top 3/4 view (isometric or similar)  
**Drawing Type:** Sectional cut revealing interior  
**Purpose:** Spatial understanding, technical communication  
**Application:** Architecture, technical illustration, design presentation

## Technical Notes

**Axonometric vs Perspective:**

- Axonometric: parallel projection, no vanishing points
- Perspective: convergence, vanishing points
- Axonometric preferred for technical accuracy
- Perspective for realistic appearance
- Professional choice depends on purpose
