# Architecture - 3D Model to 2D Floor Plan Conversion

## Description of Resulting Image

A professional presentation-ready 2D architectural drawing sheet generated from a 3D cutaway model or sectional 3D building plan, featuring accurate floor plans with precise dimensions, clear annotations, and beautifully composed architectural sheet layout. The output showcases a clean technical drawing with properly scaled proportions matching the uploaded 3D design, including all essential architectural elements—wall positions, openings, room sizes, door and window placements, circulation paths, and structural components—extracted strictly from the source 3D model. The drawing maintains professional drafting standards with clear room labels, dimension lines, architectural symbols, and technical annotations, presented in a polished sheet layout that may include 2-3 presentation annotations, section markers, and reference to the original 3D view for comparison. The final composition balances technical precision with visual clarity, creating a buildable, accurate, and visually refined architectural document suitable for construction documentation, client presentations, or permit submissions.

## Usage

Perfect for architectural firms, building designers, construction companies, real estate developers, interior designers, and engineering consultants requiring professional 2D documentation from 3D models. Ideal for creating construction drawings, permit submission documents, client presentation sheets, contractor coordination drawings, and architectural portfolio presentations. This prompt excels at converting complex 3D building information into clear, accurate, and professionally formatted 2D floor plans for residential, commercial, or mixed-use projects while maintaining strict dimensional accuracy and drafting standards.

## Image Prompt

**CRITICAL:**
Upload the provided 3D cutaway model or sectional 3D plan of the building (residential, commercial, or mixed-use) and convert it into a professional, presentation-ready 2D architectural drawing sheet.

**Subject:**
2D floor plan drawing extracted from uploaded 3D architectural model, showing accurate spatial layout, dimensions, and architectural elements in professional drafting format.

**Setting/Environment:**
Professional architectural drawing sheet with clean white background, organized layout, and standard drafting conventions.

**Visual Characteristics:**

**Floor Plan Requirements:**

- Extract all dimensions strictly from uploaded 3D model only
- Wall positions and thicknesses accurately represented
- All openings (doors, windows) shown with proper symbols
- Room sizes and spatial relationships correctly scaled
- Structural elements (columns, beams, load-bearing walls) indicated
- Layout information precisely transferred from 3D source
- **Do not guess, invent, modify, or add any dimensions, spaces, or details not visible in source model**

**Scaling and Proportions:**

- Accurate scaling matching uploaded design (common scales: 1:50, 1:100, 1:200)
- Scale notation clearly indicated on drawing
- Correct proportions maintained throughout
- True-to-source dimensional relationships

**Architectural Annotations:**

- Clear room labels (Living Room, Kitchen, Bedroom 1, Bathroom, etc.)
- Door swing directions indicated
- Window types and sizes labeled where applicable
- Dimension lines with measurements
- Wall thickness callouts
- Circulation paths implied through layout clarity
- Area calculations for major spaces (if applicable)
- Material notes or finish schedules (if applicable)

**Drawing Elements:**

- Clean line weights: thick for walls, medium for openings, thin for dimensions
- Standard architectural symbols: doors (arc showing swing), windows (sill line), stairs (with direction arrow), fixtures (bathroom/kitchen)
- Dimension lines with proper arrowheads and text
- Section cut lines with reference markers (if applicable)
- North arrow indicating building orientation
- Grid lines or reference axes (if applicable)

**Sheet Layout Composition:**

- Floor plan centered or positioned optimally on sheet
- Title block in standard location (bottom right or bottom strip)
- Drawing title: "FLOOR PLAN - [Building Type]"
- Scale notation prominently displayed
- 2-3 presentation annotations if possible:
  - Key features highlighted
  - Design notes or specifications
  - Material callouts or construction notes
- Reference to original 3D view: small 3D perspective image attached or positioned on sheet for comparison
- Sheet number, project name, date, and revision information

**Professional Standards:**

- Maintain professional drafting standards (AIA, ISO, or local building code requirements)
- Precise line work with no overlaps or gaps
- Consistent font usage (typically sans-serif like Arial, Helvetica, or architectural font)
- Proper text sizing hierarchy
- Aligned dimensions and annotations
- Clean, buildable, and construction-ready presentation
