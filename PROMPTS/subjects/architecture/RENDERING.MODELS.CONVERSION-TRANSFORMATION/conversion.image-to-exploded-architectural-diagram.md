# Exploded Architectural Diagram

## Description

Create high-detail exploded architectural diagrams based on uploaded building images. Extract exact structure, proportions, floors, massing, and façade language from the original building, then separate each layer vertically into organized functional layers with clean spacing between each element.

## Overview

This prompt transforms building photographs or renderings into comprehensive exploded axonometric diagrams that reveal the complete organizational hierarchy of architectural systems—from foundation to rooftop gardens. Each building layer is meticulously separated and labeled, showing structural, mechanical, and architectural components in perfect alignment and scale.

**Primary Applications:**

- Architectural system analysis
- Building technology documentation
- Sustainability feature visualization
- Construction methodology explanation
- Academic study diagrams
- Competition presentation boards

## Technical Specifications

### Input Requirements

- Clear photograph or rendering of building
- Sufficient detail to identify floor levels and structural elements
- Any viewing angle (photo will be transformed to isometric/axonometric view)
- Building type and material information (if available)

### Output Format

- **View Style**: Minimal architectural studio style
- **Perspective**: Isometric or slight perspective view
- **Lighting**: Soft neutral lighting with white/light grey background
- **Shadows**: Matte soft shadows without harsh contrast
- **Detail Level**: Ultra-soft materials with realistic textures
- **Linework**: Clean, modern infographic look
- **Scale**: Floating precisely in space with equal layer separation

### Layer Organization (Bottom to Top)

1. **Base + Foundation** - Ground level structural support
2. **Exterior Façade + Cladding System** - Building envelope
3. **Structural Beams** - Primary load-bearing framework
4. **Podium Levels** - Lower floors (retail, parking, amenity)
5. **Main Structural Floors** - Intermediate floor plates
6. **Mechanical + Service Floors** - HVAC, utilities, equipment
7. **Rooftop Gardens / Roof Systems** - Green roofs, terraces, equipment

### Material Representation

- **Concrete**: Light grey, matte, subtle aggregate texture
- **Timber/Wood**: Natural grain, warm tone, accurate species
- **Metal**: Brushed or powder-coated finish, realistic reflectance
- **Terracotta**: Clay color, ceramic texture, modular panel detail
- **Stone**: Natural stone grain, precise texture matching reference
- **Glass**: Transparent or translucent with accurate tint
- All materials must match exactly from reference/uploaded image

## Detailed Breakdown

### Extraction Process

**From Original Building:**

1. **Analyze Proportions** - Measure height-to-width ratios precisely
2. **Identify Floor Heights** - Count levels and determine floor-to-floor dimensions
3. **Extract Massing** - Overall building volume and form
4. **Decode Façade Language** - Window patterns, material divisions, rhythm
5. **Locate Systems** - Identify visible mechanical, structural, and service areas
6. **Preserve Geometry** - Maintain all original design decisions exactly

**Transformation to Exploded View:**

- Convert to isometric or axonometric projection
- Maintain original proportions and scale relationships
- Preserve all architectural details and features
- Translate materials accurately to diagram representation

### Layer Separation Strategy

**Vertical Spacing:**

- Clean, consistent gap between each layer (typically 1-2 floor heights)
- Sufficient space to show detail without visual confusion
- Progressive vertical explosion from bottom to top
- Perfect alignment maintained across all layers

**Layer Components:**

1. **Base + Foundation**
   - Footings and foundation walls
   - Basement or below-grade levels
   - Ground floor slab
   - Site connection details

2. **Exterior Façade + Cladding System**
   - Complete building envelope separated from structure
   - Window systems and glazing
   - Cladding panels (terracotta, metal, stone)
   - Weatherproofing layers
   - Architectural features and ornamentation

3. **Structural Beams**
   - Primary structural framework
   - Column grids
   - Beam systems
   - Load transfer paths
   - Lateral bracing

4. **Podium Levels**
   - Lower floors (typically 1-5 stories)
   - Retail, parking, or public program
   - Amenity spaces
   - Transition zones

5. **Main Structural Floors**
   - Repetitive floor plates
   - Residential, office, or hotel levels
   - Core organization
   - Typical floor systems

6. **Mechanical + Service Floors**
   - HVAC equipment zones
   - Electrical and plumbing systems
   - Vertical circulation shafts
   - Service access areas

7. **Rooftop Gardens / Roof Systems**
   - Green roof assemblies
   - Rooftop terraces or amenities
   - Mechanical penthouse
   - Solar panels or other roof equipment
   - Parapet and edge details

## Technical Notes

### Isometric/Axonometric Specifications

**Isometric View:**

- All vertical lines remain vertical
- Horizontal lines at 30° from horizontal baseline
- No perspective distortion (parallel lines stay parallel)
- Equal scale on all three axes
- Accurate measurement possible from diagram

**Axonometric Variations:**

- **Dimetric**: Two axes equally foreshortened, one different
- **Trimetric**: All three axes foreshortened differently
- **Plan Oblique**: Plan view accurate, vertical at angle
- **Elevation Oblique**: Elevation accurate, depth at angle

### Material Texture References

**Concrete:**

- Light grey base (#CCCCCC to #E0E0E0)
- Subtle aggregate texture (0.5-1mm random dots)
- Formwork lines if board-formed
- Matte finish, no specular highlights

**Timber/Wood:**

- Species-appropriate color (oak, pine, cedar)
- Visible grain direction
- Natural color variation
- Semi-matte finish

**Metal:**

- Aluminum: Light grey, brushed texture
- Steel: Medium grey, slight reflection
- Corten: Rust orange-brown, weathered texture
- Brass/Bronze: Warm metallic, polished or patinated

**Terracotta:**

- Clay orange to red-brown (#D4725C to #B85C42)
- Modular panel joints visible
- Matte ceramic finish
- Slight color variation between units

**Stone:**

- Limestone: Cream to buff, fine texture
- Granite: Grey with crystalline structure
- Marble: White/grey veining patterns
- Sandstone: Warm tan, visible stratification

**Glass:**

- Clear: High transparency, subtle reflection
- Tinted: Blue, green, or grey tone
- Reflective: Mirror-like coating
- Translucent: Diffused light transmission

### Layer Separation Dimensions

**Standard Spacing Guide:**

- **Between Foundation and Façade**: 1.5x floor height
- **Between Façade and Structure**: 1.0x floor height
- **Between Structure and Podium**: 1.5x floor height
- **Between Podium and Main Floors**: 1.0x floor height
- **Between Main Floors and Mechanical**: 1.5x floor height
- **Between Mechanical and Roof**: 1.0x floor height

**Visual Balance:**

- Total explosion height ≈ 3-4x actual building height
- Consistent gaps create visual rhythm
- Larger gaps before major system changes
- Smaller gaps between similar layer types

### Software Workflow Recommendations

**3D Modeling Approach:**

1. **Model Building**: Rhino, SketchUp, or Revit based on source image
2. **Separate Layers**: Create distinct layers for each system
3. **Position Vertically**: Space layers with consistent gaps
4. **Set Camera**: Isometric or axonometric view
5. **Apply Materials**: Accurate textures to each component
6. **Lighting Setup**: Soft, even ambient light
7. **Render**: V-Ray, Enscape, or Lumion for realistic output

**Illustration Software Alternative:**

1. **Vector Base**: Illustrator or Affinity Designer
2. **Layer Structure**: Build each component as separate group
3. **Isometric Grid**: Use isometric grid guides
4. **Texture Application**: Pattern fills or gradient meshes
5. **Shadow Effects**: Soft drop shadows beneath layers
6. **Final Composition**: Arrange vertical spacing, add labels
