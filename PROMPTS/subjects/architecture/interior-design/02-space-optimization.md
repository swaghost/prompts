# PROMPT 02: Space Optimization & Layout

**Purpose:** Space Planning  
**Workflow Position:** Phase 1 - Planning & Layout

---

## Goal

Optimize the space before decorating. Organize furniture with logic, comfort, and real circulation—without altering the structure.

---

## Full Prompt

```
Analyze this floor plan or room and propose an optimized furniture layout for (NUMBER)
users. Preserve doors, windows, plumbing points and structural walls. Ensure comfortable
circulation, functional zones, ergonomic distances and visual balance. Show the result
as a clean top-down layout with clear furniture placement and approximate measurements.
```

---

## Variables

- **NUMBER:** 1, 2, 4, family of 4, couple, single professional, etc.

---

## Key Elements

### Analyze:

- Current floor plan or room configuration
- Number of users/occupants
- Activity requirements
- Traffic patterns

### Preserve:

- Doors (swing direction, clearance)
- Windows (natural light, views)
- Plumbing points (fixed locations)
- Structural walls (cannot be moved)

### Ensure:

- Comfortable circulation (minimum clearances)
- Functional zones (activity areas)
- Ergonomic distances (reach, movement)
- Visual balance (proportions, symmetry)

### Deliverable:

- Clean top-down layout view
- Clear furniture placement
- Approximate measurements
- Circulation paths indicated

---

## Layout Considerations

### Minimum Clearances:

- **Main circulation:** 90-120cm (36-48")
- **Secondary paths:** 60-90cm (24-36")
- **Around furniture:** 45-60cm (18-24")
- **Doorway clearance:** Full swing + 30cm (12")

### Functional Zones:

- Activity-specific areas
- Clear boundaries
- Appropriate furniture groupings
- Visual and physical separation
