# Lighting Design Assistant

## Description

A professional lighting plan creator that designs comprehensive layered lighting for any room type. This prompt recommends ambient, task, accent, and decorative lighting with specific fixture placement, colour temperature guidance (Kelvin), and lumen specifications. Creates functional, beautiful lighting schemes that transform spaces.

## Usage

Specify your room type to receive a complete lighting plan with multiple layers, fixture recommendations, technical specifications, and placement strategies. Use this for renovation planning, new construction, or upgrading existing lighting for better functionality and ambiance.

## Lighting Layers

A well-designed space includes all four layers:

**1. Ambient Lighting** (General Illumination)

- Overhead fixtures, recessed lights, cove lighting
- Provides overall visibility
- 3000K for warm general ambiance

**2. Task Lighting** (Functional Focus)

- Desk lamps, under-cabinet, reading lights
- Supports specific activities
- 4000K for clarity and focus

**3. Accent Lighting** (Highlight Features)

- Picture lights, uplights, wall washers
- Draws attention to artwork, architecture, plants
- 2700K for warm dramatic effect

**4. Decorative Lighting** (Aesthetic Impact)

- Statement chandeliers, sculptural fixtures
- Creates visual interest and style
- 2700K for ambiance

## Colour Temperature Guide (Kelvin)

- **2700K**: Warm, cozy, intimate (bedrooms, living rooms)
- **3000K**: Warm white, welcoming (general lighting)
- **4000K**: Cool white, crisp (task lighting, kitchens, offices)
- **5000K+**: Daylight, bright (workspaces, garages)

## Lumens Guide (Brightness)

**By Room Type:**

- **Living Room**: 1,500-3,000 lumens total
- **Kitchen**: 5,000-10,000 lumens total
- **Bedroom**: 2,000-4,000 lumens total
- **Bathroom**: 4,000-8,000 lumens total
- **Home Office**: 3,000-6,000 lumens total

**By Activity:**

- **Reading**: 400-800 lumens (direct task light)
- **Cooking**: 300-500 lumens per linear foot (under-cabinet)
- **General ambiance**: 10-20 lumens per square foot

## Fixture Placement Best Practices

- **Recessed Lights**: 4-6 feet apart, 18" from walls
- **Pendant Height**: 30-36" above surfaces
- **Chandelier Height**: 7 feet clearance from floor
- **Sconce Height**: 60-66" from floor (beside mirrors: eye level)
- **Under-Cabinet**: Toward front edge for task illumination

## Smart Lighting Options

- **Philips Hue**: Colour-changing, app-controlled
- **Lutron Caseta**: Dimmer switches, scenes
- **LIFX**: No hub required, WiFi bulbs
- **Motion Sensors**: Automated convenience
- **Voice Control**: Alexa, Google, Siri integration

## Best Practices

- Specify room dimensions and ceiling height
- Mention existing fixtures you must keep
- Note activities that happen in the space (reading, cooking, TV watching)
- Include natural light sources (windows, skylights)
- Specify style preferences (modern, traditional, industrial)
- Ask for specific brands if you have preferences (Restoration Hardware, West Elm, etc.)
- Request smart home compatible options if desired
