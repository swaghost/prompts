# PROMPT 04: Layered Lighting Design

**Purpose:** Lighting Expert  
**Workflow Position:** Phase 2 - Design Development

---

## Goal

Design lighting in layers. Combine ambient, task, accent, and decorative lighting to create comfort and depth.

---

## Full Prompt

```
Create a layered lighting plan for this (ROOM). Combine ambient, task, accent and
decorative lighting. Suggest fixture types, placement, color temperature and dimming
zones. Preserve the layout and architecture. Produce a warm, functional and elegant
result with realistic light bounce, soft shadows and no overexposure.
```

---

## Variables

- **ROOM:** bedroom, kitchen, living room, bathroom, dining room, office, hallway, etc.

---

## The Four Lighting Layers

### 1. Ambient Lighting (General Illumination)

- **Purpose:** Overall room brightness
- **Fixtures:** Recessed lights, ceiling fixtures, cove lighting
- **Placement:** Evenly distributed
- **Intensity:** Base level, adjustable

### 2. Task Lighting (Functional)

- **Purpose:** Specific work areas
- **Fixtures:** Under-cabinet, desk lamps, reading lights
- **Placement:** Activity-specific locations
- **Intensity:** Bright, focused

### 3. Accent Lighting (Highlighting)

- **Purpose:** Emphasize features
- **Fixtures:** Track lights, picture lights, wall washers
- **Placement:** Art, architecture, focal points
- **Intensity:** Medium, directional

### 4. Decorative Lighting (Visual Interest)

- **Purpose:** Design element, mood
- **Fixtures:** Pendants, chandeliers, sculptural fixtures
- **Placement:** Visual focal points
- **Intensity:** Varies, often dimmable

---

## Technical Specifications

### Color Temperature:

- **Warm White (2700K-3000K):** Living areas, bedrooms - cozy and inviting
- **Neutral White (3500K-4000K):** Kitchens, bathrooms - balanced and functional
- **Cool White (5000K+):** Task areas, workshops - bright and energizing

### Dimming Zones:

- Separate controls for each layer
- Scene programming capability
- Gradual transitions
- Independent zone control

### Fixture Specifications:

- Type and style for each fixture
- Exact placement coordinates
- Mounting height
- Beam angle
- Wattage/lumens
- Color rendering index (CRI 90+)

---

## Quality Requirements

### Preserve:

- Layout and furniture arrangement
- Architecture and proportions
- Camera angle and view
- Existing design elements

### Achieve:

- Warm, inviting atmosphere
- Functional and elegant result
- Realistic light bounce (indirect lighting)
- Soft shadows (no harsh contrast)
- No overexposure (balanced exposure)
- Natural light integration
- Proper color temperature consistency

## Room-Specific Guidelines

### Living Rooms:

- Focus on flexibility with multiple dimming scenes
- Layer decorative fixtures as focal points
- Provide task lighting for reading areas
- Use accent lighting for art and architecture

### Kitchens:

- Prioritize bright task lighting for work surfaces
- Use under-cabinet lights to eliminate shadows
- Add decorative pendants over islands
- Consider color temperature for food preparation (neutral-warm)

### Bedrooms:

- Emphasize warm, dimmable ambient lighting
- Provide adequate task lighting for reading
- Add accent lighting for mood
- Avoid overhead lights directly above bed

### Bathrooms:

- Combine functional and flattering lighting
- Use vertical fixtures beside mirrors (not just overhead)
- Neutral-warm color temperature (3500K)
- Add dimmer for evening/night use

### Dining Rooms:

- Center decorative fixture over table
- Use dimmer control for ambiance
- Add accent lighting on buffets or art
- Warm color temperature (2700K-3000K)

## Pro Tips

### Layering Strategy:

- Never rely on a single light source
- Each layer serves a different function
- All layers together create the complete picture

### Dimming is Essential:

- Every layer should be dimmable
- Create multiple "scenes" for different activities
- Morning bright, evening soft

### Light Quality Matters:

- High CRI (90+) shows colors accurately
- Warm temperatures (2700K-3000K) feel inviting
- Soft shadows look more natural than harsh ones

### Avoid Common Mistakes:

- Don't overlight - less is often more
- Avoid single overhead light only
- Don't neglect corners and edges
- Avoid mismatched color temperatures in same space
