# Architectural Floorplan — CAD-Style Linework

## Overview

Create detailed, fully furnished architectural floorplans using precise black CAD-style linework over clean white backgrounds. Perfect for architecture presentations, interior design portfolios, real estate marketing, construction documentation, and space planning. Features professional technical drawing aesthetic with labeled key areas, accurate proportions, room separations, and minimalist presentation.

---

## Master Prompt

```
Create a detailed, fully furnished architectural floorplan using the referenced
image, in precise black CAD-style linework over a clean white background,
showing walls, doors, windows, fixed furniture, loose furniture, and fixtures,
with clear room separations, accurate proportions, labeled key areas, and a
minimalist technical drawing aesthetic.
```

## Core Elements

### Architectural Elements

**Walls:**

- Solid black lines (thickest weight: 2-3px)
- Clear thickness representation
- Interior vs exterior wall differentiation
- Structural elements clearly defined

**Doors:**

- Standard swing notation with arc
- Sliding door track representation
- Pocket door indication
- French/double door notation
- Opening direction clearly shown

**Windows:**

- Double line representation
- Clear frame and glass indication
- Floor-to-ceiling window notation
- Bay window projections
- Window swing direction (if applicable)

---

### Furniture & Fixtures

**Fixed Furniture:**

- Built-in cabinetry (kitchen, bathroom)
- Kitchen islands and counters
- Bathroom vanities and fixtures
- Closet shelving systems
- Fireplace structures

**Loose Furniture:**

- Beds (with headboard orientation)
- Sofas and seating
- Tables (dining, coffee, side)
- Chairs and ottomans
- Storage units and shelving

**Fixtures:**

- Toilets, sinks, bathtubs, showers
- Kitchen appliances (stove, fridge, dishwasher)
- Lighting fixtures (overhead notation)
- HVAC vents and returns
- Electrical outlets (optional detail level)

---

### Room Labels & Annotations

**Primary Labels:**

- Room names (MASTER BEDROOM, LIVING ROOM, KITCHEN)
- Square footage per room
- Ceiling heights (if varying)
- Key dimensions (optional)

**Secondary Labels:**

- Furniture identification (optional)
- Material callouts (optional)
- Special features (walk-in closet, ensuite, etc.)

**Label Style:**

- Clean sans-serif font
- All caps or title case
- Strategic placement (room centers)
- Non-intrusive, clear readability

## Style Specifications

### Line Weights

| Element                | Line Weight | Purpose                     |
| ---------------------- | ----------- | --------------------------- |
| **Exterior walls**     | 2.5-3px     | Heaviest, defines perimeter |
| **Interior walls**     | 2px         | Primary structure           |
| **Doors/Windows**      | 1.5px       | Openings definition         |
| **Furniture outlines** | 1px         | Object representation       |
| **Details/fixtures**   | 0.5-1px     | Fine details                |
| **Dimension lines**    | 0.5px       | Annotations (optional)      |

---

### Drawing Conventions

**Standard Symbols:**

- Door swing: Quarter-circle arc from hinge
- Sliding door: Parallel lines with directional arrow
- Window: Double line with cross-hatch or gap indication
- Stairs: Parallel lines with up/down arrow
- Toilet: Oval with tank rectangle
- Sink: Rectangle with curved front or circular
- Stove: Square with burner circles
- Refrigerator: Rectangle with door line

---

### Scale & Proportions

**Accuracy Requirements:**

- Realistic room proportions
- Furniture scaled appropriately to space
- Door widths standard (30-36" typical)
- Window proportions accurate
- Traffic flow space maintained (36" min walkways)

**Common Room Sizes (Reference):**

- Master Bedroom: 12' x 14' to 16' x 18'
- Secondary Bedroom: 10' x 12' to 12' x 14'
- Living Room: 14' x 16' to 18' x 20'
- Kitchen: 10' x 12' to 12' x 16'
- Bathroom (Full): 8' x 10' to 10' x 12'
- Bathroom (Half): 5' x 8' to 6' x 10'

## Best Practices

### ✅ Do:

1. **Maintain accurate scale** — Furniture should be proportional to rooms
2. **Show door swings** — Essential for understanding circulation
3. **Label clearly** — Room names and sizes for context
4. **Use consistent line weights** — Hierarchy creates clarity
5. **Include all furniture** — Gives true sense of space and function
6. **Show wall thickness** — Not just lines, but structural reality
7. **Indicate materials** — Hatching for different elements (optional)

---

### ❌ Don't:

1. **Overcrowd with annotations** — Keep it minimal and clean
2. **Mix artistic and technical styles** — Stay purely CAD aesthetic
3. **Forget scale** — Everything must be proportionally accurate
4. **Omit circulation space** — Show realistic walkways (36" min)
5. **Use decorative fonts** — Technical sans-serif only
6. **Add shading or color** — Black linework on white only
7. **Show unrealistic layouts** — Must be buildable/functional

## Troubleshooting

### Issue: Proportions look off

**Solution:**

- Specify actual room dimensions in prompt
- Reference standard room sizes
- Mention "accurate proportions" explicitly
- Provide square footage constraints

---

### Issue: Furniture too large/small

**Solution:**

- Specify furniture dimensions in prompt
- Add "scaled appropriately to space"
- Reference standard furniture sizes
- Check traffic flow clearances (36" walkways)

---

### Issue: Lines aren't clean/precise

**Solution:**

- Emphasize "precise CAD-style linework"
- Request "clean technical drawing aesthetic"
- Specify "sharp lines, no sketchy quality"
- Try different AI models (MidJourney excels at this)

---

### Issue: Missing key elements

**Solution:**

- List all required elements explicitly in prompt
- Break into categories (walls, doors, windows, furniture, fixtures)
- Be specific about room contents
- Use detailed examples as reference

## Final Tips

**Secrets to professional CAD-style floorplans:**

1. **Line weight hierarchy** — Thickest for exterior walls, thinnest for details
2. **Standard symbols** — Use architectural conventions (door swings, etc.)
3. **Accurate scale** — Everything proportional creates believability
4. **Clear labeling** — Room names and sizes add context
5. **Complete furniture** — Shows true functionality of space
6. **Circulation space** — Don't forget walkways and clearances
7. **Door swings** — Essential for understanding how space works
8. **Consistent style** — Pure linework, no shading or artistic flourish
9. **Reference image** — Upload sketch or existing plan for AI to refine
10. **Specify square footage** — Keeps AI grounded in realistic sizing

**Pro tip:** For best results, provide a rough sketch or reference floorplan image and let AI convert it to precise CAD-style linework. This maintains your exact layout while giving professional technical drawing quality.
