# Interior: Design Consistency System - Multi-Room Project

**Style**: Cohesive interior design identity across entire project

---

## PROMPT

```
Maintain the exact same architectural language, furniture style, materials, color palette, lighting, decoration and design identity across every room of the project. Ensure visual consistency between all spaces as if designed by the same interior designer.
```

---

## KEY ELEMENTS

- Exact same architectural language across all rooms
- Consistent furniture style throughout
- Unified materials selection
- Consistent color palette
- Uniform lighting approach
- Cohesive decoration style
- Single design identity
- Visual consistency between all spaces
- As if designed by the same interior designer

---

## TECHNICAL SPECIFICATIONS

- **Consistency Scope**: Every room of the project
- **Consistency Elements**:
  - Architectural language
  - Furniture style
  - Materials
  - Color palette
  - Lighting
  - Decoration
  - Design identity
- **Goal**: Visual cohesion as single designer's work
- **Application**: Multi-room projects, full home design, commercial spaces

---

## USAGE NOTES

This prompt ensures design continuity across multiple spaces within a single project. Critical for creating cohesive residential or commercial environments where all spaces feel part of the same design vision. Use when generating multiple rooms that need to feel like a unified interior design project rather than disparate spaces.

**Application Strategy**:

- Use after establishing design language in first room
- Apply to each subsequent room in project
- Ensures brand consistency in commercial projects
- Creates portfolio-quality cohesive residential designs
