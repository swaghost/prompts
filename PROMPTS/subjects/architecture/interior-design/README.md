## When to Use Each Prompt

### Use 01 (Complete Concept) when:

- Starting a new design from scratch
- Need overall vision and direction
- Establishing style for entire space
- Creating initial concept for client

### Use 02 (Space Optimization) when:

- Planning furniture layout
- Solving circulation problems
- Before purchasing furniture
- Need floor plan with measurements

### Use 03 (Materials & Finishes) when:

- Testing different material combinations
- Comparing finish options
- Refining material selections
- Need to match specific style with materials

### Use 04 (Lighting Design) when:

- Creating comprehensive lighting plan
- Solving lighting problems
- Planning electrical work
- Need fixture types and placement

### Use 05 (Color Palette) when:

- Need specific color selections
- Want cohesive color scheme
- Coordinating colors with materials
- Need HEX codes for paint matching

### Use 06 (Custom Furniture) when:

- Need built-in solutions
- Standard furniture won't fit
- Maximizing storage in specific space
- Integrating technology (TV, cables)

### Use 07 (Professional Moodboard) when:

- Client presentations
- Design direction documentation
- Before purchasing items
- Team communication and alignment

### Use 08 (Realistic Rendering) when:

- Final client presentations
- Marketing/portfolio needs
- Converting sketches/models to photorealism
- Need photo-quality visualization

### Use 09 (Strategic Renovation) when:

- Working with existing space
- Structural constraints exist
- Updating outdated room
- Need before/after visualization

## Quality Standards Across All Prompts

### Preservation (What Must NOT Change):

- Original architecture
- Room proportions
- Structural elements
- Camera angles (when specified)
- Spatial relationships

### Quality Requirements (What MUST Be Present):

- Photorealistic rendering
- Accurate scale and proportions
- Realistic materials and textures
- Natural lighting integration
- Functional and buildable solutions
- Professional presentation quality

### Output Standards:

- Architectural photography quality
- High realism (passes as photograph)
- Natural imperfections (not CG-perfect)
- Accurate material representation
- Proper lighting and shadows
- Refined details throughout

## Tips for Best Results

### General Guidelines:

**Be Specific:**

- Define room type clearly
- Specify style preferences
- Note any constraints
- Describe desired mood

**Preserve What Matters:**

- Always mention preserving architecture
- Maintain proportions
- Keep camera angles consistent
- Respect structural elements

**Request Quality:**

- Ask for "photorealistic"
- Specify "architectural photography"
- Request "refined details"
- Mention "natural light"

### Variable Selection:

**Room Types:**
Living room, bedroom, kitchen, bathroom, dining room, home office, nursery, mudroom, laundry room, closet, hallway, entryway

**Style Options:**
Modern, contemporary, minimalist, Scandinavian, industrial, mid-century modern, transitional, traditional, coastal, bohemian, farmhouse, rustic, Mediterranean, Asian-inspired, eclectic

**Material Categories:**

- **Woods:** oak, walnut, maple, cherry, pine, teak, mahogany, bamboo
- **Stones:** marble, granite, limestone, travertine, slate, quartzite, concrete
- **Metals:** brass, bronze, copper, steel, chrome, iron, nickel, gold
- **Fabrics:** linen, cotton, wool, velvet, silk, leather, jute, hemp
