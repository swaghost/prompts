# Architectural Interior Detail Sheet

## Description

Transform any uploaded interior image into a comprehensive premium Architectural Interior Detail Sheet in portrait format (1080×1350). This prompt preserves the exact design while creating a complete technical documentation board featuring colorful realistic elevations, floor plans, reflected ceiling plans, cross-sections, professional dimensioning, material legends, and enlarged construction details—all presented with clean architectural drafting standards.

## Usage

Perfect for converting interior design concepts or photographs into professional architectural documentation suitable for construction, client presentations, contractor coordination, permit submissions, or portfolio pieces. Maintains design integrity while adding complete technical specifications and multi-view drawings.

## Prerequisites

- Interior image to transform (photograph, render, or sketch)
- 1080×1350 portrait format capability
- Understanding of architectural drawing conventions

## Image Prompt

Transform the uploaded interior image into a premium Architectural Interior Detail Sheet (1080×1350 portrait). Preserve the exact design, materials, colors, textures, furniture, lighting, and proportions without redesigning. Include a realistic colored main elevation/rendering, Front, Left, Right & Rear Elevations, Floor Plan, Reflected Ceiling Plan (RCP), Sections A-A, B-B & C-C. Include enlarged Joinery, Edge Profile, Panel Build-up, Ceiling, Lighting, Cabinet, Skirting, Corner Junction, and Construction Details with annotations. Use clean white background, black technical linework, thin dimension lines, callouts, labels, and organized architectural sheet layout. Ultra-detailed studio-quality interior documentation board.

### Required Elements Breakdown

**Main Views (All Required):**

1. **Colored Main Elevation/Rendering**
   - Realistic photographic-quality representation
   - Full color preserving original materials and textures
   - Primary focal view of the space
   - Center or prominent position on sheet

2. **Front Elevation**
   - Technical orthographic projection
   - Dimensioned and annotated
   - Material callouts

3. **Left Elevation**
   - Side view orthographic projection
   - Consistent scale with other elevations
   - Key dimensions shown

4. **Right Elevation**
   - Opposite side view
   - Complete dimensional information
   - Material specifications

5. **Rear Elevation**
   - Back wall technical view
   - All fixtures and features documented
   - Coordinated with other views

6. **Floor Plan**
   - Overhead view showing layout
   - Furniture placement with dimensions
   - Clearances and circulation paths
   - Fixture locations

7. **Reflected Ceiling Plan (RCP)**
   - Ceiling-mounted elements
   - Lighting fixture locations and types
   - Ceiling heights annotated
   - Material transitions

8. **Cross Sections (A-A, B-B, C-C)**
   - Vertical cuts through space
   - Show height relationships
   - Reveal concealed construction
   - Dimension ceiling heights, cabinetry depths

**Dimensioning Requirements:**

- Overall width, height, depth of space
- Furniture dimensions and spacing
- Cabinetry sizes (width, height, depth)
- Wall panel dimensions
- Ceiling height measurements
- Lighting fixture locations (coordinates)
- Clearances between elements
- All dimensions in millimeters (mm)
- Thin dimension lines with arrows
- Clear numerical callouts

**Material & Finish Legend:**

Must include numbered entries for:

- **Wall** finishes and materials
- **Ceiling** materials and systems
- **Flooring** types and specifications
- **Panels** (wall panels, decorative elements)
- **Décor** elements and finishes
- **Metal** fixtures and hardware finishes
- **Upholstery** fabric specifications
- **Lighting** fixture types and specifications
- **Glass** types (clear, frosted, fluted, etc.)
- **Hardware** (handles, fixtures, fittings)

Each legend entry should have:

- Sequential number/reference
- Material/finish name
- Blank editable specification field for details
- Reference markers on drawings

**Enlarged Construction Details:**

Include zoomed-in detail drawings for:

- **Joinery** connections and joints
- **Edge Profile** treatments and moldings
- **Panel Build-up** (layering, thickness, attachment)
- **Ceiling** construction and suspension systems
- **Lighting** mounting and integration details
- **Cabinet** construction and hardware
- **Skirting/Baseboard** profiles and installation
- **Corner Junction** details (wall meets, transitions)
- **Construction Details** with annotations explaining assembly

Each detail should:

- Show 1:5 or 1:10 scale
- Include material callouts
- Show fasteners and connections
- Have dimensional annotations
- Include construction notes

**Sheet Layout Standards:**

- **Background:** Clean white
- **Linework:** Black technical lines
- **Line Weights:** Varied (thick for walls, thin for dimensions)
- **Dimension Lines:** Thin with clear arrows
- **Callouts:** Numbered references to legend
- **Labels:** Clear, professional typography
- **Organization:** Logical grid-based layout
- **Title Block:** Project information area
- **Scale Indicators:** Noted on each view
- **North Arrow:** On floor plan
- **Sheet Border:** Professional margin

## Technical Specifications

**Drawing Standards:**

- Orthographic projections (no perspective distortion in technical views)
- Consistent scale across similar view types
- Proper lineweight hierarchy (walls thicker than dimensions)
- Standard architectural symbols and conventions
- Metric dimensioning (millimeters)
- Section cut indicators showing view directions
- Grid references for cross-sections
- Material hatching where appropriate

**Elevation Style:**

- **Main Elevation:** Photorealistic colored rendering
- **Technical Elevations:** Line drawings with material indications
- **All Elevations:** Accurately represent design without alteration
- Preserve exact proportions and relationships
- Show all visible elements (furniture, fixtures, lighting)
- Maintain original color palette and material specifications

**Dimensioning Approach:**

- String dimensions for continuous measurements
- Baseline dimensioning from common reference
- Dimension to centerlines of openings and fixtures
- Overall dimensions shown separately from detail dimensions
- Clear hierarchy: overall → major elements → details
- Dimension lines outside object lines where possible
- Extension lines with small gaps at object

**Material Documentation:**

- Numbered reference system (M1, M2, etc.)
- Legend organized by category
- Reference bubbles on drawings pointing to materials
- Consistent numbering across all views
- Blank fields allow specification customization
- Professional tabular format for legend

**Detail Callouts:**

- Enlarged views at 2x-5x scale
- Reference bubbles showing source location
- Clear annotations explaining construction
- Layer breakdowns for assemblies
- Fastener and attachment specifications
- Installation notes where relevant

1. **Preserve Original Design Integrity**

## Technical Notes

**Architectural Conventions Used:**

- ISO A-series paper size proportions adapted
- ANSI Y14.2 dimensioning standards
- Material symbols per architectural standards
- Section cut conventions (arrows indicating view direction)
- North arrow on floor plan (if orientation known)
- Scale bars and notation on each view
- Standard title block information layout

**File Preparation Tips:**

- Upload high-resolution interior images for best detail extraction
- Ensure good lighting in source image for accurate color capture
- Photograph/render from straight-on angles when possible
- Include all relevant elements in frame (floor to ceiling)
- Avoid extreme perspective distortion in source image

**Post-Processing Recommendations:**

- Export as high-resolution PDF for printing
- Save layered version for editing specifications
- Create both color and black-white versions
- Archive with project documentation
- Use as template for additional rooms in same project
