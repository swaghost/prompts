# Technical 2D Drawings - Architectural Documentation

## Description

Create technical 2D drawings of this object/building with professional architectural documentation standards. This prompt transforms 3D models, photographs, or renders into precise orthographic projections including plans, elevations, and sections with accurate dimensioning, line weights, annotations, and professional CAD-style presentation—ideal for construction documentation, architectural submissions, technical specifications, design development, and comprehensive project communication.

## Drawing Overview

**Output Type:** Technical 2D architectural drawings  
**Projection:** Orthographic (plans, elevations, sections)  
**Style:** Professional CAD/architectural line drawings  
**Purpose:** Construction documentation, technical communication  
**Application:** Architecture, engineering, construction, design development
