## Tool-Specific Guides

### For Image AI (Midjourney, DALL-E, Stable Diffusion)

**Transformations:**

- Start with clear 2D source (plan, elevation, facade)
- Specify "preserve original composition/massing/layout exactly"
- Detail required output (exploded, 3D, simplified, detailed)
- Include material and style requirements
- See: [Architectural Transformations](architectural-transformations-image.md)

**Enhancements:**

- Begin with existing render or model export
- "Preserve original composition exactly" is critical
- Specify enhancement type (materials, vegetation, lighting)
- Define quality level (photorealistic, 4K, magazine-quality)
- See: [Rendering Enhancement](architectural-rendering-enhancement.md)

**Common Parameters:**

```
--ar 16:9  (landscape renders)
--ar 4:5   (vertical presentation)
--ar 3:2   (photo standard)
--stylize 250-500 (architectural precision)
--quality 2 (higher detail)
```

### For Video AI (Runway, Pika Labs, Sora)

**Best Practices:**

- 8-15 seconds optimal duration
- Clear transformation described
- Specify camera movement
- Define lighting and atmosphere
- Include pacing notes
- See: [Architectural Animations](architectural-animations-video.md)

**Animation Types:**

- Transformations: 2D to 3D, holographic to real
- Emergences: Explosive, particle-based
- Timelapses: Construction sequences
- Reveals: Dramatic presentations

### For Text AI (ChatGPT, Claude, GPT-4)

**Effective Prompting:**

- Provide context (project type, location, size)
- State desired output format
- Include constraints (budget, codes, timeline)
- Request specific structure
- Iterate and refine
- See: [Professional Text Tools](architectural-professional-text.md)

**Common Outputs:**

- Cost estimates and feasibility
- Technical specifications (AIA, CSI, ABNT)
- Project briefs and programming
- Design concept development
- Checklists and QC protocols

## Quality Standards

### For All Prompt Types

**Composition/Intent Preservation:**

- Always include "preserve original [composition/design/layout]"
- Be explicit about what must remain unchanged
- Specify what should be added/enhanced

**Professional Quality:**

- Request appropriate quality level for use
- Specify industry standards if applicable
- Include resolution/detail requirements

**Realistic Results:**

- Describe materials accurately
- Specify appropriate lighting
- Include environmental context
- Ensure technical accuracy

**Usability:**

- Output should meet intended use
- Format appropriate for deliverable
- Quality sufficient for purpose

### Review Checklist

✓ **Accuracy** - Design intent preserved  
✓ **Quality** - Professional standard met  
✓ **Completeness** - All required elements present  
✓ **Clarity** - Communication effective  
✓ **Technical Correctness** - Realistic and buildable

## Limitations & Considerations

### AI Tool Limitations

**Image AI:**

- Composition drift (hence "preserve exactly" critical)
- Technical accuracy not guaranteed
- Material properties may be stylized
- Scale and proportion requires verification

**Video AI:**

- Short duration limitations (8-15 sec typical)
- Physics may not be accurate
- Temporal consistency challenges
- High render times

**Text AI:**

- Code/standard accuracy requires verification
- Cost estimates are preliminary only
- Local requirements need professional review
- Professional judgment always required

### Professional Responsibility

**Always:**

- Review all AI output for accuracy
- Verify code compliance independently
- Check cost estimates against real data
- Apply professional judgment
- Maintain professional liability insurance
- Follow jurisdiction requirements
- Disclose AI use when appropriate

**Never:**

- Submit AI output without review
- Rely solely on AI for code compliance
- Use AI cost estimates for contracts
- Assume technical accuracy
- Replace professional expertise
- Ignore local requirements
