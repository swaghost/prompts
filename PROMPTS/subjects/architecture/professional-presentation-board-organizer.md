# Professional Architectural Presentation Board Organizer

## Description

Create professional architectural presentation boards using ONLY uploaded plans, renders, diagrams, and project information. Do not redesign architecture or invent new drawings—simply organize the provided material into premium architecture boards with editorial magazine-style layouts.

## Overview

This prompt transforms existing architectural documentation into professionally organized presentation boards that showcase projects with maximum visual impact. The focus is entirely on layout, composition, and presentation quality rather than generating new architectural content, making it ideal for portfolio development, client presentations, and competition submissions.

**Primary Applications:**

- Portfolio presentation boards
- Client pitch materials
- Architecture competition submissions
- Exhibition display panels
- Professional project documentation
- Firm marketing materials

## Technical Specifications

### Input Requirements

- Uploaded plans (floor plans, site plans, roof plans)
- Renders (3D visualizations, photorealistic imagery)
- Diagrams (concept, analysis, technical)
- Project information (text, data, specifications)
- Logos or branding elements (optional)

### Output Format

- **Orientation**: Vertical (Portrait), A1 ratio
- **Layout Style**: Swiss Grid layout, editorial architecture magazine style
- **Quality Standards**: Adobe InDesign/Behance/Pinterest premium presentation aesthetic
- **Color Palette**: Warm neutral (beige, warm white, taupe, light grey)
- **Paper Texture**: Subtle paper texture background
- **Typography**: Modern sans-serif

### Design Specifications

- Clean margins with perfect alignment
- Generous white space for breathing room
- Large project title and concept at the top
- Main hero render at top-right position
- 4-6 circular render images aligned vertically on the left
- Supporting plans, sections, diagrams balanced throughout
- Material and furniture palettes organized neatly
- Consistent alignment and elegant typography

## Detailed Breakdown

### Layout Structure

**Hierarchical Organization:**

1. **Header Zone** (Top 15-20%)
   - Large project title (bold, prominent)
   - Project concept statement
   - Location/date/type information
   - Firm logo (if provided)

2. **Hero Image Zone** (Top-Right)
   - Main render at top-right position
   - Largest visual element on board
   - Primary architectural visualization
   - High-impact placement for immediate attention

3. **Vertical Circular Render Strip** (Left Side)
   - 4-6 circular-cropped render images
   - Vertically aligned sequence
   - Equal spacing between circles
   - Consistent sizing (typically 15-20% of board width)
   - Shows different views/perspectives of project

4. **Supporting Documentation** (Center/Lower)
   - Floor plans (properly scaled and labeled)
   - Sections and elevations
   - Site plan or context diagram
   - Technical details
   - Analytical diagrams

5. **Material/Furniture Palettes** (Organized Zone)
   - Material samples with labels
   - Furniture selections
   - Color swatches
   - Finish specifications
   - Neatly organized in grid or linear arrangement

6. **Footer/Credits** (Bottom)
   - Design team names
   - Project credits
   - Technical specifications
   - Scale references

### Swiss Grid Layout Principles

**Grid System:**

- Modular grid with consistent column structure (typically 8-12 columns)
- Horizontal flowlines for alignment
- Consistent gutter widths
- Mathematical precision in spacing
- Alignment to invisible grid lines

**Alignment Rules:**

- All elements snap to grid
- Perfect vertical and horizontal alignment
- Consistent margins on all sides
- Elements grouped by visual weight
- Balanced asymmetry following grid logic

### Editorial Magazine Aesthetic

**Visual Characteristics:**

- High contrast between text and background
- Large, bold typography for hierarchy
- Generous white space (20-30% of board)
- Professional photography styling
- Curated, intentional composition
- Clean, modern, sophisticated appearance

**Typography Standards:**

- **Project Title**: 48-72pt, bold weight
- **Section Headers**: 24-36pt, medium/bold
- **Body Text**: 10-14pt, regular weight
- **Captions**: 8-10pt, light/regular
- **Font Choices**: Sans-serif (Helvetica, Futura, Proxima Nova, Gotham)

### Color and Material Treatment

**Warm Neutral Palette:**

- **Background**: Beige (#F5F5DC), Warm White (#FAF9F6), Taupe (#E8E4E1)
- **Accents**: Light Grey (#D3D3D3), Soft Charcoal (#B8B8B8)
- **Text**: Deep Charcoal (#333333), Black (#000000)
- **Highlighting**: Subtle earth tones for emphasis

**Subtle Paper Texture:**

- Light grain overlay (5-10% opacity)
- Natural paper feel without distraction
- Enhances tactile, premium quality
- Maintains readability of all elements

## Best Practices

### Content Organization

1. **Prioritize visual hierarchy** - largest/most important at top
2. **Establish clear reading path** - logical flow through information
3. **Group related content** - plans together, renders together
4. **Balance visual weight** - distribute density evenly across board
5. **Use white space strategically** - allow breathing room around key elements

### Technical Quality

1. **High-resolution images** - minimum 300 DPI for all renders/plans
2. **Consistent image treatment** - unified color grading and style
3. **Sharp linework** - crisp plan and diagram lines
4. **Proper scaling** - accurate scale bars and dimensions
5. **Clean backgrounds** - remove artifacts and distractions from images

### Typography Excellence

1. **Limit font families** - maximum 2 typefaces (1 preferred)
2. **Maintain hierarchy** - clear size/weight distinctions
3. **Align text to grid** - snap all text blocks to layout grid
4. **Consistent spacing** - uniform line height and paragraph gaps
5. **Readable sizes** - ensure legibility at intended viewing distance

### Visual Cohesion

1. **Unified color treatment** - apply consistent color grading to all images
2. **Matched lighting** - similar tone across all renders
3. **Consistent line weights** - uniform thickness for plans/diagrams
4. **Aligned visual style** - cohesive rendering and diagram aesthetic
5. **Coordinated materials palette** - organized presentation of finishes

## Technical Notes

### Pre-Production Checklist

- [ ] Collect all project renders (3D visualizations)
- [ ] Gather all plan drawings (floor plans, site plan, roof plan)
- [ ] Obtain section and elevation drawings
- [ ] Compile diagrams (concept, analysis, circulation)
- [ ] Prepare project text (title, description, specifications)
- [ ] Source material/furniture palette images
- [ ] Verify image resolution (minimum 300 DPI)
- [ ] Determine board orientation and size
- [ ] Select color palette and typography
- [ ] Define visual hierarchy priorities

### Image Preparation Standards

**Renders:**

- Minimum 3000 x 2000 pixels (300 DPI at 10" x 6.6")
- Consistent lighting and atmospheric conditions
- Color-graded for visual unity
- Clean backgrounds without distractions
- Properly cropped to show key views

**Plans and Drawings:**

- Vector format preferred (PDF, AI, EPS) for infinite scalability
- If raster: minimum 300 DPI at final print size
- Clean linework with consistent weights
- Properly labeled with room names and dimensions
- North arrow and scale bar included

**Circular Render Treatment:**

- Square crop first (1:1 aspect ratio)
- Apply circular mask with clean edges
- Ensure focal subject centered in circle
- Maintain consistent size across all circular images
- Consider slight shadow or stroke for definition

### Layout Grid Specifications

**Swiss Grid Parameters:**

- **Columns**: 12-column grid (maximum flexibility)
- **Gutter Width**: 20-30mm between columns
- **Margins**: 30-50mm on all sides (larger for formal presentations)
- **Baseline Grid**: 12pt or 14pt for text alignment
- **Flowlines**: Horizontal divisions every 10-15% of board height

**Alignment Precision:**

- All elements aligned to 1mm precision
- Consistent spacing between related elements
- Margins equal on left/right, top/bottom may vary for hierarchy
- Text blocks aligned to column edges
- Images may span multiple columns but align to grid lines

### Typography Hierarchy Template

**Project Title:**

- Font: Helvetica Bold or Futura Bold
- Size: 60-72pt
- Weight: Bold
- Color: Deep Charcoal or Black
- Position: Top-left or top-center

**Section Headers:**

- Font: Same family as title
- Size: 24-30pt
- Weight: Medium or Bold
- Color: Dark Grey
- Position: Above related content groups

**Body Text:**

- Font: Helvetica Regular or similar sans-serif
- Size: 11-13pt
- Weight: Regular
- Color: Charcoal (#555555)
- Line Height: 1.4-1.6x font size

**Captions:**

- Font: Same family, lighter weight
- Size: 8-10pt
- Weight: Light or Regular
- Color: Medium Grey (#888888)
- Position: Below or beside images

### Circular Render Placement Guide

**Standard Configuration:**

- **Quantity**: 4-6 circular images
- **Position**: Vertically aligned along left side
- **Diameter**: 15-20% of board width (consistent across all)
- **Spacing**: Equal vertical spacing between circles
- **Alignment**: Centers aligned to single vertical grid line
- **Top Circle**: Begins below header zone
- **Bottom Circle**: Ends above footer zone

**Content Selection for Circles:**

1. Exterior hero view (main façade or perspective)
2. Contextual view (building in site)
3. Interior key space (living area, lobby)
4. Detail shot (material close-up, feature element)
5. Alternate exterior view (different angle)
6. Atmospheric view (twilight, atmospheric conditions)
