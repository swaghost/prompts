# Dynamic Sports Recreation Prompts

## Core Method

These prompts re-film the exact same slow-motion football panna from Video 1 using a new camera position. Video 1 is the absolute master for both players, action, timing, ball path, physics, pitch, environment, lighting, colour grade, contrast, atmosphere, and image feel.

## Shared Requirements

- Use Video 1 as the source and absolute master.
- Change only the camera position and the explicitly described framing.
- Preserve the identical panna beat for beat, including approach, feints, touches, ball path, reaction, physics, and slow-motion speed.
- Keep both players exactly as they appear in Video 1.
- Use one continuous shot with no cuts.
- Match Video 1's look exactly and retain true slow motion.
- Use no music or dialogue; keep only the specified slowed diegetic sound world.
