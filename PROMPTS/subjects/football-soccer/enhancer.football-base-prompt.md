# Football Photo Base Prompt

## Overview

**Purpose**: Lock down athlete identity and composition before applying any style transformations  
**Usage**: **ALWAYS USE THIS FIRST** before any style-specific prompt  
**Platform**: Any AI image generator with image-to-image capability

This prompt preserves the original athlete, pose, and composition while allowing only lighting, atmosphere, and quality enhancements.

---

## Complete Prompt

```
Analyze my uploaded reference image carefully.

Preserve the athlete exactly as shown.

Keep the same identity, jersey, facial features, hairstyle, body proportions,
pose, action, camera angle, framing, environment, stadium, crowd, ball, goalposts,
field markings, composition and perspective.

Do not redesign the scene.

Only upgrade the cinematic lighting, atmosphere, weather effects, stadium
ambience, color grading, depth, realism and professional sports photography quality.

Everything must remain ultra realistic and physically accurate.
```
