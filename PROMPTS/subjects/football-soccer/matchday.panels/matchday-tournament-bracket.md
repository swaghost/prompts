# Tournament Bracket Graphics - Matchday Image Prompts

## Overview

Create clear, organized tournament structure graphics displaying group stages, knockout brackets, and tournament progression. Features clean typographic layouts, data visualization principles, and professional sports broadcast aesthetics.

**Part of:** [Matchday Graphics Collection](PROMPT.MATCHDAY.txt)

## Use Cases

- **Group Stage Updates** - Current group standings and results
- **Knockout Bracket Displays** - Tournament tree visualization
- **Progression Tracking** - Show tournament advancement
- **Social Media Posts** - Instagram, Twitter bracket graphics
- **Broadcast Graphics** - TV and streaming tournament overviews
- **Website Widgets** - Interactive bracket displays
- **Mobile App Graphics** - Tournament structure views
- **Stadium Displays** - Jumbotron bracket updates
- **Print Materials** - Tournament programs and guides
- **Fan Engagement** - Prediction and tracking graphics

## Technical Specifications

### Aspect Ratio Guidelines

**1:1 Square (Instagram Feed, Twitter):**

- Best for group standings
- Universal social format
- Compact bracket display
- Mobile and desktop friendly

**16:9 Horizontal (Broadcast, Website):**

- Full knockout bracket tree
- Desktop viewing optimized
- TV and streaming graphics
- More space for large brackets

**9:16 Vertical (Stories):**

- Live updating standings
- Mobile-first viewing
- Single group focus
- Story format engagement

**4:3 or A4 Portrait:**

- Printable brackets
- Traditional bracket format
- Print materials
- Fan prediction sheets

**Recommendation:** 1:1 for groups, 16:9 for full knockout tree, 9:16 for live updates

---

### Typography for Data Clarity

**Headers (Group/Round Labels):**

- Font Weight: Bold to Black (700-900)
- Size: Medium-large, clear hierarchy
- Style: All caps, condensed acceptable
- Color: High contrast or accent color

**Team Names:**

- Font Weight: Regular to Bold (400-700)
- Size: Medium, readable at small sizes
- Style: Clear sans-serif, no script fonts
- Color: Black or dark grey on white

**Data (Points, Scores):**

- Font Weight: Medium to Bold (500-700)
- Size: Medium, aligned in columns
- Style: Tabular numerals (equal width)
- Color: Consistent, readable

**Recommendation:** Sans-serif throughout, clear hierarchy, tabular figures for numbers

---

### Color Coding System

**Qualification Status:**

- Green/Gold: Qualified for next round
- Amber/Orange: On edge, must win
- Red/Grey: Eliminated or danger zone
- Blue: Current matches in progress

**Team Representation:**

- Flag Colors: Use national team colors
- Neutral: Black, white, grey for structure
- Accent: Gold, blue, or tournament colors

**Background:**

- White: Clean, information-focused
- Light Grey: Subtle, professional
- Dark: White text, premium feel
- Gradient: Modern, dynamic (use sparingly)

**Recommendation:** Use color strategically for information, not decoration

---

### Layout Grid Systems

**Table Grid (Group Standings):**

- Clear column alignment
- Consistent row height
- Header row distinct
- Alternating row shading optional

**Bracket Tree Grid:**

- Symmetrical left-right balance
- Equal spacing between rounds
- Vertical alignment of matches
- Clear connecting lines

**Multi-Group Layout:**

- 2x2 grid for four groups
- Equal space allocation
- Consistent styling across groups
- Clear group separation

**Recommendation:** Use grid systems for alignment, maintain consistency

## AI Tool Parameters

### Midjourney Recommendations

```
--ar 1:1        (Group standings, square social posts)
--ar 16:9       (Full bracket tree, broadcast)
--ar 9:16       (Live updates, Stories)

--stylize 100-250   (clean, data-focused, minimal interpretation)
--stylize 250-500   (balanced, professional sports graphic)

--quality 2     (high quality for text clarity)

--style raw     (more literal, less artistic)
```

**Example:**

```
Group stage bracket update graphic, clean typographic grid, tournament labels in bold, gold and white palette, four groups visible, modern sports data visualization --ar 1:1 --stylize 200 --quality 2 --style raw
```
