# Score Updates Graphics - Matchday Image Prompts

## Overview

Create dynamic, real-time score update graphics displaying live match scores, halftime updates, and full-time results. Features bold scoreboard layouts, celebration aesthetics, and shareable social media designs.

**Part of:** [Matchday Graphics Collection](PROMPT.MATCHDAY.txt)

---

## Use Cases

- **Live Score Updates** - Real-time match scores during games
- **Halftime Scores** - Mid-match status updates
- **Full-Time Results** - Final match outcomes
- **Social Media Posts** - Instagram, Twitter score graphics
- **Broadcasting Graphics** - TV and streaming scoreboards
- **Stadium Displays** - Jumbotron score updates
- **Mobile App Notifications** - Push notification graphics
- **Website Widgets** - Live score displays
- **Goal Alerts** - Immediate scoring notifications
- **Match Recaps** - Post-match result summaries

---

## Base Prompt Template

```
Match score update graphic, bold scoreboard layout, team names and flags, live sports aesthetic, high contrast, 1:1 square format.
```

**When to Use:**

- Quick score updates needed
- Standard scoreboard display
- Time-constrained projects
- Simple score announcement

**Customization:**

- Specify match stage (halftime, full-time)
- Add celebration elements for finals
- Adjust colors for winning/losing
- Modify aspect ratio for platform

## Technical Specifications

### Aspect Ratio Guidelines

**1:1 Square (Universal Social):**

- Best for score posts
- Instagram feed and Twitter
- Clean scoreboard display
- Works across platforms

**9:16 Vertical (Stories):**

- Real-time goal alerts
- Live score updates
- Mobile-first notifications
- Story engagement

**16:9 Horizontal (Broadcast):**

- TV and streaming graphics
- Website hero images
- Desktop viewing
- Landscape orientation

**4:5 Vertical (Instagram Feed):**

- Tall Instagram posts
- More screen space
- Feed-optimized

**Recommendation:** 1:1 for most score posts, 9:16 for urgent Stories, 16:9 for broadcast

---

### Score Display Typography

**Score Numbers:**

- Font Weight: Black (900) - extremely bold
- Size: Extra large, dominant visual element
- Style: Condensed or wide sans-serif
- Color: High contrast (white on dark, dark on light)

**Team Names:**

- Font Weight: Bold (700)
- Size: Medium, secondary to score
- Style: All caps common, clean sans-serif
- Color: Team colors or high contrast

**Match Status Labels:**

- Font Weight: Bold to Black (700-900)
- Style: "HALFTIME," "FULL TIME," "LIVE"
- Size: Medium, clear hierarchy
- Color: Accent color (red for live, gold for final)

**Player Names (for goal graphics):**

- Font Weight: Bold (700)
- Size: Medium-large
- Style: Surname or full name
- Color: High contrast or team color

**Recommendation:** Extra bold for scores, clear hierarchy, high contrast

---

### Color Psychology for Scores

**Live Match (In Progress):**

- Red accents: Urgency, live action
- Bright colors: Energy, ongoing
- Pulsing elements: Active, current

**Halftime:**

- Neutral or team colors
- Balanced presentation
- Clear but not urgent

**Full-Time (Winner):**

- Winning team colors dominant
- Gold accents: Victory, celebration
- Bright and celebratory

**Full-Time (Draw):**

- Balanced color split
- Neither team dominant
- Neutral or both colors equally

**Goal Alert:**

- Red or bright accent: Urgency, breaking news
- Scoring team colors: Team identification
- High contrast: Immediate visibility

**Recommendation:** Use color to convey match status and urgency

---

### Layout Hierarchy

**Primary Element - Score:**

- Largest visual element
- Central placement
- Maximum contrast
- Immediate readability

**Secondary - Team Identification:**

- Team names and/or flags
- Clear but not competing with score
- Positioned around score

**Tertiary - Match Status:**

- "LIVE," "HT," "FULL TIME"
- Smaller than score but visible
- Often as label or header

**Additional Info:**

- Match minute, date, venue
- Smallest text elements
- Supplementary information

**Recommendation:** Clear visual hierarchy, score always dominant

## AI Tool Parameters

### Midjourney Recommendations

```
--ar 1:1        (Score posts, universal social - primary)
--ar 9:16       (Stories, goal alerts, live updates)
--ar 16:9       (Broadcast graphics, horizontal)

--stylize 250-500   (professional sports graphic)
--stylize 500-750   (celebration graphics with energy)

--quality 2     (high quality for clarity)

--style raw     (more literal scoreboard style)
```

**Example Halftime:**

```
Halftime score update graphic, bold scoreboard layout, two countries as color blocks, match time clock, live sports aesthetic, high contrast, 1:1 square --ar 1:1 --stylize 400 --quality 2
```

**Example Full-Time:**

```
Full-time result announcement, winning country colors dominant, final score in large white type, stadium celebration energy, gold confetti overlay, 1:1 --ar 1:1 --stylize 600 --quality 2
```
