# Stadium Blueprint Construction Timelapse — 6-Second Build

## Description

Cinematic 6-second construction timelapse transforming an architectural blueprint into a fully photorealistic stadium. Begins with top-down technical blueprint on dark blue drafting grid, then smoothly transitions through 3D wireframe, construction phases, and final completion. Camera remains perfectly overhead, centered, and locked throughout the entire sequence. Blueprint-to-reality transformation with precise architectural consistency.

## Usage

Create dramatic stadium construction visualization showing complete build process from architectural plans to finished venue. Perfect for stadium announcements, construction progress visualization, architectural presentations, or promotional content. Emphasizes technical precision and cinematic progression.

## Prerequisites

- **Blueprint Reference Required**: Exact stadium blueprint with technical linework, labeled gates, seating sections, tunnels, VIP areas, field markings
- **Final Stadium Reference Required**: Photorealistic completed stadium image (overhead view) that matches blueprint layout exactly
- **Layout Consistency**: Blueprint and final image must show same stadium design
- **Overhead Perspective**: Both references should be from directly above, centered

## Negative Prompt

### Camera Issues to Avoid

```
camera rotation, orbiting camera, panning camera, tilted camera, side view,
ground level view, perspective changes, Dutch angle, camera shake, multiple
angles, cuts to different views, scene changes, angle switches
```

### Construction Issues to Avoid

```
stadium layout changes, different stadium design, gates moving, sections
relocating, field rotation, blueprint inconsistency, architectural changes,
wrong proportions, distorted geometry, collapsed structure, destruction
effects, exploding elements, stadium morphing into different shape
```

### Visual Quality Issues to Avoid

```
low quality, blurry, pixelated, poor rendering, unrealistic physics,
floating elements, disconnected structure, incomplete build, missing
elements, wrong materials, cheap CGI, video game graphics, cartoon style,
illustration look, flat lighting
```

### Audio Issues to Avoid

```
background music, orchestral score, electronic music, dramatic sound
effects, whoosh sounds, impact booms, narration, voiceover, dialogue, loud
construction noise, jarring sounds, artificial effects
```

### Timing & Pacing Issues to Avoid

```
too fast progression, instant completion, slow pacing, stalled animation,
jerky motion, stuttering, frame skipping, uneven speed, rushed ending,
incomplete final frame
```

### Blueprint Preparation

- Use actual architectural blueprint aesthetic (dark blue grid, white lines)

- Match final stadium's footprint and orientation exactly

### Phase Transitions

- Allow subtle overlap between phases for smooth morphing

- Match reference image as closely as possible
