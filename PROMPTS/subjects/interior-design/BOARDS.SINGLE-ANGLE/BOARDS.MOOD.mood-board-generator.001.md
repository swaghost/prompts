# Mood Board Generator

## Description

A comprehensive mood board creation tool that curates furniture, fabrics, textures, lighting, artwork, and plants for any interior style. This prompt explains how every element works together to create a cohesive design story. Perfect for visual storytelling, client presentations, and design concept development.

## Usage

Specify your interior style and room type to receive a detailed mood board concept with specific recommendations for each design element and an explanation of how they create a unified aesthetic. Use this for client pitches, design direction setting, or personal project planning.

## Style Applications

Works with any interior design aesthetic:

- Wabi-Sabi, Japandi, Scandinavian
- Mid-Century Modern, Bohemian, Coastal
- Modern Minimalist, Industrial, Contemporary
- Traditional, Transitional, English Country
- Art Deco, Maximalist, Eclectic

## Mood Board Elements

- **Furniture**: Key pieces that define the style
- **Fabrics**: Upholstery, curtains, rugs, pillows
- **Textures**: Wood, stone, metal, woven, soft materials
- **Lighting**: Fixtures that set the mood and support function
- **Artwork**: Pieces that enhance the aesthetic
- **Plants**: Greenery that brings life and completes the look
- **Style Story**: How everything works together

## ChatGPT Prompt

```
Create a detailed mood board for a [Style] interior. Recommend furniture, fabrics, textures, lighting, artwork, and plants, then explain how everything works together.

INCLUDE:
• Furniture selections with specific style characteristics
• Fabric choices (patterns, materials, colours)
• Texture combinations (rough, smooth, woven, natural)
• Lighting fixtures (ambient, task, decorative)
• Artwork recommendations (type, subject, framing)
• Plant suggestions (species, pot styles, placement)
• Style story explaining how all elements create a cohesive design

Make the mood board feel inspiring, cohesive, and ready to visualize.
```

## Output Format

The AI will provide:

1. **Furniture Selections**: 4-6 key pieces with descriptions
2. **Fabric Choices**: Textiles with patterns, textures, colours
3. **Texture Palette**: Materials that add depth (wood, stone, linen, rattan)
4. **Lighting Fixtures**: Statement pieces and functional lighting
5. **Artwork**: Style-appropriate pieces with subject suggestions
6. **Plant Recommendations**: Species that complement the aesthetic
7. **Cohesive Story**: How all elements work together to create the mood

## Mood Board Composition

**Visual Hierarchy:**

- Hero image (main inspiration photo)
- Furniture samples (key pieces)
- Material swatches (fabrics, finishes)
- Colour palette (coordinating tones)
- Detail shots (lighting, art, accessories)
- Plant imagery (greenery accent)

**Layout Options:**

- Grid format (clean, organized)
- Collage style (organic, overlapping)
- Linear flow (storytelling sequence)
- Curated clusters (grouped by element)

## Style Story Elements

The narrative should explain:

- **Colour Connection**: How colours relate and flow
- **Texture Balance**: Mix of rough and smooth, hard and soft
- **Scale Variation**: Different sizes creating visual interest
- **Material Harmony**: How finishes complement each other
- **Functional Beauty**: Aesthetic choices that serve purpose
- **Emotional Impact**: The feeling the design creates

## Best Practices

- Be specific about the style for targeted recommendations
- Mention the room type for appropriate furniture and function
- Request specific brands or price points if relevant
- Ask for shoppable links or product names for sourcing
- Include any existing pieces to work around
- Specify colour preferences or restrictions
