# Interior Design Prompts - Complete Collection Index

A comprehensive collection of professional interior design prompts including 13 living room style prompts for architectural documentation and photorealistic rendering, plus 15 professional design workflow tools covering the complete process from client consultation through final presentation.

## Overview

This collection provides two types of prompts:

**Style Prompts (13):** Detailed specifications for creating professional architectural drawings and photorealistic renders of complete living room interiors in various styles. Each generates:

- Front, Back, Left, Right elevations
- Plan View (top-down)
- Sections A-A / B-B
- Accurate dimensions and annotations
- Material schedules
- Lighting schedules
- Furniture specifications
- CAD-style professional presentations

**Process & Tool Prompts (15):** Professional workflow tools for interior designers covering concept generation, space planning, material selection, colour palettes, client presentations, budget planning, and technical documentation.

## How to Use These Prompts

### For Architectural Drawings:

Each prompt includes a detailed formula for generating professional architectural documentation. Use the provided specifications to create:

1. **Elevation Views** - Front, Back, Left, Right with dimensions
2. **Plan View** - Top-down layout with furniture placement
3. **Sections** - A-A and B-B cuts showing vertical details
4. **Schedules** - Materials, finishes, lighting, furniture
5. **Annotations** - CAD-style professional notes

### For Photorealistic Renders:

Each prompt also includes rendering parameters for creating ultra-realistic 8K visualizations with appropriate:

- Lighting conditions
- Material textures
- Camera settings
- Atmospheric qualities
- Photography style

### Customization:

All prompts are structured to allow easy customization:

- Adjust room dimensions
- Modify color palettes
- Change specific furniture pieces
- Alter material specifications
- Add or remove architectural features

## Technical Specifications

**Drawing Standards:**

- Scale: 1/4" = 1'-0" for plans and elevations
- Scale: 1/2" = 1'-0" for detailed sections
- All dimensions in feet and inches
- CAD-style professional presentation
- Material callouts and specifications

**Rendering Standards:**

- Resolution: 8K minimum
- Professional interior photography aesthetic
- Appropriate lighting for each style
- Material texture emphasis
- Architectural photography composition
