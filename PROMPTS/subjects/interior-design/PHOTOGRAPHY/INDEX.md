# Interior Design Camera Views – Index

## Overview

Professional architectural photography and rendering prompts that transform existing interior design images into specific camera viewpoints. These prompts preserve all design elements, materials, colors, and layout from the input image while changing only the camera position, angle, and photographic effects. Ideal for creating architectural presentations, portfolio work, and client visualization from existing designs.

## Core Principle

**Design Preservation**: All prompts maintain exact fidelity to the input image's design decisions. Only the camera viewpoint, angle, focal length, and photographic treatment change. No elements are added, removed, moved, or restyled.

### 2. [Eye-Level Perspective View](eye-level-perspective-view.md)

**Type**: Interior Architectural Photography  
**Viewpoint**: Human eye level from inside kitchen  
**Focal Length**: 70-100mm (compressed telephoto)  
**Depth of Field**: Shallow (f/2.8-f/4), focus on cabinetry and island  
**Lighting**: Warm natural daylight + subtle LED under-cabinet  
**Use Case**: Portfolio photography, editorial magazines, marketing materials  
**Platform**: Midjourney, Stable Diffusion + ControlNet, DALL-E 3

**Key Features:**

- Elegant compressed perspective
- Sophisticated depth of field (sharp focus, soft foreground/background)
- Premium architectural photography quality
- Natural "walking through" experience
- White handleless cabinet fronts required

## Technical Requirements

### Input Image

- Must provide existing interior design reference image
- All design elements will be preserved exactly
- Only camera viewpoint will change

### Design Preservation Rules

- ✅ Exact layout, proportions, furniture positions
- ✅ All materials, colors, textures, finishes unchanged
- ✅ All accessories, plants, lighting fixtures preserved
- ✅ Cabinet configuration and island position locked
- ❌ No added elements
- ❌ No moved furniture
- ❌ No redesigned elements
- ❌ No recolored materials

## Workflow

1. **Prepare Input Image**
   - Existing kitchen/living room interior design
   - Clear view of layout, furniture, materials

2. **Choose Camera View**
   - Section: For architectural clarity and room relationships
   - Perspective: For natural, photographic presentation

3. **Apply Prompt**
   - Use complete prompt with input image
   - Specify any material details if needed
   - Allow AI to transform viewpoint only

4. **Review Output**
   - Verify all design elements preserved
   - Check camera angle matches specification
   - Confirm no unwanted additions or changes

## Quality Standards

### Photorealism

- Accurate material representation
- Natural lighting conditions
- Realistic shadows and reflections
- True-to-life textures and finishes

### Architectural Accuracy

- Correct proportions and scale
- Proper spatial relationships
- Accurate perspective or orthographic projection
- Professional presentation quality

### Design Fidelity

- 100% preservation of input design
- No creative interpretation or redesign
- Exact color and material matching
- Precise furniture and accessory placement
