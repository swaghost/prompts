# Interior: Brazilian Contemporary Style Transformation

**Style**: Contemporary Brazilian architectural interior design

---

## PROMPT

```

Use natural wood, limestone, warm indirect lighting, linen fabrics, organic shapes, indoor plants and a sophisticated neutral color palette. Photorealistic, ultra-detailed, soft daylight, architectural photography.
```
