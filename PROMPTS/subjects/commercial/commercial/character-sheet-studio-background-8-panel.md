# Character Sheet - Clean Studio Background (9:16 Vertical)

## Prompt Description

Create a clean vertical 9:16 character sheet on a white studio background showcasing one character from multiple angles and poses. The sheet features 8 panels in a structured layout with no text, captions, or interface elements. Maintains 100% character consistency across all panels: identical face, hair, skin tone, body proportions, outfit, accessories, and overall appearance. Designed for character reference sheets, fashion lookbooks, model portfolios, and consistent character documentation.

---

## Complete Prompt

**Using the attached image as the strict reference, create a clean vertical 9:16 character sheet on a white studio background. No text, no captions, no watermark, no interface elements.**

**Keep the EXACT same person in all panels: same face, hair, skin tone, body proportions, outfit, accessories, shoes, and overall appearance. Do not change age, ethnicity, hairstyle, clothing, or identity.**

**Create 8 panels in a clean sheet layout:**

**Top row:**

1. Full-body front view
2. Full-body side profile
3. Full-body back view

**Middle row:**  
4. Full-body 3/4 (three-quarter) angle  
5. Mid-close-up portrait  
6. Side profile close-up

**Bottom row:**  
7. Back of head / hair close-up  
8. 3/4 close-up portrait

**Style: photorealistic, clean studio lighting, sharp focus, realistic skin texture, premium fashion look, minimal background, highly consistent identity across all panels.**

## Structured Breakdown

### OVERALL SPECIFICATIONS

**Format**: 9:16 vertical aspect ratio  
**Layout**: 8 panels in structured character sheet format  
**Background**: White studio background (seamless white)  
**Presentation**: Clean, professional, no text or interface elements  
**Quality**: Photorealistic, fashion photography standard

### CHARACTER CONSISTENCY (CRITICAL)

**100% Identical Across All 8 Panels**:

- Same face and facial features
- Same ethnicity and skin tone
- Same age appearance
- Same hairstyle and hair color
- Same body proportions and build
- Same outfit and clothing
- Same accessories (jewelry, watches, etc.)
- Same shoes
- Same overall styling and appearance

**Do NOT Change**:

- Age
- Ethnicity
- Hairstyle
- Clothing
- Identity
- Any physical characteristics

### PANEL LAYOUT (8 PANELS)

**Top Row (3 Panels) - Full Body Views**:

**Panel 1: Full-Body Front View**

- Character facing camera directly
- Head to toe visible
- Standing naturally
- Arms relaxed at sides or slight natural pose
- Clear view of outfit front

**Panel 2: Full-Body Side Profile**

- Character in full side view (90-degree turn)
- Head to toe visible
- Shows outfit silhouette from side
- Face in profile
- Natural standing posture

**Panel 3: Full-Body Back View**

- Character facing away from camera
- Head to toe visible
- Shows back of outfit, hair from behind
- Natural standing position
- Clear back details

**Middle Row (3 Panels) - Mixed Views**:

**Panel 4: Full-Body 3/4 (Three-Quarter) Angle**

- Character at approximately 45-degree angle
- Head to toe visible
- Shows dimension and depth
- Natural pose, slightly turned
- Reveals multiple sides

**Panel 5: Mid-Close-Up Portrait**

- Head and shoulders (upper chest visible)
- Front-facing or slight angle
- Clear facial features
- Shows hair, face, neck, upper outfit detail
- Portrait framing

**Panel 6: Side Profile Close-Up**

- Head and shoulders in profile
- Side view of face
- Shows hair profile, facial profile
- Upper body visible
- Clean profile silhouette

**Bottom Row (2 Panels) - Detail Close-Ups**:

**Panel 7: Back of Head / Hair Close-Up**

- Focus on back of head and hair
- Shows hairstyle from behind
- Neck and upper shoulders visible
- Hair detail and texture
- Back profile

**Panel 8: 3/4 Close-Up Portrait**

- Head and shoulders at three-quarter angle
- Face turned approximately 45 degrees
- Shows facial dimension
- Natural portrait expression
- Upper body visible

## Common Issues & Solutions

### Issue: Character Face or Appearance Changes Between Panels

**Solution**: Strongly emphasize "Use exact same person with identical face, hair, skin tone, body proportions, outfit, accessories in all 8 panels. Do not change identity."

### Issue: Clothing or Outfit Changes

**Solution**: Specify "Same exact outfit, clothing, accessories, shoes in every panel without variation"

### Issue: Hairstyle Inconsistency

**Solution**: State "Keep identical hairstyle and hair color across all panels, including from behind and in profile"

### Issue: Background Not Clean White

**Solution**: Request "Pure white studio background, seamless white backdrop, no shadows or floor line visible"

### Issue: Text or Labels Appear

**Solution**: Explicitly state "No text, no captions, no labels, no watermark, no interface elements"

### Issue: Panel Layout Not Matching Description

**Solution**: List each panel explicitly with row position and description: "Top row: Panel 1 (full body front), Panel 2 (full body side)..." etc.

### Issue: Inconsistent Lighting Across Panels

**Solution**: Specify "Clean consistent studio lighting across all panels, even illumination, same lighting setup for every view"

## Workflow Tips

1. **Prepare Character Reference**: High-quality full-body photo showing character clearly
2. **Define Character Details**: Note specific outfit, accessories, hairstyle to maintain
3. **Choose Panel Layout**: Standard 8-panel or customize for specific needs
4. **Generate Character Sheet**: Create complete sheet in one generation
5. **Review Consistency**: Check face, outfit, hair, proportions match across all panels
6. **Verify Panel Angles**: Ensure each view shows intended angle correctly
7. **Check Background Cleanliness**: Confirm white background is consistent
8. **Refine if Needed**: Request specific panel adjustments while maintaining consistency
