**Purpose**: Premium landing page design for product showcase and e-commerce

Create sophisticated website landing page with hero product, navigation, and full e-commerce experience.

## Complete Prompt

```
Design a premium [product category] landing page for the exact [PRODUCT NAME] shown in the
reference images. The homepage should feature a large hero banner with the [product]
floating dramatically, modern navigation bar, featured collection, product
details, technology highlights, lifestyle imagery, customer reviews, call-to-action

white backgrounds, [dark color] typography, [accent color] accent colors, subtle
```

## Key Elements Breakdown

### Homepage Sections (Top to Bottom)

1. **Navigation Bar**: Logo, menu items, search, cart
2. **Hero Banner**: Large floating product with headline
3. **Featured Collection**: Product grid or carousel
4. **Product Details**: Key features and specifications
5. **Technology Highlights**: Innovation callouts
6. **Lifestyle Imagery**: Products in context
7. **Customer Reviews**: Testimonials and ratings
8. **Call-to-Action**: Shop now, explore, sign up
9. **Footer**: Links, info, social media

### Visual Design

- **Background**: White (clean, premium)
- **Typography**: Dark color (high contrast, readable)
- **Accents**: Product colors (cohesive branding)
- **Spacing**: Premium, generous white space
- **Animations**: Subtle hover effects, transitions

### Layout Style

- **Aesthetic**: Minimal editorial
- **Inspiration**: Apple web design
- **Responsive**: Desktop-optimized layout
- **Organization**: Clear sections, visual hierarchy

## Troubleshooting

### Too Cluttered or Busy

**Problem**: Too many sections or elements competing  
**Solution**:

- Emphasize "minimalist editorial layout" and "generous premium spacing"
- Reduce number of sections to essentials
- Add "clear visual hierarchy" and "organized sections"

### Doesn't Look Premium

**Problem**: Interface looks generic or low-quality  
**Solution**:

- Add "luxury," "high-end," "premium spacing"
- Specify "Apple-inspired web design" (quality benchmark)
- Emphasize "white backgrounds" and "editorial layout"

### Navigation Not Clear

**Problem**: Menu or navigation hard to find  
**Solution**:

- Specify "modern sticky navigation bar at top"
- Add "clear menu structure with logo, navigation, icons"
- Ensure: "Professional navigation hierarchy"

### Product Not Hero

**Problem**: Product gets lost in layout  
**Solution**:

- Emphasize "large hero banner with [product] floating dramatically"
- Add "product as primary focal point in hero section"
- Specify "[product] takes up significant hero space"
