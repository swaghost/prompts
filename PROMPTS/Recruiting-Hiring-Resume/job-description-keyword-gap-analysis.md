# Job Description Keyword Gap Analysis

## Prompt

"Here are 3 job descriptions for roles I want [paste]. Compare them to my profile. Tell me which keywords I'm missing and exactly where to place them so I show up in searches."

## Purpose

Identify keyword gaps between job descriptions you're interested in and your current LinkedIn profile. Get specific placement recommendations to optimize for recruiter searches.

## Use Case

- Targeting specific job postings
- Optimizing profile for multiple similar roles
- Understanding skill gaps
- Strategic keyword placement

## What You'll Get

- List of missing keywords from the job descriptions
- Common patterns across all 3 job descriptions
- Exact placement recommendations (headline, about, experience, skills)
- Priority order for keyword additions
- Natural ways to incorporate keywords

## Variables to Replace

- `[paste]` - The full text of 3 job descriptions for roles you want

## Analysis Includes

1. **Missing Keywords** - What's in the JDs but not in your profile
2. **Keyword Frequency** - Which terms appear across all 3 JDs (highest priority)
3. **Placement Strategy** - Where each keyword should go
4. **Natural Integration** - How to add keywords without sounding robotic
5. **Skills Section** - Which skills to add/prioritize

## Why 3 Job Descriptions?

Analyzing multiple JDs for similar roles helps identify:

- Universal requirements vs. company-specific preferences
- Most important keywords that appear repeatedly
- Industry-standard terminology
- Skills prioritization
