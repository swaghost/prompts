## FACS (FACIAL ACTION CODING SYSTEM)

### System Overview:

**FACS** is the comprehensive taxonomy of human facial expressions developed by Paul Ekman and Wallace Friesen. Each **Action Unit (AU)** represents a specific facial muscle movement that can be objectively coded.

**Purpose in This Sequence:**

- Precise control of facial expressions
- Scientific accuracy in muscle movements
- Reproducible expression patterns
- Subtle micro-expression study
- Emotion component isolation

## FACS CODING NOTES

### Accuracy Requirements:

- **Anatomically correct** muscle movements
- **FACS-compliant** (matches Ekman system)
- **Reproducible** (could be coded by FACS coder)
- **Isolated** (each AU distinct unless combined specified)

### Intensity Coding:

FACS uses A-E intensity scale:

- **A:** Trace
- **B:** Slight
- **C:** Marked/Pronounced
- **D:** Severe/Extreme
- **E:** Maximum

**For this sequence:** Likely B-C intensity (Slight to Pronounced) for visibility without exaggeration.

### Combination Coding:

- If multiple AUs occur simultaneously, use + (e.g., AU6+AU12)
- This prompt specifies individual beats (one AU per beat currently)
- Combinations could be added to specific beats if desired
