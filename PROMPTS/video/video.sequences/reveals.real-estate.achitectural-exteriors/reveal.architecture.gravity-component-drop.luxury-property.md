# Luxury Property Gravity Component Drop Reveal

## Classification

**Product Category:** luxury-property exterior
**Reveal Effect:** gravity-driven component drop
**Reveal Mechanism:** complete architectural parts descend in timed order and fit into the final property
**Sequence Type:** reference-match component assembly

## Description of Resulting Video or Video Sequence

A 10-second continuous reveal where roof, walls, windows, balconies, doors, stone panels, trees, and pool sections drop from above and assemble the exact reference property.

## Usage

For construction reels, modular-building campaigns, real-estate launches, and satisfying assembly visuals.

## Engines/Models

Reference-aware video model with rigid-body gravity, precise landing, collision avoidance, and final-frame matching.

## Prerequisites / Dependencies

- Completed exterior as `@reference`.
- Optional aligned empty-site plate.

## Storyboard Requirement

Optional five-panel board: empty site and hovering parts, foundation drop, wall/floor assembly, detail installation, final hero.

## Effect

### Effect Name: Gravity Component Drop

Components remain complete and rigid, descend vertically or along short crane-like paths, and land only after supporting elements exist. Nothing floats after contact.

## Video Prompt

```text
Use @reference as the final exterior design target and exact final visual match. Create a 10-second continuous gravity-driven property assembly.

0.0-1.0s: Begin looking at an empty property site from the final camera direction. Complete architectural components hover high above: foundation sections, walls, floor plates, windows, balconies, doors, roof, stone panels, trees, and pool sections.
1.0-3.0s: Gravity activates and foundation and primary wall components descend first, landing with controlled weight and precise alignment.
3.0-6.2s: Floors, upper walls, balconies, and roof sections drop in sequence and lock onto completed supports without collision.
6.2-8.5s: Windows, doors, facade panels, pool sections, paths, and landscape elements descend and settle into final positions.
8.5-10.0s: All components are stable and fully photorealistic. Finish with a subtle hero glide on the property matching @reference.

No people, text, logos, cuts, uncontrolled impacts, bouncing structure, crushed components, pieces passing through each other, unsupported roof, floating elements, duplicate parts, architecture drift, or unfinished final state.
```

## Exterior Reveal Checklist

- [ ] Hovering inventory corresponds only to reference components.
- [ ] Foundation and supports land before upper elements.
- [ ] Components remain rigid and avoid collision.
- [ ] Landings show weight, contact, and stable locking.
- [ ] Trees and pool elements install last.
- [ ] No floating or duplicated component remains.
- [ ] Final one-take 10-second property matches `@reference`.
