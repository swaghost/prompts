# Luxury Property Pop-Up Book Reveal

## Classification

**Product Category:** luxury-property exterior
**Reveal Effect:** architectural pop-up book
**Reveal Mechanism:** property and site elements unfold from book pages before scaling into real architecture
**Sequence Type:** reference-match miniature-to-full-scale reveal

## Description of Resulting Video or Video Sequence

A 10-second luxury reveal where an architectural book opens on an empty site, unfolds the property as a detailed pop-up model, then expands into the exact full-scale reference exterior.

## Usage

For architecture storytelling, developer presentations, hospitality campaigns, and premium editorial property reveals.

## Engines/Models

Reference-aware video model with hinge folding, scale transition, and final-frame lock.

## Prerequisites / Dependencies

- Completed property as `@reference`.
- Optional book cover or brand reference without visible final logos.

## Storyboard Requirement

Optional six-panel board: closed book, opening pages, pop-up walls, complete miniature, scale expansion, final hero.

## Effect

### Effect Name: Pop-Up Book to Property

All paper elements hinge from page folds in ordered motion. The complete miniature must match the final design before scale expansion and material conversion.

## Video Prompt

```text
Use @reference as the final exterior design target and exact final visual match. Create a 10-second continuous cinematic luxury property reveal.

0.0-1.0s: Begin with a large premium architectural book lying closed on the empty site.
1.0-2.2s: The book opens smoothly to a central spread.
2.2-5.5s: Walls, roof, balconies, windows, trees, pool, and paths unfold upward from precise page hinges as an intricate pop-up model matching @reference.
5.5-7.5s: The completed paper model expands continuously from miniature to full scale while maintaining exact proportions and site alignment.
7.5-9.0s: Paper surfaces become realistic concrete, stone, timber, glass, metal, vegetation, and water. Book pages disappear into the final ground plane.
9.0-10.0s: Finish on the full-scale photorealistic property matching @reference.

No people, text, logos, cuts, random book text, extra pages, tearing, crumpling, disconnected pop-up pieces, scale jump, geometry drift, visible book in final scene, or paper texture on final materials.
```

## Exterior Reveal Checklist

- [ ] One book opens in a physically plausible way.
- [ ] Elements hinge from the page rather than float independently.
- [ ] Miniature model matches the reference before scaling.
- [ ] Scale transition is continuous and aligned to the site.
- [ ] Pages disappear cleanly into final terrain.
- [ ] Final property matches `@reference`.
- [ ] Sequence remains one continuous 10-second take.
