# Luxury Property Invisible Conveyor Installation

## Classification

**Product Category:** luxury-property exterior
**Reveal Effect:** self-installing conveyor assembly
**Reveal Mechanism:** components travel one invisible path and install sequentially at their final destinations
**Sequence Type:** reference-match component assembly

## Description of Resulting Video or Video Sequence

A 10-second luxury construction sequence where building and landscape components travel along an implied conveyor route and install themselves into the exact reference property.

## Usage

For modular building, manufacturing, property-development, and satisfying precision-assembly campaigns.

## Engines/Models

Reference-aware video model with object-path control, contact alignment, and final-frame lock.

## Prerequisites / Dependencies

- Completed property as `@reference`.
- Optional aligned empty-site plate.

## Storyboard Requirement

Optional five-panel board: empty path, walls arriving, windows/facade, site components, final hero.

## Effect

### Effect Name: Invisible Conveyor Installation

One readable path routes rigid components in logical order. Parts travel visibly, stop at exact destinations, and lock once; no visible machine is required.

## Video Prompt

```text
Use @reference as the final exterior design target and exact final visual match. Create a 10-second continuous cinematic luxury construction video.

0.0-1.0s: Start with an empty site while one sleek invisible conveyor path is implied through the property footprint.
1.0-3.8s: Foundation, wall, and floor components travel along the path one by one and install into exact positions.
3.8-6.5s: Windows, facade panels, doors, balconies, and roof pieces follow and lock into the stable structure.
6.5-8.8s: Plants, driveway sections, paths, pool elements, and exterior lights arrive and install in final reference locations.
8.8-10.0s: The conveyor flow stops and the camera presents the completed photorealistic property matching @reference.

No people, text, logos, cuts, visible industrial conveyor unless requested, teleporting parts, collisions, wrong order, unsupported roof, duplicate components, floating pieces, sliding after lock, or architecture drift.
```

## Exterior Reveal Checklist

- [ ] One coherent component path is readable.
- [ ] Structure arrives before facade and landscape.
- [ ] Every part travels visibly and locks once.
- [ ] Components avoid collision and preserve scale.
- [ ] Conveyor activity stops before final hero frame.
- [ ] Property matches `@reference` exactly.
- [ ] Sequence is one continuous 10-second shot.
