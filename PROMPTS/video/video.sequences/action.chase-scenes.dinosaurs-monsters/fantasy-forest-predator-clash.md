# Fantasy Forest Predator Clash — InVideo Agent One

**MULTI-CHARACTER CINEMATIC SEQUENCE / SEEDANCE 2.5 + GPT IMAGE 2**

---

## Platform Chain

**GPT Image 2** (character reference sheets + environment board) → **InVideo Agent One** → **Seedance 2.5** (20-second continuous sequence)

---

## Concept

Single continuous cinematic scene showing four-beat emotional story arc: hero meditating in fantasy forest, massive predator stalking from shadows, sudden clash with attack and dodge, twist reveal where "predator" is affectionate pet. Treat Agent One like production crew with full creative brief upfront, build complete reference set for environment and both characters, then generate as one continuous 20-second sequence with consistent tone and identity across all beats.

**Style:** Photoreal epic-fantasy cinema, awe-driven with kinetic action burst  
**Format:** 4K cinematic quality, extremely detailed materials and dynamic effects  
**Duration:** 20 seconds continuous (four 5-second beats)  
**Audio:** Natural sounds only, no music

---

## Workflow Overview

**STAGE 0:** Brief the agent and set its role  
**STAGE 1:** Build reference set (forest + hero + predator)  
**STAGE 2:** Generate the full 20-second sequence  
**STAGE 3:** Review and finalize with targeted fixes

---

## STAGE 0: Brief the Agent and Set Its Role

**Before generating anything**, open conversation by giving Agent One the full picture. Make clear this is single continuous shot (not separate scenes), so everything — environment, both characters, emotional turn — must stay consistent within one sequence.

### Agent Brief:

"I want you to act as my AI filmmaking crew for a single continuous fantasy scene, about 20 seconds long, told in four beats: a quiet meditation moment, a predator stalking in, a sudden clash, and a twist where the predator turns out to be affectionate. I'll give you a forest reference board and two character reference sheets — one for the hero, one for the predator. Please hold onto the environment style and both character identities across the whole sequence, since this is one continuous shot, not separate clips."

**Why this matters:** This framing tells agent to treat four beats as one coherent shot with consistent tone, rather than four disconnected generations stitched together.

---

## STAGE 1: Build the Reference Set

**Before touching video**, lock down everything scene depends on: environment and both characters.

### 1.1 — Forest Environment Board

Rather than generating brand-new environment reference, **curate one directly from footage you already like**.

**What to tell Agent One:**

"Here's my environment reference for the forest — I've put together a board of six frames from footage I liked, showing the mood, light, and density of vegetation I want. Treat this as the visual target for the forest environment across the whole scene."

**Deliverable:** 6-frame reference board showing mood, lighting, vegetation density

---

### 1.2 — Hero Character Reference Sheet

Same reusable character-sheet approach: **combine personal photo with costume reference**, adjusted to fit fantasy setting.

**What to tell Agent One:**

"Now let's build the hero's character sheet. Use GPT Image 2. Combine my reference photo with this costume reference, but adjust the costume design as shown in my notes — add the fantasy-appropriate changes rather than reproducing the costume photo exactly."

**Deliverable:** Professional character reference sheet (3 panels: full body front, face close-up front, face side profile)

---

### 1.3 — Predator Character Reference Sheet

Since there's no photo to work from, **agent builds creature from reference imagery + written appearance description**.

**What to tell Agent One:**

"Now let's build a character sheet for the predator. Use GPT Image 2. I don't have a photo for this one — instead, use these creature reference images plus my written description of its appearance: [insert your appearance notes — size, coloring, texture, distinguishing features]. Make sure its scale reads as roughly 2–3 times the hero's height, since that's important for the stalking and clash beats later."

**Deliverable:** Professional character reference sheet for creature with explicit scale ratio

---

### Reusable Character Reference Sheet Prompt (GPT Image 2)

**USE FOR BOTH HERO AND PREDATOR** — only reference images and description change:

```
professional character reference sheet, white background, three panels side by side, same subject: left panel full body front view standing in neutral pose, center panel close-up face front view, right panel close-up face side profile 90 degrees, photorealistic hyperrealistic texture with natural detail, flat soft studio lighting, consistent identity across all three views, same subject same face same proportions, 8k ultra sharp, NOT cartoon NOT anime NOT illustration NOT stylized NOT blurry NOT 3D render, avoid smooth plastic texture, avoid different subjects, avoid shadows on background.
```

**Critical:** Once agent generates forest board and both character sheets, **confirm them explicitly before moving on** — this locks them into project memory as @Image 1 (forest), @Image 2 (hero), @Image 3 (predator) for generation stage.

---

## STAGE 2: Generate the Scene — Meditation, Ambush, Clash, Bond

### Set the Scene for Agent One:

"Now let's generate the full sequence. This is one continuous 20-second shot in four beats: he's meditating, the predator stalks in, they clash, and then it turns out to be affectionate. Generate it with Seedance 2.5. Use the forest board for the environment, the hero sheet for the main character, and the predator sheet for the creature. Keep it photoreal, epic-fantasy in tone, 4K cinematic quality, with only natural sounds and no music."

---

### Full Generation Prompt (0–20 seconds):

**Photoreal epic-fantasy cinema, awe-driven with a sudden burst of kinetic action. 4K cinematic quality, extremely detailed materials and dynamic effects.**

**0–5 sec:** Smooth camera movement showcasing the beauty of a fantasy forest @Image 1. The main character @Image 2 is meditating with his eyes closed, sitting on the ground in the forest.

**5–10 sec:** From a distance, a predator @Image 3 is creeping up behind him quietly and slowly. The predator is of very impressive size, 2–3 times taller than the main character. After a few seconds, the main character senses the predator's presence, opens his eyes and waits for the attack.

**10–15 sec:** The monster senses that it has been detected and jumps quickly and powerfully towards the hero. The main character dodges with a quick and confident leap to the side. The predator quickly turns its body and assumes an attacking stance facing the hero. The hero also takes up a defensive position.

**15–20 sec:** The predator jumps at the hero, but doesn't attack him; instead, it starts to show affection. The main character smiles and rejoices in his pet's love. His huge and predatory appearance seems deceptive at this moment. The predator is very kind to its owner and shows its goodwill.

**Only natural sounds. No music.**

---

### Inputs Attached Alongside This Prompt:

- **@Image 1** — forest environment reference board (6 frames)
- **@Image 2** — hero character reference sheet
- **@Image 3** — predator character reference sheet

---

## STAGE 3: Review and Finalize

Once sequence comes back, **close the loop with agent before calling it done**:

**Final Review Prompt:**

"The sequence looks good. Check that the predator's scale stays consistent relative to the hero across all four beats, and that the tone shift from threatening to affectionate in the last beat reads clearly. If the scale or the emotional turn feels off in any beat, regenerate just that portion rather than the whole 20 seconds."

**Why targeted fixes work:** Because whole scene was generated as one continuous shot (not four separate clips), targeted fixes stay grounded in same environment and character references instead of drifting from rest of sequence.

## Critical Workflow Principles

### 1. One Continuous Shot, One Brief

**Telling agent upfront** that this is single sequence (not separate clips) keeps tone and identity consistent across all four story beats.

### 2. Curate References, Don't Always Generate Them

Forest board came from real footage frames, not fresh generation. Use whichever source gets you cleanest reference fastest.

### 3. One Character-Sheet Template, Many Subjects

Same reference-sheet prompt worked for both human hero AND fantasy creature, just by swapping input images and description.

### 4. State Scale and Proportion Explicitly

For creature much larger than hero, **spelling out size ratio** in prompt keeps it consistent across beats. "2–3 times taller than the main character" locked in from beginning.

### 5. Confirm Before Moving On

**Approving reference set before generating scene** keeps agent's project memory clean and avoids inconsistencies compounding across sequence.

### 6. Targeted Fixes vs. Full Regeneration

Because entire scene generated as one continuous shot, can regenerate specific beat without losing consistency with rest of sequence.

## Style Notes

**DO:**

- Brief agent with full story arc upfront
- Lock down all references before video generation
- Confirm references explicitly (locks into @Image memory)
- State scale ratios explicitly for size consistency
- Specify "one continuous shot" in brief
- Use curated footage for environment references
- Apply same character-sheet template to different subjects
- Request targeted fixes for specific beats
- Maintain logical story progression across beats
- Keep emotional tone shift clear in final beat

**DON'T:**

- Jump straight to video without reference set
- Generate environment from scratch if footage exists
- Skip explicit scale specifications for creatures
- Treat four beats as separate disconnected clips
- Regenerate entire 20 seconds for single-beat fix
- Mix reference sources mid-generation
- Rush through confirmation stage
- Assume agent remembers context without @Image locks

## Pro Tips

**Reference Sheet Template Reusability:**

- Save the GPT Image 2 character-sheet prompt
- Use for humans, creatures, animals, characters
- Only swap input images and written description
- Maintains consistent 3-panel format across projects

**Environment Board Strategy:**

- Curate 6 frames showing variety within consistent style
- Include different angles/distances of same location type
- Show lighting conditions clearly
- Capture vegetation/terrain density
- Demonstrate color palette and atmosphere

**Scale Specification:**

- Always include size ratio for creatures vs. humans
- Use explicit measurements: "2–3 times taller"
- Repeat in both reference stage AND generation prompt
- Mention why scale matters: "important for stalking and clash beats"

**Agent Memory Management:**

- Confirm each reference explicitly: "This is the forest board"
- Wait for agent to acknowledge before moving forward
- Use @Image notation to lock references into memory
- Reference locked images in generation prompt with @Image tags

**Continuous Shot Consistency:**

- State "one continuous shot" in initial brief
- Emphasize "consistent tone and identity across all beats"
- Request targeted fixes: "regenerate just that portion"
- Avoid separate clip language like "stitch together"

## Common Pitfalls to Avoid

**Inconsistent Scale:**

- Predator size shifts between beats
- Solution: Explicit ratio specification upfront

**Tone Drift:**

- Final affectionate beat reads as continued threat
- Solution: Clear emotional shift description in beat 4 prompt

**Reference Confusion:**

- Agent mixes up character identities mid-sequence
- Solution: Confirm and lock @Image references before generation

**Disconnected Beats:**

- Four beats feel like separate clips stitched together
- Solution: Brief agent upfront about "one continuous shot"

**Camera Inconsistency:**

- Different camera style or quality across beats
- Solution: Single prompt covering all four beats maintains consistency
