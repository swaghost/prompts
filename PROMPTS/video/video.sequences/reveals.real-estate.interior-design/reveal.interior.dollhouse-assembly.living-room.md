# Living Room Luxury Dollhouse Assembly

## Classification

**Product Category:** living-room interior
**Reveal Effect:** precision dollhouse assembly
**Reveal Mechanism:** architectural finishes, furniture, lighting, textiles, plants, and decor install piece by piece like a premium model
**Sequence Type:** reference-match interior assembly

## Description of Resulting Video or Video Sequence

A 10-second continuous living-room build where every fixed finish and loose object assembles with model-like precision before becoming fully photorealistic.

## Usage

For interior-design studios, furniture campaigns, staging presentations, and satisfying room-assembly videos.

## Engines/Models

Reference-aware video model with object inventory control, placement physics, immutable room shell, and final-frame lock.

## Prerequisites / Dependencies

- Finished living room as `@reference`.
- Optional aligned empty-room shell.

## Storyboard Requirement

Optional six-panel board: empty shell, flooring/paneling, primary furniture, secondary furniture, styling/light, hero frame.

## Effect

### Effect Name: Luxury Dollhouse Assembly

Each complete object arrives through a direct path, lands at realistic scale, and remains fixed. Fixed architecture never shifts or warps.

## Video Prompt

```text
Use @reference as the final living room design target and exact final visual match. Create a 10-second continuous interior assembly.

0.0-1.0s: Begin with an empty room shell from the exact final camera position.
1.0-3.0s: Flooring and wall paneling install precisely while walls, ceiling, openings, and built-in geometry remain fixed.
3.0-6.2s: Sofa, chairs, and tables assemble and settle at correct scale and reference positions with contact shadows.
6.2-8.8s: Lighting, curtains, rug, plants, artwork, books, and decor install in logical order. Textiles settle and hanging objects damp naturally.
8.8-10.0s: The stylized precision assembly becomes fully photorealistic and ends on a smooth cinematic hero shot matching @reference exactly.

No people, text, logos, cuts, moving walls, floating furniture, object morphing, partial objects, duplicate decor, wrong scale, blocked circulation, unstable textiles, or room-layout drift.
```

## Interior Reveal Checklist

- [ ] Room shell and camera remain immutable.
- [ ] Fixed finishes install before loose objects.
- [ ] Primary furniture precedes decor.
- [ ] Every item matches the reference inventory and position.
- [ ] Contact, textiles, hanging objects, and shadows behave physically.
- [ ] Final room is fully photorealistic.
- [ ] Sequence is continuous, 10 seconds, and matches `@reference`.
