# Living Room Invisible-Drawer Reveal

## Classification

**Product Category:** living-room interior

**Reveal Effect:** hidden spatial drawer installation

**Reveal Mechanism:** invisible drawers extend from floor and walls, expose final components, then close while installed objects remain

**Sequence Type:** reference-match compartment reveal

## Description of Resulting Video or Video Sequence

Large invisible drawers slide from architectural surfaces to reveal flooring, furniture, textiles, shelving, decor, and lighting, leaving each component installed as they close.

## Usage

Use for storage-inspired transformations, interior product reveals, architectural presentations, and surreal but orderly room assembly.

## Engines/Models

Reference-aware video model with planar extrusion, hidden-compartment continuity, object support, geometry restoration, and final-frame lock.

## Prerequisites / Dependencies

- Finished living room as `@reference`.
- Aligned empty shell with walls and floor suitable for planar drawer motion.
- Exact component grouping and final locations.

## Storyboard Requirement

Optional six-panel board: empty shell, floor drawer, wall drawers, furniture installation, drawer closure, hero frame.

## Effect

### Effect Name: Invisible Spatial Drawers

Architectural planes extend as clean temporary compartments; components transfer directly to final supports before each plane closes flush without leaving seams.

```text
Preserve shell geometry, camera, inventory, layout, materials, lighting, and @reference fidelity. No permanent wall openings, visible drawer seams, object retraction, collisions, duplicates, cuts, or unfinished final frame.
```
