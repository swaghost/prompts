# Living Room Giant-Hand Finishing Reveal

## Classification

**Product Category:** living-room interior
**Reveal Effect:** giant-hand styling placement
**Reveal Mechanism:** one realistic hand places finishing objects sequentially into an already furnished room
**Sequence Type:** reference-match interior styling reveal

## Description of Resulting Video or Video Sequence

A 10-second styling film where a giant hand installs cushions, rug, books, lamps, curtains, art, plants, and accessories until the living room matches the final reference.

## Usage

For interior stylists, furniture and decor brands, residential marketing, and satisfying room-finishing videos.

## Engines/Models

Reference-aware video model with hand anatomy, object placement, occlusion, textile physics, and final-frame lock.

## Prerequisites / Dependencies

- Finished living room as `@reference`.
- Optional aligned unfinished-room first frame with main furniture already present.

## Storyboard Requirement

Optional six-panel board: unfinished room, textiles, rug/books, lamps/curtains, art/plants, hero frame.

## Effect

### Effect Name: Giant-Hand Interior Styling

One anatomically correct hand places each loose item with visible approach, contact, release, and exit. Fixed architecture and main furniture remain unchanged.

## Video Prompt

```text
Use @reference as the final living room design target and exact final visual match. Create a 10-second continuous interior styling video.

0.0-1.0s: Start with the main furniture already in place inside a simple unfinished version of the room, from the exact final camera position.
1.0-8.8s: One giant realistic human hand enters from above and places finishing pieces one by one in logical order: cushions, rug, coffee-table books, lamps, curtains, artwork, plants, and decorative accessories. Every object matches @reference, approaches visibly, makes physical contact, settles, and is released before the next placement.
With each placement, materials, shadows, reflections, and styling become more polished and realistic. Cushions compress, rug lies flat beneath furniture, curtains hang from their actual support, artwork mounts to the correct wall, and plants remain rooted in their containers.
8.8-10.0s: The hand exits completely. End with a subtle cinematic push-in on the fully photorealistic room matching @reference.

No other people, text, logos, cuts, extra hands, malformed fingers, hand clipping, floating objects, moved main furniture, changed walls, duplicate decor, impossible object scale, or unfinished styling.
```

## Interior Reveal Checklist

- [ ] Fixed shell and main furniture remain unchanged.
- [ ] One plausible hand performs all placements.
- [ ] Every object matches the reference inventory and location.
- [ ] Approach, contact, release, and settling are visible.
- [ ] Textiles and mounted objects behave physically.
- [ ] Hand exits before final hero frame.
- [ ] Final 10-second room matches `@reference`.
