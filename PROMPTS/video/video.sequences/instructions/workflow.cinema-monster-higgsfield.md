## The Recipe

**Formula:** cast → location → 50 references → one detailed scene

### Step 1: Build the Cast

Generate each character as a studio photo, then turn it into a **4-panel reference sheet** (front / profile / back, same scale) — that's what locks identity from every angle.

### Step 2: Build the Location

Build the location as its own **clean plate** — empty, no people, no light you don't control.

### Step 3: Drop Everything into Seedance 2.5

On higgsfield.ai — it takes up to 50 references in one generation: images, clips, even audio.

### Step 4: Write the Scene

Tag each reference for what it controls, lay out the space, then describe exactly what happens. **The more detail, the better.** Hit generate.

**Pro Tip:** Run each prompt 3× and keep the best take.

## Workflow Summary

### Phase 1: Character Creation

**For Each Character:**

1. Generate studio photo on white background (GPT Image 2, Midjourney, etc.)
2. Use that photo to generate 4-panel reference sheet (front, profile, back, close-up)
3. Verify all panels match in scale, lighting, and identity

**Key Requirements:**

- Pure white seamless background
- Same scale across all full-length panels
- Identical lighting across all panels
- Clean commercial studio lighting
- Soft contact shadows beneath feet
- No environment, props, or text

---

### Phase 2: Location Creation

**Build Clean Plate:**

1. Generate empty location with no people
2. Ensure all lighting is practical and controllable
3. Match desired atmosphere and mood
4. Verify perspective and architecture are correct

**Key Requirements:**

- Empty space (no people anywhere)
- Practical lights only (sconces, lamps, etc.)
- Clear spatial layout
- Consistent material textures
- No projector beams or uncontrolled light

---

### Phase 3: Scene Generation (Seedance 2.5)

**Setup:**

1. Open Higgsfield.ai
2. Select Seedance 2.5
3. Upload all references (characters + location)

**Prompt Structure:**

1. **Technical specs:** Duration, shot type, visual style, lighting mood
2. **Reference tags:** @image1, @image2, @image3, etc. — specify what each controls
3. **Spatial layout:** Describe the space and where everything is positioned
4. **Action beats:** Detailed description of what happens, frame by frame

**Critical Prompt Elements:**

- Tag each reference explicitly (@image1 as...)
- Describe spatial relationships clearly
- Detail every action beat
- Specify camera movement (or lock)
- Define lighting and atmosphere
- Include negative prompts if needed

**Pro Workflow:**

- Generate 3 variations
- Keep the best take
- Refine prompt if needed and regenerate

## Key Principles

### 1. Reference Sheet Quality = Character Consistency

**4-Panel Layout:**

- Panel 1: Head and shoulders close-up
- Panel 2: Full length front view
- Panel 3: Full length side profile
- Panel 4: Full length back view

**Why This Works:**

- Locks identity from every angle
- Provides model with complete character data
- Ensures consistency across different shots
- Prevents face/body drift during generation

### 2. Clean Plates = Controlled Lighting

## Troubleshooting

### Character Face Changes

**Problem:** Generated character doesn't match reference sheet  
**Solution:**

- Ensure reference sheet has clear, sharp images
- All 4 panels must show identical face
- Tag reference explicitly: "@image1 as [name] reference — face, hair, eyes, etc."
- Add to prompt: "Keep [character] face exactly as shown in reference"

### Spatial Layout Issues

**Problem:** Characters positioned incorrectly  
**Solution:**

- Be extremely specific about spatial layout
- Use directional terms (left, right, foreground, background)
- Describe character positions relative to each other
- Reference specific location features

### Lighting Inconsistencies

**Problem:** Lighting doesn't match location reference  
**Solution:**

- Specify exact light sources in prompt
- Match atmospheric conditions to location
- Describe shadow directions
- Reference specific practicals by name

### Action Confusion

**Problem:** Characters do wrong actions or nothing happens  
**Solution:**

- Break down action into smaller beats
- Describe each beat sequentially
- Be specific about timing
- Specify what DOESN'T change (camera lock, background, etc.)
