## Troubleshooting

**Issue:** Logo morphs or changes during animation

- **Solution:** Ensure "Do not redesign or modify the logo" is in prompt, emphasize "maintain identical logo design," verify reference image is clear and high-quality

**Issue:** Embroidery looks unrealistic or CGI-like

- **Solution:** Verify using Seedance 2.5 **1080p** (not standard resolution), ensure Nano Banana 2 image has realistic embroidery texture, include "photorealistic live action" in prompt

**Issue:** Thread colors change or flicker

- **Solution:** Include specific thread colors in Nano Banana 2 prompt, ensure "maintain identical thread colors" is in Seedance prompt, add "no color flickering" to negatives if needed

**Issue:** Cap color shifts during animation

- **Solution:** Specify exact cap color in Nano Banana 2 ("navy blue" not just "blue"), ensure "maintain identical cap color" is in Seedance prompt

**Issue:** Animation lacks detail (threads not visible)

- **Solution:** Verify using 1080p resolution, emphasize "macro close-up" and "individual embroidery threads become visible" in prompt, ensure Nano Banana 2 image shows clear stitch detail

**Issue:** Machine movement looks jerky or unnatural

- **Solution:** Ensure "natural machine movement" is in prompt, add "smooth continuous motion" if needed, verify "perfect temporal consistency" is included

**Issue:** Background is distracting or inconsistent

- **Solution:** Nano Banana 2 should use "soft studio lighting" and neutral background, Seedance prompt maintains this with "professional embroidery workshop" context

**Issue:** Logo appears incomplete in final frame

- **Solution:** Ensure "The final shot should look identical to the uploaded embroidered cap with the completed logo perfectly stitched" is at end of prompt

## Comparison: This Workflow vs. Two-Frame Method

### **Cap Embroidery (This Workflow)**

**Method:** Single image → Animation  
**Steps:** Generate cap image in Nano Banana 2 → Animate in Seedance 2.5  
**Pros:**

- Simpler workflow (only one image generation)
- Faster process (no matching second frame needed)
- Logo consistency easier to maintain
- Ideal for finished product showcases

**Best for:** Cap embroidery, finished product reveals, brand merchandise marketing

---

### **Two-Frame Logo Embroidery (Alternative Method)**

**Method:** First frame (partial) → Final frame (complete) → Animation  
**Steps:** Generate partial embroidery → Generate completed embroidery → Animate progression  
**Pros:**

- Shows clear embroidery progression (partial to complete)
- More satisfying transformation
- Better for process demonstration
- Works on any surface (not just caps)

**Best for:** Logo patch embroidery, flat surface embroidery, progression showcases
