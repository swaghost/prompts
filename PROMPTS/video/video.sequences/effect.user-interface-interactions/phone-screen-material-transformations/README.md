# Phone Screen Material Transformations

Three source-video commercial VFX prompts that modify only a tracked phone-screen effect while preserving the uploaded video.

- [01 Matcha screen pour](01-matcha-screen-pour.md): Existing on-screen text becomes creamy matcha, then pours from the phone as it tilts.
- [02 Foam screen burst](02-foam-screen-burst.md): A blown phone screen releases dense, frame-filling soap-like foam.
- [03 Rhinestone transfer](03-rhinestone-transfer.md): Rhinestones transfer from the phone onto the touched path of the subject's body.

## Shared Input Requirement

Upload the original video as the sole source reference. Preserve its subject, phone, background, lighting, framing, motion, and original audio. Each prompt specifies the only permitted VFX modification.
