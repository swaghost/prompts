# Bar Fight - Glass Table Crash Scene

## Description

Create an ultra-detailed, shot-by-shot bar fight choreography centered around a dramatic glass table crash sequence. This prompt generates cinematic fight action with precise camera work, realistic physics for glass shattering, slow-motion capture moments, handheld tracking shots, and atmospheric lighting—perfect for action filmmaking, VFX pre-visualization, stunt coordination, or cinematic game sequences.

## Scene Overview

**Setting:** Bar/club interior with glass-topped table
**Action:** Fighter thrown through thick glass table, dramatic slow-motion glass destruction
**Style:** Dark cinematic noir with high contrast, single cyan overhead light
**Duration:** ~6 shots covering setup to aftermath
**Key Elements:** Glass physics, handheld camera, slow-motion impact, fighter combat

## Best Practices

**For Realistic Fight Choreography:**

1. **Glass Physics Accuracy**
   - Thick glass shatters into hundreds of pieces
   - Shards blast upward from impact force
   - Drift downward with spinning motion
   - Gradual settling throughout scene
   - Realistic weight and movement

2. **Camera Work Variety**
   - Mix static and handheld shots
   - Use slow-motion for key impacts
   - Tight tracking for action intensity
   - Wide shots for spatial context
   - Follow important objects (flying glass)

3. **Fight Choreography Flow**
   - Clear action progression
   - Multiple opponents engaged sequentially
   - Use environment (glass shards as weapons)
   - Show fatigue and exertion
   - Build to climactic finish

4. **Timing & Pacing**
   - Vary shot durations for rhythm
   - Slow-motion for dramatic moments
   - Fast handheld for intensity
   - Holds for dramatic beats
   - Silence for impact

5. **Visual Continuity**
   - Track glass shard count/size
   - Consistent lighting throughout
   - Character positioning clear
   - Wounds/damage accumulate
   - Environmental consistency
