## Troubleshooting

### Common Issues and Fixes

**Problem: Figure looks like a toy/doll instead of realistic miniature human**

```
Fix: Emphasize "realistic skin pores and texture, photographic quality, not a toy or figurine, real human at miniature scale"
```

**Problem: UI interface text is unreadable or garbled**

```
Fix: Add "clean readable Spotify interface, legible text, professional UI design, accurate music player controls"
```

**Problem: Proportions feel off, scale doesn't read as surreal**

```
Fix: Add "extreme size contrast, tiny human versus giant smartphone, clear scale difference, person should be 1/20th the size of phone screen"
```

**Problem: Lighting looks flat, no depth**

```
Fix: Add "realistic shadow cast by figure onto screen surface, directional studio lighting, depth and dimension, 3D volume"
```

**Problem: Reference image identity not preserved**

```
Fix: Re-upload reference and emphasize "exact same face, hair, and identity as reference image, perfect consistency"
```
