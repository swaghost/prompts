## Workflow

1. Choose a style.
2. Replace the bracketed subject fields.
3. Generate the visual artwork first.
4. Add final headlines, brand names, product details, logos, and calls to action in design software for precise typography.
5. Generate multiple variations and refine composition, lighting, and color.
