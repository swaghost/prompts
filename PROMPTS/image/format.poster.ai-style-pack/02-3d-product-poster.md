# 3D Product Poster

**Character:** Dimensional, realistic, luxurious  
**Best for:** Technology, cosmetics, shoes, watches, beverages, luxury products

## Image Prompt

```text
Create a high-end 3D advertising poster featuring [PRODUCT]. Place the product as the main hero object in the center of the composition. Use realistic materials, detailed textures, dramatic studio lighting, cinematic reflections, soft atmospheric shadows, and floating design elements around the product. Create a premium luxury advertising aesthetic with depth and dimensional composition. Add subtle motion-inspired elements and elegant environmental details. Hyper-realistic 3D render, professional product photography style, cinematic lighting, high detail, premium commercial advertisement, vertical 4:5 poster composition.
```

## Pro Tip

Describe the exact product rather than using a generic noun, for example: `a luxury transparent perfume bottle with golden details`.

## Negative Prompt

```text
generic product, altered product geometry, incorrect label, warped logo, plastic materials, flat lighting, weak reflections, clutter, excessive floating objects, low detail, cartoon, watermark
```
