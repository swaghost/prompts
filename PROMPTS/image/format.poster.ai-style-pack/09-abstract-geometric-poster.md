# Abstract Geometric Poster

**Character:** Abstract, modern, geometric  
**Best for:** Branding, events, cultural graphics, experimental editorial design

## Image Prompt

```text
Create a bold abstract geometric poster inspired by contemporary graphic design. Use dynamic geometric shapes, circles, lines, grids, layered forms, visual rhythm, and balanced negative space. Build an energetic composition with strong contrast and modern artistic direction. Use a refined color palette with carefully controlled gradients and subtle textures. Create a visually engaging design that feels experimental, modern, and professionally art-directed. High-end abstract graphic design, geometric composition, clean visual hierarchy, premium poster aesthetic, vertical 4:5 format.
```

## Pro Tip

Choose only two or three dominant colors to maintain visual consistency.

## Negative Prompt

```text
random shapes, weak grid, uncontrolled gradients, too many colors, muddy palette, no focal rhythm, clip-art appearance, decorative clutter, illegible text, watermark, logo
```
