# Editorial Magazine Poster

**Character:** High-fashion, editorial, bold  
**Best for:** Fashion, beauty, lifestyle brands, personal branding, magazine covers

## Image Prompt

```text
Create a sophisticated editorial magazine-style poster featuring [SUBJECT]. Use a bold modern composition inspired by high-fashion magazines and premium editorial design. Focus on expressive visual storytelling, artistic photography, dramatic lighting, refined styling, and a strong modern grid structure. Leave intentional negative space for typography and layout. Create a luxurious, confident, and visually striking aesthetic with professional art direction. High-fashion editorial photography style, premium magazine aesthetic, clean composition, detailed textures, vertical 4:5 poster format.
```

## Pro Tip

Reserve intentional negative space and add final typography during layout production.
