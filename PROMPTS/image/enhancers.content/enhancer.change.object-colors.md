# Change Colors

## Purpose

Change the colors of specific objects or elements within an image while preserving textures, lighting, material properties, and photographic realism, enabling color variations without re-photographing.

## Description of Target Content or Subject

Any image requiring object color changes including product photography for color variants, wardrobe color adjustments, item recoloring for design exploration, branding color updates, or any scenario where object colors need modification while maintaining realism.

## Discovery - Description of Resulting Output

A photorealistic image with specified objects displaying new colors while preserving original textures and material properties, maintaining consistent lighting and shadow information, keeping highlights and shading appropriate for the new color, preserving depth and three-dimensionality, and achieving natural appearance as if originally photographed in the new color.

## Usage

Perfect for e-commerce product variants, fashion color options, interior design visualization, and creative color exploration. Ideal for product marketers, e-commerce businesses, designers, and photographers. This prompt excels at realistic object recoloring while maintaining photographic authenticity and material integrity.

## Prerequisites

**MANDATORY:**

- Source image
- Specification of which object(s) to recolor
- Desired new color(s)

## Prompt

Change the color of [SPECIFIC OBJECT/ELEMENT] to [NEW COLOR] while keeping all textures, lighting, and material properties intact. Preserve the original texture detail and material characteristics. Maintain consistent highlights, shadows, and shading appropriate for the new color. Ensure the recolored object retains depth and three-dimensionality. The result should look naturally photographed in the new color with complete photographic realism.
