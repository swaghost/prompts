# Art Deco Poster Collection

A collection of elegant Art Deco image prompts for premium vertical posters. The shared visual language combines symmetrical geometry, stepped architecture, sunburst motifs, jewel tones, metallic accents, and period-inspired typography with clean modern print discipline.

## Shared Rules

- Vertical 2:3 or 4:5 poster composition
- Strong symmetry, stepped forms, fan and sunburst geometry
- Limited palette of black, ivory, jewel tones, and restrained metallic gold
- Elegant period-inspired display typography with exact spelling
- Flat graphic illustration or finely controlled screen-print texture
- No photorealistic clutter, modern logos, gradients, or random extra text
