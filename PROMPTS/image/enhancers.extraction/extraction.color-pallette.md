# 🎨 **Prompt: Extract the Color Palette from an Image or Video**

**Prompt:**  
“Analyze the visual color palette of this image/video. Identify the dominant colors, secondary supporting colors, and subtle accent tones. Provide each color with a descriptive name (e.g., ‘dusty rose’, ‘petrol blue’, ‘warm sand’) and include its approximate hex value. Group the palette into categories:  
- **Primary colors** (most visually dominant)  
- **Secondary colors** (supporting tones)  
- **Accents** (small but emotionally important colors)  

Explain how these colors interact: contrast, harmony, temperature (warm/cool), saturation, and mood. Describe what emotional or stylistic impression the palette creates (e.g., nostalgic, cinematic, sterile, vibrant, moody). If the image/video contains lighting effects, note how they shift the palette.”
