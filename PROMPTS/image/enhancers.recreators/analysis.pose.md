# Pose‑Analysis Prompts

Use these to extract body mechanics, emotional intention, and editorial posture.

## Pose Prompt A — Body Mechanics

“Analyze the model’s pose. Describe the position of every major body part: arms, hands, legs, hips, shoulders, spine, head angle. Explain how weight is distributed and how the pose interacts with props (car hood, hose, pole, platform).”

## Pose Prompt B — Emotional Expression

“Break down the emotional intention behind the pose: confidence, seduction, aggression, playfulness, rebellion. Describe how facial expression, gaze direction, and micro‑posture contribute to the mood.”

## Pose Prompt C — Editorial Function

“Explain how the pose serves the fashion editorial: how it highlights clothing, how it uses diagonals or tension, how it creates dynamic motion, how it interacts with water spray or carwash equipment, and how it fits the overall narrative.”
