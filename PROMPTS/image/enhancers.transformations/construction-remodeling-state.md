# Construction/Remodeling State - Unfinished Building Transformation

## Description

Transform the scene into a realistic unfinished construction state, exposing raw concrete, structural surfaces, and unpainted materials with visible construction details such as rough textures while maintaining the original architecture. This prompt converts completed spaces into mid-construction or renovation states showing exposed structure, unfinished surfaces, construction materials, and building process—ideal for construction documentation, renovation visualization, design development presentation, construction marketing, and educational architectural communication.

## Transformation Overview

**Effect:** Completed → Under construction/renovation  
**State:** Unfinished construction phase  
**Structure:** Original architecture maintained  
**Materials:** Raw exposed, unpainted, structural  
**Purpose:** Construction visualization, renovation state, process documentation
