## How to Use

1. Use Higgsfield AI for image generation; Kling or Runway can animate the images.
2. Set the aspect ratio to 3:4 portrait.
3. Copy the complete prompt for the selected scene.
4. Swap outfit colors, hair details, or locations while preserving the camera and environmental structure.
5. Add `hyperrealistic, editorial fashion photography, 4K, sharp focus` when additional realism is needed.
