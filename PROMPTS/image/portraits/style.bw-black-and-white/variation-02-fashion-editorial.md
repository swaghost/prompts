## Platform-Specific Tips

**ChatGPT with DALL-E:**

- Upload clear reference image
- Specify "Vogue-style editorial" for premium fashion aesthetic
- Request "ultra-realistic skin texture" for detailed results
- Can ask for multiple variations with different head tilts

**MidJourney:**

- Use `--style raw` for photorealistic fashion photography
- Add `--ar 4:5` for typical editorial portrait format
- Include "editorial fashion photography" in prompt
- Consider `--stylize 300-500` for balanced artistic quality
