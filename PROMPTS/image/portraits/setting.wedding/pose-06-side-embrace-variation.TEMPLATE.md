## Platform-Specific Tips

**MidJourney:**

- Use `--cref` with reference image for identity preservation
- Add `--ar 2:3` or `--ar 4:5` for vertical portrait format
- Use `--style raw` for photorealistic wedding photography
- Specify "side embrace" or "arm around from side" clearly
- Include details about head positioning and closeness
- Consider `--stylize 400-600` for romantic quality

**DALL-E 3:**

- Upload reference image first
- Emphasize "side embrace, not from behind"
- Be specific about arm placement (waist/shoulder/back)
- Clearly state gaze directions and expressions

**Adobe Firefly:**

- Use generative fill on subjects
- Emphasize "relaxed side embrace"
- Specify woman's positioning and response clearly
