## Platform-Specific Tips

**MidJourney:**

- Use `--cref` with reference image for identity preservation
- Add `--ar 2:3` or `--ar 4:5` for vertical portrait format
- Use `--style raw` for photorealistic wedding photography
- Specify exact positioning: "man on left, woman on right"
- Clearly state gaze direction for each subject
- Include hand connection details
- Consider `--stylize 400-600` for traditional elegance

**DALL-E 3:**

- Upload reference image first
- Be explicit about side-by-side positioning
- State who is looking where very clearly
- Specify distance between subjects
- Detail hand and bouquet positions

**Adobe Firefly:**

- Use generative fill on subjects
- Emphasize "standing still, side-by-side"
- Specify formal posed quality
- Detail expressions clearly
