# Prompt Module - Style, Subject, and Expression

## Style Prefixes

### Ultra-Photorealistic Cinema

```
A cinematic film still, ultra-photorealistic. Camera: extreme ground-level low angle.
```

### Raw Documentary

```
Raw documentary photograph, unretouched photojournalism aesthetic, ground-level perspective.
```

### High-Fashion Editorial

```
Vogue editorial photograph, cinematic fashion film still, extreme low-angle composition.
```

### Art-House Cinema

```
35mm film still from art-house cinema, ground-level Dutch angle, poetic natural lighting.
```

### Commercial Fashion

```
High-end fashion campaign photograph, studio-quality on location, low-angle hero shot.
```

## Subject Templates

```
[AGE AND PRESENTATION] person with [BUILD / PHYSICAL CHARACTERISTICS], [HAIR DESCRIPTION], [FACIAL FEATURES], natural human realism, realistic skin texture, no artificial smoothing.
```

```
[AGE AND PRESENTATION] person with a calm, relaxed, friendly expression and subtle natural smile, maintaining direct eye contact with the camera.
```

## Expression Variations

### Calm Confidence

```
person with a calm, relaxed, friendly expression and subtle natural smile, maintaining direct eye contact with the camera
```

### Stoic Intensity

```
person with a serious, contemplative expression, slight furrow in the brow, piercing direct gaze, lips slightly parted, conveying quiet strength
```

### Pensive Distance

```
person with a distant, thoughtful expression, gaze directed slightly past the camera, subtle melancholy in the eyes, natural solemn demeanor
```

### Playful Defiance

```
person with a slight smirk, one eyebrow raised, direct challenging gaze, hint of amusement in the eyes, confident and slightly rebellious expression
```

### Serene Detachment

```
person with a neutral, almost blank expression, soft unfocused gaze, completely relaxed facial muscles, zen-like calmness, no smile
```

### Vulnerable Strength

```
person with a gentle, vulnerable expression, slight downward tilt of the head, eyes meeting camera with quiet courage, hint of emotion held back
```

## Demographic Controls

Add age, build, hair, and distinctive features only when they are necessary to direct the result. For a reference-based generation, preserve the uploaded subject's identity, natural proportions, skin tone, hairstyle characteristics, and facial features rather than inventing a new identity.
