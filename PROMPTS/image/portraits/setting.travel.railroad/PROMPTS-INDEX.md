## Assembly Formula

```text
[STYLE] + [SUBJECT] + [WARDROBE] + [SCENE] + [ENVIRONMENT] + [CAMERA] + [LIGHTING] + [MOOD] + [NEGATIVE]
```

Use one selection from each module, then append the negative prompt from the selected platform or scene. Keep the subject, outfit, location, time of day, and colour grade unchanged when creating a coherent carousel.
