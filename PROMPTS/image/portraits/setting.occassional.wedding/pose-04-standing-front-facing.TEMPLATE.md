## Platform-Specific Tips

**MidJourney:**

- Use `--cref` with reference image for identity preservation
- Add `--ar 2:3` or `--ar 4:5` for vertical portrait format
- Use `--style raw` for photorealistic wedding photography
- Specify exact gaze direction for each subject clearly
- Include expression details (smiling/serious/romantic)
- Consider `--stylize 400-600` for editorial quality

**DALL-E 3:**

- Upload reference image first
- Be very specific about who is looking where
- Clearly state expressions for both subjects
- Specify hand positioning and bouquet location

**Adobe Firefly:**

- Use generative fill on subjects
- Emphasize "standing still, posed"
- Specify gaze directions clearly for both
