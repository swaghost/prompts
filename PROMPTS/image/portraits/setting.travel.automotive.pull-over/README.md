## Shared Settings

- **Model:** Higgsfield Soul 2.0
- **Ratio:** 3:4 portrait
- **Variants:** 4 per prompt
- **Style:** Grainy analog film, sun-bleached Americana, candid editorial fashion photography
- **Negative:** No text, no watermark, no logo, no signature

## Production Notes

Keep the film-grain and grade wording to preserve the era. Generate each scene at four variants, then select for the strongest natural gesture, vehicle detail, and film texture. Swap vehicles while retaining the same vintage period, chrome treatment, denim styling, analog grain, and restrained editorial direction.
