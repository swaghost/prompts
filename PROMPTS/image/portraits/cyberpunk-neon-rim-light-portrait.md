## Pro Tips

- **Reference Quality**: Use high-resolution reference images with clear facial detail for best identity preservation
- **Expression**: Natural, confident expressions work best—avoid extreme expressions that distort features
- **Facial Hair**: More beard/facial hair detail in reference = better preserved texture in output
- **Lighting Test**: Try different neon color combinations to match your aesthetic
- **Aspect Ratio**: 10:21 (tall vertical) is perfect for phone wallpapers and vertical social media
- **Eyes Through Lenses**: Ensure reference shows eyes clearly—AI needs to see them to preserve iris detail
- **Multiple Generations**: Generate 3-5 versions and select the one with best identity match and lighting balance
