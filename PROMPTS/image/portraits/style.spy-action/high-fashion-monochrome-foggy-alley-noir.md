**ChatGPT/DALL-E:**

- Upload reference photo maintaining 100% facial similarity and recognition
- Do not alter facial features, bone structure, or jawline
- Use only the provided photo as appearance reference
- Preserve exact likeness, age, and natural features
- Specify "exact person from reference in noir fashion scenario"

- Use `--cref [reference_url]` for character consistency
