## Identity Preservation Settings

**ChatGPT/DALL-E:**

- Upload reference photo maintaining 100% facial similarity and recognition
- Do not alter facial features, bone structure, or distinctive characteristics
- Use only the uploaded photo as appearance reference
- Preserve exact likeness, age, and natural features
- Specify "exact person from reference in luxury desert scenario"

- Use `--cref [reference_url]` for character consistency
- Add `--cw 100` for maximum identity preservation

- Consider `--ar 3:4` for premium portrait format
