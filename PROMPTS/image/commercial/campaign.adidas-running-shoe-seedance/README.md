# Adidas Running Shoe Storyboard Campaign

A conceptual premium sportswear campaign built from a reference image of a black-and-white Adidas Cloudfoam running shoe. The workflow creates a ten-panel image storyboard, then converts those beats into a ten-second Seedance 2.0 commercial.

## Assets

- [10-Panel Product Storyboard](storyboard.adidas-running-shoe-10-panel.md)
- [10-Second Seedance Sequence](../../../video/video.sequences/storyboards.products/seq.adidas-running-shoe-10-second-commercial.md)

## Product Lock

- Preserve the reference shoe's black mesh upper, white three-stripe placement, Cloudfoam sole, heel design, proportions, and colorway.
- Keep product geometry and branding stable across all image panels and video shots.
- Use authorized product imagery and brand assets before commercial publication.
