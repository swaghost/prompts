# The Pattern - Patterns That Move

## Image Prompt

```text
Create a sophisticated photorealistic 3:4 vertical fashion campaign poster for BRAINN.AI. CANVAS: 1200 x 1600 px.

Create a visually artistic Rajasthan textile environment. A large richly handwoven rug hangs vertically from an aged sandstone wall. The camera focuses primarily on the intricate geometric rug pattern. The rug features traditional Rajasthan-inspired geometry, diamonds, stepped motifs, lines and subtle imperfections created by hand weaving. Within the visual composition, selected geometric lines subtly evolve into the visual rhythm of Adidas three stripes. The transformation must feel like an artistic pattern relationship, not a literal printed Adidas logo.

In the lower portion of the composition, naturally place an Adidas Suede sneaker in a rich forest-green suede colourway. The sneaker is not the centre of the image. The rug pattern remains the dominant visual element. Include subtle yarn threads and wooden textile tools at the bottom edge. Natural side lighting reveals individual woven fibres and imperfect handmade texture.

Typography: TOP LEFT: STEAL PROMPTS. TOP RIGHT: @BRAINN.AI. Large headline: PATTERNS THAT MOVE. Small: TRADITION -> MOTION.

Contemporary art direction x Rajasthan craftsmanship x Adidas streetwear. No CGI. No synthetic rug. No excessive decoration.
```

## Specifications

- **Format:** 1200 x 1600 px, 3:4 vertical
- **Suede colorway:** Forest green
- **Focus:** Rug geometry as the dominant visual element
