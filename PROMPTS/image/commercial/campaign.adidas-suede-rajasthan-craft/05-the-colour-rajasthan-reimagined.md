# The Colour - Rajasthan, Reimagined

## Image Prompt

```text
Create a premium photorealistic 3:4 vertical fashion editorial poster for BRAINN.AI. CANVAS: 1200 x 1600 px.

Create a sophisticated contemporary textile installation inspired by Rajasthan. Use multiple handwoven rugs and textile panels hanging vertically against a warm sandstone architectural wall. Colour palette: terracotta, deep maroon, dusty pink, mustard ochre, forest green, cream, deep navy.

Place THREE different Adidas Suede sneakers naturally within the installation: 1. cream suede, 2. mustard/ochre suede, 3. deep green suede. Use only Adidas Suede silhouettes. Do not make the shoes identical in colour. The sneakers should feel like part of a contemporary fashion-art installation rather than a retail display. The rugs remain visually important, but the composition is balanced between textiles, architecture and footwear. Show authentic handmade irregularities, visible woven fibres and subtle imperfections.

Typography: TOP LEFT: STEAL PROMPTS. TOP RIGHT: @BRAINN.AI. Large headline: RAJASTHAN, REIMAGINED. Small: COLOUR. CRAFT. CULTURE.

High-end fashion campaign x contemporary Indian art direction.
```

## Specifications

- **Format:** 1200 x 1600 px, 3:4 vertical
- **Suede colorways:** Cream, mustard / ochre, deep green
- **Focus:** Textile installation and color-system storytelling
