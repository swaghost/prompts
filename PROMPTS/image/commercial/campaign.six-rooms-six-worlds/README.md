# Six Rooms, Six Worlds

Six INNOVAA.AI fashion editorials staged as ceilingless interior rooms built outdoors. Each scene combines saturated slide-film color, tactile antiques, botanical shadows, expressive silk wardrobe, real skin texture, and one controlled color-world.

## Shared Rules

- Vertical 4:5 editorial fashion photography
- One 21-year-old adult model alone in frame
- Outdoor room with one tall plaster wall and no ceiling
- Real skin, pores, sweat, flyaways, natural asymmetry, and no retouching
- Saturated slide-film response, fine grain, slight vignette, and mild edge softness
- Higgsfield Soul 2, ChatGPT Images, or Midjourney V7
