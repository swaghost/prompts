# Brand Presentation 05: Mobile App UI Presentation

## Overview

**Purpose**: Premium mobile shopping app interface showcasing product  
**Platform**: Any AI image generator  
**Style**: Modern UI/UX design, luxury e-commerce, Apple-inspired interface

Create sophisticated mobile app UI with product as hero, modern interface elements, and premium user experience.

---

## When to Use

- ✓ App development presentations
- ✓ UX/UI portfolio showcases
- ✓ Client pitch decks
- ✓ Mobile commerce proposals
- ✓ Digital product strategy

## Complete Prompt

```
Design a premium [product category] shopping mobile app UI featuring the exact
[PRODUCT NAME] from the reference images. Display the [product] as the hero product with
multiple product images, color selector, size selection, price section, add-to-cart
button, wishlist icon, product description, customer ratings, and modern
glassmorphism UI elements. Use a clean interface with [color 1], [color 2], and [color 3]
matching the [product] color palette. Minimal Apple-inspired interface, luxury ecommerce
experience, modern typography, soft shadows, realistic smartphone mockup, Figma
presentation style, ultra detailed, 4K.
```

### Example (Lacoste Sneaker):

```
Design a premium sneaker shopping mobile app UI featuring the exact Lacoste
sneaker from the reference images. Display the shoe as the hero product with
multiple product images, color selector, size selection, price section, add-to-cart
button, wishlist icon, product description, customer ratings, and modern
glassmorphism UI elements. Use a clean interface with black, white, and burnt orange
matching the shoe color palette. Minimal Apple-inspired interface, luxury ecommerce
experience, modern typography, soft shadows, realistic smartphone mockup, Figma
presentation style, ultra detailed, 4K.
```

## Key Elements Breakdown

### Essential UI Components

1. **Hero Product Image**: Large, prominent product display
2. **Product Gallery**: Multiple angles/views (swipeable)
3. **Color Selector**: Available color options
4. **Size Selection**: Size dropdown or buttons
5. **Price Display**: Clear, prominent pricing
6. **Add-to-Cart Button**: Primary CTA (call-to-action)
7. **Wishlist Icon**: Heart or bookmark icon
8. **Product Description**: Key features and details
9. **Customer Ratings**: Stars and review count
10. **Modern UI Elements**: Glassmorphism, shadows, gradients

### Visual Design

- **Color Palette**: Matches product colors (2-3 primary)
- **Typography**: Modern, clean, readable
- **Layout**: Minimal, Apple-inspired
- **Spacing**: Professional, comfortable
- **Shadows**: Soft, realistic depth

### Device Presentation

- **Mockup**: Realistic smartphone (iPhone/Android)
- **Screen**: High-quality display rendering
- **Style**: Figma presentation aesthetics
- **Quality**: 4K detailed rendering

## Troubleshooting

### UI Too Cluttered

**Problem**: Too many elements competing for attention  
**Solution**:

- Emphasize "minimal interface" and "Apple-inspired clean design"
- Add "generous white space" and "professional spacing"
- Prioritize: Product image → CTA → Price → Other elements

### Product Not Prominent

**Problem**: Product image too small or not hero  
**Solution**:

- Specify "product as hero element taking up [percentage] of screen"
- Add "large prominent product display dominating interface"
- Reduce other elements: "minimal supporting UI elements"

### Colors Don't Match Product

**Problem**: UI colors clash with or don't complement product  
**Solution**:

- Emphasize "color palette extracted from product colors"
- List specific product colors to use in UI
- Add "cohesive color system matching product exactly"

### Doesn't Look Premium/Luxury

**Problem**: Interface looks generic or low-quality  
**Solution**:

- Add "ultra-premium," "luxury ecommerce," "high-end interface"
- Specify "soft shadows," "glassmorphism," "refined typography"
- Reference: "Apple Store app aesthetic" or "luxury fashion app quality"
