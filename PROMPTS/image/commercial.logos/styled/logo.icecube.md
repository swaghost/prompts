# Logo in Ice Cube - 3D Photorealistic

## Description

Create a stunning 3D photorealistic visualization of any logo encased within a rippling crystal-clear ice cube, illuminated from below with soft LED glow. This prompt produces ultra-detailed commercial-quality renders featuring perfectly realistic ice texture, water droplets, light refractions, and dancing light patterns cast onto surfaces. Ideal for premium product presentations, brand campaigns, and eye-catching social media content.

## Usage

Perfect for creating luxurious, attention-grabbing brand visualizations that convey freshness, premium quality, and modern aesthetic. Works exceptionally well for beverage brands, cooling products, summer campaigns, or any brand seeking a sophisticated frozen aesthetic.

## Prerequisites

## Best Practices

**For Optimal Results:**

1. **Logo Integration**
   - Provide high-resolution logo file or vector
   - Ensure logo has clear visibility within ice
   - Consider logo colors against ice and background
   - Test both light and dark logo versions
   - Maintain brand recognition despite refraction

2. **Ice Realism**
   - Request crystal-clear transparency for premium look
   - Include natural imperfections for authenticity
   - Specify rippling or smooth surface based on aesthetic
   - Add realistic internal structure (bubbles, fractures)
   - Ensure proper scale relationship to logo size

3. **Lighting Strategy**
   - Soft LED glow creates premium, not harsh appearance
   - Underglow emphasizes luminosity and depth
   - Dancing light patterns add dynamic interest
   - Balance brightness to preserve detail
   - Consider colored lighting for brand color integration

4. **Surface & Environment**
   - Matte black background provides luxury aesthetic
   - Water droplets add freshness and cold impression
   - Light patterns on surface create visual interest
   - Keep background simple to focus on logo
   - Ensure surface complements brand identity

5. **Technical Excellence**
   - Request 8K resolution for maximum commercial versatility
   - Specify photorealistic quality explicitly
   - Include "suitable for commercial sale" for quality benchmark
   - Use vertical aspect ratio for social media optimization
   - Ensure proper refraction physics for realism

**Resolution & Format Tips:**

- **1080x1440 (3:4)** - Instagram posts, Facebook, Pinterest
- **1080x1920 (9:16)** - Instagram/TikTok Stories, Reels
- **1080x1080 (1:1)** - Square social media posts
- **3840x2160 (16:9)** - Horizontal for websites, presentations
- **8K minimum** - Ensures print quality at any size

**Brand Integration:**

- Match LED glow color to brand colors
- Consider logo orientation within ice cube
- Test visibility with various ice opacity levels
- Ensure brand guidelines compatibility
- Create series with consistent aesthetic

## Technical Notes

**Rendering Considerations:**

- Request proper caustics calculation for dancing light patterns
- Ensure subsurface scattering for ice translucency
- Specify accurate IOR (Index of Refraction) for ice: ~1.31
- Include global illumination for realistic light bounce
- Request chromatic aberration for realistic refraction edges

**File Delivery:**

- Request transparent PNG for compositing flexibility
- Include layered PSD with separate elements if possible
- Deliver both web-optimized and print-ready versions
- Provide multiple aspect ratios for various platforms
- Include alternate color temperature versions
