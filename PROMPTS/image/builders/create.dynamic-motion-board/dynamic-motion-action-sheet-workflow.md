# Action Sheet Workflow - Dynamic Motion & Stunt Choreography

## Overview

This workflow creates professional action sheets (storyboards) for dynamic motion sequences and stunt choreography, then animates them into realistic video using AI. The technique is ideal for fight choreography, stunts, athletic movements, and complex physical actions that require precise pose-to-pose control.

**Final Output**: A 4-15 second video showing realistic, physics-based action choreography animated from a professional action sheet blueprint.

## Step 1: Create Action Sheet in GPT Image 2

### Purpose

Create a professional **ACTION SHEET** (storyboard) that serves as the exact animation blueprint for your action sequence. This is a motion study reference board showing 5-8 sequential keyframes with timing, movement arrows, and camera reference.

### Platform Settings

- **Tool**: GPT Image 2.0 (Deevid AI)
- **Aspect Ratio**: 16:9
- **Resolution**: 1K or 2K
- **Generation Time**: ~30-60 seconds

### Action Sheet Prompt Template

See [action-sheet-image-prompt.md](action-sheet-image-prompt.md) for the complete detailed prompt template.

### Quick Prompt Structure

```
STYLE: Ultra realistic live-action stunt reference board. Clean white studio background. Professional motion study sheet. Cinematic but physically realistic. High detail anatomy and body mechanics.

LAYOUT:
- 5 to 8 sequential panels
- Numbered keyframes
- Timing breakdown
- Movement direction arrows
- Camera reference diagram
- Sequence flow at bottom
- Clean infographic design
- White and gray minimalist layout
- Blue accent graphics

CHARACTER: [Describe character appearance]

OUTFIT: [Describe outfit]

ACTION: [Describe the action sequence step-by-step]

CAMERA: Locked low front angle. Single continuous shot.

IMPORTANT:
- Every panel must represent a hard keyframe
- Motion must follow realistic physics
- Maintain continuous momentum
- Maintain realistic center of gravity
- Avoid superhero motion
- Avoid floating body movement
- Keep movement readable and physically believable

TEXT ELEMENTS:
- Action title
- Timing for each panel
- Notes section
- Key points section
- Movement direction
- Camera reference
- Sequence flow diagram

ASPECT RATIO: 16:9
```

### Example Action Descriptions

**Aerial Headscissors Takedown**:

```
ACTION: Female attacker performs aerial headscissors takedown on male opponent.
1. Approach and setup - attacker rushes forward, lowers body level
2. Jump and thigh clamp - explosive jump, thighs clamp around opponent's head
3. Headscissor lock mid-air - legs fully lock, core contracts, pull downward
4. Twist and rotate to side - hip twist redirects momentum sideways/downward
5. Drive down head first - opponent's head reaches ground first
6. Follow through and roll - bodies roll through impact momentum
7. Control and stabilize - attacker releases gradually, stabilizes on floor
```

**Parkour Wall Run**:

```
ACTION: Athlete performs vertical wall run and backflip.
1. Sprint approach - building speed, low body position
2. Plant and launch - one foot plants on wall, explosive upward drive
3. Wall run ascent - alternating steps, maintaining vertical momentum
4. Peak height - body extends fully at highest point
5. Rotation initiation - backward arch begins, arms guide rotation
6. Mid-air rotation - tucked position, full backflip
7. Landing preparation - body opens, legs extend for landing
8. Ground contact - absorb impact, stabilize position
```

**Martial Arts Combo**:

```
ACTION: Martial artist executes spinning kick combination.
1. Fighting stance - balanced ready position
2. Lead kick setup - weight shifts, chamber leg
3. First kick extension - roundhouse kick fully extended
4. Retraction and spin - pull kick back, begin body rotation
5. Spin transition - 360° rotation on planted foot
6. Second kick chamber - opposite leg chambers during spin
7. Second kick impact - spinning back kick fully extended
8. Recovery stance - return to fighting stance, maintain balance
```

### Critical Success Factors

**Realistic Physics**:

- Follow natural body mechanics
- Show realistic center of gravity
- Maintain continuous momentum
- Display proper weight transfer

**Clear Keyframes**:

- Each panel is a distinct pose
- Numbered sequentially (01, 02, 03...)
- Timing indicated for each panel
- Movement arrows show direction

**Professional Layout**:

- Clean white studio background
- Infographic-style design
- Blue accent colors for graphics
- Clear text labels and annotations

**Camera Consistency**:

- Single locked camera angle
- Consistent framing across panels
- No perspective changes
- Professional stunt reference style

### What You Get

- **Professional action sheet image** in 16:9 format
- **5-8 sequential panels** showing keyframe poses
- **Timing breakdown** for each panel
- **Movement arrows** indicating direction
- **Clean infographic design** ready for animation reference
- **Blueprint for Step 2** video generation

## Step 2: Generate Video in Seedance 2.0

### Purpose

Animate your action sheet into a realistic video sequence. Seedance 2.0 interprets your action sheet as an exact animation blueprint, creating physically realistic interpolation between the keyframe poses.

### Platform Settings

- **Tool**: Seedance 2.0 (Deevid AI)
- **Input**: Action sheet image from Step 1 (+ optional character reference sheets)
- **Aspect Ratio**: 16:9
- **Resolution**: 1080p
- **Duration**: 4-15 seconds (specify in prompt)
- **Generation Time**: ~5-10 minutes

### Video Generation Prompt Template

See [action-sheet-video-prompt.md](action-sheet-video-prompt.md) for the complete detailed prompt template.

### Core Video Prompt Structure

```

The uploaded Action Sheet is the exact animation blueprint.
[Optional: The uploaded Character Sheet is the exact appearance reference.]

Every panel is a HARD KEYFRAME.

Follow panel order exactly.

Interpolate movement ONLY between provided poses.

Movement direction is LEFT TO RIGHT.

Do not mirror choreography. Maintain screen-space consistency.

Single continuous shot. Locked camera. No cuts. No zoom. No reframing. No automatic tracking.

Maintain:
- Realistic inertia
- Realistic gravity
- Grounded momentum
- Continuous force transfer
- Realistic body weight
- Low center of gravity

Avoid:
- Floating motion
- Anime movement
- Superhero motion
- Exaggerated posing
- Unrealistic flexibility

TIMING BREAKDOWN:
0.0s–1.0s: Preparation pose
1.0s–3.5s: Main motion sequence
3.5s–5.0s: Final pose hold

FINAL POSE: Maintain slight residual movement:
- Breathing
- Cloth movement
- Body stabilization

FINAL INSTRUCTION: The result must look like the uploaded action sheet brought to life exactly as designed.
```

## Workflow Tips & Best Practices

### Action Sheet Design

**Panel Count**:

- **5-6 panels**: Simple movements (single kick, jump, roll)
- **7-8 panels**: Complex sequences (aerial takedowns, combo moves)
- **More panels**: Break into multiple action sheets

**Keyframe Selection**:

- Choose critical poses (start, peak, impact, finish)
- Show weight transfer points
- Include rotation apex points
- Capture momentum changes

**Clear Communication**:

- Number panels clearly (01, 02, 03...)
- Add timing for each panel
- Include movement direction arrows
- Note important details

### Video Generation

**Timing Guidelines**:

- **4-6 seconds**: Simple movements
- **7-10 seconds**: Medium complexity
- **11-15 seconds**: Complex sequences
- **Longer**: Break into multiple segments

**Character References**:

- Upload separate character sheets for consistency
- Include front, side, back views if available
- Show costume/outfit details clearly
- Maintain consistent character appearance

**Multiple Attempts**:

- Generate 2-3 versions
- Compare pose accuracy
- Select best physics
- May need to adjust prompt

### Common Adjustments

**Too Fast Movement**:

- Increase total duration
- Add more timing to middle sections
- Emphasize "controlled" movement

**Floating or Unrealistic**:

- Strengthen physics constraints
- Add "grounded momentum" emphasis
- Specify "realistic body weight"

**Wrong Direction**:

- Clarify "LEFT TO RIGHT" or specific direction
- Add "do not mirror choreography"
- Emphasize screen-space consistency

**Camera Movement**:

- Strengthen "locked camera" instruction
- Add "no automatic tracking"
- Specify "identical framing throughout"

## Troubleshooting Guide

### Action Sheet Issues

**Problem: Panels Look Too Similar**

**Cause**: Not enough distinction between keyframes

**Solutions**:

- Be more specific about pose differences
- Emphasize timing changes
- Describe exact limb positions
- Use more dramatic keyframe poses

**Problem: Movement Arrows Unclear**

**Cause**: Generic layout description

**Solutions**:

- Specify arrow style and color
- Request "clear blue directional arrows"
- Emphasize "movement flow indicators"
- Ask for numbered sequence flow

**Problem: Too Cluttered or Messy**

**Cause**: Too many elements requested

**Solutions**:

- Simplify to essential panels
- Reduce text elements
- Emphasize "clean minimalist layout"
- Focus on white space and clarity

### Video Generation Issues

**Problem: AI Doesn't Follow Action Sheet**

**Cause**: Prompt doesn't emphasize blueprint fidelity

**Solutions**:

- Start with "STRICT POSE REPLICATION MODE"
- Add "Every panel is a HARD KEYFRAME"
- Emphasize "DO NOT reinterpret choreography"
- Strengthen "exact animation blueprint" language

**Problem: Movement Looks Floating or Unrealistic**

**Cause**: Physics constraints not strong enough

**Solutions**:

- Add comprehensive "Avoid floating motion" section
- Strengthen gravity and momentum requirements
- Emphasize "grounded" and "realistic body weight"
- Add "trained professional stunt performer" comparison

**Problem: Camera Moves or Reframes**

**Cause**: Automatic tracking taking over

**Solutions**:

- Emphasize "LOCKED camera"
- Add "No automatic tracking" explicitly
- Strengthen "single continuous shot" language
- Add "identical framing throughout"

**Problem: Wrong Direction or Mirrored**

**Cause**: AI interpreting composition differently

**Solutions**:

- Specify exact direction: "LEFT TO RIGHT"
- Add "Do not mirror choreography"
- Emphasize "screen-space consistency"
- Specify rotation direction if relevant

**Problem: Timing Off or Too Fast/Slow**

**Cause**: Timing breakdown not specific enough

**Solutions**:

- Provide exact timing for each panel
- Break down into smaller time segments
- Specify total duration clearly
- Add pacing descriptors (explosive, controlled, smooth)

**Problem: Characters Look Different**

**Cause**: No character reference provided

**Solutions**:

- Upload character reference sheets
- Describe character appearance in detail
- Include face, hair, outfit, proportions
- Generate character sheet first if needed

**Problem: Too Cinematic or Stylized**

**Cause**: AI adding creative interpretation

**Solutions**:

- Emphasize "professional stunt reference style"
- Add "clean white studio background"
- Specify "flat neutral lighting"
- Avoid cinematic language in prompt
