## Image Prompt

**CRITICAL:**
Use the uploaded image as a reference. Keep the model and her clothing consistent. Change only the emotion.

**Subject:**
The exact same model from the reference image maintaining identical appearance: same face, same hair style and color, same clothing, same body proportions, same pose, same everything EXCEPT facial expression.

**Facial Expression - Anger:**
Eyebrows drawn downward and inward forming a deep vertical crease between them (glabellar lines). Eyes fixed with an intense, unwavering stare showing controlled intensity. Lips pressed firmly together showing restraint. Jaw set with determination. Subtle tension visible in the cheeks and lower face. Overall expression conveying controlled anger and stern disapproval. Not screaming or exaggerated - a cold, controlled, intimidating anger.

**Setting/Environment:**
Match the exact background and environment from the reference image. Maintain all environmental elements, lighting conditions, and atmospheric qualities exactly as they appear in the reference.

**Lighting:**
Maintain the exact same lighting setup as the reference image. Same light direction, intensity, color temperature, and quality. Lighting naturally enhancing the intensity of the expression through shadow definition.

**Composition:**
Identical composition to reference image. Same framing, same camera angle, same subject positioning, same background arrangement. Only facial expression changes.

**Style & Aesthetic:**
Match the exact photographic style of the reference image. Maintain same color grading, same contrast levels, same overall aesthetic approach. Professional portrait quality with authentic emotion capture.

**Technical Specifications:**
Match technical quality of reference image. Maintain same resolution, sharpness, color accuracy, and professional finishing. Sharp focus on face, especially eyes and brow tension. Natural skin texture preservation including tension lines.

**Color Palette:**
Maintain exact color palette from reference image. Same clothing colors, same background colors, same skin tones, same overall color harmony. Possible subtle intensity in overall mood but maintaining natural color accuracy.

**Mood & Atmosphere:**
Controlled anger, stern disapproval, intimidating intensity, cold rage, determined confrontation, serious displeasure, restrained fury, commanding presence.
