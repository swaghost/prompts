## Concept

This is the foundational empty plate used as the **first frame** for all Eclipse Silhouette Series shots. Everything downstream depends on this file. Generate it first, keep it, and feed it in as a reference image when you generate each subject plate—that is what keeps the ring diameter, ridge curve, and corona brightness identical across the series.

**Critical:** If the ring shifts even slightly between plates, the cuts stop matching and the set falls apart.

## Pro Tips

### Consistency is Critical

- This plate must remain **identical** across your series
- Even slight variations in ring size or ridge curve break the illusion
- Always use this exact file as reference when generating subject plates

### Avoid These Mistakes

- ❌ Don't add any elements to the crest (no rocks, vegetation, structures)
- ❌ Don't change eclipse size between generations
- ❌ Don't alter the ridge curve
- ❌ Don't shift the color temperature

### Quality Checks

- ✓ Eclipse ring is perfectly circular
- ✓ Corona has consistent amber-white color
- ✓ Ridge is smooth continuous curve
- ✓ Crest is completely bare and empty
- ✓ Film grain and halation present
- ✓ Anamorphic characteristics visible

## Troubleshooting

**Issue:** Corona goes wispy and white, not a tight ring  
**Solution:** Drop "total solar eclipse" back to "eclipse ring" — the astro-photo phrasing can pull it toward documentary style

**Issue:** Ridge has unwanted elements (rocks, plants, structures)  
**Solution:** Emphasize "The crest is completely empty — no figures, no vegetation, no structures, no landmarks"

**Issue:** Eclipse looks too perfect/CGI  
**Solution:** Emphasize "Photographic, not rendered" and ensure film emulation details are included

**Issue:** Colors too saturated  
**Solution:** Emphasize "cold desaturated grey" and "neutral grey-violet sky"
