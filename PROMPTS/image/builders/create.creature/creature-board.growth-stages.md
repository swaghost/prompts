# 05 — Creature Board (Growth Stages & Design Evolution)

**Purpose:** Generate a multi-panel reference showing the same creature design across different life stages or scales  
**Use Case:** Fantasy/sci-fi creatures that grow, evolve or transform during a narrative, ensuring design consistency  
**Platform:** GPT Image 2, Picsart Flow

## What This Builder Does

Creates a composite image showing the same creature at different stages of development — from juvenile to adult, or small to massive scale. All panels share identical design language (anatomy, texture, color, markings) with proportional changes appropriate to each stage.

This ensures a baby dragon and adult dragon read as the same species, or a creature that starts small and grows to kaiju scale maintains recognizable features throughout.

## Template Prompt

```
[PASTE YOUR STYLE BIBLE HERE]

Creature design reference sheet, multi-panel composite showing the SAME creature species at different growth stages or scales, evenly spaced with thin white gutters between panels.

CREATURE SPECIES: [Name or type], [overall design concept — dragon, alien, beast, etc.]

DESIGN LANGUAGE (consistent across all stages): [Anatomy — body plan, limb count, head shape, tail, wings if applicable; Texture — skin/scales/fur/feathers, surface quality; Color palette — 3-4 primary colors; Markings — stripes, spots, patterns, distinguishing features; Eyes — color, shape, placement; Special features — horns, claws, teeth, bioluminescence, etc.]

LIGHTING & SETUP: Clean neutral studio lighting with soft key and gentle fill, flat off-white seamless background fading to light grey gradient, consistent lighting direction across all panels, gentle ambient occlusion shadows under creatures.

STAGES (all panels show the same species design with proportional growth changes):

Stage 1 — HATCHLING / JUVENILE: [Size comparison, e.g., "house cat sized"], newly emerged or very young, large head relative to body, oversized eyes, stubby limbs, soft features, underdeveloped secondary features (small horns, tiny wings), vulnerable posture.

Stage 2 — ADOLESCENT: [Size comparison, e.g., "large dog sized"], proportions balancing out, limbs lengthening, features sharpening, secondary features (horns, wings, spines) developing but not fully grown, more confident posture.

Stage 3 — ADULT: [Size comparison, e.g., "horse sized"], fully mature proportions, powerful build, all features fully developed, strong musculature visible under skin/scales, dominant posture, peak physical form.

Stage 4 — ELDER / ALPHA: [Size comparison, e.g., "small building sized"], massive scale, thicker proportions, additional growth features (larger horns, extra spines, battle scars, etc.), weathered texture, ancient and imposing posture.

Stage 5 — COLOSSAL [optional]: [Size comparison, e.g., "skyscraper sized"], kaiju-scale, same design language but monumental, environment dwarfed in background for scale reference, epic cinematic framing.

CRITICAL: Identical species design — same anatomy, same color palette, same markings pattern, same eye color and shape across all stages. Only size, proportions and feature development change. Photorealistic creature rendering, detailed texture (visible scales/fur/skin detail), natural musculature and anatomy, no inconsistent markings or color shift between stages.
```

## Builder Variables

**Creature Design Variables (Customize These):**

- **Base anatomy:** Quadruped, biped, serpentine, insectoid, aquatic, avian, hybrid
- **Limb count & type:** Four legs, two legs + two arms, wings (bat/bird/insect), tentacles, fins
- **Head shape:** Reptilian, feline, canine, alien, bird-like, elongated, broad
- **Body build:** Sleek, muscular, armored, soft, skeletal, bulky, serpentine
- **Skin/surface:** Scales (plate/diamond/snake), fur (short/long/coarse), feathers, chitin, smooth skin, rocky/crystalline
- **Color palette:** 3-5 colors max (primary body, secondary accent, eye color, special features)
- **Pattern/markings:** Stripes, spots, tiger-like, symmetrical, random, gradient, glowing veins
- **Eyes:** Color, shape (round/slit/alien), placement (forward/side), glow/normal
- **Special features:** Horns, antlers, spines, frills, bioluminescence, extra eyes, tail weapon, wings

**Growth Stage Variables:**

- **Stage 1 size comparison:** Mouse, cat, small dog, etc.
- **Stage 2 size comparison:** Large dog, deer, pony, etc.
- **Stage 3 size comparison:** Horse, bear, elephant, car, etc.
- **Stage 4 size comparison:** Truck, small building, bus, etc.
- **Stage 5 size comparison (optional):** Multi-story building, skyscraper, mountain, etc.

**Proportional Changes by Stage:**

- **Juvenile:** Large head, big eyes, short limbs, soft/rounded features
- **Adolescent:** Limbs elongating, features sharpening, awkward gangly build
- **Adult:** Fully proportioned, peak muscle definition, all features mature
- **Elder:** Thicker/broader, additional growth (horns, spines), battle scars, weathering
- **Colossal:** Same proportions as adult/elder but monumental scale

## Usage Tips

- **Lock the pattern** — "Glowing cracks along spine ridge" must stay in same location across all stages, just larger
- **Size comparisons are critical** — "Horse sized" gives model scale context; without it, stages blur together
- **Eyes stay same color** — Eye color changing reads as different species; keep it locked
- **Anatomy count** — Four legs in Stage 1 = four legs in Stage 5; limb count doesn't change with growth
- **"Same design language" repetition** — Say it in the critical block, model respects repetition as constraint
- **Battle scars only on elder** — Adds age without breaking design; scars shouldn't appear then vanish across stages

## When to Use This Builder

✅ **Use Creature Board when:**

- Creature grows or evolves during story (egg → adult, small → giant)
- Fantasy/sci-fi narrative requires consistent creature design
- You need scale reference for VFX or creature shots (small, medium, kaiju)
- Multiple creatures of same species appear at different ages
- Designing original creature for multiple shots/scenes

❌ **Don't use Creature Board when:**

- Creature only appears at one size/age (just generate single reference)
- Each stage is a completely different species (make separate boards)
- Creature transforms into something unrecognizable (metamorphosis ≠ growth)
- Real-world animal (use photo reference instead)
