# Change Outfit

## Purpose

Try different clothing options on subjects in photos, enabling virtual wardrobe changes while keeping everything else unchanged including pose, person, background, and lighting.

## Description of Target Content or Subject

Portrait or full-body photos where outfit changes are desired including fashion visualization, styling exploration, e-commerce clothing try-on, or professional attire visualization.

## Discovery - Description of Resulting Output

A photorealistic image with the subject wearing new clothing while preserving their exact pose, body position, facial expression, and all other image elements, with realistic clothing drape and fit matching body geometry, appropriate fabric textures and materials, consistent lighting and shadows on the new garment, and seamless integration appearing naturally photographed.

## Usage

Perfect for fashion visualization, virtual styling, e-commerce try-on experiences, and wardrobe planning. Ideal for fashion retailers, stylists, personal shoppers, and consumers. This prompt excels at realistic virtual outfit changes while maintaining photographic authenticity.

## Prerequisites

**MANDATORY:**

- Source image with subject
- Description of desired new outfit

## Prompt

Change the outfit in this image to: [DESCRIBE NEW OUTFIT/CLOTHING]. Keep everything else exactly the same including the person, pose, background, lighting, and all other elements. Ensure the new clothing fits naturally with realistic drape and body geometry. Apply appropriate fabric textures and materials. Maintain consistent lighting and shadows on the garment. The result should look naturally photographed with the person wearing this outfit.
