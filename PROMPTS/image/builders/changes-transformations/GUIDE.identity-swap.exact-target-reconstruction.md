# Exact Target Reconstruction with Identity Swap

**Source date:** 18 August 2026  
**Source:** [Google Docs](https://docs.google.com/document/d/1JjswLhaQuhY9ME_ZBgejAAbaML3wnoJfJqgF-lAmXTA/mobilebasic?urp=gmail_link)

## Purpose

Replace the person in a target image with a supplied reference character while preserving the target's pose, wardrobe, camera, lighting, background, composition, and photographic treatment.

## Prerequisites

- **Target image:** Controls the complete scene, pose, wardrobe, camera, lighting, and environment.
- **Reference character image:** Controls only the replacement person's identity, anatomy, and distinctive physical traits.

## Usage

Supply both images with clear labels, then use the variant that most closely describes the target pose. These prompts are specialized for the source's full-body floating studio portrait with a cream ribbed sweater, charcoal wide-leg trousers, overhead spotlight, and black void background.

– exact full-body floating pose

– exact backward body lean

– exact head tilt

– exact arm positions

– same camera distance

– same subject scale

– same crop

subtle volumetric haze.
