# Vertical 9:16 Character Sheet - 8 Panel Reference

## Description

Using an attached image as the strict reference, create a clean vertical 9:16 character sheet on a white studio background. No text, no captions, no watermark, no interface elements. Keep the exact same person in all panels: same face, hair, skin tone, body proportions, outfit, accessories, shoes, and overall appearance. Do not change age, ethnicity, hairstyle, clothing, or identity.

## Usage

Perfect for character design reference, animation turnarounds, fashion design documentation, modeling portfolios, game character sheets, and visual development. Ideal for 3D modeling reference, costume design, character consistency guides, and professional model cards in vertical social media format (9:16).

## Prerequisites

- Reference image of character/person to replicate
- Clear view of outfit, hair, and features
- Character details to maintain consistency
- Desired background color (white studio default)
- Photography style preferences

**Panel 3: Full-Body Back View**

- Rear view, back of head visible

**Panel 4: Full-Body 3/4 View**

- Three-quarter angle (45-degree turn)
- Shows front-side of body

**MIDDLE ROW (Close-Up Portraits):**

**BOTTOM ROW (Detail Close-Ups):**

**Panel 8: 3/4 Close-Up Portrait**

## Character Consistency Guidelines

**Facial Features:**

- Exact same face structure
- Identical eye shape, color, and placement
- Same nose, mouth, ears
- Matching skin texture and complexion
- Consistent facial proportions
- Neutral, relaxed expression throughout

**Hair:**

- Identical hairstyle in all panels
- Same hair color and highlights
- Consistent hair length and volume
- Matching texture (straight, wavy, curly)
- Same styling and finish
- Hair falls naturally based on angle

**Body & Proportions:**

- Same height and build
- Consistent body type
- Matching proportions (shoulders, waist, hips, legs)
- Identical posture and stance
- Same overall silhouette

**Clothing & Outfit:**

- Exact same garments in all panels
- Consistent fit and draping
- Same colors and patterns
- Matching accessories (jewelry, belts, bags)
- Identical shoes throughout
- Same level of formality/style

**Skin & Coloring:**

- Consistent skin tone
- Same undertones (warm, cool, neutral)
- Matching complexion
- Consistent makeup (if any)
- Same level of skin detail/texture

## Photography Execution

**Camera Settings:**

- Standard lens (50mm equivalent) for natural proportions
- Consistent camera height for each view type
- Even lighting across all panels
- Sharp focus throughout
- Minimal depth of field variation

**Full-Body Shots (Panels 1-4):**

- Camera positioned to show head to toe
- Subject centered in frame
- Approximately 8-10 feet distance
- Entire body and outfit clearly visible
- Slight headroom above subject

**Close-Up Portraits (Panels 5-6, 8):**

- Head and shoulders framing
- Face clearly visible and detailed
- Upper body included
- Closer camera distance (3-4 feet)
- Facial features sharp and clear

**Detail Close-Up (Panel 7):**

- Focus on hair and upper back
- Close enough to see hair texture
- Back of outfit visible
- Similar framing to portrait close-ups

**Poses:**

- Natural, relaxed stance
- Arms at sides or gently positioned
- Neutral expression (can be slight smile)
- Weight evenly distributed
- Professional model posing
- Consistent across angles (not dramatically different per panel)
