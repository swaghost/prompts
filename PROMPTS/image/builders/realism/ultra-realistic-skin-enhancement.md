## Pro Tips

### Maximum Realism

- **Start with Best Source**: Higher quality source images produce better results. If possible, use original uncompressed files rather than social media downloads.
- **Preserve Identity First**: Always prioritize maintaining the subject's exact identity, facial structure, and features over enhancement. Natural imperfections are better than altered features.
- **Natural Skin Philosophy**: Real skin has pores, texture, blemishes, and variation. Perfect smooth skin looks fake. Embrace authentic skin characteristics.
- **Age-Appropriate Enhancement**: Younger subjects have fewer wrinkles and smoother skin. Older subjects should retain appropriate age indicators (smile lines, crow's feet, natural texture).

### Professional Quality

- **Medium Format Aesthetic**: Hasselblad and Phase One cameras produce specific look - shallow DOF, creamy bokeh, exceptional detail, natural color science. Request these characteristics explicitly.
- **Lighting Matters**: Professional studio lighting has soft quality with gradual falloff, subtle rim lighting for separation, and balanced exposure. Specify "professional soft studio lighting" not just "good lighting."
- **16-bit Color Depth**: Standard 8-bit has visible banding in gradients. 16-bit provides smooth transitions critical for professional skin tone rendering.
- **Focus Stacking**: Mention "focus stacked" for portraits to ensure both eyes and entire face are sharp, mimicking professional portrait technique.

### Technical Execution

- **Intelligent Upscaling**: Modern AI upscalers use "intelligent texture reconstruction" - they analyze context and add appropriate detail rather than just sharpening. This creates realistic pores and texture.
- **Avoid Over-Sharpening**: Request "increase sharpness while maintaining natural realism" not "maximum sharpness." Over-sharpening creates halos and unnatural edges.
- **Subsurface Scattering**: This is how light penetrates skin layers, creating natural glow and depth. Request it explicitly for realistic skin rendering.
- **PBR and Path-Tracing**: These are 3D rendering terms but communicate you want physically accurate light behavior - realistic shadows, reflections, light bounce.

### Platform-Specific Tips

- **For Magnific AI**: Use "Cinematic" or "Film" style preset. Set creativity lower (0.3-0.5) to preserve identity. Use "Face Engine" option for facial detail.
- **For Topaz Gigapixel AI**: Use "High Fidelity" model for portraits. Adjust "Suppress Noise" and "Remove Blur" sliders carefully - too much creates plastic skin.
- **For Stable Diffusion**: Use ControlNet with Canny or Depth map to preserve structure. Use face restoration models like CodeFormer or GFPGAN after upscaling.
- **For Midjourney**: Use "--cref" (character reference) with source image URL. Add "--cw 100" for maximum character consistency. Use "--style raw" for photorealism.

### Customization Options

- **Ethnicity Preservation**: Always specify "preserve exact ethnicity" if working with diverse subjects. AI may try to westernize features.
- **Age Enhancement**: Can request "maintain exact age" or "age regression to 10 years younger while preserving identity" for specific use cases.
- **Skin Tone Accuracy**: Request "maintain exact skin tone and melanin levels" to prevent lightening or darkening that sometimes occurs in AI processing.
- **Expression Lock**: If source has specific expression (smile, serious, etc.), explicitly state "preserve exact expression and emotion" to prevent AI changing it.

### Common Issues & Solutions

**Problem: Plastic/Waxy Skin**

- **Cause**: Over-smoothing or beauty filter artifacts
- **Solution**: Emphasize "visible pores, natural texture, realistic blemishes" more strongly. Use negative prompt "plastic skin, beauty filter, wax face"

**Problem: Changed Identity**

- **Cause**: AI trying to "improve" features based on training data
- **Solution**: Start prompt with "preserving identity, facial proportions, and features EXACTLY" and use lower creativity/strength settings

**Problem: Over-Sharpened with Halos**

- **Cause**: Aggressive sharpening creating light halos around edges
- **Solution**: Request "natural sharpness increase" not "maximum sharpness" and include "no oversharpening halos" in negative prompt

**Problem: Uncanny Valley Effect**

- **Cause**: Too-perfect features or unrealistic symmetry
- **Solution**: Request "natural facial asymmetry, authentic imperfections, realistic human variation" and use "uncanny valley" in negative prompt

**Problem: Lost Ethnic Features**

- **Cause**: AI defaulting to most common training data features
- **Solution**: Explicitly state subject's ethnicity and request preservation. Use reference images from same ethnic background if possible.

**Problem: Fake-Looking Eyes**

- **Cause**: AI-generated eye detail that doesn't match real iris patterns
- **Solution**: Request "preserve original eye color and iris pattern exactly" and emphasize "natural iris fibers matching subject's actual eyes"

### Advanced Techniques

- **Multi-Pass Enhancement**: First upscale, then enhance skin detail, then refine eyes/hair specifically for best results
- **Selective Enhancement**: Use layers/masks to enhance face more than background, maintaining realistic depth of field
- **Lighting Correction**: Fix lighting issues (shadows, color casts) before AI enhancement for better base quality
- **Noise Reduction First**: Remove noise/grain from source before upscaling - AI upscalers can amplify noise into texture artifacts
