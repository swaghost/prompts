# Professional AI Character Model Sheets and Turnarounds

## Purpose

Create a production-ready character model sheet, model turnaround, or lookbook from one uploaded reference photo. The sheet preserves the subject's identity while documenting full-body views, expressions, action poses, materials, colours, and biographical details for image, video, animation, fashion, and character-production workflows.

## Visual Anatomy of the Model Sheet

Use a modular grid with these sections:

```text
+--------------------------------------------------------+
| CHARACTER NAME & BIO   | 3-WAY FULL-BODY TURNAROUND   |
| Personality, age,      | Front | Side | Back          |
| height, build          |                              |
+--------------------------------------------------------+
| EXPRESSION STRIP       | DYNAMIC ACTION POSES       |
| Neutral, happy,        | Walking, sitting, action   |
| serious, focused      |                              |
+------------------------+-----------------------------+
| COLOR & FABRIC SWATCHES| CLOSE-UP REFERENCE PORTRAIT|
| Materials and colours  | Clean studio lighting      |
+------------------------+-----------------------------+
```

### Required Content

- **Turnaround:** Symmetrical A-pose or natural standing pose in front, 90-degree side profile, and back views.
- **Expression strip:** Four or five close-up headshots showing neutral, happy or smiling, thoughtful, focused or determined, and surprised emotions.
- **Dynamic poses:** Three or four lifestyle or action poses such as sitting on a stool, walking, holding props, or running.
- **Production callouts:** Circular fabric or material close-ups, colour palette chips, and biographical notes.
- **Identity:** The same recognizable person, face, hair, proportions, outfit, and accessories in every panel.

## Step 01: Upload the Reference Photo

1. Start a new ChatGPT conversation using an image-capable model.
2. Upload one clear, front-facing reference photo of the subject.
3. Paste the Master Consistency Anchor below.
4. Paste one of the style prompts from Step 02.
5. Generate one complete composite sheet.

### Master Consistency Anchor

```text
Maintain the exact facial identity, bone structure, eye shape, skin tone, and hair texture of the person in the uploaded reference photo across every panel of the character sheet. Do not alter their face. Preserve the same age, ethnicity, body proportions, hair, outfit, accessories, and shoes unless the selected style prompt explicitly specifies a new wardrobe. Render a comprehensive high-resolution character design sheet using the requested layout, with every panel clearly showing the same person.
```

## Step 03: Midjourney and Flux.1 Workflow

For Midjourney v6 or Flux.1, use the uploaded image as the identity reference and append the selected style direction:

```text
[IMAGE_URL] A comprehensive character sheet, model turnaround sheet, front view, side view, back view, multiple facial expressions, dynamic action poses, material swatches, clean grey studio background, 8K resolution, photorealistic, sharp focus --ar 4:5 --style raw --cref [IMAGE_URL] --cw 20 --iw 2.0
```

### Parameter Notes

- `--cref [IMAGE_URL]`: Character-reference image used to map the face across views.
- `--cw 20`: Preserves facial identity while allowing the wardrobe to follow the selected prompt.
- `--ar 4:5`: Vertical ratio suited to turnaround, expression, pose, and swatch sections.
- `--iw 2.0`: Gives the uploaded image strong influence where supported.

If the platform struggles with a dense composite, generate the turnaround, expressions, poses, and material callouts separately, then assemble them in a design tool using the same reference image and identity anchor.

## Step 04: Add Graphic Design and Text Overlays

Use Canva, Photoshop, or Figma when the generated sheet needs accurate labels or production metadata.

### Character Header

- **Main name:** Large condensed bold sans-serif such as Bebas Neue, Anton, Oswald, or Impact in solid black `#111111`.
- **Sub-header:** Spaced all-caps text such as `CHARACTER SHEET` with generous tracking.

### Metadata Block

Use clean tabular alignment for:

- `AGE:`
- `HEIGHT:`
- `BUILD:`
- `OCCUPATION:`
- `PERSONALITY:`
- `WARDROBE:`

### Turnaround Labels

Place small, tracked labels above or below each figure:

- `FRONT VIEW`
- `SIDE VIEW`
- `BACK VIEW`

### Colour Palette Chips

Draw small rounded squares or circles at the bottom of the sheet. Sample five or six dominant hex colours directly from the outfit with the eyedropper tool. Keep swatches aligned, evenly spaced, and subordinate to the character views.

### Text Fidelity Rule

Add labels in post-production when exact spelling matters. Do not allow the image model to invent extra names, metadata, labels, logos, or technical information.

## Production Checklist

- [ ] One clear reference photo is uploaded.
- [ ] The Master Consistency Anchor is included.
- [ ] The selected style prompt is appended without losing the identity rules.
- [ ] Front, side, and back views are present.
- [ ] Four or five expression headshots are present.
- [ ] Three or four dynamic poses are present.
- [ ] Material callouts and colour swatches are present where requested.
- [ ] The same face, hair, body proportions, age, and identity appear in every panel.
- [ ] Wardrobe and accessories remain consistent within the selected style.
- [ ] Full-body figures show the complete body and feet.
- [ ] The sheet has a clean, readable grid with no overlapping panels.
- [ ] Added labels are spelled correctly and limited to intentional metadata.
- [ ] The final sheet is high resolution and suitable for production reference.
