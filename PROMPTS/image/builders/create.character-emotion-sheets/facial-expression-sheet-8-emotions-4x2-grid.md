# Facial Expression Sheet - 8 Emotions 4x2 Grid

## Description

Use an uploaded image as the identity reference only. Reconstruct the person into a standardized head-and-shoulders studio portrait regardless of the input framing. Create one professional facial expression sheet with exactly eight portraits arranged in a clean 4×2 grid on a pure white seamless background. Keep the same person perfectly consistent in every portrait, preserving identical facial identity, hairstyle, bangs, hair length, skin tone, facial proportions, neck, and clothing visible at the neckline.

## Usage

Perfect for character design, animation reference, emotion studies, acting portfolios, game character development, emoji creation, and visual communication guides. Ideal for demonstrating emotional range, creating character emotion charts, and providing reference for animators and illustrators.

## Prerequisites

- Reference photo of person (any framing)
- Clear view of face and features
- Desired emotion set (8 expressions provided)
- Studio portrait setup requirements
- White background preference

## Image Prompt

**[ATTACH IDENTITY REFERENCE IMAGE]**

Use the uploaded image as the identity reference only.

**Portrait Reconstruction:**

Reconstruct the person into a standardized head-and-shoulders studio portrait regardless of the input framing.

**Framing Specifications:**

- Crop from just below the collarbones to slightly above the head
- Head fills about 70–75% of the frame
- Head-and-shoulders crop only
- **Never generate:** full-body, half-body, waist-up, upper-body, or bust shot
- Tight, professional portrait framing

**Identity Consistency (Must Match Across All 8 Portraits):**

- **Facial Identity:** Exact same person in every portrait
- **Hairstyle:** Identical hair styling, no changes
- **Bangs:** Same bang length and positioning
- **Hair Length:** Consistent hair length throughout
- **Skin Tone:** Exact skin color and complexion
- **Facial Proportions:** Same bone structure and features
- **Neck:** Consistent neck appearance
- **Clothing:** Same outfit visible at neckline/collarbone area
- **Framing:** Identical crop and camera distance
- **Camera Angle:** Straight-on front view (0°) for all
- **Lighting:** Same soft, diffused studio lighting
- **Color Grading:** Consistent color treatment

**What May Change:**

- **Only the facial expression** - nothing else

**8 Facial Expressions - 4×2 Grid Layout:**

Create exactly eight portraits with these expressions in order:

**Top Row (Left to Right):**

1. **Neutral**
   - Relaxed, natural resting face
   - Mouth closed, calm expression
   - Eyes open naturally
   - No emotion displayed

2. **Soft Smile**
   - Gentle, subtle smile
   - Lips closed or slightly parted
   - Warm, friendly expression
   - Eyes soft and pleasant

3. **Big Smile (Teeth Visible)**
   - Wide, genuine smile
   - Teeth clearly visible
   - Happy, joyful expression
   - Eyes engaged in smile

4. **Laughing**
   - Active laughter expression
   - Mouth open, genuine laugh
   - Eyes crinkled with joy
   - Animated, energetic happiness

**Bottom Row (Left to Right):**

5. **Surprised**
   - Wide eyes, raised eyebrows
   - Mouth open in surprise
   - Shocked or amazed expression
   - Sudden realization look

6. **Angry**
   - Furrowed brow, intense gaze
   - Tense facial muscles
   - Stern or upset expression
   - Visible displeasure or frustration

7. **Sad**
   - Downturned mouth
   - Sad or disappointed eyes
   - Melancholic expression
   - Possibly slight frown

8. **Winking**
   - One eye closed in wink
   - Other eye open normally
   - Playful or flirtatious
   - Slight smile optional

## Expression Guidelines

**Neutral:**

- Baseline expression
- Natural resting face
- No emotion
- Relaxed facial muscles

**Soft Smile:**

- Subtle, gentle warmth
- Approachable and friendly
- Not exaggerated
- Natural pleasantness

**Big Smile (Teeth Visible):**

- Genuine happiness
- Full engagement
- Teeth clearly shown
- Eyes participate in smile (Duchenne smile)

**Laughing:**

- Active, dynamic expression
- Genuine laughter moment
- Open mouth
- Joy radiating from face

**Surprised:**

- Sudden reaction
- Wide eyes essential
- Raised eyebrows
- Open mouth showing shock

**Angry:**

- Clear displeasure
- Furrowed brow critical
- Tense face
- Intense eye contact

**Sad:**

- Visible melancholy
- Downturned features
- Eyes show sadness
- Quiet sorrow

**Winking:**

- One eye closed
- Playful or knowing
- Slight smile enhances effect
- Other eye fully open

## Technical Execution

**Photography Simulation:**

- 85mm portrait lens focal length
- f/2.8-f/4 aperture range
- Soft beauty lighting setup

- No harsh shadows or hot spots
