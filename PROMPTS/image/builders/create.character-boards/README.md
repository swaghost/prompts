## Workflow

1. Upload one clear full-body or three-quarter character reference image.
2. Paste one master prompt without deleting its structure.
3. Generate the board using the attached image as the source of truth for identity and design.
4. Confirm the result is natively composed in exact 4:5 portrait format, ideally 1080 x 1350 px or higher.
5. Regenerate instead of cropping if the result is 9:16, square, or extra tall.

## Shared Rules

- Preserve the same face, age, body proportions, costume language, signature traits, and visual identity across panels unless the prompt explicitly requires progression.
- Keep every board native to exact 4:5 portrait format. Keep titles, labels, panels, and captions inside the safe area.
- Use readable English labels and do not invent canon. If a fact cannot be inferred from the reference, use `UNKNOWN` or `CLASSIFIED`.
- Keep the same border system, typography hierarchy, grain, interface language, and accent palette across a multi-board set.
- Treat the board as a production reference system, not a generic mood board.

## Quick Correction Line

```
Keep all existing content and character identity. Rebuild the entire composition natively in EXACT 4:5 portrait aspect ratio. Do not crop a 9:16 poster. Reflow every panel, title, label, and caption inside the 4:5 safe area.
```

## Quality Control

- [ ] True 4:5 portrait output, not cropped from another ratio
- [ ] Same identity, age, proportions, and signature design across panels
- [ ] Main title and hero image read first
- [ ] English labels are legible and not clipped or garbled
- [ ] Borders, UI, grain, and accent colours form one visual system
- [ ] Nothing important touches the outer edge

## Fast Regeneration Commands

```
Keep the exact same character identity and outfit. Improve face consistency across every panel.

Reduce visual clutter by 15% while preserving all required panels and labels.

Increase typography readability and give the hero image stronger visual priority.

Rebuild natively in EXACT 4:5 portrait format; keep all content inside the safe area.

Keep the same board design but make the lighting and materials more cinematic and premium.
```
