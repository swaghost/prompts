# Villain Dossier

## Description

A classified intelligence-style character reference board for documenting a villain or antihero through surveillance portraits, threat analysis, behavioral notes, abilities, evidence, sightings, vulnerabilities, and encounter records. Unsupported facts remain explicitly unknown or classified so the dossier adds atmosphere without inventing canon.

## Use It When

Best for villains, antiheroes, and darker characters where a classified case-file aesthetic adds story.

## Prerequisites

- One clear full-body, three-quarter, or portrait reference image
- Readable face, costume, distinguishing features, and visually supported objects or abilities
- Optional verified character metadata; unsupported facts must use `UNKNOWN`, `UNCONFIRMED`, or `CLASSIFIED`

## Workflow

1. Upload the villain or character reference as the single visual source of truth.
2. Supply verified metadata only when available, then paste the complete master prompt.
3. Generate natively in exact 4:5 portrait format, ideally 1080 x 1350 px or higher.
4. Check identity continuity, factual restraint, label readability, and evidence relevance.
5. Regenerate rather than crop if the dossier is 9:16, square, landscape, or elongated.

## Continuity Rules

- Preserve the same face, age, body proportions, costume, signature traits, and visual identity in every photograph.
- Do not invent biography, crimes, abilities, weaknesses, affiliations, or encounter history.
- Use `UNKNOWN`, `UNCONFIRMED`, `REDACTED`, or `CLASSIFIED` whenever the image cannot establish a fact.
- Keep titles, labels, redactions, tables, images, and warning strips inside the 4:5 safe area.
- Maintain one archival texture, border system, typography hierarchy, surveillance UI, and restrained accent palette.
- Keep the dossier legible and analytical rather than sensational or decorative.

## Master Prompt

```
Create a single high-resolution classified intelligence document titled "VILLAIN DOSSIER" using the attached villain or character image as the single source of truth for appearance, face, hair, costume, physical characteristics, and visual identity.

Build the document specifically inside an EXACT 4:5 vertical Instagram carousel frame. Never create an elongated dossier page or 9:16 poster. Design it as a premium classified intelligence, law-enforcement, or secret-agency case file rather than a normal character board.

Use a near-black paper/interface background, distressed archival textures, thin purple/red/green accents sampled from the subject, stamped markings, evidence photography, surveillance UI, subtle fingerprints, redactions, file numbers, and restrained analog grain. Include a large hero surveillance portrait.

HEADER: VILLAIN DOSSIER · CLASSIFIED · SUBJECT ID · THREAT LEVEL.

SUBJECT PROFILE: ALIAS · KNOWN ALIASES · SPECIES · APPROX. AGE · HEIGHT · BUILD · DISTINGUISHING FEATURES · OCCUPATION · AFFILIATION · CURRENT STATUS. Use UNKNOWN or CLASSIFIED when the image cannot establish a fact.

PANEL 01 — MUGSHOT ARCHIVE: FRONT · LEFT PROFILE · RIGHT PROFILE.
PANEL 02 — THREAT LEVEL ANALYSIS: Large numerical threat indicator plus analytical bars for INTELLIGENCE · COMBAT · INFLUENCE · UNPREDICTABILITY · MOBILITY · DANGER.
PANEL 03 — BEHAVIORAL PROFILE: Short concise descriptors inferred from visual presentation, formatted like intelligence notes.
PANEL 04 — KNOWN ABILITIES: 5–6 icon-based capability entries with short descriptions based only on visible or inferable traits.
PANEL 05 — ORIGIN / BACKGROUND: A small archival photograph plus a concise CLASSIFIED / UNKNOWN background summary rather than fabricated canon.
PANEL 06 — EVIDENCE FILE: 3–5 photographed objects or details associated visually with the supplied character.
PANEL 07 — MODUS OPERANDI: Compact tactical or behavioural analysis.
PANEL 08 — WEAKNESSES / VULNERABILITIES: Use UNKNOWN or UNCONFIRMED when unsupported.
PANEL 09 — SIGHTINGS / LOCATIONS: Three surveillance-style environmental thumbnails.
PANEL 10 — DETENTION / ENCOUNTER HISTORY: Minimal classified table with redacted or unknown entries where facts are unavailable.

Add the warning strip: "EXTREME CAUTION · CLASSIFIED MATERIAL · AUTHORIZED ACCESS ONLY".

Photorealistic subject depiction, sophisticated dossier design, crisp English typography, realistic archival photography, subtle wear, cinematic grading, extremely detailed.
```

## Negative Prompt

```
9:16, square, elongated page, invented canon, unsupported biography, inconsistent face, altered identity, unreadable redactions, clutter, sensational gore, cartoon, low detail, watermark, or clipped text.
```

## Quick Correction Line

```text
Keep all existing content and exact subject identity. Rebuild the dossier natively in EXACT 4:5 portrait aspect ratio. Do not crop an elongated page. Reflow every photograph, panel, label, redaction, table, warning strip, and caption inside the 4:5 safe area. Replace unsupported facts with UNKNOWN, UNCONFIRMED, or CLASSIFIED.
```

## Quality Checklist

- [ ] Output is native 4:5 portrait, not an elongated or cropped document.
- [ ] The same identity, age, costume, and distinguishing features appear in every image.
- [ ] The hero surveillance portrait, title, and threat level establish clear hierarchy.
- [ ] Every factual claim is visually supported or marked unknown, unconfirmed, redacted, or classified.
- [ ] Evidence objects, abilities, sightings, and behavioral notes relate to the supplied character.
- [ ] English labels, tables, stamps, and redactions are readable and safely framed.
- [ ] Archival texture, UI, grain, borders, and accent colors form one restrained system.
- [ ] No invented canon, sensational gore, watermark, or clipped text appears.
