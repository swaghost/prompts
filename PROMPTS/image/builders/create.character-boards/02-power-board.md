# Power Board

## Use It When

Best for visualizing a character's power system, intensity, and combat effects.

## Master Prompt

```
Create a single high-resolution, densely packed character power reference sheet titled "POWER BOARD" using the attached character image as the single source of truth for identity, appearance, body proportions, costume, equipment, and visual language.

Generate in EXACT 4:5 vertical Instagram carousel aspect ratio. Design the entire layout natively for 4:5, not cropped from a taller poster. Preserve the exact same character identity and outfit throughout every panel.

Use a dark near-black cinematic background, thin yellow/gold technical borders, subtle character-specific energy accents, premium videogame ability-menu aesthetics, production-reference UI, faint grain, and dramatic lighting. Include one large hero image of the character demonstrating their signature power.

METADATA: SUBJECT · POWER CLASS · POWER SOURCE · COMBAT STYLE · RANGE · CONTROL · INTENSITY · SIGNATURE POWER.

PANEL 01 — CORE POWERS: Show 6 separate cinematic demonstrations: PRIMARY POWER · SECONDARY POWER · DEFENSIVE POWER · MOVEMENT POWER · SPECIAL POWER · ULTIMATE POWER.

PANEL 02 — POWER ACTIVATION: Four sequential stages: DORMANT · CHARGE · ACTIVATION · RELEASE.

PANEL 03 — POWER INTENSITY: Four progressively stronger versions: 25% · 50% · 75% · 100%.

PANEL 04 — IMPACT STUDIES: Show four cinematic examples of powers interacting with the environment: energy impact, defensive interaction, movement effect, and maximum-force impact.

PANEL 05 — POWER STATISTICS: Premium HUD-style bars for POWER · SPEED · RANGE · CONTROL · DEFENSE · STAMINA · DESTRUCTIVE POTENTIAL.

PANEL 06 — ENERGY / COLOR PALETTE: 6 HEX-coded swatches derived from the character and power effects.

Add the bottom caption: "Use this power board as a visual reference for consistent depiction of the character's powers across all generations." Bottom-right tags: STYLE · Power System · Realistic · Cinematic.

High-end cinematic realism, readable English labels, consistent character, realistic VFX integration, controlled visual density, 8K appearance.
```

## Negative Prompt

```
9:16, square, cropped poster, inconsistent character, random powers, unreadable HUD, excessive VFX, invented equipment, clutter, cartoon, low detail, watermark, logo, or clipped safe-area content.
```
