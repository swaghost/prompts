# Transformation Board

## Description

A cinematic VFX-development board that documents one character transforming from a stable base form into a final physical, armored, creature, material, or energy state. Sequential body, face, silhouette, surface, trigger, and color studies make the transformation reproducible rather than a set of unrelated redesigns.

## Use It When

Best for characters with physical, armor, creature, or energy transformations.

## Prerequisites

- One clear full-body or three-quarter base-character reference image
- Readable face, anatomy, costume, materials, silhouette, and defining traits
- Optional verified final-form direction or transformation trigger; avoid unsupported canon when none is supplied

## Workflow

1. Upload the base character reference as the single source of truth.
2. Define the transformation type or final-state direction when needed.
3. Paste the complete master prompt and generate natively in exact 4:5 portrait format, ideally 1080 x 1350 px or higher.
4. Verify that every stage preserves identity and forms a physically continuous progression.
5. Regenerate rather than crop if the output is 9:16, square, landscape, or extra tall.

## Continuity Rules

- Preserve the same face, age, anatomy, body proportions, costume lineage, and signature traits across every stage.
- Ensure each stage grows directly from the previous state with plausible material, anatomical, armor, or energy continuity.
- Keep one trigger, transformation direction, color progression, and final-form logic.
- Keep titles, labels, panels, silhouettes, swatches, and captions inside the 4:5 safe area.
- Use readable English and do not invent unsupported story canon.
- Treat the board as a VFX production reference, not six independent character concepts.

## Master Prompt

```
Create a single high-resolution cinematic transformation reference sheet titled "TRANSFORMATION BOARD" using the attached character image as the single source of truth for the character's base identity, anatomy, costume, materials, colours, and defining visual traits.

Compose every element natively for an EXACT 4:5 vertical Instagram carousel canvas. The transformation must feel continuous and physically believable; every stage must clearly represent the same subject.

Use a near-black premium production-board background, thin yellow/gold borders, subtle cinematic glow, technical annotations, fine grain, and high-end creature/VFX-development presentation. The large hero image shows FINAL TRANSFORMATION.

PANEL 01 — TRANSFORMATION SEQUENCE: Show 6 sequential full-body stages: BASE FORM · INITIAL CHANGE · 25% · 50% · 75% · FINAL FORM. The progression must be gradual rather than six unrelated designs.

PANEL 02 — FACE TRANSFORMATION: 5 close-ups showing facial/head progression from base to final.
PANEL 03 — BODY / ANATOMY TRANSFORMATION: 4 studies: TORSO · ARM / HAND · BACK · LEG / FOOT.
PANEL 04 — MATERIAL / SURFACE DEVELOPMENT: 4 extreme macros showing transformation of skin, fabric, armor, organic material, or energy surfaces.
PANEL 05 — TRANSFORMATION TRIGGER: Three cinematic frames: BEFORE · TRIGGER · AFTER.
PANEL 06 — SILHOUETTE PROGRESSION: 5 clean silhouettes demonstrating how overall body shape evolves.
PANEL 07 — COLOR PALETTE: 6 HEX-coded swatches representing base-to-final transformation colours.

Add the bottom caption: "Use this transformation board as a visual reference for consistent transformation progression across all generations." Bottom-right tags: STYLE · Transformation · VFX Ready · Cinematic.

Highly detailed, realistic material transitions, consistent identity, cinematic VFX-development quality, sharp English labels, 8K appearance.
```

## Negative Prompt

```
9:16, square, unrelated character stages, abrupt random designs, identity drift, impossible anatomy, unreadable labels, cropped panels, excessive glow, cartoon, low detail, watermark, logo, or content outside the safe area.
```

## Quick Correction Line

```text
Keep all existing content, base identity, and transformation logic. Rebuild the entire composition natively in EXACT 4:5 portrait aspect ratio. Do not crop a 9:16 poster. Reflow every sequence stage, close-up, anatomy study, material macro, silhouette, swatch, and caption inside the 4:5 safe area.
```

## Quality Checklist

- [ ] Output is native 4:5 portrait with all panels inside the safe area.
- [ ] The same identity, age, proportions, and signature traits survive every stage.
- [ ] Six full-body stages form a gradual, physically believable progression.
- [ ] Face, anatomy, material, trigger, and silhouette studies agree with the main sequence.
- [ ] The final-transformation hero image and title read first.
- [ ] Material changes, energy effects, and body transitions avoid abrupt morphing or impossible anatomy.
- [ ] Labels and HEX-coded swatches are legible and consistent.
- [ ] No unrelated redesign, excessive glow, watermark, or clipped content appears.

## Fast Regeneration Commands

```text
Keep the exact same base identity and final form. Improve identity continuity across every transformation stage.

Make the six stages progress more gradually with clear physical transitions between adjacent states.

Reduce glow and visual clutter by 15% while preserving all required VFX-development panels.

Increase label readability and give the final-transformation hero image stronger visual priority.

Rebuild natively in EXACT 4:5 portrait format and keep all content inside the safe area.
```
