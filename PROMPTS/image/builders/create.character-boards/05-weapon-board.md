# Weapon Board

## Use It When

Best for weapon-heavy characters, tactical fighters, and signature loadouts.

## Master Prompt

```
Create a single high-resolution character-specific weapon reference sheet titled "WEAPON BOARD" using the attached character image as the visual source of truth.

Design the board natively in EXACT 4:5 portrait Instagram carousel aspect ratio. Do not output 9:16 or an elongated infographic. Analyze the character's visual language, era, costume, materials, and fighting style, then create a coherent weapon/loadout system that feels naturally designed for this character. The character must remain visually consistent whenever shown.

Use a near-black tactical background, thin yellow/gold technical borders, premium armory UI, subtle film grain, cinematic product photography, realistic materials, and controlled accent lighting. The large hero section shows CHARACTER + SIGNATURE WEAPON.

METADATA: SUBJECT · COMBAT CLASS · PRIMARY WEAPON · SECONDARY WEAPON · RANGE · MATERIAL · FIGHTING STYLE · LOADOUT TYPE.

PANEL 01 — PRIMARY WEAPON: Large isolated studio product shot with FRONT · SIDE · 3/4 VIEW.
PANEL 02 — SECONDARY LOADOUT: Show 4 complementary weapons or tools designed in the same visual language.
PANEL 03 — WEAPON DETAILS: 4 macro studies: GRIP · EDGE / IMPACT AREA · MECHANISM · MATERIAL / ENGRAVING.
PANEL 04 — COMBAT APPLICATION: 4 cinematic character frames: READY · ATTACK · DEFENSE · FINISHER.
PANEL 05 — LOADOUT PLACEMENT: Full-body neutral character with clean callouts showing where each item is carried.
PANEL 06 — WEAPON STATES: PRISTINE · ACTIVE · USED · DAMAGED.
PANEL 07 — MATERIAL / COLOR PALETTE: 6 HEX-coded swatches derived from character and weapon materials.

Add the bottom caption: "Use this weapon board as a visual reference for consistent depiction of the character's loadout across all generations." Bottom-right tags: STYLE · Tactical · Realistic · Cinematic.

Production-quality weapon design, realistic scale, consistent weapon geometry, highly detailed materials, clean English labels, cinematic product lighting, 8K appearance.
```

## Negative Prompt

```
9:16, square, elongated infographic, weapon geometry drift, impossible scale, extra weapons, unsafe handling, unreadable callouts, clutter, cartoon, low detail, watermark, logo, or clipped panels.
```
