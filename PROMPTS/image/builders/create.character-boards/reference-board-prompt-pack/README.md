# Reference Board Prompt Pack

Five production-ready GPT Image 2 prompts for consistent cinematic character boards. Each uses one uploaded character reference and produces a native 4:5 Instagram carousel board at 3000 x 3750 px or higher.

## Workflow

1. Upload one clear character reference where face, body, hairstyle, and signature clothing are easy to read.
2. Paste the matching complete prompt without deleting its layout or consistency rules.
3. Use the same reference image for regeneration and refinement to reduce identity drift.
4. Export in native 4:5 portrait format; do not crop from another ratio.

## Shared Board Rules

- **Platform:** GPT Image 2
- **Format:** Exact 4:5 vertical Instagram carousel, 3000 x 3750 px preferred
- **Layout:** Board fills 96-98% of canvas; thin black perimeter only; no white margins, sidebars, or excess padding
- **Design system:** Matte black and charcoal, distressed golden-yellow borders and typography, subtle film grain, compact hero header
- **CTA:** Upper-left `COMMENT` in white above `FACE` in golden yellow; no panel numbering
- **Text:** Render only the specified CTA, board title, and panel labels
- **Reference:** Keep the same source image for all iterations
