# Genre Board - Aang

## Platform and Format

**Platform:** GPT Image 2  
**Format:** Exact 4:5 vertical Instagram carousel, 3000 x 3750 px preferred

## Prompt

```text
Create a premium vertical 4:5 GENRE BOARD featuring Aang from Avatar: The Last Airbender. Use the uploaded image as the identity reference. Preserve the same age-appropriate young Air Nomad: bald head, bright blue arrow tattoo centred on his forehead and scalp, friendly expressive face and orange-and-yellow monk robes.

LAYOUT: Exact Instagram carousel ratio 4:5. The board fills 96-98% of the canvas. No white margins, side bars or excessive padding. Use only a thin solid black perimeter frame, matte-black and charcoal production-board styling, distressed golden-yellow borders and typography, subtle film grain, a compact hero header with a large portrait, and the exact title "GENRE BOARD".

CTA: In the extreme upper-left, render COMMENT in white above FACE in golden yellow. No panel numbering.

PANEL GRID: Create a precise 3x3 grid reimagining Aang as: HIGH FANTASY / CYBERPUNK / WESTERN / FILM NOIR / SAMURAI / STEAMPUNK / SCI-FI / EPIC ADVENTURE / MYSTERY.

CONSISTENCY: Each panel changes the environment, wardrobe styling, lighting and genre atmosphere while preserving Aang's face, age, bald head, blue arrow tattoo and identity.

STYLE: Premium cinematic animated concept art, highly detailed, coherent across every panel, age-appropriate, wholesome and fully clothed.

TEXT: Render only COMMENT, FACE, GENRE BOARD and the nine genre labels.

AVOID: No other characters, combat, weapons, threatening poses, sexualisation, panel numbers, logos, watermark, additional text or misspellings.
```

## Output Checklist

- [ ] Nine distinct genre treatments in a 3x3 grid
- [ ] Aang remains age-appropriate, fully clothed, and identifiable in every panel
- [ ] Bald head, blue arrow tattoo, face, and identity are preserved
- [ ] No combat, weapons, threatening poses, sexualisation, or unapproved text
