# Genre Board - Aang

## Description

A cinematic genre-exploration board that reinterprets one age-appropriate character through nine visual genres while keeping identity, age, facial structure, signature markings, and core recognizability intact. Environments, wardrobe styling, lighting, and atmosphere change; the character does not become nine unrelated people.

## Use It When

Use this board for alternate-genre pitches, visual-development exploration, campaign concepts, adaptation studies, world-building, and controlled style comparisons.

## Prerequisites

- One clear identity reference with face, age cues, hairstyle, markings, and baseline wardrobe visible
- A list of nine genre directions with safe, age-appropriate styling
- A model capable of consistent identity through environmental and costume changes
- Native 4:5 output; do not crop a square, landscape, or 9:16 image

## Workflow

1. Upload one character reference as the identity source of truth.
2. Paste the full prompt without removing genre labels, age safeguards, or layout rules.
3. Generate natively at exact 4:5, preferably 3000 x 3750 px or higher.
4. Confirm that every genre reads clearly while the same age-appropriate character remains identifiable.
5. Regenerate if identity, signature markings, safety constraints, labels, or panel count drift.

## Continuity Rules

- Preserve the exact friendly face, apparent age, bald head, bright blue arrow tattoo, body proportions, and core identity.
- Keep all treatments wholesome, non-sexualized, fully clothed, and appropriate for a young character.
- Change environment, wardrobe styling, palette, lighting, and genre atmosphere only as needed for each panel.
- Do not introduce combat, weapons, threatening behavior, or mature redesigns.
- Keep one coherent board layout, border, typography, grain, and production-art quality.

## Platform and Format

**Platform:** GPT Image 2  
**Format:** Exact 4:5 vertical Instagram carousel, 3000 x 3750 px preferred

## Prompt

```text
Create a premium vertical 4:5 GENRE BOARD featuring Aang from Avatar: The Last Airbender. Use the uploaded image as the identity reference. Preserve the same age-appropriate young Air Nomad: bald head, bright blue arrow tattoo centred on his forehead and scalp, friendly expressive face and orange-and-yellow monk robes.

LAYOUT: Exact Instagram carousel ratio 4:5. The board fills 96-98% of the canvas. No white margins, side bars or excessive padding. Use only a thin solid black perimeter frame, matte-black and charcoal production-board styling, distressed golden-yellow borders and typography, subtle film grain, a compact hero header with a large portrait, and the exact title "GENRE BOARD".

CTA: In the extreme upper-left, render COMMENT in white above FACE in golden yellow. No panel numbering.

PANEL GRID: Create a precise 3x3 grid reimagining Aang as: HIGH FANTASY / CYBERPUNK / WESTERN / FILM NOIR / SAMURAI / STEAMPUNK / SCI-FI / EPIC ADVENTURE / MYSTERY.

CONSISTENCY: Each panel changes the environment, wardrobe styling, lighting and genre atmosphere while preserving Aang's face, age, bald head, blue arrow tattoo and identity.

STYLE: Premium cinematic animated concept art, highly detailed, coherent across every panel, age-appropriate, wholesome and fully clothed.

TEXT: Render only COMMENT, FACE, GENRE BOARD and the nine genre labels.

AVOID: No other characters, combat, weapons, threatening poses, sexualisation, panel numbers, logos, watermark, additional text or misspellings.
```

## Output Checklist

- [ ] Nine distinct genre treatments in a 3x3 grid
- [ ] Aang remains age-appropriate, fully clothed, and identifiable in every panel
- [ ] Bald head, blue arrow tattoo, face, and identity are preserved
- [ ] No combat, weapons, threatening poses, sexualisation, or unapproved text

## Negative Prompt

```text
9:16, square, landscape, cropped board, white margins, fewer than nine panels, extra panels, duplicate genre, unclear genre, identity drift, changed face, adult aging, changed body proportions, hair added, missing blue arrow tattoo, misplaced tattoo, sexualization, revealing clothing, mature styling, combat, weapons, threatening pose, blood, gore, other characters, inconsistent board design, panel numbers, extra text, misspelled labels, logo, watermark
```

## Quick Correction Line

```text
Keep the exact same age-appropriate character identity, bald head, blue arrow tattoo, nine genre labels, board design, and approved text. Rebuild natively in exact 4:5 portrait format with one hero header and a complete 3x3 genre grid. Make each genre visually distinct while keeping the character wholesome, fully clothed, nonviolent, and immediately recognizable.
```
