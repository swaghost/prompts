# Ability Board

## Description

A gameplay-style production board that defines one character's active abilities, signature cast sequence, ultimate state, passive traits, statistics, effect details, and VFX palette. It preserves character and costume continuity while turning the skill set into a readable, repeatable visual system.

## Use It When

Best for game-style characters with a clear skill set, elemental system, or ultimate ability.

## Prerequisites

- One clear full-body or three-quarter character reference image
- Readable costume, equipment, silhouette, elemental cues, and signature visual traits
- Optional verified class, role, ability names, or mechanics; otherwise use functional labels and avoid invented canon

## Workflow

1. Upload the character reference image as the single source of truth.
2. Supply verified ability names or mechanics when exact canon is required.
3. Paste the complete master prompt and generate natively in exact 4:5 portrait format, ideally 1080 x 1350 px or higher.
4. Verify character continuity, ability distinction, cast order, environmental interaction, and UI readability.
5. Regenerate rather than crop if the output is 9:16, square, landscape, or extra tall.

## Continuity Rules

- Preserve the same face, age, body proportions, costume, equipment, and elemental language across every demonstration.
- Keep six abilities visually distinct while deriving them from one coherent source and VFX grammar.
- Ensure charge, cast, impact, aftermath, activation, peak, and final impact follow readable temporal order.
- Keep titles, labels, HUD elements, icons, panels, swatches, and captions inside the 4:5 safe area.
- Use readable English and avoid unsupported canon; use descriptive functional names when necessary.
- Treat the board as a game-production reference, not a decorative effects collage.

## Master Prompt

```
Create a single high-resolution cinematic gameplay-style reference sheet titled "ABILITY BOARD" using the attached character image as the single source of truth for appearance, costume, body proportions, colours, elemental theme, and overall visual identity.

Compose the board specifically for an EXACT 4:5 vertical Instagram carousel ratio with all information readable inside the safe area. Keep the character identical across all demonstrations.

Use a dark near-black videogame ability-screen aesthetic, thin yellow/gold borders, character-specific elemental accents, premium HUD elements, cinematic VFX, subtle film grain, and realistic production-design presentation. The large hero image shows the character performing their SIGNATURE ABILITY.

METADATA: SUBJECT · CLASS · ELEMENT / ENERGY TYPE · COMBAT ROLE · ABILITY SOURCE · SPECIALIZATION · ULTIMATE STATE.

PANEL 01 — ABILITY SET: Create 6 distinct abilities: ABILITY 01 — BASIC · ABILITY 02 — PROJECTILE / RANGED · ABILITY 03 — DEFENSIVE · ABILITY 04 — MOBILITY · ABILITY 05 — SPECIAL · ABILITY 06 — ULTIMATE. Give each a short one-line English description.

PANEL 02 — SIGNATURE ABILITY BREAKDOWN: Four sequential frames: CHARGE · CAST · IMPACT · AFTERMATH.
PANEL 03 — ULTIMATE ABILITY: Three cinematic frames: ACTIVATION · PEAK · FINAL IMPACT.
PANEL 04 — PASSIVE TRAITS: 4 icon-based passive abilities with concise descriptions.
PANEL 05 — STATS: HUD bars for POWER · SPEED · DEFENSE · RANGE · CONTROL · STAMINA · DIFFICULTY.
PANEL 06 — EFFECT DETAILS: 4 macro VFX studies showing particles, ice/fire/energy/material effects, impact texture, and environmental interaction appropriate to the supplied character.
PANEL 07 — COLOR / VFX PALETTE: 6 HEX-coded swatches.

Add the bottom caption: "Use this ability board as a visual reference for consistent depiction of the character's abilities across all generations." Bottom-right tags: STYLE · Ability System · Game Ready · Cinematic.

Photorealistic or source-consistent character rendering, premium AAA-game presentation, highly detailed VFX, consistent costume and identity, sharp readable English typography, 8K appearance.
```

## Negative Prompt

```
9:16, square, cropped poster, inconsistent character, random abilities, unreadable HUD, excessive VFX, invented canon, clutter, cartoon, low detail, watermark, logo, or content outside the 4:5 safe area.
```

## Quick Correction Line

```text
Keep all existing content, character identity, costume, and ability system. Rebuild the entire composition natively in EXACT 4:5 portrait aspect ratio. Do not crop a 9:16 poster. Reflow every ability panel, cast sequence, passive icon, HUD bar, effect study, swatch, and caption inside the 4:5 safe area.
```

## Quality Checklist

- [ ] Output is native 4:5 portrait with every element inside the safe area.
- [ ] Character identity, costume, equipment, proportions, and elemental language remain consistent.
- [ ] Six active abilities are distinct, readable, and part of one coherent system.
- [ ] Signature and ultimate sequences follow correct charge-to-aftermath order.
- [ ] Passive icons, statistics, effect studies, and palette agree with the active abilities.
- [ ] VFX interact believably with character, light, atmosphere, and environment.
- [ ] Ability names, descriptions, HUD labels, and HEX codes are legible.
- [ ] No random ability, invented canon, excessive VFX, watermark, or clipped content appears.

```text
Make all six abilities more visually distinct while preserving one shared elemental and VFX language.

Clarify the signature and ultimate timing from charge through impact and aftermath.

Reduce VFX and UI clutter by 15% while improving label and icon readability.

```
