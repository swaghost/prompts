# Ability Board

## Use It When

Best for game-style characters with a clear skill set, elemental system, or ultimate ability.

## Master Prompt

```
Create a single high-resolution cinematic gameplay-style reference sheet titled "ABILITY BOARD" using the attached character image as the single source of truth for appearance, costume, body proportions, colours, elemental theme, and overall visual identity.

Compose the board specifically for an EXACT 4:5 vertical Instagram carousel ratio with all information readable inside the safe area. Keep the character identical across all demonstrations.

Use a dark near-black videogame ability-screen aesthetic, thin yellow/gold borders, character-specific elemental accents, premium HUD elements, cinematic VFX, subtle film grain, and realistic production-design presentation. The large hero image shows the character performing their SIGNATURE ABILITY.

METADATA: SUBJECT · CLASS · ELEMENT / ENERGY TYPE · COMBAT ROLE · ABILITY SOURCE · SPECIALIZATION · ULTIMATE STATE.

PANEL 01 — ABILITY SET: Create 6 distinct abilities: ABILITY 01 — BASIC · ABILITY 02 — PROJECTILE / RANGED · ABILITY 03 — DEFENSIVE · ABILITY 04 — MOBILITY · ABILITY 05 — SPECIAL · ABILITY 06 — ULTIMATE. Give each a short one-line English description.

PANEL 02 — SIGNATURE ABILITY BREAKDOWN: Four sequential frames: CHARGE · CAST · IMPACT · AFTERMATH.
PANEL 03 — ULTIMATE ABILITY: Three cinematic frames: ACTIVATION · PEAK · FINAL IMPACT.
PANEL 04 — PASSIVE TRAITS: 4 icon-based passive abilities with concise descriptions.
PANEL 05 — STATS: HUD bars for POWER · SPEED · DEFENSE · RANGE · CONTROL · STAMINA · DIFFICULTY.
PANEL 06 — EFFECT DETAILS: 4 macro VFX studies showing particles, ice/fire/energy/material effects, impact texture, and environmental interaction appropriate to the supplied character.
PANEL 07 — COLOR / VFX PALETTE: 6 HEX-coded swatches.

Add the bottom caption: "Use this ability board as a visual reference for consistent depiction of the character's abilities across all generations." Bottom-right tags: STYLE · Ability System · Game Ready · Cinematic.

Photorealistic or source-consistent character rendering, premium AAA-game presentation, highly detailed VFX, consistent costume and identity, sharp readable English typography, 8K appearance.
```

## Negative Prompt

```
9:16, square, cropped poster, inconsistent character, random abilities, unreadable HUD, excessive VFX, invented canon, clutter, cartoon, low detail, watermark, logo, or content outside the 4:5 safe area.
```
