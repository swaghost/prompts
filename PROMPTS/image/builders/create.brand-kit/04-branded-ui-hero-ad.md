# Branded UI Hero Advertisement Builder

## Purpose

Turn a supplied UI screenshot and brand reference into a premium social-media advertisement while keeping the interface and brand identity accurate.

## Prompt

```
Use the provided UI screenshot and brand reference to create a premium, creative social media advertisement. Preserve the UI exactly and integrate it naturally into a striking hero scene. Follow the brand's logo, colors, typography, spacing, proportions, and visual identity. Add ONE bold headline, ONE short subtext, and the brand logo. Create a clever, realistic, art-directed composition with cinematic lighting, depth, perspective, reflections, realistic materials, and professional commercial-photography quality. Avoid generic backgrounds, random 3D elements, excessive text, or an AI-generated look. Make the final design feel like a high-end brand campaign, not a simple UI mockup.
```

## Reference and Output Rules

- Treat the uploaded UI screenshot as immutable: preserve its screen content, layout, typography, colors, and proportions.
- Use the brand reference to control the logo, visual language, color relationships, and material choices.
- Include exactly one bold headline and one short supporting line; keep both legible and subordinate to the UI.
- Use one clear hero concept with intentional depth and perspective rather than decorative clutter.
- Keep the product or interface as the visual focal point and make the advertising context believable.

## Technical Specifications

High-resolution social advertising creative, premium commercial photography, realistic screen reflections, physically accurate lighting, crisp UI rendering, polished brand-campaign finish, 4:5 vertical format unless another platform format is specified.

## Negative Prompt

No altered UI, changed screen content, misspelled text, extra headlines, excessive copy, random 3D objects, generic stock background, warped perspective, unreadable logo, fake reflections, flat compositing, low-resolution screen, AI artifacts, or amateur mockup appearance.
