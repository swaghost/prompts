# 06 — Shot Board (12-Panel Storyboard for Narrative Sequences)

**Purpose:** Generate a 12-panel storyboard showing key beats of a narrative sequence in chronological order  
**Use Case:** Pre-visualize story flow, lock shot composition, plan camera moves, and reference visual continuity before generating video  
**Platform:** GPT Image 2, Picsart Flow

## What This Builder Does

Creates a 4×3 grid (12 panels) showing the visual progression of a scene or short film, from establishing shot to resolution. Each panel represents a distinct story beat with specific framing, action and composition.

This serves as both creative planning tool and consistency reference — upload to Topview Canvas and reference specific panels when prompting video shots to maintain visual continuity.

## Template Prompt

```
[PASTE YOUR STYLE BIBLE HERE]

12-panel storyboard, 4 rows × 3 columns grid, showing chronological visual beats of a narrative sequence, evenly spaced with thin white gutters between panels.

STORY SUMMARY (one paragraph): [Brief description of the narrative — who, where, what happens, emotional arc, resolution]

CHARACTER(S): [For each character appearing, provide: age, gender, ethnicity, hair, distinguishing features, wardrobe. If character board exists, reference it here.]

LOCATION: [Environment description — setting, time of day, lighting, key spatial features. If location board exists, reference it here.]

VISUAL STYLE & TONE: [Cinematography approach — lens choices, camera movement style, lighting mood, color grading direction]

PANELS (reading left to right, top to bottom):

Panel 1 — [SHOT TYPE]: [Action/composition description, what's in frame, where camera is positioned, what's happening]

Panel 2 — [SHOT TYPE]: [Continue sequence]

Panel 3 — [SHOT TYPE]: [Continue sequence]

[Continue through Panel 12]

CRITICAL: Consistent character appearance (face, hair, wardrobe), consistent location/environment, consistent lighting direction and color temperature, consistent time of day across all panels unless specified otherwise. Photorealistic cinematic rendering, film-accurate shot framing, natural character poses and expressions, coherent visual narrative flow.
```

```

Influenced by Denis Villeneuve and Duncan Jones (Moon), grounded and tactile sci-fi.

## Builder Variables

**Story Variables (Customize These):**

- **Genre:** Drama, action, comedy, horror, sci-fi, fantasy, romance, thriller
- **Narrative structure:** Linear sequence, flashback, parallel action, reveal/twist
- **Story duration:** 30-second beat, 1-minute sequence, 3-minute short, full narrative arc
- **Emotional arc:** Journey from [starting emotion] to [ending emotion]
- **Core conflict:** Internal struggle, external obstacle, relationship tension, survival, discovery

**Character Variables:**

- See Character Board builder (age, gender, ethnicity, hair, features, wardrobe)
- Expression range needed: neutral, surprised, fearful, joyful, angry, sad, determined, etc.
- Props/tools character interacts with

**Location Variables:**

- See Location Board builder (environment type, era, lighting, dressing)
- Key spatial features: windows, doors, furniture, obstacles
- Weather/atmosphere: rain, fog, dust, smoke, clear

**Cinematography Variables:**

- **Shot types:** Wide, medium, close-up, extreme close-up, over-the-shoulder, POV, aerial
- **Camera movement:** Static, push-in, pull-out, tracking, pan, tilt, handheld, crane, orbit
- **Lens choice:** Wide (24mm), standard (35-50mm), telephoto (85-135mm), macro
- **Depth of field:** Deep focus (everything sharp) vs shallow (subject sharp, background soft)
- **Lighting approach:** Naturalistic, dramatic, high-key, low-key, silhouette, practical sources
- **Color palette:** Warm, cool, desaturated, saturated, monochrome, complementary contrast

## Panel Distribution Strategy

**12 panels typically break down as:**

- **Panels 1-2:** Establishing (wide shots introducing location/characters/situation)
- **Panels 3-5:** Setup/rising action (medium shots, character introduction, conflict emerging)
- **Panels 6-8:** Climax/core action (close-ups, peak emotional moment, key decision)
- **Panels 9-10:** Resolution action (medium shots, consequences playing out)
- **Panels 11-12:** Denouement (wide or medium-close, emotional landing, visual conclusion)

Adjust based on narrative — action sequences use more panels for choreography, quiet dramas use more panels for emotional beats.

## Usage Tips

- **Shot types in caps** — Makes panel structure scannable; helps model parse framing intent
- **Repeat compositions deliberately** — Panel 3 and Panel 10 both "Close-Up Hands" creates visual rhyme; specify "repeat composition"
- **Lighting continuity** — If time passes, specify "now dusk" or "later, night"; otherwise keep time/light locked
- **Reference previous panels** — "Camera at opposite end from Panel 1" ties spatial logic together
- **Character eyeline** — Specify "looking into lens" vs "looking off-camera left" for coherent eyeline match
- **Emotional progression** — Each panel should have clear character expression: surprised → concentrated → emotional → resolved

## Integration with Video

Upload storyboard to Topview Canvas, name @storyboard_sequence, reference specific panels in video prompts:

```
REFERENCES: Use @storyboard_sequence for shot composition and visual flow. Character appearance matches @char_astronaut throughout.

0-4s: [Matches @storyboard_sequence Panel 1] Wide establishing, camera looking down cylindrical corridor toward Earth porthole, astronaut walks deeper into station, handheld drift, cool teal and warm amber lighting.

4-8s: [Matches @storyboard_sequence Panel 2] Medium tracking shot following astronaut from behind, hand trailing wall, dust floating in amber light.

[Continue mapping each video beat to specific storyboard panels]
```

Video generation follows pre-visualized framing and flow, reducing composition guesswork.

## When to Use This Builder

✅ **Use Shot Board when:**

- Planning multi-shot narrative sequence or short film
- Need to pre-visualize story flow before generating expensive video
- Team review/approval required before production
- Complex action or emotional arc needs careful shot progression
- Want to maintain visual continuity across 10+ shots

❌ **Don't use Shot Board when:**

- Single-shot video (no cuts, no storyboard needed)
- Abstract/non-narrative sequence (no story beats to map)
- Improvised/experimental approach where pre-viz constrains creativity
- Story is still in flux (finish script first, then storyboard)

## Advanced: Animatic Workflow

Once storyboard is generated and approved:

1. Upload storyboard to Topview Canvas as @storyboard
2. Generate each panel as a separate static image using identical prompts (higher resolution)
3. Compile static images into timed animatic with temp music/voiceover
4. Use animatic for final shot-by-shot video prompt timing
5. Replace static images with video shots one by one

This workflow = storyboard → high-res images → animatic → final video, each step referencing the previous.
