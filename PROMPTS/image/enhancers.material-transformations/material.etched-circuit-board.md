## Material Description

A copper trace turns at ninety or forty-five degrees, never freehand. Give the model the routing rule and you stop getting wires that merely look like wires. This prompt creates authentic PCB routing with real manufacturing constraints.

## Key Characteristics

- Two-layer copper routing on green FR-4
- Straight segments and 45° turns only
- No free curves in traces
- Vias stitching between layers
- Copper pour with hatch grid
- Matte solder mask over copper
- White silkscreen legend
- Bare gold-plated pads and edge fingers
- Production marks and fiducials

## Technical Details

**Material Properties:**

- Green FR-4 substrate
- Two-layer copper
- Matte green solder mask
- White silkscreen
- Bare gold plating (pads/fingers)

**Routing Rules:**

- Straight segments only
- 90° and 45° turns (never freehand curves)
- Thick power traces
- Fine signal traces
- Vias stitch between layers
- Copper pour with hatch grid

**PCB Finishing:**

- Solder mask over copper
- Traces as raised darker channels
- Silkscreen component outlines
- Reference designators (tiny technical sans)
- Gold-plated pads where mask cut away
- Gold-plated edge fingers

**Production Marks:**

- Date code
- Fiducial in each corner
- Milled edges with mouse bites
- Hand-soldered joints
- Brown flux residue

**Lighting:**

- Flat close lighting
- Product shot style
