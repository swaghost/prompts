# Machined Billet - Material Transformation

**Source:** The Material Pack by Waviboy | [waviboy.com/material-pack](https://www.waviboy.com/material-pack)

## Material Description

A machined part can only have shapes a cutter can physically reach. Name the tool and you stop getting detail no tool could ever produce. This prompt creates CNC-machined aluminium with authentic tool paths and machining constraints.

## Key Characteristics

- CNC-machined from solid aluminium billet
- Cool blue-grey specular sheen
- Fine directional machining grain
- Concentric tool paths in parallel arcs
- Every edge chamfered or filleted
- No undercuts (cutter can't reach)
- Bead-blasted matte finish with hard anodizing

## Image Edit Prompt

Transform the subject of this photograph into an object CNC-machined from a solid billet of aluminium. Abandon the original rendering entirely: there is no skin, no cloth and no clay left anywhere in the frame, only bare metal with a cool blue-grey specular sheen and a fine directional machining grain running across every face. Nothing here was moulded or grown: every surface was cut away by a spinning endmill, so concentric tool paths ripple across the broad faces in fine parallel arcs, every edge is chamfered or filleted to one consistent radius, and the form is simplified into the machinable version of itself with no undercut a cutter could never reach. Soft details become hard geometry: countersunk fasteners, precision-tapped holes, a laser-etched serial number and a shallow engraved index line. The whole part is bead-blasted to an even matte and hard-anodised in a single flat colour, so light reads as a broad soft sheen rather than a mirror, with the anodising going slightly deeper and darker in the internal corners. A witness mark shows where it was held in the vice. Cold neutral studio light, plain seamless ground, shallow depth of field. Keep the subject, pose, framing and composition exactly as they are.

## Technical Details

**Material Properties:**

- Solid aluminium billet
- Cool blue-grey metal
- Directional machining grain
- Bead-blasted matte finish
- Hard anodized coating

**Manufacturing Evidence:**

- Concentric tool paths
- Chamfered/filleted edges (consistent radius)
- Countersunk fasteners
- Tapped holes
- Laser-etched serial number
- Engraved index line
- Vice witness mark

**Manufacturing Constraints:**

- No undercuts (cutter can't reach)
- Only machinable geometries
- Hard edges, not soft details

**Lighting:**

- Cold neutral studio light
- Plain seamless background
- Shallow depth of field
- Broad soft sheen (not mirror)
