# Pizza Split Frame Composition - Same Moment Divided

## Description of Resulting Image

A creative split-frame iPhone photograph showing one continuous moment horizontally divided into two equal sections. The same person appears twice in one image with one whole pizza on the table - both halves interact with the same pizza from different perspectives. This single continuous photograph creates a surreal yet cohesive composition maintaining identical camera angle, framing, lighting, and restaurant setting.

Use this prompt for creative food photography content ideal for Instagram, TikTok, or restaurant marketing.
