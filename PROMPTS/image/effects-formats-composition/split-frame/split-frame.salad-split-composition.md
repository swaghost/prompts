# Salad Split Frame Composition - Same Moment Divided

## Description of Resulting Image

A creative split-frame photograph showing one continuous moment horizontally divided into two connected halves. The same person appears twice in one image with one salad bowl - the lower half holds the bowl overhead while the upper half eats from the same bowl using a fork. This single continuous photograph captures the same subject at the same moment from two different perspectives, creating a surreal yet cohesive composition that matches exact framing, lighting, and restaurant interior.

## Usage

Use this prompt when creating creative split-frame content for social media, especially food photography with a playful twist. This effect works exceptionally well for Instagram, TikTok, or creative portfolio pieces that showcase both the food and the dining experience simultaneously. The technique creates visual interest through impossible perspective while maintaining photographic realism in each half.
