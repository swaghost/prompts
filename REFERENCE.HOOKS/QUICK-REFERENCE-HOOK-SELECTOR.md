# Quick-Reference Hook Selector

**Use this guide when:** You're about to create content and need to choose the perfect hook fast.

---

## 🚦 START HERE: Answer 3 Questions

1. **Who's watching?** (Cold | Warm | Hot audience)
2. **What do you want?** (Views | Engagement | Sales | Authority)
3. **What's your proof?** (Story | Data | Experience | None yet)

---

## 🎯 Quick Hook Matrix

### For COLD Audiences (Don't know you)

| You Want      | Use This Hook Type             | Example Templates                                               |
| ------------- | ------------------------------ | --------------------------------------------------------------- |
| **Views**     | Curiosity, Relatable, Trending | "POV: You have 100 ideas until..." / "Nobody tells you this..." |
| **Followers** | Pattern Interrupt, Contrarian  | "Unpopular opinion..." / "Stop doing X..."                      |
| **Trust**     | Vulnerable Story, Relatable    | "I almost quit because..." / "You're not lazy..."               |

**⚠️ Avoid:** Authority claims, inside jokes, sales pitches

---

### For WARM Audiences (Know you, don't buy)

| You Want         | Use This Hook Type        | Example Templates                                      |
| ---------------- | ------------------------- | ------------------------------------------------------ |
| **Authority**    | Experience, Analysis      | "After X years..." / "I analyzed 100..."               |
| **Credibility**  | Proof, Case Studies       | "This one change increased..." / "Client went from..." |
| **Deeper Trust** | Transformation, Framework | "A year ago I couldn't..." / "My repeatable system..." |

**⚠️ Avoid:** Basic 101 content, entertainment without substance

---

### For HOT Audiences (Ready to act)

| You Want               | Use This Hook Type   | Example Templates                                           |
| ---------------------- | -------------------- | ----------------------------------------------------------- |
| **Sales**              | Myth-Busting, Bridge | "Biggest myth costing you..." / "Content bridge between..." |
| **Action**             | Urgency, Challenge   | "Fix this before..." / "Try this for 7 days..."             |
| **Objection Handling** | Myth-Busting         | "You don't need X to get Y..."                              |

**⚠️ Avoid:** Pure education, unrelated entertainment

## ⚡ Hook Selection by Situation

### "I need views/reach fast"

→ **Curiosity + Relatability**

- POV formats
- Pattern interrupts
- Trending topic angles
- "Why is no one talking about..."

### "I need engagement (comments/shares)"

→ **Questions + Contrarian**

- Direct questions: "Why do some grow while others..."
- Polarizing takes: "Unpopular opinion..."
- Call-outs: "If you're X, you need..."
- Relatable: "When you finally post and..."

### "I need credibility fast"

→ **Proof + Authority**

- Results: "This one change increased X by Y%"
- Experience: "After X years, here's what works..."
- Case studies: "Client went from X to Y"
- Data: "I analyzed 100 and found..."

### "I need sales/conversions"

→ **Myth-Busting + Urgency**

- "Biggest myth costing you..."
- "Fix this before you..."
- "The longer you wait..."
- Challenge: "Try for 7 days and watch..."

### "I need connection/community"

→ **Relatable + Permission**

- "You're not lazy, your process..."
- "POV: You have 100 ideas until..."
- "Creators will understand..."
- "Nobody talks about how..."

## 🔧 Hook Customization Template

**Formula:** [Hook Type] + [Your Topic] + [Specific Result/Emotion]

### Examples:

**Curiosity Hook:**

- Template: "I found something that doesn't add up about [TOPIC]"
- Customized: "I found something that doesn't add up about LinkedIn growth"

**Contrarian Hook:**

- Template: "Stop trying to [COMMON ACTION] if you want [RESULT]"
- Customized: "Stop trying to post daily if you want engagement"

**Transformation Hook:**

- Template: "A year ago I couldn't [RESULT]. Today everything is different."
- Customized: "A year ago I couldn't get 100 views. Today I average 50K."

**Authority Hook:**

- Template: "After [X] years in [INDUSTRY], here's what actually works"
- Customized: "After 8 years in copywriting, here's what actually works"

## 🎬 Platform-Specific Quick Tips

### TikTok/Reels/Shorts

**Best:** POV, Relatable, Trending, Challenge
**Time:** Hook in first 0.3 seconds
**Length:** 7-10 words max

### LinkedIn

**Best:** Authority, Contrarian Wisdom, Case Studies
**Time:** Hook in first line
**Length:** 1-2 sentences

### YouTube

**Best:** Curiosity, Authority, Transformation
**Time:** Hook in first 5 seconds
**Length:** 10-15 words

### Email

**Best:** Question, Personal Story, Direct Address
**Time:** Subject line + first sentence
**Length:** Subject: 4-6 words / First line: 10-15 words

## 🧠 Hook Power Combos

**The Attention Stack** (for views):

1. Open: Curiosity hook
2. Middle: Relatable observation
3. Close: Pattern interrupt

**The Trust Stack** (for authority):

1. Open: Transformation story
2. Middle: Proof/results
3. Close: Framework

**The Conversion Stack** (for sales):

1. Open: Myth-busting
2. Middle: Case study proof
3. Close: Urgency/challenge

**The Viral Stack** (for reach):

1. Open: POV relatable
2. Middle: Surprising insight
3. Close: Shareable question

## 🚨 Hook Warning Signs (What NOT to Do)

### ❌ Dead Hook Indicators:

- "In this video I'm going to..."
- "Today I want to talk about..."
- "Hey guys, welcome back..."
- Generic greetings with no tension
- Topic announcement without curiosity

### ✅ Fix With:

- Start mid-action
- Lead with conflict
- Open with results
- Begin with question
- Start with relatable struggle

## 📋 Quick Hook Checklist

Before posting, verify your hook has:

- [ ] **Stops Scroll** - Would YOU pause for this?
- [ ] **Creates Curiosity** - Gap between what they know and want to know?
- [ ] **Promises Value** - Clear "what's in it for me"?
- [ ] **Matches Audience Temperature** - Right complexity for their awareness?
- [ ] **Delivers on Promise** - Content actually fulfills the hook?

## 🔄 Hook Rotation Strategy

**Don't use same hook type twice in a row.**

**Weekly rotation:**

- Monday: Authority/Experience
- Wednesday: Relatable/Story
- Friday: Curiosity/Question
- Weekend: Transformation/Proof

**This ensures:**

- Variety keeps feed fresh
- Different hooks attract different segments
- You don't become predictable
- Broader emotional range
