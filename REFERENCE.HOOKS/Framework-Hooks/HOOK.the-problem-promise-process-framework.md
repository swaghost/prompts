# The Problem, Promise, Process Framework

## Hook Group

Framework Hooks

## Desired Viewer Perception

The viewer should see you as someone who understands fundamental storytelling and persuasion structure. You're positioned as a strategic communicator who can teach the architecture of compelling content.

## Desired Viewer Emotional/Intellectual/Psychological/Physical Elicitations or Response

- **Intellectual:** Three-part logic comprehension, narrative structure understanding
- **Emotional:** Confidence in framework simplicity, excitement about universal applicability
- **Psychological:** Storytelling mastery anticipation, strategic clarity, pattern recognition
- **Physical:** Mental framework encoding, structural thinking activation, content planning

## Psychology

This three-part structure mirrors how humans naturally process persuasive communication. Problem creates relevance and urgency, Promise creates desire and hope, Process creates believability and actionability. The alliteration makes it memorable. This framework leverages the psychological progression people need: recognizing a problem, believing a solution exists, and understanding how to achieve it. The simplicity (just three elements) makes it feel achievable while the completeness (covering beginning, middle, end) makes it feel comprehensive.

## Example

"Every piece of high-performing content follows Problem, Promise, Process: Problem (here's what's wrong), Promise (here's what's possible), Process (here's how to get there). This works because it matches how people make decisions: recognizing they need change, believing change is possible, learning how to implement it."

## Why it works

This hook works because it provides a universal content architecture that works across formats and topics. The three-part structure is simple enough to remember but complete enough to be useful. The alliterative naming (Problem, Promise, Process) creates memorability. By explaining the framework, you demonstrate mastery of persuasive communication principles. It addresses the core challenge creators face: organizing information in a way that captures attention, builds desire, and drives action. The framework's universality means it can be applied immediately to any content type. It also positions you as understanding fundamental principles rather than superficial tactics.

## Pitfalls - How it can fail

The hook fails if the framework is too similar to widely-known structures (like PAS: Problem, Agitate, Solution), seeming unoriginal. It can backfire if you don't provide concrete examples showing the framework in action, leaving it abstract. If viewers apply it mechanically without understanding why each element matters, the content feels formulaic. The simplicity can be misleading if people expect the framework alone to guarantee results without execution quality. It also fails if presented as the only way to structure content, dismissing other valid approaches.

## Unintended Consequences - How it can backfire

This can create predictable content where audiences recognize and tire of the pattern. It may lead to over-emphasis on problem-focus, creating problem-saturated content that feels negative. The framework can become a template that prevents creative structural experimentation. If everyone in a space uses the same framework, content becomes homogeneous rather than differentiated. The simplicity might also cause people to undervalue the nuance and skill required to execute each element well, leading to surface-level implementation.
