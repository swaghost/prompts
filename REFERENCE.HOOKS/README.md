# Viral Hooks Reference Library

A comprehensive collection of 1,050+ viral content hooks organized by psychological trigger and strategic purpose. Each hook includes detailed psychological analysis, examples, implementation guidance, and potential pitfalls.

## About This Library

This reference library is based on Kelly Gallo's collection of 1000+ Viral Hooks, expanded with in-depth psychological analysis and strategic implementation guidance. Each hook file follows a standardized template that explores:

- **Hook Group**: Category and psychological trigger
- **Desired Viewer Perception**: How you want to be positioned
- **Emotional/Intellectual/Psychological/Physical Elicitations**: Multi-dimensional response mapping
- **Psychology**: Deep analysis of why the hook works
- **Example**: Concrete implementation with real scenarios
- **Why It Works**: Strategic explanation of effectiveness
- **Pitfalls**: Common failure modes to avoid
- **Unintended Consequences**: How the hook can backfire
- **File Under**: Tags for cross-referencing

## How To Use This Library

1. **Browse by Category**: Click into any category below to see available hooks
2. **Study the Psychology**: Each hook explains why it works at a psychological level
3. **Adapt to Your Context**: Use the examples and frameworks to customize hooks for your specific audience
4. **Avoid Pitfalls**: Learn from the documented failure modes before implementing
5. **Cross-Reference Tags**: Use the "File Under" tags to find related hooks across categories

## Hook Variations

Each base hook in hook.eval.md includes 5 strategic variations:

1. **Base Hook** - The core formula
2. **"Save this before you forget it"** - Urgency + value preservation
3. **"and the last point matters most"** - Suspense + priority signaling
4. **"Before you scroll:"** - Pattern interruption + immediate relevance
5. **"Start with this"** - Beginner-friendly + foundational positioning

## Contributing New Hooks

To add new hooks to this library:

1. Use the [\_TEMPLATE.HOOK.md](_TEMPLATE.HOOK.md) as your starting point
2. Follow the naming convention: `HOOK.hook-name-in-kebab-case.md`
3. Provide 500-800 words of psychological analysis
4. Include concrete examples and implementation guidance
5. Document potential pitfalls and backfire scenarios
6. Add appropriate tags in the "File Under" section
7. Update the relevant category README.md with your new hook
8. Update this master index if creating a new category
