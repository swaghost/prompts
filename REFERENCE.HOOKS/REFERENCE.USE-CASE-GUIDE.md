# Hook Selection Guide by Use Case & Situation

This guide helps you choose the right hook based on your specific content goal, audience temperature, and desired outcome.

---

## 📍 By Audience Temperature

### ❄️ Cold Audience (Don't Know You Yet)

**Goal:** Stop scroll, build credibility quickly, create curiosity

**Best Hook Types:**

- **Curiosity Hooks** - Create information gaps that demand resolution
  - [I Found Something That Doesn't Add Up](Curiosity-and-Intrigue-Hooks/HOOK.i-found-something-that-doesn-t-add-up.md)
  - [Why Is No One Talking About This](Trending-Topics-and-Current-Events-Hooks/HOOK.why-is-no-one-talking-about-this.md)

- **Relatable Hooks** - Build immediate "they get me" connection
  - [POV: You Have 100 Content Ideas Until It's Time To Film](Relatable-Hooks/HOOK.pov-you-have-100-content-ideas-until-its-time-to-film.md)
  - [You're Not Lazy Your Content Process Is Too Complicated](Relatable-Hooks/HOOK.youre-not-lazy-your-content-process-is-too-complicated.md)

- **Contrarian Hooks** - Pattern interrupt through unexpected perspective
  - [Unpopular Opinion: Common Belief Is Keeping You Stuck](Contrarian-Hooks/)
  - [Stop Trying To Common Action If You Want Result](Contrarian-Hooks/)

**Avoid:** Hard sells, inside jokes, assumed knowledge, long-form authority building

---

### 🌡️ Warm Audience (Know You, Haven't Bought)

**Goal:** Deepen trust, demonstrate expertise, show results

**Best Hook Types:**

- **Authority Hooks** - Establish credibility through experience
  - [After Years In Industry Here's What Actually Works](Authority-and-Expertise-Hooks/HOOK.after-years-in-industry-heres-what-actually-works.md)
  - [I've Analyzed Hundreds Of Content Type](Authority-and-Expertise-Hooks/)

- **Proof Hooks** - Show evidence of effectiveness
  - [This One Change Increased Metric By Percentage](Case-Studies-and-Proof-Hooks/HOOK.this-one-change-increased-metric-by-percentage.md)
  - [Every Single Client Who Did This Hit Their First 1k](Case-Studies-and-Proof-Hooks/)

- **Transformation Hooks** - Demonstrate possibility
  - [A Year Ago I Could Not Result Today Everything Is Different](Transformation-and-Success-Story-Hooks/HOOK.a-year-ago-i-could-not-result-today-everything-is-different.md)
  - [From Broke To Booked Out Here's How](Transformation-and-Success-Story-Hooks/)

**Avoid:** Basic 101 content, overly salesy language, repetitive formats

---

### 🔥 Hot Audience (Ready to Buy/Act)

**Goal:** Reduce friction, handle objections, create urgency

**Best Hook Types:**

- **Conversion Hooks** - Bridge education to action
  - [The Content Bridge Between Education And Sales](Conversion-Hooks/HOOK.the-content-bridge-between-education-and-sales.md)

- **Myth-Busting Hooks** - Remove objections
  - [The Biggest Myth About Topic Is Costing You Result](Objection-Busting-and-Myth-Breaking-Hooks/HOOK.the-biggest-myth-about-topic-is-costing-you-result.md)

- **Urgency Hooks** - Create action pressure
  - [Fix This Before You Post Again](Urgency-and-Storytelling-Hooks/HOOK.fix-this-before-you-post-again.md)
  - [The Longer You Wait The Harder It Gets](Fear-and-Urgency-Hooks/)

- **Challenge Hooks** - Create commitment
  - [Try This For Seven Days And Watch What Happens](Challenge-Hooks/HOOK.try-this-for-seven-days-and-watch-what-happens.md)

**Avoid:** Pure entertainment, unrelated stories, educational content without clear next steps

## 📊 Hook Selection Decision Tree

```
START: What's your primary goal?

├─ Build Awareness
│  ├─ Cold Audience? → Curiosity, Relatable, Contrarian
│  └─ Trending Topic? → Trend-jacking, Hot Take

├─ Build Authority
│  ├─ Have Results? → Proof, Case Studies
│  ├─ Have Experience? → Authority, Framework
│  └─ Have Story? → Transformation, Journey

├─ Drive Engagement
│  ├─ Want Comments? → Questions, POV, Controversial
│  └─ Want Shares? → Relatable, Surprising, Contrarian

├─ Generate Leads/Sales
│  ├─ Overcome Objections? → Myth-Busting
│  ├─ Create Urgency? → Loss Aversion, Scarcity
│  └─ Demonstrate Value? → Case Studies, Quick Wins

└─ Build Connection
   ├─ Show Vulnerability? → Personal Story, Struggle
   ├─ Grant Permission? → Reframing, Validation
   └─ Create Community? → Relatable, Shared Experience
```

## 🎬 Quick Hook Pairing Strategies

### The Authority Stack

1. Start with transformation story
2. Follow with results proof
3. Close with framework

### The Engagement Stack

1. Start with relatable observation
2. Follow with surprising insight
3. Close with direct question

### The Conversion Stack

1. Start with myth-busting
2. Follow with proof
3. Close with urgency/challenge
