# The Mobile Optimizer

## Description

Act as a mobile website optimization specialist. Fix mobile performance issues completely by redesigning the layout so it feels premium on mobile, optimizing button sizes so they're effortless to tap, and improving loading speed to prevent visitors from leaving.

## Role

Mobile website optimization specialist with expertise in mobile-first design, touch interface optimization, mobile performance engineering, and mobile conversion optimization.

## Expertise

- Mobile-first responsive design
- Touch interface and tap target optimization
- Mobile page speed and performance
- Mobile user experience (UX)
- Mobile conversion optimization
- Mobile layout and visual hierarchy
- Progressive enhancement
- Mobile testing and validation
- Cross-device compatibility

## Prompt

Act as a mobile website optimization specialist. My website looks bad on phones, and I'm losing customers because of it. Fix it completely: redesign the layout so it feels premium on mobile, optimize button sizes so they're effortless to tap, and improve loading speed to prevent visitors from leaving.

## Variables to Replace

When using this prompt, provide context about:

- **Current website URL** (if available) or description of current mobile issues
- **Primary mobile problems** (slow loading, poor layout, small buttons, etc.)
- **Target mobile audience** (if specific device or demographic)
- **Website type** (e-commerce, service, blog, portfolio, etc.)
- **Conversion goals** (purchases, signups, bookings, etc.)

## Expected Output

**Complete Mobile Optimization Plan:**

1. **Mobile Layout Redesign - Premium Feel**

   **Current Mobile Issues Diagnosis:**
   - Desktop layout forced onto mobile
   - Text too small or too large
   - Images not optimized for mobile
   - Horizontal scrolling problems
   - Navigation issues
   - Content hierarchy broken

   **Mobile-First Layout Solutions:**
   - Single-column layout for clarity
   - Simplified navigation (hamburger or bottom nav)
   - Thumb-zone optimization (important actions in reach)
   - Card-based layouts for easy scanning
   - Collapsible sections for long content
   - Mobile-optimized typography:
     - Minimum 16px body text
     - Larger headlines for impact
     - Sufficient line spacing (1.5-1.6)
     - Shorter line lengths (40-60 characters)
   - White space utilization
   - Mobile-specific hero sections
   - Sticky headers or footers for navigation
   - Swipe-friendly carousels or galleries

   **Premium Mobile Design Elements:**
   - High-quality, optimized images
   - Smooth animations and transitions
   - Professional color scheme
   - Consistent spacing system
   - Modern UI components
   - Glass morphism or depth effects (subtle)
   - Micro-interactions on tap
   - Loading states and skeleton screens

2. **Button & Tap Target Optimization - Effortless Interaction**

   **Touch Interface Standards:**
   - Minimum tap target: 44×44 pixels (Apple) or 48×48 pixels (Google)
   - Spacing between taps: minimum 8px
   - Primary buttons: larger and more prominent
   - Thumb-reachable positioning (bottom 2/3 of screen)

   **Button Optimization:**
   - CTAs sized 48px height minimum
   - Full-width buttons for mobile (edge to edge with padding)
   - High contrast for visibility
   - Clear tap feedback (visual response)
   - Disabled state clarity
   - Button text: large, clear, action-oriented
   - Sticky CTAs for key actions
   - Bottom-sheet CTAs for important conversions

   **Form Optimization:**
   - Large input fields (44px minimum)
   - Proper input types (email, tel, number)
   - Autocomplete and autofill enabled
   - Minimal fields (reduce friction)
   - Clear error messaging
   - Inline validation
   - Show/hide password toggle
   - Mobile keyboard optimization

   **Navigation Optimization:**
   - Large, tappable menu items
   - Bottom navigation bar for apps (3-5 items)
   - Hamburger menu with clear close button
   - Full-screen menus with large targets
   - Breadcrumbs simplified or removed

3. **Loading Speed Optimization - Prevent Abandonment**

   **Performance Audit:**
   - Current load time measurement
   - Identify bottlenecks:
     - Large images
     - Unoptimized code
     - Too many requests
     - Render-blocking resources
     - Third-party scripts

   **Speed Improvement Strategies:**

   **Image Optimization:**
   - Compress all images (70-85% quality)
   - Use modern formats (WebP, AVIF)
   - Implement lazy loading
   - Serve responsive images (srcset)
   - Use CDN for image delivery
   - Remove unnecessary images on mobile

   **Code Optimization:**
   - Minify CSS, JavaScript, HTML
   - Remove unused CSS and JavaScript
   - Defer non-critical JavaScript
   - Inline critical CSS
   - Reduce plugin bloat
   - Optimize database queries

   **Resource Loading:**
   - Implement browser caching
   - Use CDN for static assets
   - Reduce HTTP requests
   - Combine files where possible
   - Remove render-blocking resources
   - Preload critical resources

   **Mobile-Specific Optimization:**
   - Reduce mobile page weight (aim <1MB)
   - Mobile-first code splitting
   - Adaptive serving (lighter assets for mobile)
   - Remove unnecessary mobile features
   - Optimize for 3G and 4G networks

   **Loading Experience:**
   - Skeleton screens while loading
   - Progressive content loading
   - Instant feedback on interactions
   - Perceived performance improvements
   - Offline functionality (PWA features)

   **Target Metrics:**
   - Largest Contentful Paint (LCP): <2.5s
   - First Input Delay (FID): <100ms
   - Cumulative Layout Shift (CLS): <0.1
   - Total page load: <3 seconds
   - Time to Interactive: <3.5 seconds

4. **Mobile Conversion Optimization**

   **Friction Reduction:**
   - One-click purchasing options
   - Guest checkout enabled
   - Autofill and payment autofill
   - Minimal form fields
   - Clear progress indicators
   - Save for later options

   **Trust Signals:**
   - Security badges visible
   - Testimonials formatted for mobile
   - Trust indicators near CTAs
   - Clear return/refund policies

   **Mobile-Specific Features:**
   - Click-to-call buttons
   - Google Maps integration
   - SMS verification
   - Mobile wallet integration
   - Social login options
   - QR code functionality

5. **Testing & Validation**

   **Testing Checklist:**
   - Test on actual devices (iPhone, Android)
   - Test on multiple screen sizes
   - Test in portrait and landscape
   - Test with slow connections (throttling)
   - Test forms and checkout flows
   - Test navigation and menus
   - Verify tap targets are comfortable
   - Check text readability
   - Validate loading performance

   **Tools to Use:**
   - Google Mobile-Friendly Test
   - PageSpeed Insights
   - Lighthouse mobile audit
   - Real device testing
   - BrowserStack or similar
   - Google Analytics mobile reports

## Mobile Optimization Principles

**Mobile-First Philosophy:**

- Design for mobile first, desktop second
- Simplify, don't just shrink
- Touch-friendly by default
- Performance is a feature
- Content hierarchy is critical
- Progressive enhancement

**Mobile User Behavior:**

- Shorter attention spans
- Quick decision-making
- One-handed usage common
- Expecting instant results
- Less tolerance for friction
- Easily distracted

**Mobile Performance Impact:**

- 53% abandon if load >3 seconds
- 1-second delay = 7% conversion loss
- Mobile users expect faster load than desktop
- Speed is a competitive advantage
