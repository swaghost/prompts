# Professional Character Reference Sheet Template

## Purpose

Create a compact professional character reference sheet that maintains identity consistency across multiple views, expressions, poses, and detail crops.

## Format Specifications

**Dimensions:** Exactly 1920x1080 px (Landscape 16:9)  
**Grid Layout:** 2 columns × 2 rows (2×2 grid)  
**Background:** Warm off-white studio background  
**Dividers:** Narrow gaps and thin light-grey dividers  
**Text:** None (no text, titles, names, labels, captions, numbers, symbols, or logos)

## Grid Structure

### Top Left: Turnaround Views

**Five small full-body turnaround views in one row:**

- Front
- 3/4 front
- Side
- 3/4 back
- Back

**Requirements:**

- Neutral stance, arms relaxed
- Complete figure visible from head to shoes
- Identical scale and camera height
- Clean presentation

### Top Right: Head and Shoulders Grid

**Six head-and-shoulders portraits in a 2×3 grid:**

**Expressions/Views (6 portraits):**

- Neutral subtle closed-mouth smile with slightly visible teeth (surprised, thoughtful, mildly annoyed)
- Add one larger frontal close-up below them with neutral expression and direct gaze

**Requirements:**

- Natural smile with slightly visible teeth
- Surprised expression
- Thoughtful and mildly annoyed expressions
- Clean editorial layout
- Ultra-high detail

### Bottom Left: Full-Body Poses

**Three full-body poses:**

1. Front-facing with hands in pockets
2. Confident 3/4 stance with arms crossed
3. Walking toward the camera

**Requirements:**

- Complete figure visible from head to shoes
- Dynamic but professional

### Bottom Right: Circular Detail Crops

**Four circular detail crops:**

1. Eye and makeup
2. Hair and hairline
3. Garment fabric and neckline
4. Lower hem with legs and shoes

**Requirements:**

- Circular crop format
- Extreme close-up detail
- Sharp focus

## Core Principles

### Identity Consistency

- Use the uploaded image as the **only identity and outfit reference**
- Preserve the **exact same face**, natural asymmetry, skin tone, eyes, facial features, hairstyle, makeup, body proportions, outfit, accessories, and shoes in every image
- Generate all views, expressions, and poses automatically without requesting additional references

### Photography Style

- Realistic professional studio fashion photography
- Soft diffused light
- Natural skin texture and pores
- Realistic hair and fabric
- Neutral true-to-life colors
- Deep depth of field
- Every fragment sharp
- Clean editorial layout
- Ultra-high detail

## Critical Avoidances

**DO NOT:**

- Request additional references
- Include any text
- Create full-width horizontal strips
- Make oversized figures
- Leave empty central space
- Create overlapping fragments
- Change identity, face, outfit, hairstyle, or proportions
- Create duplicate views or expressions
- Crop body or feet (in full-body views)
- Add extra limbs
- Create malformed hands or feet
- Apply beauty-filter skin or plastic skin
- Use illustration, anime, CGI, 3D rendering, doll, or figurine styles
- Add blurry details

## Usage Note

This sheet provides comprehensive character reference for maintaining identity consistency across animation, video, or illustration projects.

## Example Use Case

Input: Single character photo  
Output: Comprehensive reference sheet with turnarounds, expressions, poses, and detail crops
