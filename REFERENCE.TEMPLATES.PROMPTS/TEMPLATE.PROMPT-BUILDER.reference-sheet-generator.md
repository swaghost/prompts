Use this template to create consistency reference sheets for products or characters. These sheets maintain identity across multiple views for video/animation pipelines.

## FORMAT 1: Product Consistency Sheet

### Purpose

Create a video-ready product consistency sheet maintaining exact product identity across all views.

### Format Specifications

**Dimensions:** Exactly [1920x1080 px] or [custom resolution]
**Aspect Ratio:** Landscape 16:9 [or custom]
**Grid Layout:** [4 columns × 3 rows] = [12 panels total]
**Background:** [Seamless neutral light-grey studio / Custom color]
**Gaps:** [Narrow equal gaps / Custom spacing]
**Text/Labels:** None (unless specified)

### Reference Image Protocol

**CRITICAL:**
Use the uploaded product photo as the **only reference**. Reproduce the **exact same physical product** in every panel:

- Identical: shape, proportions, dimensions, color, materials, finish
- Identical: logo, label, typography, hardware, distinctive details
- **Do not** redesign the product or create alternative versions

### Grid Structure (Customize as Needed)

#### Row 1: Primary Views

1. [Front view]
2. [3/4 front view]
3. [Side view]
4. [Back view]

#### Row 2: Additional Views

5. [Opposite side view]
6. [Top view]
7. [Underside or base view]
8. [Centered 3/4 hero view]

#### Row 3: Detail Views

9. [Close-up of: logo/label/specific feature]
10. [Macro view of: material/surface texture]
11. [Close-up of: functional element/construction]
12. [Close-up of: most distinctive visual detail]

### Photography Style

**Quality Level:** Photorealistic professional studio product photography

**Lighting:**

- [Neutral soft diffused / Dramatic / Custom]
- Identical across all panels
- [Natural contact shadows / No shadows / Custom]

**Technical Requirements:**

- Physically accurate materials
- Controlled reflections
- True-to-life colors
- [Deep depth of field / Shallow in detail crops]
- Sharp edges and clear surface details

**Product Presentation:**

- Complete product visible in panels [1-8] (nothing cropped)
- Consistent scale across all panels
- Same orientation logic and geometry
- Conservative extrapolation for hidden sides (no new branding/controls/decorative elements)

### Critical Avoidances - Product Integrity

**DO NOT:**

- Create color variations or alternative designs
- Invent packaging or new branding elements
- Add lifestyle scenes, models, hands, props
- Use different backgrounds or dramatic lighting changes
- Change shape, proportions, or alter logo
- Show inconsistent materials
- Create duplicate views
- Crop product in panels 1-8
- Make product float or add blurry details
- Use plastic-looking surfaces or CGI appearance
- Add garbled text where none exists
