# Product Consistency Sheet Template

## Purpose

Create a video-ready product consistency sheet that maintains exact product identity across all views for video generation workflows.

## Format Specifications

**Dimensions:** Exactly 1920x1080 px (Landscape 16:9)  
**Grid Layout:** 4 columns × 3 rows (12 panels total)  
**Background:** Seamless neutral light-grey studio background  
**Gaps:** Narrow equal gaps between panels  
**Text:** None (no titles, captions, labels, numbers, arrows, borders, or additional text)

## Grid Structure

### Row 1: Primary Views

1. Front view
2. 3/4 front view
3. Side view
4. Back view

### Row 2: Additional Views

5. Opposite side view
6. Top view
7. Underside or base view
8. Centered 3/4 hero view

### Row 3: Detail Views

9. Close-up of the original logo or label
10. Macro view of the main material and surface texture
11. Close-up of the main functional or construction element
12. Close-up of the product's most distinctive visual detail

## Core Principles

### Identity Consistency

- Use the uploaded product photo as the **only reference**
- Reproduce the **exact same physical product** in every panel
- Identical: shape, proportions, dimensions, color, materials, finish, logo, label, typography, hardware, distinctive details
- **Do not** redesign the product or create alternative versions

### Product Integrity

- Show the complete product in panels 1-8 with nothing cropped
- Keep the same orientation logic, geometry, and real construction across all views
- Preserve the original logo and label exactly
- If a hidden side is not visible in the reference, extrapolate it conservatively without adding new branding, controls, openings, or decorative elements

### Photography Style

- Photorealistic professional studio product photography
- Neutral soft diffused lighting
- Physically accurate materials
- Controlled reflections
- Natural contact shadows
- True-to-life colors
- Deep depth of field
- Sharp edges and clear surface details

### Consistent Scale

- Identical lighting across all panels
- Consistent product scale throughout
- Maintain uniform photographic style

## Critical Avoidances

**DO NOT:**

- Create color variations
- Create alternative designs
- Invent new packaging
- Add lifestyle scenes, models, hands, or props
- Use different backgrounds
- Apply dramatic lighting changes
- Change shape or proportions
- Alter the logo
- Invent text where none exists
- Show inconsistent materials
- Create duplicate views
- Crop the product (panels 1-8)
- Make product appear to float
- Add blurry details, illustration, CGI appearance
- Use plastic-looking surfaces
- Add garbled text

## Usage Note

This sheet will be used as a **product identity reference for video generation**. Prioritize exact product consistency over creative styling.

## Example Use Case

Input: Single product photo  
Output: 12-view consistency sheet maintaining exact product identity across all angles and details
